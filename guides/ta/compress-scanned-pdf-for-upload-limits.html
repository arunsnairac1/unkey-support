ஸ்கேன் PDF-இல் ஒவ்வொரு பக்கமும் ஒரு புகைப்படம் என்பதால் பெரிதாகிறது; Mac-இல் Preview-இன் Reduce File Size, iPhone-இல் Preview-இன் export விருப்பங்களைப் பயன்படுத்துங்கள், குறைவான எளிய பக்கங்களை ஸ்கேன் செய்யுங்கள், பதிவேற்றும் முன் கடவுச்சொல்லை நீக்குங்கள்.

விசா, பாஸ்போர்ட், தேர்வு, கடன் போர்ட்டல்கள் பெரும்பாலும் ஒரு கோப்புக்கு சில நூறு கிலோபைட் அல்லது இரண்டு மெகாபைட் என்று பதிவேற்ற வரம்பு வைத்திருக்கும். ஸ்கேன் செய்த PDF-இல் ஒவ்வொரு பக்கமும் புகைப்படமாகச் சேமிக்கப்படுவதால் அந்த வரம்பைத் தாண்டிவிடும். விரைவான தீர்வுகள்: படச் சுருக்கத்துடன் PDF-ஐ மீண்டும் சேமிப்பது (Mac அல்லது iPhone-இல் உள்ள Preview இதை இலவசமாகச் செய்யும்), தேவையான பக்கங்களை மட்டும் ஸ்கேன் செய்வது, முதலில் கடவுச்சொல்லை நீக்குவது. பல போர்ட்டல்களால் பாதுகாக்கப்பட்ட கோப்புகளைப் படிக்க முடியாது.

சுருக்குவதற்கு முன்

  • சரியான வரம்பையும் வடிவத்தையும் பாருங்கள். போர்ட்டல் பக்கத்தில் அதிகபட்ச அளவு, அது ஒரு கோப்புக்கா மொத்தத்துக்கா, PDF வேண்டுமா JPEG வேண்டுமா என்று பாருங்கள். விதிகள் போர்ட்டலுக்குப் போர்ட்டல் மாறும், காலப்போக்கிலும் மாறும்; எனவே பதிவேற்றப் பக்கத்தில் உள்ளதையே பின்பற்றுங்கள்.
  • கடவுச்சொல்லை நீக்குங்கள். பாதுகாக்கப்பட்ட PDF-ஐத் திறந்து சரிபார்க்க போர்ட்டலால் முடியாது. பார்க்க: iPhone, Mac, Windows, Android.
  • அசல் கோப்பை வைத்திருங்கள். சுருக்கினால் படத் தரம் குறையும். போர்ட்டல் மங்கலான ஸ்கேனை நிராகரித்தால் பயன்படுத்த, முழுத் தரமுள்ள நகலை வைத்திருங்கள்.

Mac-இல்: Preview

  1. Preview-இல் PDF-ஐத் திறந்து File > Export தேர்ந்தெடுங்கள்.
  2. Quartz Filter மெனுவில் Reduce File Size தேர்ந்தெடுங்கள்.
  3. புதிய பெயர் கொடுத்து Save அழுத்துங்கள்.

சுருக்கப்பட்ட PDF “அசலை விடத் தரம் குறைவாக இருக்கலாம்” என்று Apple குறிப்பிடுகிறது. அதே Export சாளரத்தில் Optimize images for screen, Save images as JPEG ஆகிய விருப்பங்களும் உள்ளன (Apple: Reduce the size of a PDF in Preview on Mac). எழுத்து அதிகமுள்ள ஸ்கேன்களில் Reduce File Size படிக்க முடியாத அளவுக்குப் பாதிக்கலாம்; எனவே பதிவேற்றும் முன் முடிவைத் திறந்து பெரிதாக்கிப் பாருங்கள்.

iPhone அல்லது iPad-இல்: Preview (iOS 26 மற்றும் அதற்குப் பின்)

  1. Preview செயலியில் PDF-ஐத் திறங்கள்.
  2. கோப்புப் பெயருக்கு அருகிலுள்ள மெனுவைத் தொட்டு Export தேர்ந்தெடுங்கள்.
  3. PDF தேர்ந்தெடுத்து, Optimize Images for Screen, Save Images as JPEG இரண்டையும் இயக்குங்கள்.
  4. உறுதிப்படுத்தும் பொத்தானைத் தொட்டு, இடத்தைத் தேர்ந்தெடுத்து, பெயரை மாற்றி Save தொடுங்கள்.

Optimize Images for Screen “சிறிய கோப்பை உருவாக்கும்” என்று Apple கூறுகிறது (Apple: Export or compress PDFs in Preview on iPhone). போர்ட்டலுக்கு JPEG தேவைப்பட்டால், அதே திரையில் அளவு ஸ்லைடருடன் JPEG-ஆக ஏற்றுமதி செய்யலாம்.

தொடக்கத்திலேயே சிறிதாக ஸ்கேன் செய்யுங்கள்

  • கேட்கப்பட்ட பக்கங்கள் மட்டும். பதிவேற்றும் முன் தேவையற்ற பக்கங்களை நீக்குங்கள். iPhone-இல் Preview பக்கங்களை நீக்கவும் வரிசை மாற்றவும் உதவும் (Apple).
  • கேமராவை அல்ல, ஆவண ஸ்கேனரைப் பயன்படுத்துங்கள். Notes, Files, Preview ஆகியவை பக்கத்தை வெட்டிச் சமப்படுத்தும் (Apple: How to scan documents on iPhone). மேசையோடு எடுத்த புகைப்படத்தை விட வெட்டப்பட்ட ஸ்கேன் சிறியது.
  • கிரேஸ்கேல் அல்லது கருப்பு-வெள்ளை: எழுத்து ஆவணங்களுக்கு, போர்ட்டல் அனுமதித்தால். Preview ஸ்கேனரில் ஒவ்வொரு ஸ்கேனின் நிறத்தையும் மாற்றலாம் (Apple). புகைப்படங்களுக்கும், அதிகாரி பார்க்க வேண்டிய முத்திரைகளுக்கும் நிறத்தை வைத்திருங்கள்.
  • ஒரு ஆவணத்துக்கு ஒரு கோப்பு. போர்ட்டலில் தனித்தனி இடங்கள் இருந்தால், எல்லாவற்றையும் ஒரே பெரிய PDF-ஆக இணைக்காதீர்கள்.

பொதுவான சிக்கல்கள்

  • இன்னும் பெரிதாக உள்ளது: இரண்டு விருப்பங்களையும் இயக்கி மீண்டும் ஏற்றுமதி செய்யுங்கள், அல்லது கிரேஸ்கேலில் மீண்டும் ஸ்கேன் செய்யுங்கள்.
  • எழுத்து மங்கலாக உள்ளது: அதிகமாகச் சுருக்கிவிட்டீர்கள். அசலுக்குத் திரும்பி ஒரே ஒரு விருப்பத்தை மட்டும் பயன்படுத்துங்கள்.
  • போர்ட்டல் “கோப்பு சிதைந்துள்ளது” அல்லது “encrypted” என்கிறது: கோப்பு இன்னும் கடவுச்சொல்லால் பாதுகாக்கப்பட்டிருக்கலாம் அல்லது கட்டுப்பாடுகள் இருக்கலாம். கடவுச்சொல்லை நீக்கி மீண்டும் முயலுங்கள்.
  • கோப்பு பெரிதாகிவிட்டது: பெரும்பாலும் உண்மையான எழுத்துகள் கொண்ட PDF ஏற்கெனவே சிறியது. மீண்டும் சேமித்தால் அளவு கூடலாம். அசல் கோப்பையே பதிவேற்றுங்கள்.

UnKey மூலம்

iPhone, iPad, Mac-இல் உள்ள UnKey Pro-வில் ஸ்கேன்களுக்கான Compress கருவி உள்ளது. புகைப்படம் போன்ற பக்கங்களை மீண்டும் குறியாக்கி, உண்மையான எழுத்துள்ள பக்கங்களைத் தொடாமல் விடுவதால் எழுத்து தெளிவாக இருக்கும்; நீங்கள் கொடுத்த கோப்பை விடப் பெரிய கோப்பை அது ஒருபோதும் தராது. இது ஆஃப்லைனில் இயங்குவதால் உங்கள் பாஸ்போர்ட் அல்லது வங்கி ஸ்கேன் சுருக்கும் இணையதளத்துக்குப் பதிவேற்றப்படாது. கடவுச்சொல் நீக்கம் இலவசம்; Compress ஒருமுறை செலுத்தும் Pro வாங்குதலின் பகுதி.

கேள்விகள்

சுருக்கினால் என் ஆவணங்கள் படிக்க முடியாமல் போகுமா?

அளவுக்கு மீறிச் சுருக்கினால் போகலாம். சுருக்கிய நகலைத் திறந்து சிறிய எழுத்துகளைப் பெரிதாக்கிப் பாருங்கள்; அசலையும் வைத்திருங்கள்.

2 பக்க ஸ்கேன் ஏன் 8 MB ஆக உள்ளது?

ஸ்கேன் செய்த ஒவ்வொரு பக்கமும் உயர் தெளிவுத்திறன் புகைப்படம். வங்கியின் எழுத்து PDF-கள் படங்களை அல்ல, எழுத்துகளைச் சேமிப்பதால் மிகச் சிறியவை.

கடவுச்சொல் உள்ள PDF-களை போர்ட்டல்கள் ஏற்குமா?

பலவற்றால் அவற்றைப் படிக்க முடியாது. போர்ட்டல் வேறுவிதமாகச் சொன்னால் தவிர, பதிவேற்றும் முன் கடவுச்சொல்லை நீக்குங்கள்.

பாஸ்போர்ட், வங்கி அறிக்கைகளுக்கு ஆன்லைன் சுருக்கிகள் பாதுகாப்பானவையா?

அவை உங்கள் கோப்பை ஒரு சர்வருக்குப் பதிவேற்றுகின்றன. அடையாள, நிதி ஆவணங்களை உங்கள் சொந்தச் சாதனத்திலேயே சுருக்குவது பாதுகாப்பானது.

வடிவங்கள் மாறலாம். கடவுச்சொல் வேலை செய்யவில்லை என்றால், ஆவணத்துடன் வந்த மின்னஞ்சலைப் பாருங்கள் அல்லது வழங்கிய நிறுவனத்தைத் தொடர்பு கொள்ளுங்கள். இங்கே குறிப்பிடப்பட்டுள்ள எந்த வங்கி, நிறுவனம் அல்லது அதிகார அமைப்புடனும் UnKey-க்கு தொடர்பு இல்லை.

ஆங்கிலத்திலிருந்து மொழிபெயர்க்கப்பட்டது. ஏதேனும் வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அடிப்படை.

ஒருமுறை திறந்தால் போதும்.

நீங்கள் ஏற்கெனவே திறக்கக்கூடிய PDF-களிலிருந்து UnKey கடவுச்சொல்லை நீக்குகிறது, iPhone, iPad மற்றும் Mac-இல். ஆஃப்லைனில் இயங்கும், எதுவும் பதிவேற்றப்படாது. கடவுச்சொல்லை ஒருமுறை சேமித்தால், அடுத்த மாத ஸ்டேட்மென்ட்டை Face ID திறக்கும்.
