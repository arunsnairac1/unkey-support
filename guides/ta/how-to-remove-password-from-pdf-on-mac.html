Mac-இல் PDF கடவுச்சொல்லை நீக்குவது எப்படி (2026)

அக்டோபர் 2026 அன்று புதுப்பிக்கப்பட்டது

இந்த மொழியில் படிக்க: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · Português · தமிழ் · తెలుగు

கடவுச்சொல்லுடன் PDF-ஐ Preview-இல் திறந்து, File > Export தேர்ந்தெடுத்து, திறப்பதற்கான கடவுச்சொல் அமைக்கப்படவில்லை என்பதை உறுதி செய்து, புதிய நகலைச் சேமியுங்கள்.

Mac-இல் macOS உடன் வரும் Preview செயலி மூலம் PDF கடவுச்சொல்லை இலவசமாக நீக்கலாம். PDF-ஐத் திறந்து கடவுச்சொல்லை உள்ளிட்டு, File > Export தேர்ந்தெடுத்து, திறப்பதற்கான கடவுச்சொல் இல்லாத புதிய நகலைச் சேமியுங்கள். கடவுச்சொல் உங்களுக்குத் தெரிந்திருக்க வேண்டும்; அது இல்லாமல் Preview கோப்பைத் திறக்காது.

முறை 1: Preview, File > Export

  1. PDF-ஐ இருமுறை கிளிக் செய்து Preview-இல் திறந்து கடவுச்சொல்லை உள்ளிடுங்கள்.
  2. File > Export தேர்ந்தெடுத்து, நகலுக்கு “Statement-Oct-unlocked” போன்ற புதிய பெயர் கொடுங்கள்.
  3. Permissions கிளிக் செய்து, Require Password To Open Document தேர்ந்தெடுக்கப்படவில்லை என்பதை உறுதி செய்யுங்கள். பழைய macOS பதிப்புகளில் Export சாளரத்தில் அதற்குப் பதிலாக Encrypt தேர்வுப்பெட்டி இருக்கும்; அதைத் தேர்ந்தெடுக்காமல் விடுங்கள்.
  4. Save கிளிக் செய்யுங்கள்.
  5. புதிய கோப்பை மூடி மீண்டும் திறங்கள். கடவுச்சொல் கேட்காமல் திறக்க வேண்டும்.

Apple-இன் தற்போதைய வழிகாட்டி Export சாளரம், Permissions பொத்தான், Require Password To Open Document விருப்பம் ஆகியவற்றை விவரிக்கிறது (Apple: Password-protect a PDF in Preview on Mac). அதே பக்கத்தின் macOS Big Sur பதிப்பு நேரடியாகவே இப்படிச் சொன்னது: “நீங்கள் குறியாக்கிய PDF-இலிருந்து கடவுச்சொல்லை நீக்க, PDF-ஐத் திறந்து மீண்டும் export செய்யுங்கள்; இம்முறை குறியாக்க விருப்பத்தை அணைத்துவிடுங்கள்” (Apple, macOS Big Sur guide).

அந்த PDF-இல் உரிமையாளர் (அனுமதி) கடவுச்சொல்லும் இருந்து அது உங்களுக்குத் தெரியும் என்றால், File > Edit Permissions மூலம் திறக்கும் கடவுச்சொல்லையும், எந்த வசதிகளுக்குக் கடவுச்சொல் தேவை என்பதையும் மாற்றலாம்.

முறை 2: Print > Save as PDF

அச்சிடக்கூடிய எந்த Mac செயலியும் புதிய PDF-ஐ உருவாக்கலாம் (Apple: Save a document as a PDF on Mac):

  1. கடவுச்சொல்லுடன் PDF-ஐத் திறங்கள்.
  2. File > Print தேர்ந்தெடுங்கள்.
  3. PDF பாப்-அப் மெனுவைக் கிளிக் செய்து Save as PDF தேர்ந்தெடுங்கள்.
  4. Security Options-ஐக் கிளிக் செய்யாதீர்கள்; ஏனெனில் அங்குதான் கடவுச்சொல்லை மீண்டும் சேர்ப்பீர்கள்.

அச்சிட்ட நகலில் இணைப்புகள், படிவப் புலங்கள், புத்தகக்குறிகள் இல்லாமல் போகலாம். ஆவணம் அச்சிடுவதைத் தடுத்தால் இந்த முறை சாம்பல் நிறத்தில் இருக்கலாம்.

முறை 3: Mac-க்கான UnKey

UnKey Mac-இலும் இலவசம். ஒருமுறை செலுத்தும் UnKey Pro, iPhone, iPad, Mac-இல் தொகுப்பாகப் பூட்டு நீக்குவதையும் பிற Pro கருவிகளையும் சேர்க்கிறது. PDF-ஐ சாளரத்தில் இழுத்துப்போட்டு, கடவுச்சொல்லை உள்ளிட்டால், பூட்டு நீக்கிய நகலைச் சேமிக்கும். UnKey Pro ஒரே நேரத்தில் பல கோப்புகளையும் தொகுப்பாகப் பூட்டு நீக்கும்; ஒரே கடவுச்சொல் உள்ள ஓர் ஆண்டின் மாதாந்திர அறிக்கைகளுக்கு இது பயனுள்ளது. UnKey ஆஃப்லைனில் இயங்கும், எதையும் பதிவேற்றாது, உங்களுக்கு ஏற்கெனவே தெரிந்த கடவுச்சொற்களை மட்டுமே நீக்கும்.

முறை 4: Command line (தொழில்நுட்பம் அறிந்தவர்களுக்கு)

இலவச, திறந்த மூல கருவியான qpdf இதை Terminal-இல் செய்யும்: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. உள்ளீட்டுக் கோப்பு குறியாக்கப்பட்டிருந்தாலும் --decrypt “குறியாக்கம் இல்லாத வெளியீட்டுக் கோப்பை உருவாக்கும்” என்று அதன் ஆவணம் விவரிக்கிறது (qpdf documentation). இதை நீங்களே நிறுவ வேண்டும், எ.கா. Homebrew மூலம். Command line-இல் கடவுச்சொல்லைத் தட்டச்சு செய்தால் அது உங்கள் shell history-யில் தங்கிவிடலாம்.

இன்னும் கடவுச்சொல் கேட்டால்

  • நகலுக்குப் பதிலாக அசலைத் திறந்திருக்கலாம். கோப்புப் பெயரைச் சரிபாருங்கள்.
  • மீண்டும் export செய்து, Permissions-இல் Require Password To Open Document அணைக்கப்பட்டுள்ளதா என்று பாருங்கள்.
  • அதற்குப் பதிலாக Print > Save as PDF முயலுங்கள்.
  • Preview கடவுச்சொல்லை நிராகரித்தால், பெரிய எழுத்துகளையும் தேதி வடிவத்தையும் சரிபார்த்து, ஆவணத்துடன் வந்த மின்னஞ்சலைப் படியுங்கள்.

அசலை நீக்கும் முன்

பூட்டு நீக்கிய PDF-ஐ அந்தக் கோப்பை வைத்திருக்கும் எவரும் திறக்கலாம். குடும்பத்துடன் பகிர்ந்த iCloud Drive கோப்புறைகளும், உங்கள் Mac-ஐ இரவல் வாங்கும் எவரும் இதில் அடங்குவர். பூட்டு நீக்கிய அறிக்கைகளைத் தனிப்பட்ட இடத்தில் வையுங்கள். மேலும் அறிய, PDF கடவுச்சொல்லை நீக்குவது பாதுகாப்பானதா என்பதைப் பாருங்கள்.

கேள்விகள்

Preview உண்மையிலேயே இலவசமா?

ஆம். Preview ஒவ்வொரு Mac-உடனும் வருகிறது; கடவுச்சொல்லை உள்ளிட்ட பின் திறப்பதற்கான கடவுச்சொல் இல்லாத PDF-ஆக export செய்ய முடியும்.

எனக்குத் தெரியாத கடவுச்சொல்லை Preview நீக்குமா?

நீக்காது. கோப்பைத் திறக்கும் முன் Preview கடவுச்சொல்லைக் கேட்கும்; அதைத் தாண்ட முறையான வழி இல்லை.

Mac-இல் பல PDF-களை ஒரே நேரத்தில் பூட்டு நீக்குவது எப்படி?

Preview ஒரு நேரத்தில் ஒரு கோப்பைத்தான் கையாளும். ஒரே கடவுச்சொல் உள்ள பல PDF-களை UnKey Pro தொகுப்பாகப் பூட்டு நீக்கும்; தொழில்நுட்பம் அறிந்தவர்கள் qpdf-ஐ ஸ்கிரிப்ட் செய்யலாம். பல PDF-களை ஒரே நேரத்தில் பூட்டு நீக்குவது பற்றிய எங்கள் வழிகாட்டியைப் பாருங்கள்.

Print > Save as PDF ஏன் சாம்பல் நிறத்தில் உள்ளது?

அந்த PDF-இல் அச்சிடுவதைத் தடுக்கும் அனுமதிக் கடவுச்சொல் இருக்கலாம். உரிமையாளர் கடவுச்சொல் தெரிந்தால் File > Edit Permissions-இல் உள்ளிடுங்கள்; இல்லையெனில் Export முறையைப் பயன்படுத்துங்கள்.

வடிவங்கள் மாறலாம். கடவுச்சொல் வேலை செய்யவில்லை என்றால், ஆவணத்துடன் வந்த மின்னஞ்சலைப் பாருங்கள் அல்லது வழங்கிய நிறுவனத்தைத் தொடர்பு கொள்ளுங்கள். இங்கே குறிப்பிடப்பட்டுள்ள எந்த வங்கி, நிறுவனம் அல்லது அதிகார அமைப்புடனும் UnKey-க்கு தொடர்பு இல்லை.

ஆங்கிலத்திலிருந்து மொழிபெயர்க்கப்பட்டது. ஏதேனும் வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அடிப்படை.

ஒருமுறை திறந்தால் போதும்.

நீங்கள் ஏற்கெனவே திறக்கக்கூடிய PDF-களிலிருந்து UnKey கடவுச்சொல்லை நீக்குகிறது, iPhone, iPad மற்றும் Mac-இல். ஆஃப்லைனில் இயங்கும், எதுவும் பதிவேற்றப்படாது. கடவுச்சொல்லை ஒருமுறை சேமித்தால், அடுத்த மாத ஸ்டேட்மென்ட்டை Face ID திறக்கும்.
