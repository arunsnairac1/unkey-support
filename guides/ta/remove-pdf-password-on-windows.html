Windows-இல் PDF கடவுச்சொல்லை நீக்குவது எப்படி (2026)

அக்டோபர் 2026 அன்று புதுப்பிக்கப்பட்டது

இந்த மொழியில் படிக்க: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

Microsoft Edge அல்லது Chrome-இல் கடவுச்சொல்லுடன் PDF-ஐத் திறந்து, Ctrl+P அழுத்தி, Save as PDF (அல்லது Microsoft Print to PDF) தேர்ந்தெடுத்துப் புதிய நகலைச் சேமியுங்கள்; கட்டண Acrobat நேரடியாகவே பாதுகாப்பை நீக்கும்.

Windows 10, 11-இல் உங்களிடம் ஏற்கெனவே உள்ள உலாவியைக் கொண்டே PDF கடவுச்சொல்லை இலவசமாக நீக்கலாம். Microsoft Edge அல்லது Google Chrome-இல் PDF-ஐத் திறந்து, கடவுச்சொல்லைத் தட்டச்சு செய்து, Ctrl + P அழுத்தி, அச்சுப்பொறியாக Save as PDF (அல்லது Microsoft Print to PDF) தேர்ந்தெடுத்துச் சேமியுங்கள். புதிய கோப்பு கடவுச்சொல் இல்லாமல் திறக்கும். முதலில் கடவுச்சொல் உங்களுக்குத் தெரிந்திருக்க வேண்டும்.

முறை 1: Microsoft Edge (உள்ளமைந்தது)

  1. File Explorer-இல் PDF-ஐ வலது கிளிக் செய்து Open with > Microsoft Edge தேர்ந்தெடுங்கள்.
  2. Edge கேட்கும்போது கடவுச்சொல்லைத் தட்டச்சு செய்யுங்கள்.
  3. Ctrl + P அழுத்துங்கள், அல்லது More மெனுவைத் (மூன்று புள்ளிகள்) திறந்து Print தேர்ந்தெடுங்கள்.
  4. Printer-இன் கீழ் Save as PDF அல்லது Microsoft Print to PDF தேர்ந்தெடுங்கள்.
  5. Save (அல்லது Print) கிளிக் செய்து, கோப்புறையைத் தேர்ந்தெடுத்து, நகலுக்குப் புதிய பெயர் கொடுங்கள்.
  6. புதிய கோப்பைத் திறந்து அது இனி கடவுச்சொல் கேட்கவில்லை என்று பாருங்கள்.

Microsoft-இன் உள்ளமைந்த PDF reader வழிகாட்டி Edge வழியைக் காட்டுகிறது: More மெனுவின் கீழ் Print-ஐக் கண்டு, விருப்பங்களைத் தேர்ந்தெடுத்து, அச்சிடுங்கள் (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF என்பது Windows உடன் வரும் ஓர் அச்சுப்பொறி. அது பட்டியலில் இல்லையென்றால், Windows Optional Features-இல் மீண்டும் இயக்கலாம் என்று Microsoft சொல்கிறது (Microsoft: KB5058499 known issue).

முறை 2: Google Chrome

Chrome பயன்படுத்தினால் படிகள் கிட்டத்தட்ட அதேதான்: Chrome-இல் PDF-ஐத் திறந்து, கடவுச்சொல்லை உள்ளிட்டு, Ctrl + P அழுத்தி, Destination-ஐ Save as PDF ஆக அமைத்து, Save கிளிக் செய்யுங்கள் (Google: Print from Chrome). மேலும் விவரங்கள் எங்கள் Chrome வழிகாட்டியில் உள்ளன.

முறை 3: Adobe Acrobat Pro அல்லது Standard (கட்டணம்)

கட்டண Acrobat கோப்பை மீண்டும் அச்சிடாமல் குறியாக்கத்தையே நீக்கும்; அதனால் இணைப்புகளும் படிவப் புலங்களும் அப்படியே இருக்கும். Adobe இரண்டு வழிகளை ஆவணப்படுத்தியுள்ளது (Adobe: Remove passwords from PDFs):

  • Protect கருவிகள்: PDF-ஐத் திறந்து, Protect கருவிகளுக்குச் சென்று Remove Security தேர்ந்தெடுங்கள். கோப்பில் திறப்பதற்கான கடவுச்சொல் மட்டும் இருந்தால் OK மூலம் உறுதிப்படுத்துங்கள். அனுமதிக் கடவுச்சொல்லும் இருந்தால், Acrobat முதலில் அந்தக் கடவுச்சொல்லைக் கேட்கும்.
  • Security அமைப்புகள்: ஆவணத்தின் security பண்புகளைத் திறந்து, Security தாவலுக்குச் சென்று, Change Settings தேர்ந்தெடுத்து, கடவுச்சொல் விருப்பங்களை அழித்துச் சேமியுங்கள்.

Adobe-இன் மெனுக்கள் பதிப்புகளுக்கிடையே இடம் மாறும்; இந்தப் பெயர்கள் தெரியவில்லை என்றால் Acrobat-இன் கருவித் தேடலில் “Remove Security” என்று தேடுங்கள். இலவச Acrobat Reader பாதுகாக்கப்பட்ட PDF-களைத் திறக்கும், ஆனால் பாதுகாப்பை நீக்குவதற்கான கருவி அல்ல. அதற்குப் பதிலாக முறை 1 அல்லது 2-ஐப் பயன்படுத்துங்கள்.

முறை 4: qpdf (தொழில்நுட்பம் அறிந்தவர்களுக்கு)

இலவச, திறந்த மூல qpdf கருவி Windows-இல் இயங்கும். qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf குறியாக்கம் இல்லாத நகலை எழுதும் (qpdf documentation). கடவுச்சொல் உங்கள் command history-யில் சேமிக்கப்படலாம்; பகிரப்பட்ட கணினியில் பிறகு அதை அழித்துவிடுங்கள்.

சரிபார்க்க வேண்டியவை

  • Print சாம்பல் நிறத்தில் உள்ளதா? அச்சிடுவதைத் தடுக்கும் அனுமதிக் கடவுச்சொல் அந்த PDF-இல் இருக்கலாம். பார்க்க: அச்சிடல், நகலெடுத்தல் கட்டுப்பாடுகள்.
  • கடவுச்சொல் நிராகரிக்கப்பட்டதா? Caps Lock, தேதி வடிவம், உங்கள் வங்கியிடம் உள்ள விவரங்களைச் சரிபாருங்கள். பார்க்க: PDF கடவுச்சொல் ஏன் வேலை செய்யவில்லை.
  • பகிரப்பட்ட அல்லது அலுவலகக் கணினியா? பூட்டு நீக்கிய நகலை அதைக் காணும் எவரும் திறக்கலாம். தனிப்பட்ட கோப்புறையில் சேமித்து, Downloads-இலிருந்து நீக்கிவிடுங்கள்.

உங்களிடம் iPhone, iPad அல்லது Mac இருந்தால், அந்தச் சாதனங்களில் UnKey ஆஃப்லைனில் கடவுச்சொல்லை நீக்கும்; அடுத்த மாத அறிக்கைக்காகக் கடவுச்சொல்லையும் சேமிக்கும். Windows-க்கு UnKey செயலி இல்லை.

கேள்விகள்

Windows-இல் எதையாவது நிறுவ வேண்டுமா?

வேண்டாம். Microsoft Edge-உம் Microsoft Print to PDF அச்சுப்பொறியும் Windows 10, 11 உடன் வருகின்றன.

ஆன்லைன் “unlock PDF” தளங்கள் சிறப்பாக வேலை செய்யுமா?

அவை அதே வேலையைச் செய்கின்றன, ஆனால் உங்கள் ஆவணத்தை வேறொருவரின் சர்வருக்குப் பதிவேற்றுகின்றன. வங்கி அறிக்கைகள், வரி ஆவணங்களுக்கு இங்குள்ள ஆஃப்லைன் முறைகள் பாதுகாப்பானவை.

நான் மறந்த கடவுச்சொல்லை இவற்றில் ஏதாவது நீக்குமா?

நீக்காது. Edge, Chrome, Acrobat, qpdf எல்லாவற்றுக்கும் சரியான கடவுச்சொல் தேவை. வடிவத்துக்கு PDF-உடன் வந்த மின்னஞ்சலைப் பாருங்கள்.

நகலில் இணைப்புகள் ஏன் வேலை செய்யவில்லை?

PDF-ஆக அச்சிடுவது பக்கங்களை மீண்டும் உருவாக்குவதால் இணைப்புகளும் படிவப் புலங்களும் போகலாம். Acrobat-இன் Remove Security அல்லது qpdf அவற்றைப் பாதுகாக்கும்.

வடிவங்கள் மாறலாம். கடவுச்சொல் வேலை செய்யவில்லை என்றால், ஆவணத்துடன் வந்த மின்னஞ்சலைப் பாருங்கள் அல்லது வழங்கிய நிறுவனத்தைத் தொடர்பு கொள்ளுங்கள். இங்கே குறிப்பிடப்பட்டுள்ள எந்த வங்கி, நிறுவனம் அல்லது அதிகார அமைப்புடனும் UnKey-க்கு தொடர்பு இல்லை.

ஆங்கிலத்திலிருந்து மொழிபெயர்க்கப்பட்டது. ஏதேனும் வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அடிப்படை.

ஒருமுறை திறந்தால் போதும்.

நீங்கள் ஏற்கெனவே திறக்கக்கூடிய PDF-களிலிருந்து UnKey கடவுச்சொல்லை நீக்குகிறது, iPhone, iPad மற்றும் Mac-இல். ஆஃப்லைனில் இயங்கும், எதுவும் பதிவேற்றப்படாது. கடவுச்சொல்லை ஒருமுறை சேமித்தால், அடுத்த மாத ஸ்டேட்மென்ட்டை Face ID திறக்கும்.
