PDF அச்சிடல், நகலெடுத்தல் கட்டுப்பாடுகள் - விளக்கம்

திறப்பதற்கான கடவுச்சொல் PDF-ஐப் படிப்பதையே தடுக்கும்; உரிமையாளர் (அனுமதி) கடவுச்சொல் அச்சிடுதல், நகலெடுத்தல், திருத்துதல் போன்ற செயல்களை மட்டுமே கட்டுப்படுத்தும்.

PDF-களுக்கு இரண்டு வெவ்வேறு கடவுச்சொற்கள் இருக்கலாம். திறப்பதற்கான கடவுச்சொல் (open password, user password என்றும் சொல்வர்) கோப்பைப் பார்க்கவே தேவை. உரிமையாளர் கடவுச்சொல் (owner password, permissions password என்றும் சொல்வர்) கோப்பைத் திறக்க விடும், ஆனால் அச்சிடுதல், எழுத்தை நகலெடுத்தல், திருத்துதல் போன்றவற்றைக் கட்டுப்படுத்தும். கட்டுப்பாடுகளை முறையாக நீக்க உரிமையாளர் கடவுச்சொல் தேவை.

இரண்டு கடவுச்சொற்களும் எளிய மொழியில்

திறப்பதற்கான (user) கடவுச்சொல்உரிமையாளர் (அனுமதி) கடவுச்சொல்
நீங்கள் காண்பதுஎதுவும் தெரியும் முன் கடவுச்சொல் கேட்கும் திரைகோப்பு திறக்கும், ஆனால் Print அல்லது Copy சாம்பல் நிறத்தில் இருக்கும்
எதைப் பாதுகாக்கிறதுகுறியாக்கப்பட்ட முழு உள்ளடக்கத்தையும்அச்சிடுதல், நகலெடுத்தல், திருத்துதல், கருத்திடுதல் போன்ற செயல்களை
வழக்கமான பயன்பாடுவங்கி அறிக்கைகள், வரி ஆவணங்கள்வெளியிடப்பட்ட அறிக்கைகள், படிவங்கள், ஒப்பந்தங்கள்

Adobe-ம் இந்தப் பிரிவை இப்படியே விவரிக்கிறது. PDF-ஐத் திறக்க Document Open கடவுச்சொல் தேவை; அச்சிடுதல், திருத்துதல், நகலெடுத்தல் போன்ற வசதிகளை அனுமதிக் கடவுச்சொல் கட்டுப்படுத்தும் (Adobe: Password security overview). qpdf-இன் ஆவணம் ஒரு முக்கிய விவரத்தைச் சேர்க்கிறது: user கடவுச்சொல்லால் திறந்த கோப்புகளுக்கு readers “பாதுகாப்புக் கட்டுப்பாடுகளைப் பயன்படுத்தும்”, owner கடவுச்சொல்லால் திறக்கும்போது “பாதுகாப்புக் கட்டுப்பாடுகளை மாற்றவோ மீறவோ அனுமதிக்கும்” (qpdf).

கட்டுப்பாடுகள் எப்படி நடைமுறைப்படுத்தப்படுகின்றன

கட்டுப்பாடுகளை மதிப்பதா என்பதை PDF reader தானாகத் தீர்மானிப்பதைப் பொறுத்தே அவை அமைந்துள்ளன. தன் சொந்தத் தயாரிப்புகள் அவற்றை நடைமுறைப்படுத்துவதாகவும், மூன்றாம் தரப்புத் தயாரிப்புகள் இந்த அமைப்புகளை ஆதரிக்கவில்லை என்றால், பெறுபவர்கள் சில அல்லது எல்லாக் கட்டுப்பாடுகளையும் தவிர்க்கக்கூடும் என்றும் Adobe குறிப்பிடுகிறது (Adobe). எனவே அனுமதிக் கடவுச்சொல் பூட்டு அல்ல, “தயவுசெய்து வேண்டாம்” என்ற பணிவான வேண்டுகோள் போன்றது. ஆனால் அது ஆசிரியரின் விருப்பத்தைப் புறக்கணிக்க ஒரு காரணம் ஆகாது. யாராவது நகலெடுப்பதைக் கட்டுப்படுத்தியிருந்தால், பதிப்புரிமை அல்லது ஒப்பந்தம் போன்ற காரணம் பொதுவாக இருக்கும்.

உரிமையாளர் கடவுச்சொல் இருந்தால் கட்டுப்பாடுகளை மாற்றுவது

Mac-இல் (Preview): PDF-ஐத் திறந்து, File > Edit Permissions தேர்ந்தெடுத்து, உரிமையாளர் கடவுச்சொல்லை உள்ளிடுங்கள். பின் கடவுச்சொல் இல்லாமல் அனுமதிக்க விரும்பும் செயல்களைத் தேர்ந்தெடுத்து Apply கிளிக் செய்யலாம் (Apple: Password-protect a PDF in Preview on Mac). புதிய நகல் வேண்டுமென்றால் அதே Permissions பலகை File > Export-இலும் தோன்றும்.

Adobe Acrobat-இல்: அனுமதிக் கடவுச்சொல்லை நீக்குவதற்கான Adobe-இன் வழிமுறைகள் அதை Enter Password பெட்டியில் தட்டச்சு செய்யச் சொல்கின்றன (Adobe: How to remove a PDF password).

Command line-இல்: --password=OWNERPASSWORD --decrypt உடன் qpdf குறியாக்கம் இல்லாத நகலை எழுதும். கோப்புகளின் மீது தயாரிப்பாளர்கள் வைக்கும் கட்டுப்பாடுகளைத் தவிர்க்க இந்த விருப்பம் உருவாக்கப்படவில்லை என்று அதன் ஆவணம் குறிப்பிடுகிறது (qpdf).

இரண்டு கடவுச்சொற்களும் உள்ள உங்கள் சொந்த ஆவணங்கள்

வங்கி அறிக்கைகள் வழக்கமாகத் திறப்பதற்கான கடவுச்சொல்லை மட்டுமே பயன்படுத்தும். ஒன்றைத் திறந்துவிட்டால், பொதுவாகச் சுதந்திரமாக அச்சிடவும் நகலெடுக்கவும் முடியும். Preview அல்லது Acrobat-இல் PDF-ஐ நீங்களே உருவாக்கி இரண்டு கடவுச்சொற்களையும் அமைத்திருந்தால், அனுமதிகளை மாற்ற அல்லது கட்டுப்பாடற்ற நகலை export செய்ய உரிமையாளர் கடவுச்சொல்லைப் பயன்படுத்துங்கள்.

மாதாந்திர அறிக்கைகள் போன்ற உங்கள் சொந்தக் கோப்புகளின் திறப்பதற்கான கடவுச்சொல்லை நீக்க, Mac-இல் Preview அல்லது iPhone, iPad, Mac-இல் UnKey பயன்படுத்தலாம். UnKey ஆஃப்லைனில் இயங்கும்; உங்களுக்கு ஏற்கெனவே தெரிந்த கடவுச்சொற்களுடன் மட்டுமே வேலை செய்யும்.

உரிமையாளர் கடவுச்சொல் இல்லாதபோது

  • ஆசிரியர் அல்லது அனுப்பியவரிடம் கட்டுப்பாடற்ற நகலையோ அச்சிட/நகலெடுக்க அனுமதியையோ கேளுங்கள்.
  • நிரப்ப வேண்டிய படிவம் என்றால், நிரப்புவது ஏற்கெனவே அனுமதிக்கப்பட்டுள்ளதா என்று பாருங்கள். கட்டுப்பாடுள்ள பல PDF-கள் படிவம் நிரப்புவதை அனுமதிக்கும்.
  • பணி அல்லது சட்ட ஆவணம் என்றால், கட்டுப்பாடு வேண்டுமென்றே வைக்கப்பட்டது என்று கொள்ளுங்கள்.

கேள்விகள்

PDF உரிமையாளர் கடவுச்சொல் என்றால் என்ன?

இது அச்சிடுதல், நகலெடுத்தல், திருத்துதல் போன்ற அனுமதிகளைக் கட்டுப்படுத்தும் கடவுச்சொல். அது இல்லாமலும் கோப்பைத் திறக்கலாம், ஆனால் அமைப்புகளை மதிக்கும் readers-இல் கட்டுப்படுத்தப்பட்ட செயல்கள் தடுக்கப்படும்.

PDF-ஐத் திறக்க முடிகிறது, ஆனால் அச்சிட முடியவில்லை, ஏன்?

அச்சிடுவதை அனுமதிக்காத உரிமையாளர் (அனுமதி) கடவுச்சொல் அந்தக் கோப்பில் உள்ளது. Preview-இல் File > Edit Permissions-இல் உரிமையாளர் கடவுச்சொல்லை உள்ளிடுங்கள், அல்லது கட்டுப்பாடற்ற நகலை அனுப்பியவரிடம் கேளுங்கள்.

வங்கி அறிக்கைகளுக்கு அச்சிடல் கட்டுப்பாடுகள் உண்டா?

பொதுவாக இல்லை. அவை வழக்கமாகத் திறப்பதற்கான கடவுச்சொல்லை மட்டுமே பயன்படுத்தும்; எனவே கோப்பைத் திறந்ததும் அச்சிடலாம்.

PDF நகலெடுப்புக் கட்டுப்பாடுகளை நீக்குவது சட்டப்படி சரியா?

உங்கள் சொந்தக் கோப்பில், உங்கள் சொந்த உரிமையாளர் கடவுச்சொல்லுடன் அனுமதிகளை மாற்றுவது சரியே. வேறொருவரின் ஆவணத்தில் கட்டுப்பாடுகளைத் தவிர்ப்பது பதிப்புரிமையை அல்லது ஒப்பந்த விதிகளை மீறலாம்; எனவே உரிமையாளரிடம் கேளுங்கள்.

வடிவங்கள் மாறலாம். கடவுச்சொல் வேலை செய்யவில்லை என்றால், ஆவணத்துடன் வந்த மின்னஞ்சலைப் பாருங்கள் அல்லது வழங்கிய நிறுவனத்தைத் தொடர்பு கொள்ளுங்கள். இங்கே குறிப்பிடப்பட்டுள்ள எந்த வங்கி, நிறுவனம் அல்லது அதிகார அமைப்புடனும் UnKey-க்கு தொடர்பு இல்லை.

ஆங்கிலத்திலிருந்து மொழிபெயர்க்கப்பட்டது. ஏதேனும் வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அடிப்படை.

ஒருமுறை திறந்தால் போதும்.

நீங்கள் ஏற்கெனவே திறக்கக்கூடிய PDF-களிலிருந்து UnKey கடவுச்சொல்லை நீக்குகிறது, iPhone, iPad மற்றும் Mac-இல். ஆஃப்லைனில் இயங்கும், எதுவும் பதிவேற்றப்படாது. கடவுச்சொல்லை ஒருமுறை சேமித்தால், அடுத்த மாத ஸ்டேட்மென்ட்டை Face ID திறக்கும்.
