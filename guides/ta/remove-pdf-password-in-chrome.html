Chrome-இல் PDF கடவுச்சொல்லை நீக்குவது எப்படி (2026)

அக்டோபர் 2026 அன்று புதுப்பிக்கப்பட்டது

இந்த மொழியில் படிக்க: English · العربية · Deutsch · Español · हिन्दी · Bahasa Indonesia · Português · தமிழ்

Chrome-இல் கடவுச்சொல்லுடன் PDF-ஐத் திறந்து, Ctrl+P அல்லது Cmd+P அழுத்தி, Destination-ஐ Save as PDF ஆக அமைத்து, கடவுச்சொல் இல்லாத புதிய நகலைச் சேமியுங்கள்.

Google Chrome, Windows, Mac, Linux-இல் கடவுச்சொல் உள்ள PDF-இன் நகலை கடவுச்சொல் இல்லாமல் இலவசமாகச் சேமிக்க முடியும். Chrome-இல் PDF-ஐத் திறந்து, கடவுச்சொல்லைத் தட்டச்சு செய்து, Ctrl + P (Mac-இல் Cmd + P) அழுத்தி, Destination-ஐ Save as PDF ஆக அமைத்துச் சேமியுங்கள். கடவுச்சொல் உங்களுக்கு ஏற்கெனவே தெரிந்திருக்க வேண்டும்; அது இல்லாமல் Chrome கோப்பைத் திறக்காது.

படிப்படியாக (கணினி)

  1. PDF-ஐ Chrome சாளரத்தில் இழுத்துப்போடுங்கள், அல்லது கோப்பை வலது கிளிக் செய்து Open with > Google Chrome தேர்ந்தெடுங்கள்.
  2. Chrome கடவுச்சொல் கேட்கும். தட்டச்சு செய்து Enter அழுத்துங்கள்.
  3. Windows அல்லது Linux-இல் Ctrl + P, Mac-இல் Cmd + P அழுத்துங்கள். மெனு வழியாகவும் செய்யலாம்: File > Print.
  4. Print சாளரத்தில் Destination-ஐ Save as PDF ஆக அமைத்துக்கொள்ளுங்கள்.
  5. Save கிளிக் செய்யுங்கள். புதிய கோப்புக்கு Statement-Sep-2026-unlocked.pdf போன்ற தெளிவான பெயர் கொடுங்கள்.
  6. மூடிவிட்டுப் புதிய கோப்பை மீண்டும் திறங்கள். கடவுச்சொல் கேட்காமல் உடனே திறக்க வேண்டும்.

விசைப்பலகை குறுக்குவழிகள், Print சாளரத்தில் இலக்கைத் தேர்ந்தெடுப்பது, Save as PDF விருப்பம் ஆகியவற்றை Google-இன் உதவிப் பக்கம் விவரிக்கிறது (Google: Print from Chrome).

Android தொலைபேசியில்

Android-இல் Chrome-இலும் இதே விருப்பம் உள்ளது. Google-இன் படிகள்: More > Share தொடுங்கள், Print தொடுங்கள், பின் Save as PDF தொட்டு கோப்பைச் சேமிக்கும் இடத்தைத் தேர்ந்தெடுங்கள் (Google: Print from Chrome on Android). உங்கள் தொலைபேசியிலுள்ள PDF-ஐ Chrome திறக்குமா என்பது Chrome பதிப்பைப் பொறுத்தது. திறக்கவில்லை என்றால், Android-இல் கடவுச்சொல் உள்ள PDF-ஐத் திறப்பது பற்றிய எங்கள் வழிகாட்டியைப் பாருங்கள்.

இந்த முறையில் எதை இழப்பீர்கள்

Print சாளரம் வழியாகச் சேமித்தால், திரையில் உள்ளதிலிருந்து முற்றிலும் புதிய PDF உருவாகும். அறிக்கையைப் படிக்க, காப்பகப்படுத்த, பதிவேற்ற இது போதும். ஆனால் அசலை நீக்கும் முன் நகலைச் சரிபாருங்கள்:

  • இணைப்புகளும் புத்தகக்குறிகளும் வேலை செய்யாமல் போகலாம்.
  • படிவப் புலங்கள் தட்டையாக்கப்படலாம்; அதனால் அவற்றில் இனி தட்டச்சு செய்ய முடியாது.
  • டிஜிட்டல் கையொப்பங்கள் மாற்றப்படாது. கையொப்பமிட்ட அசல் போர்ட்டலுக்குத் தேவை என்றால், அசலைப் பதிவேற்றுங்கள்.
  • பக்க அளவு அச்சு அமைப்புகளைப் பின்பற்றும். More settings-இல், காகித அளவும் scale-உம் பக்கங்களைச் சுருக்கவோ வெட்டவோ இல்லை என்பதைப் பாருங்கள்.

Save as PDF வேலை செய்யவில்லை என்றால்

  • அச்சிடுதல் தடுக்கப்பட்டுள்ளது. சில PDF-களில் அச்சிடுவதை நிறுத்தும் அனுமதிக் கடவுச்சொல் இருக்கும். அனுமதிக் கடவுச்சொல் திறப்பதற்கான கடவுச்சொல்லிலிருந்து வேறுபட்டது. பார்க்க: PDF அச்சிடல், நகலெடுத்தல் கட்டுப்பாடுகள் விளக்கம்.
  • Chrome கடவுச்சொல்லை நிராகரிக்கிறது. பெரிய எழுத்துகள், தேதி வடிவம், உங்கள் வங்கியிடம் உள்ள விவரங்களைச் சரிபாருங்கள். பார்க்க: PDF கடவுச்சொல் ஏன் வேலை செய்யவில்லை.
  • கோப்பு வேறொரு செயலியில் திறந்தது. சில கணினிகள் PDF-களை இயல்பாக வேறு வியூவரில் திறக்கும். அதற்குப் பதிலாக கோப்பை Chrome தாவலுக்குள் இழுத்துப்போடுங்கள்.

கடவுச்சொல்லை நீக்க வேறு வழிகள்

Windows-இல் Microsoft Edge இதே போல் வேலை செய்யும் (பார்க்க: Windows-இல் PDF கடவுச்சொல்லை நீக்குவது). Mac-இல் Preview கடவுச்சொல் இல்லாத நகலை export செய்யும் (Mac வழிகாட்டி). iPhone, iPad, Mac-இல் UnKey ஆஃப்லைனில் பூட்டு நீக்கிய நகலைச் சேமிக்கும்; கோப்பை மீண்டும் அச்சிடாமல் குறியாக்கத்தையே நீக்குவதால் எழுத்து, இணைப்புகள், பக்கங்கள் அப்படியே இருக்கும். Chrome போலவே, உங்களுக்கு ஏற்கெனவே தெரிந்த கடவுச்சொல்லுடன் மட்டுமே இது வேலை செய்யும்.

கேள்விகள்

இதைச் செய்யும்போது Chrome என் PDF-ஐப் பதிவேற்றுமா?

இல்லை. உங்கள் கணினியிலுள்ள PDF-ஐத் திறந்து Save as PDF மூலம் சேமிப்பது உங்கள் கணினியிலுள்ள உலாவிக்குள்ளேயே நடக்கும். Drive-இல் ஒரு நகல் வேண்டுமென்றால் மட்டும் தனியான “Save to Google Drive” இலக்கைப் பயன்படுத்துங்கள்.

எனக்குத் தெரியாத கடவுச்சொல்லை Chrome நீக்குமா?

நீக்காது. எதையும் காட்டும் முன் Chrome கடவுச்சொல்லைக் கேட்கும். இழந்துவிட்டால், PDF கடவுச்சொல்லை மறந்தால் என்ன செய்வது என்பதைப் பாருங்கள்.

சேமித்த நகல் அசலிலிருந்து ஏன் வேறுபடுகிறது?

Save as PDF பக்கங்களை ஒரு புதிய கோப்பில் அச்சிடுவதால், இணைப்புகள், படிவப் புலங்கள், கையொப்பங்கள் தப்பாமல் போகலாம். எழுத்தும் வடிவமைப்பும் பொதுவாக ஒரே மாதிரி இருக்கும்.

இது அனுமதிக்கப்பட்டதா?

உங்கள் சொந்த ஆவணங்களுக்கு, எ.கா. உங்கள் வங்கி அறிக்கைக்கு, ஆம். சுதந்திரமாகத் திறக்க உங்களுக்கு உரிமை இல்லாத கோப்புகளின் பாதுகாப்பை நீக்காதீர்கள்.

வடிவங்கள் மாறலாம். கடவுச்சொல் வேலை செய்யவில்லை என்றால், ஆவணத்துடன் வந்த மின்னஞ்சலைப் பாருங்கள் அல்லது வழங்கிய நிறுவனத்தைத் தொடர்பு கொள்ளுங்கள். இங்கே குறிப்பிடப்பட்டுள்ள எந்த வங்கி, நிறுவனம் அல்லது அதிகார அமைப்புடனும் UnKey-க்கு தொடர்பு இல்லை.

ஆங்கிலத்திலிருந்து மொழிபெயர்க்கப்பட்டது. ஏதேனும் வேறுபாடு இருந்தால், ஆங்கிலப் பக்கமே அடிப்படை.

ஒருமுறை திறந்தால் போதும்.

நீங்கள் ஏற்கெனவே திறக்கக்கூடிய PDF-களிலிருந்து UnKey கடவுச்சொல்லை நீக்குகிறது, iPhone, iPad மற்றும் Mac-இல். ஆஃப்லைனில் இயங்கும், எதுவும் பதிவேற்றப்படாது. கடவுச்சொல்லை ஒருமுறை சேமித்தால், அடுத்த மாத ஸ்டேட்மென்ட்டை Face ID திறக்கும்.
