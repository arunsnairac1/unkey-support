Mac లో PDF నుంచి పాస్‌వర్డ్ ఎలా తీసేయాలి (2026)

అక్టోబర్ 2026న అప్‌డేట్ చేయబడింది

ఈ భాషలో చదవండి: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · සිංහල · தமிழ் · తెలుగు

Preview లో పాస్‌వర్డ్‌తో PDF తెరిచి, File > Export ఎంచుకుని, open పాస్‌వర్డ్ సెట్ కాలేదని నిర్ధారించుకుని, కొత్త కాపీని సేవ్ చేయండి.

Mac లో macOS తో వచ్చే Preview యాప్‌తో PDF పాస్‌వర్డ్‌ను ఉచితంగా తీసేయవచ్చు. PDF తెరిచి, పాస్‌వర్డ్ ఇచ్చి, File > Export ఎంచుకుని, open పాస్‌వర్డ్ లేని కొత్త కాపీని సేవ్ చేయండి. మీకు పాస్‌వర్డ్ తెలిసి ఉండాలి. అది లేకుండా Preview ఫైల్‌ను తెరవదు.

పద్ధతి 1: Preview, File > Export

  1. PDF పై డబుల్-క్లిక్ చేసి Preview లో తెరిచి, పాస్‌వర్డ్ ఇవ్వండి.
  2. File > Export ఎంచుకుని, కాపీకి "Statement-Oct-unlocked" వంటి కొత్త పేరు ఇవ్వండి.
  3. Permissions క్లిక్ చేసి Require Password To Open Document ఎంచుకోకుండా (not selected) ఉందని నిర్ధారించుకోండి. పాత macOS వెర్షన్లలో Export విండోలో బదులుగా Encrypt చెక్‌బాక్స్ ఉంటుంది. దాన్ని టిక్ చేయకుండా వదిలేయండి.
  4. Save క్లిక్ చేయండి.
  5. కొత్త ఫైల్‌ను మూసివేసి మళ్లీ తెరవండి. పాస్‌వర్డ్ అడగకుండా తెరుచుకోవాలి.

Apple ప్రస్తుత గైడ్ Export విండోను, Permissions బటన్‌ను, Require Password To Open Document ఎంపికను వివరిస్తోంది (Apple: Password-protect a PDF in Preview on Mac). అదే పేజీ macOS Big Sur వెర్షన్ నేరుగా ఇలా చెప్పింది: "మీరు ఎన్‌క్రిప్ట్ చేసిన PDF నుంచి పాస్‌వర్డ్ తీసేయడానికి, PDF తెరిచి, ఈసారి ఎన్‌క్రిప్షన్ ఎంపికను ఆఫ్ చేసి మళ్లీ ఎగుమతి చేయండి" (Apple, macOS Big Sur guide).

PDF కి యజమాని (అనుమతుల) పాస్‌వర్డ్ కూడా ఉండి అది మీకు తెలిస్తే, File > Edit Permissions తో open పాస్‌వర్డ్‌ను, ఏ ఫీచర్లకు పాస్‌వర్డ్ కావాలో మార్చవచ్చు.

పద్ధతి 2: Print > Save as PDF

ప్రింట్ చేయగల ఏ Mac యాప్ అయినా కొత్త PDF తయారు చేయగలదు (Apple: Save a document as a PDF on Mac):

  1. PDF ను పాస్‌వర్డ్‌తో తెరవండి.
  2. File > Print ఎంచుకోండి.
  3. PDF పాప్-అప్ మెనూ క్లిక్ చేసి Save as PDF ఎంచుకోండి.
  4. Security Options క్లిక్ చేయవద్దు, పాస్‌వర్డ్‌ను మళ్లీ జోడించేది అదే.

ప్రింట్ చేసిన కాపీలో లింకులు, ఫారమ్ ఫీల్డ్‌లు, బుక్‌మార్క్‌లు పోవచ్చు. డాక్యుమెంట్ ప్రింటింగ్‌ను అడ్డుకుంటే ఈ పద్ధతి బూడిద రంగులో ఉండవచ్చు.

పద్ధతి 3: Mac కోసం UnKey

UnKey Mac లో కూడా ఉచితం. ఒకసారి కొనే UnKey Pro బ్యాచ్ అన్‌లాక్‌ను, iPhone, iPad, Mac లలో ఇతర Pro టూల్స్‌ను జోడిస్తుంది. PDF ను విండోపైకి లాగి, పాస్‌వర్డ్ ఇస్తే, అది అన్‌లాక్ చేసిన కాపీని సేవ్ చేస్తుంది. ఒకే పాస్‌వర్డ్ ఉన్న ఏడాది నెలవారీ స్టేట్‌మెంట్లకు ఉపయోగపడేలా, UnKey Pro ఒకేసారి అనేక ఫైళ్లను బ్యాచ్-అన్‌లాక్ చేయగలదు. UnKey ఆఫ్‌లైన్‌లో పనిచేస్తుంది, ఏదీ అప్‌లోడ్ చేయదు, మీకు ఇప్పటికే తెలిసిన పాస్‌వర్డ్లను మాత్రమే తీసేస్తుంది.

పద్ధతి 4: కమాండ్ లైన్ (సాంకేతిక వినియోగదారులకు)

ఉచిత, ఓపెన్-సోర్స్ టూల్ qpdf దీన్ని Terminal లో చేయగలదు: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. దాని డాక్యుమెంటేషన్ --decrypt ను "ఇన్‌పుట్ ఫైల్ ఎన్‌క్రిప్ట్ అయి ఉన్నా, ఎన్‌క్రిప్షన్ లేని అవుట్‌పుట్ ఫైల్‌ను సృష్టించడం" అని వివరిస్తోంది (qpdf documentation). దీన్ని Homebrew వంటి వాటితో మీరే ఇన్‌స్టాల్ చేసుకోవాలి. కమాండ్ లైన్‌లో పాస్‌వర్డ్ టైప్ చేస్తే అది మీ shell చరిత్రలో మిగిలిపోవచ్చు.

ఇంకా పాస్‌వర్డ్ అడుగుతుంటే

  • కాపీకి బదులు అసలు ఫైల్‌ను తెరిచి ఉండవచ్చు. ఫైల్ పేరు చూడండి.
  • మళ్లీ ఎగుమతి చేసి, Permissions లో Require Password To Open Document ఆఫ్‌లో ఉందో చూడండి.
  • బదులుగా Print > Save as PDF ప్రయత్నించండి.
  • Preview పాస్‌వర్డ్‌ను తిరస్కరిస్తే, పెద్దక్షరాలు, తేదీ ఫార్మాట్ చూసి, డాక్యుమెంట్‌తో వచ్చిన ఇమెయిల్ చదవండి.

అసలు ఫైల్ తొలగించే ముందు

అన్‌లాక్ చేసిన PDF ఫైల్ ఉన్న ఎవరికైనా తెరుచుకుంటుంది. కుటుంబంతో షేర్ చేసిన iCloud Drive ఫోల్డర్లు, మీ Mac ను అరువు తీసుకునేవారు కూడా అందులో ఉంటారు. అన్‌లాక్ చేసిన స్టేట్‌మెంట్లను ప్రైవేట్ స్థలంలో ఉంచండి. మరిన్ని వివరాలకు PDF పాస్‌వర్డ్ తీసేయడం సురక్షితమేనా చూడండి.

ప్రశ్నలు

Preview నిజంగా ఉచితమేనా?

అవును. Preview ప్రతి Mac తో వస్తుంది, పాస్‌వర్డ్ ఇచ్చాక open పాస్‌వర్డ్ లేకుండా PDF ను ఎగుమతి చేయగలదు.

నాకు తెలియని పాస్‌వర్డ్‌ను Preview తీసేయగలదా?

లేదు. ఫైల్ తెరిచే ముందే Preview పాస్‌వర్డ్ అడుగుతుంది, దాన్ని దాటే న్యాయమైన మార్గం లేదు.

Mac లో అనేక PDF లను ఒకేసారి అన్‌లాక్ చేయడం ఎలా?

Preview ఒకసారి ఒక ఫైల్‌నే చేస్తుంది. ఒకే పాస్‌వర్డ్ ఉన్న అనేక PDF లను UnKey Pro బ్యాచ్-అన్‌లాక్ చేయగలదు, సాంకేతిక వినియోగదారులు qpdf తో స్క్రిప్ట్ రాయవచ్చు. మా అనేక PDF లను ఒకేసారి అన్‌లాక్ చేసే గైడ్ చూడండి.

Print > Save as PDF ఎందుకు బూడిద రంగులో ఉంది?

PDF కి ప్రింటింగ్‌ను అడ్డుకునే అనుమతుల పాస్‌వర్డ్ ఉండవచ్చు. యజమాని పాస్‌వర్డ్ మీకు తెలిస్తే File > Edit Permissions లో ఇవ్వండి. లేకపోతే Export పద్ధతి వాడండి.

ఫార్మాట్‌లు మారవచ్చు. పాస్‌వర్డ్ పని చేయకపోతే, డాక్యుమెంట్‌తో వచ్చిన ఇమెయిల్ చూడండి లేదా జారీ చేసిన సంస్థను సంప్రదించండి. ఇక్కడ పేర్కొన్న ఏ బ్యాంకు, యజమాని లేదా అధికార సంస్థతోనూ UnKeyకి సంబంధం లేదు.

ఇంగ్లిష్ నుండి అనువదించబడింది. ఏదైనా తేడా ఉంటే, ఇంగ్లిష్ పేజీనే ప్రామాణికం.

ఒక్కసారి అన్‌లాక్ చేయండి.

మీరు ఇప్పటికే తెరవగలిగే PDFల నుండి UnKey పాస్‌వర్డ్‌ను తొలగిస్తుంది, iPhone, iPad, Macలో. ఆఫ్‌లైన్‌లో పని చేస్తుంది, ఏదీ అప్‌లోడ్ కాదు. పాస్‌వర్డ్‌ను ఒక్కసారి సేవ్ చేయండి, వచ్చే నెల స్టేట్‌మెంట్‌ను Face ID తెరుస్తుంది.
