Windows లో PDF పాస్‌వర్డ్ ఎలా తీసేయాలి (2026)

అక్టోబర్ 2026న అప్‌డేట్ చేయబడింది

ఈ భాషలో చదవండి: English · العربية · বাংলা · Deutsch · Español · Filipino · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · Italiano · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · ไทย · اردو · Tiếng Việt

Microsoft Edge లేదా Chrome లో పాస్‌వర్డ్‌తో PDF తెరిచి, Ctrl+P నొక్కి, Save as PDF (లేదా Microsoft Print to PDF) ఎంచుకుని కొత్త కాపీని సేవ్ చేయండి; చెల్లింపు Acrobat నేరుగా సెక్యూరిటీని తీసేయగలదు.

Windows 10, 11 లలో మీ దగ్గరున్న బ్రౌజర్‌తోనే PDF పాస్‌వర్డ్‌ను ఉచితంగా తీసేయవచ్చు. PDF ను Microsoft Edge లేదా Google Chrome లో తెరిచి, పాస్‌వర్డ్ టైప్ చేసి, Ctrl + P నొక్కి, ప్రింటర్‌గా Save as PDF (లేదా Microsoft Print to PDF) ఎంచుకుని సేవ్ చేయండి. కొత్త ఫైల్ పాస్‌వర్డ్ లేకుండా తెరుచుకుంటుంది. ముందుగా మీకు పాస్‌వర్డ్ తెలిసి ఉండాలి.

పద్ధతి 1: Microsoft Edge (అంతర్నిర్మితం)

  1. File Explorer లో PDF పై రైట్-క్లిక్ చేసి Open with > Microsoft Edge ఎంచుకోండి.
  2. Edge అడిగినప్పుడు పాస్‌వర్డ్ టైప్ చేయండి.
  3. Ctrl + P నొక్కండి, లేదా More మెనూ (మూడు చుక్కలు) తెరిచి Print ఎంచుకోండి.
  4. Printer కింద Save as PDF లేదా Microsoft Print to PDF ఎంచుకోండి.
  5. Save (లేదా Print) క్లిక్ చేసి, ఫోల్డర్ ఎంచుకుని కాపీకి కొత్త పేరు ఇవ్వండి.
  6. కొత్త ఫైల్ తెరిచి, అది ఇకపై పాస్‌వర్డ్ అడగడం లేదని చూడండి.

Microsoft అంతర్నిర్మిత PDF రీడర్ గైడ్ Edge మార్గాన్ని చూపిస్తోంది: More మెనూ కింద Print ను కనుగొని, ఎంపికలు ఎంచుకుని, ప్రింట్ చేయండి (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF అనేది Windows తో వచ్చే ప్రింటర్. జాబితాలో అది లేకపోతే, Windows Optional Features లో దాన్ని తిరిగి ఆన్ చేయవచ్చని Microsoft చెబుతోంది (Microsoft: KB5058499 known issue).

పద్ధతి 2: Google Chrome

Chrome వాడుతుంటే దశలు దాదాపు అవే: PDF ను Chrome లో తెరిచి, పాస్‌వర్డ్ ఇచ్చి, Ctrl + P నొక్కి, Destination ను Save as PDF కు సెట్ చేసి, Save క్లిక్ చేయండి (Google: Print from Chrome). మరిన్ని వివరాలు మా Chrome గైడ్ లో ఉన్నాయి.

పద్ధతి 3: Adobe Acrobat Pro లేదా Standard (చెల్లింపు)

చెల్లింపు Acrobat ఫైల్‌ను మళ్లీ ప్రింట్ చేయకుండా ఎన్‌క్రిప్షన్‌నే తీసేస్తుంది, కాబట్టి లింకులు, ఫారమ్ ఫీల్డ్‌లు చెక్కుచెదరవు. Adobe రెండు మార్గాలను వివరిస్తోంది (Adobe: Remove passwords from PDFs):

  • Protect టూల్స్: PDF తెరిచి, Protect టూల్స్‌కు వెళ్లి Remove Security ఎంచుకోండి. ఫైల్‌కు open పాస్‌వర్డ్ మాత్రమే ఉంటే OK తో నిర్ధారించండి. అనుమతుల పాస్‌వర్డ్ కూడా ఉంటే, Acrobat ముందు ఆ పాస్‌వర్డ్ అడుగుతుంది.
  • Security సెట్టింగ్స్: డాక్యుమెంట్ సెక్యూరిటీ ప్రాపర్టీస్ తెరిచి, Security ట్యాబ్‌కు వెళ్లి, Change Settings ఎంచుకుని, పాస్‌వర్డ్ ఎంపికలను తొలగించి సేవ్ చేయండి.

Adobe మెనూలు వెర్షన్‌ను బట్టి మారతాయి, కాబట్టి ఈ పేర్లు కనిపించకపోతే Acrobat టూల్ సెర్చ్‌లో “Remove Security” కోసం వెతకండి. ఉచిత Acrobat Reader రక్షిత PDF లను తెరవగలదు కానీ సెక్యూరిటీ తీసేయడానికి ఆ టూల్ కాదు. బదులుగా పద్ధతి 1 లేదా 2 వాడండి.

పద్ధతి 4: qpdf (సాంకేతిక వినియోగదారులకు)

ఉచిత, ఓపెన్-సోర్స్ qpdf టూల్ Windows లో నడుస్తుంది. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf ఎన్‌క్రిప్షన్ లేని కాపీని రాస్తుంది (qpdf documentation). పాస్‌వర్డ్ మీ కమాండ్ చరిత్రలో సేవ్ కావచ్చు, కాబట్టి షేర్ చేసిన PC లో తర్వాత దాన్ని తొలగించండి.

చూసుకోవలసినవి

  • Print బూడిద రంగులో ఉందా? PDF కి ప్రింటింగ్‌ను అడ్డుకునే అనుమతుల పాస్‌వర్డ్ ఉండవచ్చు. ప్రింటింగ్, కాపీ పరిమితులు చూడండి.
  • పాస్‌వర్డ్ తిరస్కరించబడిందా? Caps Lock, తేదీ ఫార్మాట్, మీ బ్యాంక్ దగ్గరున్న వివరాలు చూడండి. PDF పాస్‌వర్డ్ ఎందుకు పనిచేయడం లేదు చూడండి.
  • షేర్ చేసిన లేదా ఆఫీస్ PC నా? అన్‌లాక్ చేసిన కాపీ కనుగొన్న ఎవరికైనా తెరుచుకుంటుంది. ప్రైవేట్ ఫోల్డర్‌లో సేవ్ చేసి, Downloads నుంచి తొలగించండి.

మీకు iPhone, iPad లేదా Mac కూడా ఉంటే, ఆ పరికరాల్లో UnKey ఆఫ్‌లైన్‌లో పాస్‌వర్డ్ తీసేస్తుంది, వచ్చే నెల స్టేట్‌మెంట్ కోసం పాస్‌వర్డ్‌ను కూడా సేవ్ చేయగలదు. Windows కు UnKey యాప్ లేదు.

ప్రశ్నలు

Windows లో ఏదైనా ఇన్‌స్టాల్ చేయాలా?

అవసరం లేదు. Microsoft Edge, Microsoft Print to PDF ప్రింటర్ Windows 10, 11 తో వస్తాయి.

ఆన్‌లైన్ “unlock PDF” సైట్లు బాగా పనిచేస్తాయా?

అవి అదే పని చేస్తాయి కానీ మీ డాక్యుమెంట్‌ను వేరొకరి సర్వర్‌కు అప్‌లోడ్ చేస్తాయి. బ్యాంక్ స్టేట్‌మెంట్లు, పన్ను పత్రాలకు ఇక్కడి ఆఫ్‌లైన్ పద్ధతులు సురక్షితం.

వీటిలో ఏదైనా మర్చిపోయిన పాస్‌వర్డ్‌ను తీసేయగలదా?

లేదు. Edge, Chrome, Acrobat, qpdf అన్నింటికీ సరైన పాస్‌వర్డ్ కావాలి. ఫార్మాట్ కోసం PDF వచ్చిన ఇమెయిల్ చూడండి.

కాపీలో లింకులు ఎందుకు పనిచేయడం లేదు?

PDF కి ప్రింట్ చేస్తే పేజీలు మళ్లీ నిర్మించబడతాయి, ఇది లింకులను, ఫారమ్ ఫీల్డ్‌లను వదిలేయవచ్చు. Acrobat Remove Security లేదా qpdf వాటిని ఉంచుతాయి.

ఫార్మాట్‌లు మారవచ్చు. పాస్‌వర్డ్ పని చేయకపోతే, డాక్యుమెంట్‌తో వచ్చిన ఇమెయిల్ చూడండి లేదా జారీ చేసిన సంస్థను సంప్రదించండి. ఇక్కడ పేర్కొన్న ఏ బ్యాంకు, యజమాని లేదా అధికార సంస్థతోనూ UnKeyకి సంబంధం లేదు.

ఇంగ్లిష్ నుండి అనువదించబడింది. ఏదైనా తేడా ఉంటే, ఇంగ్లిష్ పేజీనే ప్రామాణికం.

ఒక్కసారి అన్‌లాక్ చేయండి.

మీరు ఇప్పటికే తెరవగలిగే PDFల నుండి UnKey పాస్‌వర్డ్‌ను తొలగిస్తుంది, iPhone, iPad, Macలో. ఆఫ్‌లైన్‌లో పని చేస్తుంది, ఏదీ అప్‌లోడ్ కాదు. పాస్‌వర్డ్‌ను ఒక్కసారి సేవ్ చేయండి, వచ్చే నెల స్టేట్‌మెంట్‌ను Face ID తెరుస్తుంది.
