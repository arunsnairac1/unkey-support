Chrome లో PDF పాస్‌వర్డ్ ఎలా తీసేయాలి (2026)

అక్టోబర్ 2026న అప్‌డేట్ చేయబడింది

ఈ భాషలో చదవండి: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

Chrome లో పాస్‌వర్డ్‌తో PDF తెరిచి, Ctrl+P లేదా Cmd+P నొక్కి, Destination ను Save as PDF కు సెట్ చేసి, పాస్‌వర్డ్ లేని కొత్త కాపీని సేవ్ చేయండి.

Google Chrome, పాస్‌వర్డ్ ఉన్న PDF కి పాస్‌వర్డ్ లేని కాపీని Windows, Mac, Linux లలో ఉచితంగా సేవ్ చేయగలదు. PDF ను Chrome లో తెరిచి, పాస్‌వర్డ్ టైప్ చేసి, Ctrl + P (Mac లో Cmd + P) నొక్కి, Destination ను Save as PDF కు సెట్ చేసి సేవ్ చేయండి. మీకు ముందే పాస్‌వర్డ్ తెలిసి ఉండాలి. అది లేకుండా Chrome ఫైల్‌ను తెరవలేదు.

దశలవారీగా (కంప్యూటర్)

  1. PDF ను Chrome విండోలోకి లాగండి, లేదా ఫైల్‌పై రైట్-క్లిక్ చేసి Open with > Google Chrome ఎంచుకోండి.
  2. Chrome పాస్‌వర్డ్ అడుగుతుంది. టైప్ చేసి Enter నొక్కండి.
  3. Windows లేదా Linux లో Ctrl + P, Mac లో Cmd + P నొక్కండి. మెనూ ద్వారా కూడా చేయవచ్చు: File > Print.
  4. ప్రింట్ విండోలో Destination ను Save as PDF కు సెట్ చేయండి.
  5. Save క్లిక్ చేయండి. కొత్త ఫైల్‌కు Statement-Sep-2026-unlocked.pdf లాంటి స్పష్టమైన పేరు ఇవ్వండి.
  6. మూసివేసి కొత్త ఫైల్‌ను మళ్లీ తెరవండి. పాస్‌వర్డ్ అడగకుండా వెంటనే తెరుచుకోవాలి.

Google సహాయ పేజీ కీబోర్డ్ షార్ట్‌కట్లను, ప్రింట్ విండోలో Destination ఎంపికను, Save as PDF ఎంపికను వివరిస్తోంది (Google: Print from Chrome).

Android ఫోన్‌లో

Android లో Chrome లోనూ ఇదే ఎంపిక ఉంది. Google చెప్పిన దశలు: More > Share నొక్కి, Print నొక్కి, తర్వాత Save as PDF నొక్కి ఫైల్ ఎక్కడ సేవ్ చేయాలో ఎంచుకోండి (Google: Print from Chrome on Android). మీ ఫోన్‌లో ఉన్న PDF ను Chrome తెరుస్తుందా అనేది Chrome వెర్షన్‌ను బట్టి ఉంటుంది. తెరవకపోతే మా Android లో పాస్‌వర్డ్ ఉన్న PDF తెరవడం గైడ్ చూడండి.

ఈ పద్ధతిలో ఏం కోల్పోతారు

ప్రింట్ విండో ద్వారా సేవ్ చేస్తే, స్క్రీన్‌పై ఉన్నదాని నుంచి సరికొత్త PDF తయారవుతుంది. చదవడానికి, భద్రపరచడానికి లేదా స్టేట్‌మెంట్ అప్‌లోడ్ చేయడానికి ఇది సరిపోతుంది. కానీ అసలు ఫైల్ తొలగించే ముందు కాపీని పరిశీలించండి:

  • లింకులు, బుక్‌మార్క్‌లు పనిచేయకపోవచ్చు.
  • ఫారమ్ ఫీల్డ్‌లు సమతలమై, ఇకపై వాటిలో టైప్ చేయలేకపోవచ్చు.
  • డిజిటల్ సంతకాలు కొనసాగవు. పోర్టల్‌కు సంతకం ఉన్న అసలు ఫైల్ కావాలంటే, అసలుదాన్నే అప్‌లోడ్ చేయండి.
  • పేజీ సైజు ప్రింట్ సెట్టింగ్స్‌ను అనుసరిస్తుంది. More settings కింద, కాగితం సైజు, స్కేల్ పేజీలను కుదించలేదని, కత్తిరించలేదని చూసుకోండి.

Save as PDF పనిచేయకపోతే

  • ప్రింటింగ్ నిరోధించబడింది. కొన్ని PDF లకు ప్రింటింగ్‌ను ఆపే అనుమతుల పాస్‌వర్డ్ ఉంటుంది. అనుమతుల పాస్‌వర్డ్ open పాస్‌వర్డ్ కంటే వేరు. PDF ప్రింటింగ్, కాపీ పరిమితుల వివరణ చూడండి.
  • Chrome పాస్‌వర్డ్‌ను తిరస్కరిస్తోంది. పెద్దక్షరాలు, తేదీ ఫార్మాట్, మీ బ్యాంక్ రికార్డుల్లోని వివరాలు చూడండి. PDF పాస్‌వర్డ్ ఎందుకు పనిచేయడం లేదు చూడండి.
  • ఫైల్ వేరే యాప్‌లో తెరుచుకుంది. కొన్ని కంప్యూటర్లు PDF లను డిఫాల్ట్‌గా వేరే రీడర్‌లో తెరుస్తాయి. బదులుగా ఫైల్‌ను Chrome ట్యాబ్‌లోకి లాగండి.

పాస్‌వర్డ్ తీసేయడానికి ఇతర మార్గాలు

Windows లో Microsoft Edge కూడా ఇలాగే పనిచేస్తుంది (Windows లో PDF పాస్‌వర్డ్ తీసేయడం చూడండి). Mac లో Preview పాస్‌వర్డ్ లేని కాపీని ఎగుమతి చేయగలదు (Mac గైడ్). iPhone, iPad, Mac లో UnKey అన్‌లాక్ చేసిన కాపీని ఆఫ్‌లైన్‌లో సేవ్ చేస్తుంది, ఫైల్‌ను మళ్లీ ప్రింట్ చేయకుండా ఎన్‌క్రిప్షన్‌ను తీసేస్తుంది కాబట్టి టెక్స్ట్, లింకులు, పేజీలు యథాతథంగా ఉంటాయి. Chrome లాగే, ఇది మీకు ఇప్పటికే తెలిసిన పాస్‌వర్డ్‌తో మాత్రమే పనిచేస్తుంది.

ప్రశ్నలు

ఇలా చేసినప్పుడు Chrome నా PDF ను అప్‌లోడ్ చేస్తుందా?

లేదు. మీ కంప్యూటర్‌లోని PDF ఫైల్‌ను తెరిచి Save as PDF తో సేవ్ చేయడం మీ కంప్యూటర్‌లోని బ్రౌజర్‌లోనే జరుగుతుంది. Drive లో కాపీ కావాలంటే మాత్రమే వేరుగా ఉన్న “Save to Google Drive” ఎంపిక వాడండి.

నాకు తెలియని పాస్‌వర్డ్‌ను Chrome తీసేయగలదా?

లేదు. ఏదైనా చూపే ముందే Chrome పాస్‌వర్డ్ అడుగుతుంది. పోగొట్టుకుంటే PDF పాస్‌వర్డ్ మర్చిపోతే ఏం చేయాలో చూడండి.

సేవ్ చేసిన కాపీ అసలు ఫైల్ కంటే ఎందుకు భిన్నంగా ఉంది?

Save as PDF పేజీలను కొత్త ఫైల్‌లోకి ప్రింట్ చేస్తుంది, కాబట్టి లింకులు, ఫారమ్ ఫీల్డ్‌లు, సంతకాలు మిగలకపోవచ్చు. టెక్స్ట్, లేఅవుట్ సాధారణంగా అలాగే కనిపిస్తాయి.

ఇది అనుమతించబడిందా?

మీ బ్యాంక్ స్టేట్‌మెంట్ వంటి మీ సొంత డాక్యుమెంట్లకు అవును. స్వేచ్ఛగా తెరిచే హక్కు లేని ఫైళ్ల రక్షణను తీసేయవద్దు.

ఫార్మాట్‌లు మారవచ్చు. పాస్‌వర్డ్ పని చేయకపోతే, డాక్యుమెంట్‌తో వచ్చిన ఇమెయిల్ చూడండి లేదా జారీ చేసిన సంస్థను సంప్రదించండి. ఇక్కడ పేర్కొన్న ఏ బ్యాంకు, యజమాని లేదా అధికార సంస్థతోనూ UnKeyకి సంబంధం లేదు.

ఇంగ్లిష్ నుండి అనువదించబడింది. ఏదైనా తేడా ఉంటే, ఇంగ్లిష్ పేజీనే ప్రామాణికం.

ఒక్కసారి అన్‌లాక్ చేయండి.

మీరు ఇప్పటికే తెరవగలిగే PDFల నుండి UnKey పాస్‌వర్డ్‌ను తొలగిస్తుంది, iPhone, iPad, Macలో. ఆఫ్‌లైన్‌లో పని చేస్తుంది, ఏదీ అప్‌లోడ్ కాదు. పాస్‌వర్డ్‌ను ఒక్కసారి సేవ్ చేయండి, వచ్చే నెల స్టేట్‌మెంట్‌ను Face ID తెరుస్తుంది.
