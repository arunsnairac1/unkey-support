Windows वर PDF चा पासवर्ड कसा काढावा (२०२६)

ऑक्टोबर 2026 रोजी अपडेट केले

या भाषेत वाचा: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

PDF पासवर्डसह Microsoft Edge किंवा Chrome मध्ये उघडा, Ctrl+P दाबा, Save as PDF (किंवा Microsoft Print to PDF) निवडा आणि नवी प्रत सेव्ह करा; सशुल्क Acrobat थेट सुरक्षा काढू शकते.

Windows 10 आणि 11 वर तुमच्याकडे आधीपासून असलेल्या ब्राउझरने तुम्ही PDF चा पासवर्ड मोफत काढू शकता. PDF Microsoft Edge किंवा Google Chrome मध्ये उघडा, पासवर्ड टाइप करा, Ctrl + P दाबा, प्रिंटर म्हणून Save as PDF (किंवा Microsoft Print to PDF) निवडा आणि सेव्ह करा. नवी फाइल पासवर्डशिवाय उघडते. आधी पासवर्ड तुम्हाला माहीत असणे आवश्यक आहे.

पद्धत १: Microsoft Edge (अंगभूत)

  1. File Explorer मध्ये PDF वर राइट-क्लिक करा आणि Open with > Microsoft Edge निवडा.
  2. Edge पासवर्ड मागेल तेव्हा तो टाइप करा.
  3. Ctrl + P दाबा, किंवा More मेनू (तीन ठिपके) उघडून Print निवडा.
  4. Printer खाली Save as PDF किंवा Microsoft Print to PDF निवडा.
  5. Save (किंवा Print) वर क्लिक करा, फोल्डर निवडा आणि प्रतीला नवीन नाव द्या.
  6. नवी फाइल उघडून ती पासवर्ड विचारत नाही याची खात्री करा.

Microsoft चे अंगभूत PDF रीडरचे मार्गदर्शक Edge चा मार्ग दाखवते: More मेनूखाली Print शोधा, पर्याय निवडा, मग प्रिंट करा (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF हा Windows सोबत येणारा प्रिंटर आहे. तो यादीत नसेल तर Windows Optional Features मध्ये तो पुन्हा चालू करता येतो असे Microsoft म्हणते (Microsoft: KB5058499 known issue).

पद्धत २: Google Chrome

तुम्ही Chrome वापरत असाल तर पायऱ्या जवळजवळ सारख्याच आहेत: PDF Chrome मध्ये उघडा, पासवर्ड टाका, Ctrl + P दाबा, Destination म्हणून Save as PDF निवडा आणि Save वर क्लिक करा (Google: Print from Chrome). अधिक तपशील आमच्या Chrome मार्गदर्शकात आहेत.

पद्धत ३: Adobe Acrobat Pro किंवा Standard (सशुल्क)

सशुल्क Acrobat फाइल पुन्हा प्रिंट करण्याऐवजी एन्क्रिप्शनच काढते, त्यामुळे लिंक आणि फॉर्म फील्ड तशीच राहतात. Adobe दोन मार्ग सांगते (Adobe: Remove passwords from PDFs):

  • Protect टूल्स: PDF उघडा, Protect टूल्समध्ये जा आणि Remove Security निवडा. फाइलला फक्त ओपन पासवर्ड असेल तर OK ने पुष्टी करा. तिला परवानगी पासवर्डही असेल तर Acrobat आधी तो पासवर्ड मागते.
  • Security settings: कागदपत्राचे security properties उघडा, Security टॅबवर जा, Change Settings निवडा, पासवर्ड पर्याय काढून टाका आणि सेव्ह करा.

Adobe चे मेनू आवृत्त्यांनुसार हलतात, त्यामुळे ही नेमकी नावे दिसत नसतील तर Acrobat च्या टूल सर्चमध्ये “Remove Security” शोधा. मोफत Acrobat Reader संरक्षित PDF उघडू शकते पण सुरक्षा काढण्याचे टूल ते नाही. त्याऐवजी पद्धत १ किंवा २ वापरा.

पद्धत ४: qpdf (तांत्रिक वापरकर्त्यांसाठी)

मोफत, ओपन-सोर्स qpdf टूल Windows वर चालते. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf एन्क्रिप्शनशिवायची प्रत लिहिते (qpdf documentation). पासवर्ड तुमच्या कमांड हिस्टरीमध्ये सेव्ह होऊ शकतो, म्हणून शेअर केलेल्या PC वर नंतर तो पुसून टाका.

तपासण्याच्या गोष्टी

  • Print धूसर आहे? PDF मध्ये प्रिंटिंग थांबवणारा परवानगी पासवर्ड असू शकतो. प्रिंटिंग आणि कॉपी बंधने पाहा.
  • पासवर्ड नाकारला? Caps Lock, तारखेचा फॉरमॅट आणि बँकेकडे असलेली तुमची माहिती तपासा. PDF पासवर्ड का चालत नाही पाहा.
  • शेअर केलेला किंवा ऑफिसचा PC? अनलॉक केलेली प्रत ज्याला सापडेल त्याला उघडता येते. ती खासगी फोल्डरमध्ये सेव्ह करा आणि Downloads मधून डिलीट करा.

तुमच्याकडे iPhone, iPad किंवा Mac असेल, तर UnKey त्या डिव्हाइसवर ऑफलाइन पासवर्ड काढते आणि पुढच्या महिन्याच्या स्टेटमेंटसाठी पासवर्ड सेव्ह करू शकते. Windows साठी UnKey अ‍ॅप नाही.

प्रश्न

Windows वर काही इंस्टॉल करावे लागते का?

नाही. Microsoft Edge आणि Microsoft Print to PDF प्रिंटर Windows 10 आणि 11 सोबत येतात.

ऑनलाइन “unlock PDF” साइट्स जास्त चांगल्या चालतात का?

त्या तेच काम करतात, पण तुमचे कागदपत्र दुसऱ्याच्या सर्व्हरवर अपलोड करतात. बँक स्टेटमेंट आणि कर कागदपत्रांसाठी येथील ऑफलाइन पद्धती अधिक सुरक्षित आहेत.

यापैकी कोणतीही पद्धत विसरलेला पासवर्ड काढू शकते का?

नाही. Edge, Chrome, Acrobat आणि qpdf सर्वांना बरोबर पासवर्ड लागतो. फॉरमॅटसाठी PDF सोबत आलेला ईमेल तपासा.

प्रतीमध्ये लिंक चालेनाशा का होतात?

PDF मध्ये प्रिंट केल्याने पाने पुन्हा बनवली जातात आणि त्यात लिंक व फॉर्म फील्ड गळू शकतात. Acrobat चे Remove Security किंवा qpdf त्या टिकवतात.

स्रोत

  • Microsoft Support – View, print, and edit PDFs in a PDF reader
  • Microsoft Support – KB5058499 (Microsoft Print to PDF known issue)
  • Google Chrome Help – Print from Chrome
  • Adobe – Remove passwords from PDFs in Acrobat
  • qpdf – Command-line options

फॉरमॅट बदलू शकतात. पासवर्ड चालला नाही, तर दस्तऐवजासोबत आलेला ईमेल पाहा किंवा जारीकर्त्याशी संपर्क साधा. येथे नमूद केलेल्या कोणत्याही बँक, नियोक्ता किंवा प्राधिकरणाशी UnKey चा संबंध नाही.

इंग्रजीतून भाषांतरित. काही फरक असल्यास इंग्रजी पेज हाच आधार.

एकदाच अनलॉक करा.

तुम्ही आधीच उघडू शकता अशा PDF मधून UnKey पासवर्ड काढून टाकतो, iPhone, iPad आणि Mac वर. ऑफलाइन चालते, काहीही अपलोड होत नाही. पासवर्ड एकदा सेव्ह करा, पुढच्या महिन्याचे स्टेटमेंट Face ID उघडेल.
