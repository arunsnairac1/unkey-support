Mac वर PDF मधून पासवर्ड कसा काढावा (२०२६)

ऑक्टोबर 2026 रोजी अपडेट केले

या भाषेत वाचा: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

PDF पासवर्डसह Preview मध्ये उघडा, File > Export निवडा, ओपन पासवर्ड लावलेला नाही याची खात्री करा आणि नवी प्रत सेव्ह करा.

Mac वर तुम्ही macOS सोबत येणाऱ्या Preview अ‍ॅपने PDF चा पासवर्ड मोफत काढू शकता. PDF उघडा, पासवर्ड टाका, मग File > Export निवडा आणि ओपन पासवर्ड नसलेली नवी प्रत सेव्ह करा. पासवर्ड माहीत असणे आवश्यक आहे. त्याशिवाय Preview फाइल उघडणार नाही.

पद्धत १: Preview, File > Export

  1. PDF वर डबल-क्लिक करून Preview मध्ये उघडा आणि पासवर्ड टाका.
  2. File > Export निवडा आणि प्रतीला नवीन नाव द्या, उदा. “Statement-Oct-unlocked”.
  3. Permissions वर क्लिक करा आणि Require Password To Open Document निवडलेले नाही याची खात्री करा. जुन्या macOS आवृत्त्यांमध्ये Export विंडोमध्ये त्याऐवजी Encrypt चेकबॉक्स असतो. तो रिकामा ठेवा.
  4. Save वर क्लिक करा.
  5. नवी फाइल बंद करून पुन्हा उघडा. ती पासवर्ड न विचारता उघडली पाहिजे.

Apple चे सध्याचे मार्गदर्शक Export विंडो, Permissions बटण आणि Require Password To Open Document पर्यायाचे वर्णन करते (Apple: Password-protect a PDF in Preview on Mac). याच पानाच्या macOS Big Sur आवृत्तीत Apple ने थेट म्हटले होते: “तुम्ही एन्क्रिप्ट केलेल्या PDF मधून पासवर्ड काढण्यासाठी PDF उघडा आणि ती पुन्हा एक्सपोर्ट करा, यावेळी एन्क्रिप्शन पर्याय बंद ठेवून” (Apple, macOS Big Sur guide).

PDF मध्ये मालक (परवानगी) पासवर्डही असेल आणि तो तुम्हाला माहीत असेल, तर File > Edit Permissions मधून तुम्ही ओपनिंग पासवर्ड आणि कोणत्या सुविधांना पासवर्ड लागतो ते बदलू शकता.

पद्धत २: Print > Save as PDF

प्रिंट करू शकणारे कोणतेही Mac अ‍ॅप नवी PDF तयार करू शकते (Apple: Save a document as a PDF on Mac):

  1. PDF पासवर्डसह उघडा.
  2. File > Print निवडा.
  3. PDF पॉप-अप मेनूवर क्लिक करा आणि Save as PDF निवडा.
  4. Security Options वर क्लिक करू नका, कारण पासवर्ड परत लावण्याची जागा तीच आहे.

प्रिंट केलेल्या प्रतीमधील लिंक, फॉर्म फील्ड किंवा बुकमार्क गमावले जाऊ शकतात. कागदपत्र प्रिंटिंग रोखत असेल तर ही पद्धत धूसर असू शकते.

पद्धत ३: Mac साठी UnKey

UnKey Mac वरही मोफत आहे. UnKey Pro, जी एकदाच करायची खरेदी आहे, iPhone, iPad आणि Mac वर एकाच वेळी अनेक फाइल अनलॉक करणे आणि इतर Pro टूल्स देते. PDF विंडोवर ड्रॅग करा, पासवर्ड टाका आणि ते अनलॉक केलेली प्रत सेव्ह करते. UnKey Pro एकाच वेळी अनेक फाइलही अनलॉक करू शकते, जे एकच पासवर्ड असलेल्या वर्षभराच्या मासिक स्टेटमेंटसाठी उपयुक्त आहे. UnKey ऑफलाइन चालते, काहीही अपलोड करत नाही आणि फक्त तुम्हाला आधीच माहीत असलेले पासवर्ड काढते.

पद्धत ४: कमांड लाइन (तांत्रिक वापरकर्त्यांसाठी)

मोफत, ओपन-सोर्स टूल qpdf हे Terminal मध्ये करू शकते: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. त्याचे दस्तऐवजीकरण --decrypt चे वर्णन “इनपुट फाइल एन्क्रिप्टेड असली तरी एन्क्रिप्शनशिवाय आउटपुट फाइल तयार करणे” असे करते (qpdf documentation). ते तुम्हाला स्वतः इंस्टॉल करावे लागते, उदा. Homebrew ने. कमांड लाइनवर पासवर्ड टाइप केल्याने तो तुमच्या शेल हिस्टरीमध्ये राहू शकतो.

तरीही पासवर्ड विचारत असेल तर

  • तुम्ही प्रतीऐवजी मूळ फाइल उघडली असेल. फाइलचे नाव तपासा.
  • पुन्हा एक्सपोर्ट करा आणि Permissions मध्ये Require Password To Open Document बंद आहे याची खात्री करा.
  • त्याऐवजी Print > Save as PDF वापरून पाहा.
  • Preview ने पासवर्ड नाकारला तर कॅपिटल अक्षरे आणि तारखेचा फॉरमॅट तपासा, आणि कागदपत्रासोबत आलेला ईमेल वाचा.

मूळ फाइल डिलीट करण्यापूर्वी

अनलॉक केलेली PDF फाइल असलेल्या कोणालाही उघडता येते. यात कुटुंबासोबत शेअर केलेले iCloud Drive फोल्डर आणि तुमचा Mac उसना घेणारे कोणीही येतात. अनलॉक केलेली स्टेटमेंट खासगी ठिकाणी ठेवा. अधिक माहितीसाठी PDF पासवर्ड काढणे सुरक्षित आहे का ते पाहा.

प्रश्न

Preview खरोखर मोफत आहे का?

हो. Preview प्रत्येक Mac सोबत येते आणि तुम्ही पासवर्ड टाकल्यावर ओपन पासवर्डशिवाय PDF एक्सपोर्ट करू शकते.

मला माहीत नसलेला पासवर्ड Preview काढू शकते का?

नाही. Preview फाइल उघडण्यापूर्वी पासवर्ड विचारते, आणि त्यावर कायदेशीर मार्ग नाही.

Mac वर एकाच वेळी अनेक PDF अनलॉक कशा कराव्यात?

Preview एका वेळी एकच फाइल हाताळते. UnKey Pro एकच पासवर्ड असलेल्या अनेक PDF एकत्र अनलॉक करू शकते, आणि तांत्रिक वापरकर्ते qpdf ची स्क्रिप्ट करू शकतात. एकाच वेळी अनेक PDF अनलॉक करण्याचे आमचे मार्गदर्शक पाहा.

Print > Save as PDF धूसर का आहे?

PDF मध्ये प्रिंटिंग रोखणारा परवानगी पासवर्ड असू शकतो. मालक पासवर्ड माहीत असेल तर File > Edit Permissions मध्ये तो टाका. नाहीतर Export पद्धत वापरा.
