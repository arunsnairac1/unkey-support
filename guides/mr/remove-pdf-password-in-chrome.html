Chrome मध्ये PDF चा पासवर्ड कसा काढावा (२०२६)

ऑक्टोबर 2026 रोजी अपडेट केले

या भाषेत वाचा: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

PDF पासवर्डसह Chrome मध्ये उघडा, Ctrl+P किंवा Cmd+P दाबा, Destination म्हणून Save as PDF निवडा आणि पासवर्डशिवाय नवी प्रत सेव्ह करा.

Google Chrome पासवर्ड असलेल्या PDF ची पासवर्डशिवायची प्रत Windows, Mac आणि Linux वर मोफत सेव्ह करू शकते. PDF Chrome मध्ये उघडा, पासवर्ड टाका, Ctrl + P दाबा (Mac वर Cmd + P), Destination म्हणून Save as PDF निवडा आणि सेव्ह करा. पासवर्ड तुम्हाला आधीच माहीत असणे आवश्यक आहे. त्याशिवाय Chrome फाइल उघडू शकत नाही.

पायरी पायरीने (संगणकावर)

  1. PDF Chrome विंडोमध्ये ड्रॅग करा, किंवा फाइलवर राइट-क्लिक करून Open with > Google Chrome निवडा.
  2. Chrome पासवर्ड मागते. तो टाइप करा आणि Enter दाबा.
  3. Windows किंवा Linux वर Ctrl + P, किंवा Mac वर Cmd + P दाबा. तुम्ही मेनूही वापरू शकता: File > Print.
  4. प्रिंट विंडोमध्ये Destination म्हणून Save as PDF निवडा.
  5. Save वर क्लिक करा. नव्या फाइलला स्पष्ट नाव द्या, जसे की Statement-Sep-2026-unlocked.pdf.
  6. ती बंद करून नवी फाइल पुन्हा उघडा. ती लगेच, पासवर्ड न विचारता उघडली पाहिजे.

Google चे मदत पान कीबोर्ड शॉर्टकट, प्रिंट विंडोमध्ये Destination निवडणे आणि Save as PDF पर्यायाबद्दल सांगते (Google: Print from Chrome).

Android फोनवर

Android वरील Chrome मध्येही हाच पर्याय आहे. Google च्या पायऱ्या: More > Share वर टॅप करा, Print वर टॅप करा, मग Save as PDF वर टॅप करा आणि फाइल कुठे सेव्ह करायची ते निवडा (Google: Print from Chrome on Android). तुमच्या फोनवर साठवलेली PDF Chrome उघडेल की नाही हे Chrome च्या आवृत्तीवर अवलंबून असते. उघडत नसेल तर आमचे Android वर पासवर्ड असलेली PDF उघडणे हे मार्गदर्शक पाहा.

या पद्धतीत काय गमावले जाते

प्रिंट विंडोमधून सेव्ह केल्याने स्क्रीनवर दिसणाऱ्या गोष्टींवरून पूर्णपणे नवी PDF तयार होते. वाचण्यासाठी, संग्रहासाठी किंवा स्टेटमेंट अपलोड करण्यासाठी हे चालते. पण मूळ फाइल डिलीट करण्यापूर्वी प्रत तपासा:

  • लिंक आणि बुकमार्क चालेनासे होऊ शकतात.
  • फॉर्म फील्ड सपाट होऊ शकतात, म्हणजे त्यात पुन्हा टाइप करता येणार नाही.
  • डिजिटल सह्या पुढे येत नाहीत. पोर्टलला सही केलेली मूळ फाइल हवी असेल तर मूळ फाइल अपलोड करा.
  • पानाचा आकार प्रिंट सेटिंग्जनुसार ठरतो. More settings मध्ये कागदाचा आकार आणि स्केल यामुळे पाने लहान किंवा क्रॉप झाली नाहीत ना ते तपासा.

Save as PDF चालत नसेल तर

  • प्रिंटिंग ब्लॉक केलेले आहे. काही PDF मध्ये प्रिंटिंग थांबवणारा परवानगी पासवर्ड असतो. परवानगी पासवर्ड ओपन पासवर्डपेक्षा वेगळा असतो. PDF प्रिंटिंग आणि कॉपी बंधने समजून घ्या पाहा.
  • Chrome पासवर्ड नाकारते. कॅपिटल अक्षरे, तारखेचा फॉरमॅट आणि बँकेकडे असलेली तुमची माहिती तपासा. PDF पासवर्ड का चालत नाही पाहा.
  • फाइल दुसऱ्या अ‍ॅपमध्ये उघडली. काही संगणक PDF डिफॉल्टने वेगळ्या रीडरमध्ये उघडतात. त्याऐवजी फाइल Chrome च्या टॅबमध्ये ड्रॅग करा.

पासवर्ड काढण्याचे इतर मार्ग

Microsoft Edge Windows वर असेच काम करते (Windows वर PDF पासवर्ड काढणे पाहा). Mac वर Preview पासवर्डशिवायची प्रत एक्सपोर्ट करू शकते (Mac मार्गदर्शक). iPhone, iPad आणि Mac वर UnKey ऑफलाइन अनलॉक केलेली प्रत सेव्ह करते आणि मजकूर, लिंक व पाने जशी होती तशी ठेवते, कारण ते फाइल पुन्हा प्रिंट करण्याऐवजी एन्क्रिप्शन काढते. Chrome प्रमाणेच ते तुम्हाला आधीच माहीत असलेल्या पासवर्डवरच चालते.

प्रश्न

हे करताना Chrome माझी PDF अपलोड करते का?

नाही. संगणकावरील PDF फाइल उघडून Save as PDF ने सेव्ह करणे तुमच्या संगणकावरील ब्राउझरमध्येच होते. Drive मध्ये प्रत हवी असेल तेव्हाच वेगळा “Save to Google Drive” पर्याय वापरा.

मला माहीत नसलेला पासवर्ड Chrome काढू शकते का?

नाही. Chrome काहीही दाखवण्यापूर्वी पासवर्ड विचारते. तो हरवला असेल तर PDF पासवर्ड विसरल्यास काय करावे ते पाहा.

सेव्ह केलेली प्रत मूळ फाइलपेक्षा वेगळी का असते?

Save as PDF पाने नव्या फाइलमध्ये प्रिंट करते, त्यामुळे लिंक, फॉर्म फील्ड आणि सह्या टिकणार नाहीत. मजकूर आणि मांडणी सहसा सारखी दिसते.

हे करण्याची परवानगी आहे का?

तुमच्या स्वतःच्या कागदपत्रांसाठी, जसे की बँक स्टेटमेंट, हो. जी फाइल मोकळेपणाने उघडण्याचा तुम्हाला अधिकार नाही तिचे संरक्षण काढू नका.

एकदाच अनलॉक करा.

तुम्ही आधीच उघडू शकता अशा PDF मधून UnKey पासवर्ड काढून टाकतो, iPhone, iPad आणि Mac वर. ऑफलाइन चालते, काहीही अपलोड होत नाही. पासवर्ड एकदा सेव्ह करा, पुढच्या महिन्याचे स्टेटमेंट Face ID उघडेल.
