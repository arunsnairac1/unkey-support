ಮೂಲ

2026ರ ಅಕ್ಟೋಬರ್‌ನಂತೆ, Karur Vysya Bank (KVB) ಸ್ಟೇಟ್‌ಮೆಂಟ್ PDF ಗಳು ನಿಮ್ಮ Customer ID ಅನ್ನು ಖಾಲಿ ಜಾಗವಿಲ್ಲದೆ ಇರುವಂತೆಯೇ ಟೈಪ್ ಮಾಡಿದಾಗ ತೆರೆಯುತ್ತವೆ ಎಂದು ವರದಿಯಾಗಿದೆ. ಸೆಂಥಿಲ್ ಕುಮಾರ್ ಅವರ Customer ID 881234567 ಆಗಿದ್ದರೆ, ಪಾಸ್‌ವರ್ಡ್ 881234567 ಆಗಿರುತ್ತದೆ.

ಪಾಸ್‌ವರ್ಡ್ ಫಾರ್ಮ್ಯಾಟ್

KVB ತನ್ನ ವೆಬ್‌ಸೈಟ್‌ನಲ್ಲಿ PDF ಪಾಸ್‌ವರ್ಡ್ ನಿಯಮವನ್ನು ಪ್ರಕಟಿಸಿಲ್ಲ. ಆದ್ದರಿಂದ ಈ ಪುಟದಲ್ಲಿರುವ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಪರಸ್ಪರ ಹೊಂದಿಕೆಯಾಗುವ ಸ್ವತಂತ್ರ ಮಾರ್ಗದರ್ಶಿಗಳಿಂದ ಬಂದಿವೆ. ಇವನ್ನು ಸಾಮಾನ್ಯವಾಗಿ ವರದಿಯಾದ ಮಾಹಿತಿ ಎಂದು ಪರಿಗಣಿಸಿ, ಅಧಿಕೃತವಾಗಿ ದೃಢಪಟ್ಟದ್ದು ಎಂದಲ್ಲ. ನಿಮ್ಮ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ತಂದ ಇಮೇಲ್ ಅಥವಾ ಸಂದೇಶದಲ್ಲಿ ನಿಖರವಾದ ಫಾರ್ಮ್ಯಾಟ್ ಇರುತ್ತದೆ; ಅದನ್ನೇ ನಂಬಿ.

Easemoney ಮತ್ತು ScanPilot ಎರಡೂ Customer ID ಎಂದು ವರದಿ ಮಾಡುತ್ತವೆ. ScanPilot ಎರಡು ಪರ್ಯಾಯಗಳನ್ನು ಸೂಚಿಸುತ್ತದೆ: DDMMYYYY ರೂಪದ ಹುಟ್ಟಿದ ದಿನಾಂಕ, ನಂತರ ಖಾತೆ ಸಂಖ್ಯೆಯ ಕೊನೆಯ 4 ಅಂಕೆ + DDMM. ಮೂರನೇ ಮಾರ್ಗದರ್ಶಿ TaxFetch Customer ID ನಂತರ DDMMYYYY ಎಂದು ವರದಿ ಮಾಡುತ್ತದೆ.

ಉದಾಹರಣೆ

ಸೆಂಥಿಲ್ ಕುಮಾರ್ (ಕಾಲ್ಪನಿಕ) ಅವರ Customer ID 881234567, ಖಾತೆ ಸಂಖ್ಯೆ 6789 ರಲ್ಲಿ ಕೊನೆಗೊಳ್ಳುತ್ತದೆ, ಮತ್ತು ಅವರು 22 ಜುಲೈ 1988ರಂದು ಜನಿಸಿದ್ದಾರೆ. ಕ್ರಮವಾಗಿ:

  1. 881234567 (Customer ID)
  2. 22071988 (ಹುಟ್ಟಿದ ದಿನಾಂಕ)
  3. 67892207 (ಖಾತೆಯ ಕೊನೆಯ 4 ಅಂಕೆ + DDMM)
  4. 88123456722071988 (Customer ID + DDMMYYYY)

ಪಾಸ್‌ವರ್ಡ್ ಕೆಲಸ ಮಾಡದಿದ್ದರೆ

  • Customer ID, ಖಾತೆ ಸಂಖ್ಯೆ ಅಲ್ಲ. ಇವು ಬೇರೆ ಬೇರೆ ಸಂಖ್ಯೆಗಳು.
  • ನಿಮ್ಮ Customer ID ಹುಡುಕಿ. ಇದು ನಿಮ್ಮ ಪಾಸ್‌ಬುಕ್‌ನ ಮೊದಲ ಪುಟದಲ್ಲಿ, ವೆಲ್‌ಕಮ್ ಕಿಟ್‌ನಲ್ಲಿ ಮತ್ತು KVB DLite ಆ್ಯಪ್‌ನಲ್ಲಿ ಇರುತ್ತದೆ. ನೋಂದಾಯಿತ ಮೊಬೈಲ್‌ನಿಂದ ಮಿಸ್ಡ್ ಕಾಲ್ ಕೊಟ್ಟರೆ SMS ಮೂಲಕ ಕಳಿಸುವ ಸೇವೆ ಇದೆ ಎಂದು Easemoney ವರದಿ ಮಾಡಿದೆ.
  • ಬದಲಿಗೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. KVB ನೆಟ್ ಬ್ಯಾಂಕಿಂಗ್ ಅಥವಾ DLite ನಲ್ಲಿ ನೋಡುವ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳಿಗೆ ಪಾಸ್‌ವರ್ಡ್ ಬೇಕಾಗದಿರಬಹುದು.
  • ಆ ಫೈಲ್‌ನ ಫಾರ್ಮ್ಯಾಟ್ ತಿಳಿಸುವ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಇಮೇಲ್ ಓದಿ, ಅಥವಾ ನಿಮ್ಮ ಶಾಖೆಯನ್ನು ಕೇಳಿ.

ಮತ್ತೆ ಮತ್ತೆ ಟೈಪ್ ಮಾಡಬೇಕಾಗಿಲ್ಲದಂತೆ ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು

ಪಾಸ್‌ವರ್ಡ್ ಗೊತ್ತಿದ್ದರೆ, ನಿಮ್ಮ KVB ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ನ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದೆ ತೆರೆಯುವ ಒಂದು ಪ್ರತಿಯನ್ನು ಇಟ್ಟುಕೊಳ್ಳಬಹುದು. ಸಾಲ, ವೀಸಾ ಅಥವಾ ತೆರಿಗೆ ಪೋರ್ಟಲ್ ಲಾಕ್ ಆದ ಫೈಲ್‌ಗಳನ್ನು ಒಪ್ಪದಿದ್ದಾಗಲೂ ಇದು ಉಪಯುಕ್ತ. iPhone, iPad ಅಥವಾ Mac ನಲ್ಲಿ UnKey ಬಳಸಬಹುದು: PDF ತೆರೆದು, ಪಾಸ್‌ವರ್ಡ್ ಒಮ್ಮೆ ನೀಡಿ, ಅನ್‌ಲಾಕ್ ಆದ ಪ್ರತಿಯನ್ನು ಉಳಿಸಿ. ಇದು ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಏನೂ ಅಪ್‌ಲೋಡ್ ಆಗುವುದಿಲ್ಲ, ಮತ್ತು ನೀವು ಉಳಿಸಲು ಆರಿಸಿದ ಪಾಸ್‌ವರ್ಡ್ Face ID ಅಥವಾ Touch ID ರಕ್ಷಣೆಯಲ್ಲಿ ನಿಮ್ಮ ಸಾಧನದ Keychain ನಲ್ಲಿ ಇರುತ್ತದೆ. UnKey ನಿಮಗೆ ಈಗಾಗಲೇ ಗೊತ್ತಿರುವ ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು ಮಾತ್ರ ತೆಗೆಯುತ್ತದೆ; ಊಹಿಸಲು ಅಥವಾ ಭೇದಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ. Android ನಲ್ಲಿ PDF ಅನ್ನು Google Files, Google Drive ಅಥವಾ Adobe Acrobat ನಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ನೀಡಿ ತೆರೆಯಬಹುದು, ಮತ್ತು PDF ಗೆ ಪ್ರಿಂಟ್ ಮಾಡಿದರೆ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದ ಪ್ರತಿ ಸಿಗುತ್ತದೆ. ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಹೆಚ್ಚಿನ ಬ್ರೌಸರ್‌ಗಳ print-to-PDF ಆಯ್ಕೆಯೂ ಇದನ್ನೇ ಮಾಡುತ್ತದೆ.

ಪ್ರಶ್ನೆಗಳು

KVB ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಪಾಸ್‌ವರ್ಡ್ ಏನು?

ಇದು ನಿಮ್ಮ Customer ID ಎಂದು ವರದಿಯಾಗಿದೆ. KVB ಫಾರ್ಮ್ಯಾಟ್ ಅನ್ನು ಪ್ರಕಟಿಸಿಲ್ಲ, ಹಾಗಾಗಿ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಇಮೇಲ್ ನೋಡಿ.

ನನ್ನ KVB Customer ID ಎಲ್ಲಿದೆ?

ನಿಮ್ಮ ಪಾಸ್‌ಬುಕ್‌ನ ಮೊದಲ ಪುಟದಲ್ಲಿ, ವೆಲ್‌ಕಮ್ ಕಿಟ್‌ನಲ್ಲಿ, ಮತ್ತು KVB DLite ಆ್ಯಪ್ ಹಾಗೂ ನೆಟ್ ಬ್ಯಾಂಕಿಂಗ್‌ನಲ್ಲಿ.

Customer ID ಕೆಲಸ ಮಾಡದಿದ್ದರೆ ಏನು?

DDMMYYYY ರೂಪದ ಹುಟ್ಟಿದ ದಿನಾಂಕ ಪ್ರಯತ್ನಿಸಿ, ನಂತರ ಖಾತೆ ಸಂಖ್ಯೆಯ ಕೊನೆಯ 4 ಅಂಕೆ + DDMM, ನಂತರ Customer ID + DDMMYYYY.

ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಬದಲಾಗಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ಕೆಲಸ ಮಾಡದಿದ್ದರೆ, ದಾಖಲೆಯೊಂದಿಗೆ ಬಂದ ಇಮೇಲ್ ನೋಡಿ ಅಥವಾ ನೀಡಿದ ಸಂಸ್ಥೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ. ಇಲ್ಲಿ ಹೆಸರಿಸಿರುವ ಯಾವುದೇ ಬ್ಯಾಂಕ್, ಉದ್ಯೋಗದಾತ ಅಥವಾ ಪ್ರಾಧಿಕಾರದೊಂದಿಗೆ UnKeyಗೆ ಸಂಬಂಧವಿಲ್ಲ.

ಇಂಗ್ಲಿಷ್‌ನಿಂದ ಅನುವಾದಿಸಲಾಗಿದೆ. ಏನಾದರೂ ವ್ಯತ್ಯಾಸವಿದ್ದರೆ ಇಂಗ್ಲಿಷ್ ಪುಟವೇ ಆಧಾರ.

ಒಮ್ಮೆ ಅನ್‌ಲಾಕ್ ಮಾಡಿ.
