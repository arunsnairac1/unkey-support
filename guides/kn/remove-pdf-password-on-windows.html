ಮಾರ್ಗದರ್ಶಿಗಳು · ಹೇಗೆ ಮಾಡುವುದು

Windows ನಲ್ಲಿ PDF ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು ಹೇಗೆ (2026)

ಅಕ್ಟೋಬರ್ 2026ರಲ್ಲಿ ನವೀಕರಿಸಲಾಗಿದೆ

ಈ ಭಾಷೆಯಲ್ಲಿ ಓದಿ: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · नेपाली · Português · සිංහල · தமிழ் · తెలుగు

PDF ಅನ್ನು ಪಾಸ್‌ವರ್ಡ್‌ನೊಂದಿಗೆ Microsoft Edge ಅಥವಾ Chrome ನಲ್ಲಿ ತೆರೆದು, Ctrl+P ಒತ್ತಿ, Save as PDF (ಅಥವಾ Microsoft Print to PDF) ಆರಿಸಿ ಹೊಸ ಪ್ರತಿ ಉಳಿಸಿ; ಪಾವತಿಸಿದ Acrobat ನೇರವಾಗಿ ಭದ್ರತೆಯನ್ನು ತೆಗೆಯಬಲ್ಲದು.

Windows 10 ಮತ್ತು 11 ನಲ್ಲಿ ನಿಮ್ಮ ಬಳಿ ಈಗಾಗಲೇ ಇರುವ ಬ್ರೌಸರ್‌ನಿಂದ PDF ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು ಉಚಿತವಾಗಿ ತೆಗೆಯಬಹುದು. PDF ಅನ್ನು Microsoft Edge ಅಥವಾ Google Chrome ನಲ್ಲಿ ತೆರೆದು, ಪಾಸ್‌ವರ್ಡ್ ಟೈಪ್ ಮಾಡಿ, Ctrl + P ಒತ್ತಿ, ಪ್ರಿಂಟರ್ ಆಗಿ Save as PDF (ಅಥವಾ Microsoft Print to PDF) ಆರಿಸಿ, ಉಳಿಸಿ. ಹೊಸ ಫೈಲ್ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದೆ ತೆರೆಯುತ್ತದೆ. ಮೊದಲು ನಿಮಗೆ ಪಾಸ್‌ವರ್ಡ್ ತಿಳಿದಿರಬೇಕು.

ವಿಧಾನ 1: Microsoft Edge (ಅಂತರ್ನಿರ್ಮಿತ)

  1. File Explorer ನಲ್ಲಿ PDF ಮೇಲೆ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ Open with > Microsoft Edge ಆರಿಸಿ.
  2. Edge ಕೇಳಿದಾಗ ಪಾಸ್‌ವರ್ಡ್ ಟೈಪ್ ಮಾಡಿ.
  3. Ctrl + P ಒತ್ತಿ, ಅಥವಾ More ಮೆನು (ಮೂರು ಚುಕ್ಕೆಗಳು) ತೆರೆದು Print ಆರಿಸಿ.
  4. Printer ಅಡಿಯಲ್ಲಿ Save as PDF ಅಥವಾ Microsoft Print to PDF ಆರಿಸಿ.
  5. Save (ಅಥವಾ Print) ಕ್ಲಿಕ್ ಮಾಡಿ, ಫೋಲ್ಡರ್ ಆರಿಸಿ, ಪ್ರತಿಗೆ ಹೊಸ ಹೆಸರು ಕೊಡಿ.
  6. ಹೊಸ ಫೈಲ್ ತೆರೆದು ಅದು ಇನ್ನು ಪಾಸ್‌ವರ್ಡ್ ಕೇಳುವುದಿಲ್ಲ ಎಂದು ಪರಿಶೀಲಿಸಿ.

Microsoft ನ ಅಂತರ್ನಿರ್ಮಿತ PDF ರೀಡರ್ ಮಾರ್ಗದರ್ಶಿ Edge ದಾರಿಯನ್ನು ತೋರಿಸುತ್ತದೆ: More ಮೆನು ಅಡಿಯಲ್ಲಿ Print ಹುಡುಕಿ, ಆಯ್ಕೆಗಳನ್ನು ಆರಿಸಿ, ನಂತರ ಪ್ರಿಂಟ್ ಮಾಡಿ (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF Windows ಜೊತೆ ಬರುವ ಪ್ರಿಂಟರ್. ಅದು ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣದಿದ್ದರೆ, Windows Optional Features ಅಡಿಯಲ್ಲಿ ಅದನ್ನು ಮತ್ತೆ ಆನ್ ಮಾಡಬಹುದು ಎಂದು Microsoft ಹೇಳುತ್ತದೆ (Microsoft: KB5058499 known issue).

ವಿಧಾನ 2: Google Chrome

Chrome ಬಳಸುವುದಾದರೆ ಹಂತಗಳು ಬಹುತೇಕ ಅದೇ: PDF ಅನ್ನು Chrome ನಲ್ಲಿ ತೆರೆದು, ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ, Ctrl + P ಒತ್ತಿ, Destination ಅನ್ನು Save as PDF ಗೆ ಹೊಂದಿಸಿ, Save ಕ್ಲಿಕ್ ಮಾಡಿ (Google: Print from Chrome). ನಮ್ಮ Chrome ಮಾರ್ಗದರ್ಶಿ ಯಲ್ಲಿ ಹೆಚ್ಚಿನ ವಿವರಗಳಿವೆ.

ವಿಧಾನ 3: Adobe Acrobat Pro ಅಥವಾ Standard (ಪಾವತಿಸಿದ)

ಪಾವತಿಸಿದ Acrobat ಫೈಲ್ ಅನ್ನು ಮತ್ತೆ ಪ್ರಿಂಟ್ ಮಾಡುವ ಬದಲು ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಅನ್ನೇ ತೆಗೆಯುತ್ತದೆ, ಆದ್ದರಿಂದ ಲಿಂಕ್‌ಗಳು ಮತ್ತು ಫಾರ್ಮ್ ಕ್ಷೇತ್ರಗಳು ಹಾಗೇ ಇರುತ್ತವೆ. Adobe ಎರಡು ದಾರಿಗಳನ್ನು ದಾಖಲಿಸಿದೆ (Adobe: Remove passwords from PDFs):

  • Protect ಟೂಲ್‌ಗಳು: PDF ತೆರೆದು Protect ಟೂಲ್‌ಗಳಿಗೆ ಹೋಗಿ Remove Security ಆರಿಸಿ. ಫೈಲ್‌ಗೆ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಮಾತ್ರ ಇದ್ದರೆ OK ಒತ್ತಿ ದೃಢೀಕರಿಸಿ. ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಕೂಡ ಇದ್ದರೆ, Acrobat ಮೊದಲು ಆ ಪಾಸ್‌ವರ್ಡ್ ಕೇಳುತ್ತದೆ.
  • Security ಸೆಟ್ಟಿಂಗ್‌ಗಳು: ಡಾಕ್ಯುಮೆಂಟ್‌ನ security properties ತೆರೆದು, Security ಟ್ಯಾಬ್‌ಗೆ ಹೋಗಿ, Change Settings ಆರಿಸಿ, ಪಾಸ್‌ವರ್ಡ್ ಆಯ್ಕೆಗಳನ್ನು ತೆರವುಗೊಳಿಸಿ ಉಳಿಸಿ.

Adobe ಮೆನುಗಳು ಆವೃತ್ತಿಗಳ ನಡುವೆ ಸ್ಥಳ ಬದಲಿಸುತ್ತವೆ, ಹಾಗಾಗಿ ಈ ನಿಖರ ಹೆಸರುಗಳು ಕಾಣದಿದ್ದರೆ Acrobat ನ ಟೂಲ್ ಹುಡುಕಾಟದಲ್ಲಿ “Remove Security” ಎಂದು ಹುಡುಕಿ. ಉಚಿತ Acrobat Reader ರಕ್ಷಿತ PDF ಗಳನ್ನು ತೆರೆಯಬಲ್ಲದು, ಆದರೆ ಭದ್ರತೆ ತೆಗೆಯಲು ಸೂಕ್ತ ಟೂಲ್ ಅಲ್ಲ. ಬದಲಿಗೆ ವಿಧಾನ 1 ಅಥವಾ 2 ಬಳಸಿ.

ವಿಧಾನ 4: qpdf (ತಾಂತ್ರಿಕ ಬಳಕೆದಾರರಿಗೆ)

ಉಚಿತ, ಓಪನ್-ಸೋರ್ಸ್ qpdf ಟೂಲ್ Windows ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಇಲ್ಲದ ಪ್ರತಿಯನ್ನು ಬರೆಯುತ್ತದೆ (qpdf documentation). ಪಾಸ್‌ವರ್ಡ್ ನಿಮ್ಮ ಕಮಾಂಡ್ ಹಿಸ್ಟರಿಯಲ್ಲಿ ಉಳಿಯಬಹುದು, ಆದ್ದರಿಂದ ಹಂಚಿಕೆಯ PC ಯಲ್ಲಿ ನಂತರ ಅದನ್ನು ಅಳಿಸಿ.

ಪರಿಶೀಲಿಸಬೇಕಾದವು

  • Print ಮಂದವಾಗಿದೆಯೇ? PDF ಗೆ ಪ್ರಿಂಟ್ ತಡೆಯುವ ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಇರಬಹುದು. ಪ್ರಿಂಟ್ ಮತ್ತು ಕಾಪಿ ನಿರ್ಬಂಧಗಳು ನೋಡಿ.
  • ಪಾಸ್‌ವರ್ಡ್ ತಿರಸ್ಕೃತವೇ? Caps Lock, ದಿನಾಂಕ ಫಾರ್ಮ್ಯಾಟ್ ಮತ್ತು ನಿಮ್ಮ ಬ್ಯಾಂಕ್ ಬಳಿ ಇರುವ ವಿವರಗಳನ್ನು ಪರಿಶೀಲಿಸಿ. PDF ಪಾಸ್‌ವರ್ಡ್ ಏಕೆ ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲ ನೋಡಿ.
  • ಹಂಚಿಕೆಯ ಅಥವಾ ಕಚೇರಿ PC ಯೇ? ಅನ್‌ಲಾಕ್ ಮಾಡಿದ ಪ್ರತಿ ಅದನ್ನು ಕಂಡವರಿಗೆಲ್ಲ ತೆರೆಯುತ್ತದೆ. ಖಾಸಗಿ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಉಳಿಸಿ ಮತ್ತು Downloads ನಿಂದ ಅಳಿಸಿ.

ನಿಮ್ಮ ಬಳಿ iPhone, iPad ಅಥವಾ Mac ಇದ್ದರೆ, ಆ ಸಾಧನಗಳಲ್ಲಿ UnKey ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುತ್ತದೆ ಮತ್ತು ಮುಂದಿನ ತಿಂಗಳ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಾಗಿ ಪಾಸ್‌ವರ್ಡ್ ಉಳಿಸಬಲ್ಲದು. Windows ಗೆ UnKey ಆ್ಯಪ್ ಇಲ್ಲ.

ಪ್ರಶ್ನೆಗಳು

Windows ನಲ್ಲಿ ನಾನು ಏನನ್ನಾದರೂ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬೇಕೇ?

ಇಲ್ಲ. Microsoft Edge ಮತ್ತು Microsoft Print to PDF ಪ್ರಿಂಟರ್ Windows 10 ಮತ್ತು 11 ಜೊತೆ ಬರುತ್ತವೆ.

ಆನ್‌ಲೈನ್ “unlock PDF” ಸೈಟ್‌ಗಳು ಚೆನ್ನಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತವೆಯೇ?

ಅವು ಅದೇ ಕೆಲಸ ಮಾಡುತ್ತವೆ, ಆದರೆ ನಿಮ್ಮ ದಾಖಲೆಯನ್ನು ಬೇರೆಯವರ ಸರ್ವರ್‌ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿಸುತ್ತವೆ. ಬ್ಯಾಂಕ್ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಮತ್ತು ತೆರಿಗೆ ದಾಖಲೆಗಳಿಗೆ ಇಲ್ಲಿನ ಆಫ್‌ಲೈನ್ ವಿಧಾನಗಳು ಸುರಕ್ಷಿತ.

ಇವುಗಳಲ್ಲಿ ಯಾವುದಾದರೂ ನಾನು ಮರೆತ ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು ತೆಗೆಯಬಹುದೇ?

ಇಲ್ಲ. Edge, Chrome, Acrobat ಮತ್ತು qpdf ಎಲ್ಲಕ್ಕೂ ಸರಿಯಾದ ಪಾಸ್‌ವರ್ಡ್ ಬೇಕು. ಫಾರ್ಮ್ಯಾಟ್‌ಗಾಗಿ PDF ಜೊತೆ ಬಂದ ಇಮೇಲ್ ನೋಡಿ.

ಪ್ರತಿಯಲ್ಲಿ ಲಿಂಕ್‌ಗಳು ಏಕೆ ಕೆಲಸ ಮಾಡುವುದಿಲ್ಲ?

PDF ಗೆ ಪ್ರಿಂಟ್ ಮಾಡುವುದು ಪುಟಗಳನ್ನು ಮರುನಿರ್ಮಿಸುತ್ತದೆ; ಇದರಿಂದ ಲಿಂಕ್‌ಗಳು ಮತ್ತು ಫಾರ್ಮ್ ಕ್ಷೇತ್ರಗಳು ಕಳೆದುಹೋಗಬಹುದು. Acrobat ನ Remove Security ಅಥವಾ qpdf ಅವನ್ನು ಉಳಿಸುತ್ತವೆ.

ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಬದಲಾಗಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ಕೆಲಸ ಮಾಡದಿದ್ದರೆ, ದಾಖಲೆಯೊಂದಿಗೆ ಬಂದ ಇಮೇಲ್ ನೋಡಿ ಅಥವಾ ನೀಡಿದ ಸಂಸ್ಥೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ. ಇಲ್ಲಿ ಹೆಸರಿಸಿರುವ ಯಾವುದೇ ಬ್ಯಾಂಕ್, ಉದ್ಯೋಗದಾತ ಅಥವಾ ಪ್ರಾಧಿಕಾರದೊಂದಿಗೆ UnKeyಗೆ ಸಂಬಂಧವಿಲ್ಲ.

ಇಂಗ್ಲಿಷ್‌ನಿಂದ ಅನುವಾದಿಸಲಾಗಿದೆ. ಏನಾದರೂ ವ್ಯತ್ಯಾಸವಿದ್ದರೆ ಇಂಗ್ಲಿಷ್ ಪುಟವೇ ಆಧಾರ.

ಒಮ್ಮೆ ಅನ್‌ಲಾಕ್ ಮಾಡಿ.

ನೀವು ಈಗಾಗಲೇ ತೆರೆಯಬಲ್ಲ PDFಗಳಿಂದ UnKey ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆದುಹಾಕುತ್ತದೆ, iPhone, iPad ಮತ್ತು Macನಲ್ಲಿ. ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಏನೂ ಅಪ್‌ಲೋಡ್ ಆಗುವುದಿಲ್ಲ. ಪಾಸ್‌ವರ್ಡ್ ಒಮ್ಮೆ ಉಳಿಸಿ, ಮುಂದಿನ ತಿಂಗಳ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಅನ್ನು Face ID ತೆರೆಯುತ್ತದೆ.
