ಮಾರ್ಗದರ್ಶಿಗಳು · ಹೇಗೆ ಮಾಡುವುದು

Chrome ನಲ್ಲಿ PDF ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು ಹೇಗೆ (2026)

ಅಕ್ಟೋಬರ್ 2026ರಲ್ಲಿ ನವೀಕರಿಸಲಾಗಿದೆ

ಈ ಭಾಷೆಯಲ್ಲಿ ಓದಿ: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

PDF ಅನ್ನು ಪಾಸ್‌ವರ್ಡ್‌ನೊಂದಿಗೆ Chrome ನಲ್ಲಿ ತೆರೆದು, Ctrl+P ಅಥವಾ Cmd+P ಒತ್ತಿ, ಗಮ್ಯಸ್ಥಾನವನ್ನು Save as PDF ಗೆ ಹೊಂದಿಸಿ, ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದ ಹೊಸ ಪ್ರತಿ ಉಳಿಸಿ.

Google Chrome, Windows, Mac ಮತ್ತು Linux ನಲ್ಲಿ, ಪಾಸ್‌ವರ್ಡ್ ಇರುವ PDF ನ ಪ್ರತಿಯನ್ನು ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದೆ ಉಚಿತವಾಗಿ ಉಳಿಸಬಲ್ಲದು. PDF ಅನ್ನು Chrome ನಲ್ಲಿ ತೆರೆದು, ಪಾಸ್‌ವರ್ಡ್ ಟೈಪ್ ಮಾಡಿ, Ctrl + P (Mac ನಲ್ಲಿ Cmd + P) ಒತ್ತಿ, ಗಮ್ಯಸ್ಥಾನವನ್ನು Save as PDF ಗೆ ಹೊಂದಿಸಿ, ಉಳಿಸಿ. ನಿಮಗೆ ಈಗಾಗಲೇ ಪಾಸ್‌ವರ್ಡ್ ತಿಳಿದಿರಬೇಕು. ಅದಿಲ್ಲದೆ Chrome ಫೈಲ್ ತೆರೆಯಲಾರದು.

ಹಂತ ಹಂತವಾಗಿ (ಕಂಪ್ಯೂಟರ್)

  1. PDF ಅನ್ನು Chrome ವಿಂಡೋಗೆ ಎಳೆದು ಬಿಡಿ, ಅಥವಾ ಫೈಲ್ ಮೇಲೆ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ Open with > Google Chrome ಆರಿಸಿ.
  2. Chrome ಪಾಸ್‌ವರ್ಡ್ ಕೇಳುತ್ತದೆ. ಅದನ್ನು ಟೈಪ್ ಮಾಡಿ Enter ಒತ್ತಿ.
  3. Windows ಅಥವಾ Linux ನಲ್ಲಿ Ctrl + P, Mac ನಲ್ಲಿ Cmd + P ಒತ್ತಿ. ಮೆನುವಿನಿಂದಲೂ ಮಾಡಬಹುದು: File > Print.
  4. ಪ್ರಿಂಟ್ ವಿಂಡೋದಲ್ಲಿ Destination ಅನ್ನು Save as PDF ಗೆ ಹೊಂದಿಸಿ.
  5. Save ಕ್ಲಿಕ್ ಮಾಡಿ. ಹೊಸ ಫೈಲ್‌ಗೆ Statement-Sep-2026-unlocked.pdf ನಂತಹ ಸ್ಪಷ್ಟ ಹೆಸರು ಕೊಡಿ.
  6. ಅದನ್ನು ಮುಚ್ಚಿ ಹೊಸ ಫೈಲ್ ಅನ್ನು ಮತ್ತೆ ತೆರೆಯಿರಿ. ಅದು ಪಾಸ್‌ವರ್ಡ್ ಕೇಳದೆ ತಕ್ಷಣ ತೆರೆಯಬೇಕು.

ಕೀಬೋರ್ಡ್ ಶಾರ್ಟ್‌ಕಟ್‌ಗಳು, ಪ್ರಿಂಟ್ ವಿಂಡೋದಲ್ಲಿ ಗಮ್ಯಸ್ಥಾನ ಆರಿಸುವುದು ಮತ್ತು Save as PDF ಆಯ್ಕೆಯನ್ನು Google ನ ಸಹಾಯ ಪುಟ ವಿವರಿಸುತ್ತದೆ (Google: Print from Chrome).

Android ಫೋನ್‌ನಲ್ಲಿ

Android ನ Chrome ನಲ್ಲೂ ಇದೇ ಆಯ್ಕೆ ಇದೆ. Google ನ ಹಂತಗಳು: More > Share ಒತ್ತಿ, Print ಒತ್ತಿ, ನಂತರ Save as PDF ಒತ್ತಿ ಮತ್ತು ಫೈಲ್ ಎಲ್ಲಿ ಉಳಿಸಬೇಕು ಎಂದು ಆರಿಸಿ (Google: Print from Chrome on Android). ಫೋನ್‌ನಲ್ಲಿರುವ PDF ಅನ್ನು Chrome ತೆರೆಯುತ್ತದೆಯೇ ಎಂಬುದು Chrome ಆವೃತ್ತಿಯನ್ನು ಅವಲಂಬಿಸಿದೆ. ತೆರೆಯದಿದ್ದರೆ, Android ನಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ಇರುವ PDF ತೆರೆಯುವುದು ಎಂಬ ನಮ್ಮ ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ.

ಈ ವಿಧಾನದಲ್ಲಿ ನೀವು ಕಳೆದುಕೊಳ್ಳುವುದು

ಪ್ರಿಂಟ್ ವಿಂಡೋ ಮೂಲಕ ಉಳಿಸಿದಾಗ, ಪರದೆಯಲ್ಲಿರುವುದರಿಂದ ಹೊಚ್ಚಹೊಸ PDF ತಯಾರಾಗುತ್ತದೆ. ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಓದಲು, ಆರ್ಕೈವ್ ಮಾಡಲು ಅಥವಾ ಅಪ್‌ಲೋಡ್ ಮಾಡಲು ಇದು ಸಾಕು. ಆದರೆ ಮೂಲ ಫೈಲ್ ಅಳಿಸುವ ಮೊದಲು ಪ್ರತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ:

  • ಲಿಂಕ್‌ಗಳು ಮತ್ತು ಬುಕ್‌ಮಾರ್ಕ್‌ಗಳು ಕೆಲಸ ಮಾಡದಿರಬಹುದು.
  • ಫಾರ್ಮ್ ಕ್ಷೇತ್ರಗಳು ಸಮತಟ್ಟಾಗಬಹುದು, ಹಾಗಾಗಿ ಅವುಗಳಲ್ಲಿ ಇನ್ನು ಟೈಪ್ ಮಾಡಲಾಗದು.
  • ಡಿಜಿಟಲ್ ಸಹಿಗಳು ವರ್ಗಾವಣೆಯಾಗುವುದಿಲ್ಲ. ಪೋರ್ಟಲ್‌ಗೆ ಸಹಿ ಮಾಡಿದ ಮೂಲ ಬೇಕಿದ್ದರೆ, ಮೂಲ ಫೈಲ್ ಅನ್ನೇ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
  • ಪುಟದ ಗಾತ್ರ ಪ್ರಿಂಟ್ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಅನುಸರಿಸುತ್ತದೆ. More settings ಅಡಿಯಲ್ಲಿ ಕಾಗದದ ಗಾತ್ರ ಮತ್ತು ಸ್ಕೇಲ್ ಪುಟಗಳನ್ನು ಕುಗ್ಗಿಸಿಲ್ಲ ಅಥವಾ ಕತ್ತರಿಸಿಲ್ಲ ಎಂದು ಪರಿಶೀಲಿಸಿ.

Save as PDF ಕೆಲಸ ಮಾಡದಿದ್ದರೆ

  • ಪ್ರಿಂಟಿಂಗ್ ತಡೆಯಲಾಗಿದೆ. ಕೆಲವು PDF ಗಳಿಗೆ ಪ್ರಿಂಟ್ ತಡೆಯುವ ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಇರುತ್ತದೆ. ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್‌ಗಿಂತ ಬೇರೆ. PDF ಪ್ರಿಂಟ್ ಮತ್ತು ಕಾಪಿ ನಿರ್ಬಂಧಗಳ ವಿವರಣೆ ನೋಡಿ.
  • Chrome ಪಾಸ್‌ವರ್ಡ್ ತಿರಸ್ಕರಿಸುತ್ತದೆ. ದೊಡ್ಡಕ್ಷರಗಳು, ದಿನಾಂಕ ಫಾರ್ಮ್ಯಾಟ್ ಮತ್ತು ನಿಮ್ಮ ಬ್ಯಾಂಕ್ ದಾಖಲೆಯಲ್ಲಿರುವ ವಿವರಗಳನ್ನು ಪರಿಶೀಲಿಸಿ. PDF ಪಾಸ್‌ವರ್ಡ್ ಏಕೆ ಕೆಲಸ ಮಾಡುತ್ತಿಲ್ಲ ನೋಡಿ.
  • ಫೈಲ್ ಬೇರೆ ಆ್ಯಪ್‌ನಲ್ಲಿ ತೆರೆಯಿತು. ಕೆಲವು ಕಂಪ್ಯೂಟರ್‌ಗಳು PDF ಗಳನ್ನು ಡೀಫಾಲ್ಟ್ ಆಗಿ ಬೇರೆ ರೀಡರ್‌ನಲ್ಲಿ ತೆರೆಯುತ್ತವೆ. ಬದಲಿಗೆ ಫೈಲ್ ಅನ್ನು Chrome ಟ್ಯಾಬ್‌ಗೆ ಎಳೆದು ಬಿಡಿ.

ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವ ಇತರ ದಾರಿಗಳು

Windows ನಲ್ಲಿ Microsoft Edge ಇದೇ ರೀತಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ (Windows ನಲ್ಲಿ PDF ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು ನೋಡಿ). Mac ನಲ್ಲಿ Preview ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದ ಪ್ರತಿಯನ್ನು ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಬಲ್ಲದು (Mac ಮಾರ್ಗದರ್ಶಿ). iPhone, iPad ಮತ್ತು Mac ನಲ್ಲಿ UnKey ಅನ್‌ಲಾಕ್ ಮಾಡಿದ ಪ್ರತಿಯನ್ನು ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಉಳಿಸುತ್ತದೆ ಮತ್ತು ಅಕ್ಷರಗಳು, ಲಿಂಕ್‌ಗಳು ಹಾಗೂ ಪುಟಗಳನ್ನು ಇದ್ದಂತೆಯೇ ಇಡುತ್ತದೆ, ಏಕೆಂದರೆ ಅದು ಫೈಲ್ ಅನ್ನು ಮತ್ತೆ ಪ್ರಿಂಟ್ ಮಾಡುವ ಬದಲು ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಅನ್ನು ತೆಗೆಯುತ್ತದೆ. Chrome ನಂತೆಯೇ ಅದು ನಿಮಗೆ ಈಗಾಗಲೇ ತಿಳಿದಿರುವ ಪಾಸ್‌ವರ್ಡ್‌ನೊಂದಿಗೆ ಮಾತ್ರ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

ಪ್ರಶ್ನೆಗಳು

ಇದನ್ನು ಮಾಡುವಾಗ Chrome ನನ್ನ PDF ಅನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆಯೇ?

ಇಲ್ಲ. ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಿಂದ PDF ಫೈಲ್ ತೆರೆದು Save as PDF ಮೂಲಕ ಉಳಿಸುವುದು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನ ಬ್ರೌಸರ್‌ನಲ್ಲೇ ನಡೆಯುತ್ತದೆ. Drive ನಲ್ಲಿ ಪ್ರತಿ ಬೇಕಿದ್ದರೆ ಮಾತ್ರ ಪ್ರತ್ಯೇಕ “Save to Google Drive” ಗಮ್ಯಸ್ಥಾನ ಬಳಸಿ.

ನನಗೆ ತಿಳಿಯದ ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು Chrome ತೆಗೆಯಬಹುದೇ?

ಇಲ್ಲ. Chrome ಏನನ್ನೂ ತೋರಿಸುವ ಮೊದಲು ಪಾಸ್‌ವರ್ಡ್ ಕೇಳುತ್ತದೆ. ಕಳೆದುಕೊಂಡಿದ್ದರೆ, PDF ಪಾಸ್‌ವರ್ಡ್ ಮರೆತರೆ ಏನು ಮಾಡಬೇಕು ಎಂಬುದನ್ನು ನೋಡಿ.

ಉಳಿಸಿದ ಪ್ರತಿ ಮೂಲಕ್ಕಿಂತ ಏಕೆ ಭಿನ್ನವಾಗಿದೆ?

Save as PDF ಪುಟಗಳನ್ನು ಹೊಸ ಫೈಲ್‌ಗೆ ಪ್ರಿಂಟ್ ಮಾಡುತ್ತದೆ, ಆದ್ದರಿಂದ ಲಿಂಕ್‌ಗಳು, ಫಾರ್ಮ್ ಕ್ಷೇತ್ರಗಳು ಮತ್ತು ಸಹಿಗಳು ಉಳಿಯದಿರಬಹುದು. ಅಕ್ಷರಗಳು ಮತ್ತು ವಿನ್ಯಾಸ ಸಾಮಾನ್ಯವಾಗಿ ಒಂದೇ ರೀತಿ ಕಾಣುತ್ತವೆ.

ಇದಕ್ಕೆ ಅನುಮತಿ ಇದೆಯೇ?

ನಿಮ್ಮ ಬ್ಯಾಂಕ್ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ನಂತಹ ನಿಮ್ಮ ಸ್ವಂತ ದಾಖಲೆಗಳಿಗೆ ಹೌದು. ಮುಕ್ತವಾಗಿ ತೆರೆಯಲು ನಿಮಗೆ ಹಕ್ಕಿಲ್ಲದ ಫೈಲ್‌ಗಳ ರಕ್ಷಣೆಯನ್ನು ತೆಗೆಯಬೇಡಿ.

ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಬದಲಾಗಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ಕೆಲಸ ಮಾಡದಿದ್ದರೆ, ದಾಖಲೆಯೊಂದಿಗೆ ಬಂದ ಇಮೇಲ್ ನೋಡಿ ಅಥವಾ ನೀಡಿದ ಸಂಸ್ಥೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ. ಇಲ್ಲಿ ಹೆಸರಿಸಿರುವ ಯಾವುದೇ ಬ್ಯಾಂಕ್, ಉದ್ಯೋಗದಾತ ಅಥವಾ ಪ್ರಾಧಿಕಾರದೊಂದಿಗೆ UnKeyಗೆ ಸಂಬಂಧವಿಲ್ಲ.

ಇಂಗ್ಲಿಷ್‌ನಿಂದ ಅನುವಾದಿಸಲಾಗಿದೆ. ಏನಾದರೂ ವ್ಯತ್ಯಾಸವಿದ್ದರೆ ಇಂಗ್ಲಿಷ್ ಪುಟವೇ ಆಧಾರ.

ಒಮ್ಮೆ ಅನ್‌ಲಾಕ್ ಮಾಡಿ.

ನೀವು ಈಗಾಗಲೇ ತೆರೆಯಬಲ್ಲ PDFಗಳಿಂದ UnKey ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆದುಹಾಕುತ್ತದೆ, iPhone, iPad ಮತ್ತು Macನಲ್ಲಿ. ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಏನೂ ಅಪ್‌ಲೋಡ್ ಆಗುವುದಿಲ್ಲ. ಪಾಸ್‌ವರ್ಡ್ ಒಮ್ಮೆ ಉಳಿಸಿ, ಮುಂದಿನ ತಿಂಗಳ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಅನ್ನು Face ID ತೆರೆಯುತ್ತದೆ.
