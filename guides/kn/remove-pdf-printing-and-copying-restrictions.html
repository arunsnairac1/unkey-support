ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಯಾರೂ PDF ಓದದಂತೆ ತಡೆಯುತ್ತದೆ; ಮಾಲೀಕರ (ಅನುಮತಿ) ಪಾಸ್‌ವರ್ಡ್ ಪ್ರಿಂಟ್, ಕಾಪಿ ಮತ್ತು ಎಡಿಟ್‌ನಂತಹ ಕ್ರಿಯೆಗಳನ್ನು ಮಾತ್ರ ನಿರ್ಬಂಧಿಸುತ್ತದೆ.

PDF ಗಳಿಗೆ ಎರಡು ಬೇರೆ ಬೇರೆ ಪಾಸ್‌ವರ್ಡ್‌ಗಳಿರಬಹುದು. ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ (ಯೂಸರ್ ಪಾಸ್‌ವರ್ಡ್ ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ಫೈಲ್ ಅನ್ನು ನೋಡಲೇ ಬೇಕು. ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ (ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಎಂದೂ ಕರೆಯುತ್ತಾರೆ) ಫೈಲ್ ತೆರೆಯಲು ಬಿಡುತ್ತದೆ, ಆದರೆ ಪ್ರಿಂಟ್, ಅಕ್ಷರಗಳ ಕಾಪಿ ಅಥವಾ ಎಡಿಟ್‌ನಂತಹವನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ. ನಿರ್ಬಂಧಗಳನ್ನು ಸರಿಯಾದ ರೀತಿಯಲ್ಲಿ ತೆಗೆಯಲು ನಿಮಗೆ ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ಬೇಕು.

ಎರಡು ಪಾಸ್‌ವರ್ಡ್‌ಗಳು ಸರಳವಾಗಿ

ಓಪನ್ (ಯೂಸರ್) ಪಾಸ್‌ವರ್ಡ್ಮಾಲೀಕರ (ಅನುಮತಿ) ಪಾಸ್‌ವರ್ಡ್
ನೀವು ಏನು ನೋಡುತ್ತೀರಿಏನಾದರೂ ತೋರುವ ಮೊದಲು ಪಾಸ್‌ವರ್ಡ್ ಕೇಳುವ ಬಾಕ್ಸ್ಫೈಲ್ ತೆರೆಯುತ್ತದೆ, ಆದರೆ Print ಅಥವಾ Copy ಮಂದವಾಗಿರುತ್ತದೆ
ಅದು ಏನನ್ನು ರಕ್ಷಿಸುತ್ತದೆಎನ್‌ಕ್ರಿಪ್ಟ್ ಆದ ಇಡೀ ವಿಷಯಪ್ರಿಂಟ್, ಕಾಪಿ, ಎಡಿಟ್ ಮತ್ತು ಕಾಮೆಂಟ್‌ನಂತಹ ಕ್ರಿಯೆಗಳು
ಸಾಮಾನ್ಯ ಬಳಕೆಬ್ಯಾಂಕ್ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳು, ತೆರಿಗೆ ದಾಖಲೆಗಳುಪ್ರಕಟಿತ ವರದಿಗಳು, ಫಾರ್ಮ್‌ಗಳು, ಒಪ್ಪಂದಗಳು

Adobe ಕೂಡ ಇದೇ ರೀತಿ ವಿಂಗಡಿಸುತ್ತದೆ. PDF ತೆರೆಯಲು Document Open ಪಾಸ್‌ವರ್ಡ್ ಬೇಕು, ಮತ್ತು ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಪ್ರಿಂಟ್, ಎಡಿಟ್ ಮತ್ತು ಕಾಪಿಯಂತಹ ವೈಶಿಷ್ಟ್ಯಗಳನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ (Adobe: Password security overview). qpdf ನ ದಾಖಲೆ ಒಂದು ಮುಖ್ಯ ವಿವರ ಸೇರಿಸುತ್ತದೆ: ರೀಡರ್‌ಗಳು "ಯೂಸರ್ ಪಾಸ್‌ವರ್ಡ್‌ನಿಂದ ತೆರೆದ ಫೈಲ್‌ಗಳಿಗೆ ಭದ್ರತಾ ನಿರ್ಬಂಧಗಳನ್ನು ಅನ್ವಯಿಸುತ್ತವೆ" ಮತ್ತು "ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್‌ನಿಂದ ಫೈಲ್‌ಗಳನ್ನು ತೆರೆದಾಗ ಭದ್ರತಾ ನಿರ್ಬಂಧಗಳನ್ನು ಬದಲಿಸಲು ಅಥವಾ ಮೀರಲು ಅನುಮತಿಸುತ್ತವೆ" (qpdf).

ನಿರ್ಬಂಧಗಳು ಹೇಗೆ ಜಾರಿಯಾಗುತ್ತವೆ

ನಿರ್ಬಂಧಗಳು, PDF ರೀಡರ್ ಅವನ್ನು ಗೌರವಿಸಲು ಆರಿಸಿಕೊಳ್ಳುವುದರ ಮೇಲೆ ಅವಲಂಬಿತ. ತನ್ನ ಸ್ವಂತ ಉತ್ಪನ್ನಗಳು ಅವನ್ನು ಜಾರಿಗೊಳಿಸುತ್ತವೆ, ಆದರೆ ಮೂರನೇ ವ್ಯಕ್ತಿಯ ಉತ್ಪನ್ನಗಳು ಈ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಬೆಂಬಲಿಸದಿದ್ದರೆ, ಸ್ವೀಕರಿಸುವವರು ಕೆಲವು ಅಥವಾ ಎಲ್ಲ ನಿರ್ಬಂಧಗಳನ್ನು ತಪ್ಪಿಸಬಹುದು ಎಂದು Adobe ಹೇಳುತ್ತದೆ (Adobe). ಹಾಗಾಗಿ ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಒಂದು ಬೀಗವಲ್ಲ, “ದಯವಿಟ್ಟು ಬೇಡ” ಎನ್ನುವ ವಿನಂತಿ. ಆದರೂ ಲೇಖಕರ ಇಚ್ಛೆಯನ್ನು ಕಡೆಗಣಿಸಲು ಇದು ಕಾರಣವಲ್ಲ. ಯಾರಾದರೂ ಕಾಪಿಯನ್ನು ನಿರ್ಬಂಧಿಸಿದ್ದರೆ, ಹಕ್ಕುಸ್ವಾಮ್ಯ ಅಥವಾ ಒಪ್ಪಂದದಂತಹ ಕಾರಣ ಸಾಮಾನ್ಯವಾಗಿ ಇರುತ್ತದೆ.

ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ಇದ್ದಾಗ ನಿರ್ಬಂಧಗಳನ್ನು ಬದಲಿಸುವುದು

Mac ನಲ್ಲಿ (Preview): PDF ತೆರೆದು, File > Edit Permissions ಆರಿಸಿ, ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ. ನಂತರ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದೆ ಅನುಮತಿಸಬೇಕಾದ ಕ್ರಿಯೆಗಳನ್ನು ಆರಿಸಿ Apply ಕ್ಲಿಕ್ ಮಾಡಬಹುದು (Apple: Password-protect a PDF in Preview on Mac). ಹೊಸ ಪ್ರತಿ ಬೇಕಿದ್ದರೆ File > Export ಅಡಿಯಲ್ಲೂ ಅದೇ Permissions ಪ್ಯಾನೆಲ್ ಕಾಣುತ್ತದೆ.

Adobe Acrobat ನಲ್ಲಿ: ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯಲು Adobe ನ ಸೂಚನೆಗಳು ಅದನ್ನು Enter Password ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಟೈಪ್ ಮಾಡಲು ಹೇಳುತ್ತವೆ (Adobe: How to remove a PDF password).

ಕಮಾಂಡ್ ಲೈನ್‌ನಲ್ಲಿ: --password=OWNERPASSWORD --decrypt ಜೊತೆ qpdf ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಇಲ್ಲದ ಪ್ರತಿ ಬರೆಯುತ್ತದೆ. ತಯಾರಕರು ಫೈಲ್‌ಗಳ ಮೇಲೆ ಹಾಕಿದ ನಿರ್ಬಂಧಗಳನ್ನು ತಪ್ಪಿಸಲು ಈ ಆಯ್ಕೆಯನ್ನು ಉದ್ದೇಶಿಸಿಲ್ಲ ಎಂದು ಅದರ ದಾಖಲೆ ಹೇಳುತ್ತದೆ (qpdf).

ಎರಡೂ ಪಾಸ್‌ವರ್ಡ್ ಇರುವ ನಿಮ್ಮ ಸ್ವಂತ ದಾಖಲೆಗಳು

ಬ್ಯಾಂಕ್ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳು ಸಾಮಾನ್ಯವಾಗಿ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಮಾತ್ರ ಬಳಸುತ್ತವೆ. ಒಮ್ಮೆ ತೆರೆದ ನಂತರ ನೀವು ಸಾಮಾನ್ಯವಾಗಿ ಮುಕ್ತವಾಗಿ ಪ್ರಿಂಟ್ ಮತ್ತು ಕಾಪಿ ಮಾಡಬಹುದು. Preview ಅಥವಾ Acrobat ನಲ್ಲಿ ನೀವೇ PDF ರಚಿಸಿ ಎರಡೂ ಪಾಸ್‌ವರ್ಡ್‌ಗಳನ್ನು ಹೊಂದಿಸಿದ್ದರೆ, ಅನುಮತಿ ಬದಲಿಸಲು ಅಥವಾ ನಿರ್ಬಂಧವಿಲ್ಲದ ಪ್ರತಿ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಲು ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ಬಳಸಿ.

ಮಾಸಿಕ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳಂತಹ ನಿಮ್ಮ ಸ್ವಂತ ಫೈಲ್‌ಗಳ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯಲು Mac ನಲ್ಲಿ Preview ಅಥವಾ iPhone, iPad ಅಥವಾ Mac ನಲ್ಲಿ UnKey ಬಳಸಬಹುದು. UnKey ಆಫ್‌ಲೈನ್ ಕೆಲಸ ಮಾಡುತ್ತದೆ ಮತ್ತು ನಿಮಗೆ ಈಗಾಗಲೇ ತಿಳಿದಿರುವ ಪಾಸ್‌ವರ್ಡ್‌ಗಳೊಂದಿಗೆ ಮಾತ್ರ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದಿದ್ದಾಗ

  • ಲೇಖಕರು ಅಥವಾ ಕಳುಹಿಸಿದವರಿಂದ ನಿರ್ಬಂಧವಿಲ್ಲದ ಪ್ರತಿಯನ್ನು, ಅಥವಾ ಪ್ರಿಂಟ್ ಅಥವಾ ಕಾಪಿ ಮಾಡಲು ಅನುಮತಿಯನ್ನು ಕೇಳಿ.
  • ನೀವು ತುಂಬಬೇಕಾದ ಫಾರ್ಮ್ ಆಗಿದ್ದರೆ, ತುಂಬಲು ಈಗಾಗಲೇ ಅನುಮತಿ ಇದೆಯೇ ಎಂದು ನೋಡಿ. ನಿರ್ಬಂಧಿತ ಅನೇಕ PDF ಗಳು ಇನ್ನೂ ಫಾರ್ಮ್ ತುಂಬಲು ಬಿಡುತ್ತವೆ.
  • ಕೆಲಸದ ಅಥವಾ ಕಾನೂನು ದಾಖಲೆಗೆ, ನಿರ್ಬಂಧ ಉದ್ದೇಶಪೂರ್ವಕ ಎಂದು ಭಾವಿಸಿ.

ಪ್ರಶ್ನೆಗಳು

PDF ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ಎಂದರೇನು?

ಇದು ಪ್ರಿಂಟ್, ಕಾಪಿ ಮತ್ತು ಎಡಿಟ್‌ನಂತಹ ಅನುಮತಿಗಳನ್ನು ನಿಯಂತ್ರಿಸುವ ಪಾಸ್‌ವರ್ಡ್. ಅದಿಲ್ಲದೆ ಫೈಲ್ ತೆರೆಯಬಹುದು, ಆದರೆ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಗೌರವಿಸುವ ರೀಡರ್‌ಗಳಲ್ಲಿ ನಿರ್ಬಂಧಿತ ಕ್ರಿಯೆಗಳು ತಡೆಯಲ್ಪಡುತ್ತವೆ.

PDF ತೆರೆಯಲು ಆಗುತ್ತದೆ ಆದರೆ ಪ್ರಿಂಟ್ ಮಾಡಲು ಏಕೆ ಆಗುವುದಿಲ್ಲ?

ಫೈಲ್‌ಗೆ ಪ್ರಿಂಟ್ ಅನ್ನು ಅನುಮತಿಸದ ಮಾಲೀಕರ (ಅನುಮತಿ) ಪಾಸ್‌ವರ್ಡ್ ಇದೆ. Preview ನಲ್ಲಿ File > Edit Permissions ಅಡಿಯಲ್ಲಿ ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ, ಅಥವಾ ಕಳುಹಿಸಿದವರಿಂದ ನಿರ್ಬಂಧವಿಲ್ಲದ ಪ್ರತಿ ಕೇಳಿ.

ಬ್ಯಾಂಕ್ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳಿಗೆ ಪ್ರಿಂಟ್ ನಿರ್ಬಂಧಗಳಿವೆಯೇ?

ಸಾಮಾನ್ಯವಾಗಿ ಇಲ್ಲ. ಅವು ಸಾಮಾನ್ಯವಾಗಿ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಮಾತ್ರ ಬಳಸುತ್ತವೆ, ಹಾಗಾಗಿ ಫೈಲ್ ತೆರೆದ ನಂತರ ಪ್ರಿಂಟ್ ಮಾಡಬಹುದು.

PDF ಕಾಪಿ ನಿರ್ಬಂಧಗಳನ್ನು ತೆಗೆಯುವುದು ಕಾನೂನುಬದ್ಧವೇ?

ನಿಮ್ಮ ಸ್ವಂತ ಫೈಲ್‌ನ ಅನುಮತಿಗಳನ್ನು ನಿಮ್ಮ ಸ್ವಂತ ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್‌ನೊಂದಿಗೆ ಬದಲಿಸುವುದು ಸರಿ. ಬೇರೆಯವರ ದಾಖಲೆಯ ನಿರ್ಬಂಧಗಳನ್ನು ತಪ್ಪಿಸುವುದು ಹಕ್ಕುಸ್ವಾಮ್ಯ ಅಥವಾ ಒಪ್ಪಂದದ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸಬಹುದು, ಆದ್ದರಿಂದ ಮಾಲೀಕರನ್ನು ಕೇಳಿ.
