ಮಾರ್ಗದರ್ಶಿಗಳು · ಹೇಗೆ ಮಾಡುವುದು

ಅಪ್‌ಲೋಡ್ ಗಾತ್ರ ಮಿತಿಗಾಗಿ ಸ್ಕ್ಯಾನ್ ಮಾಡಿದ PDF ಅನ್ನು ಕುಗ್ಗಿಸಿ

ಅಕ್ಟೋಬರ್ 2026ರಲ್ಲಿ ನವೀಕರಿಸಲಾಗಿದೆ

ಈ ಭಾಷೆಯಲ್ಲಿ ಓದಿ: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

ಸ್ಕ್ಯಾನ್ ಮಾಡಿದ PDF ದೊಡ್ಡದಾಗಿರಲು ಪ್ರತಿ ಪುಟವೂ ಒಂದು ಫೋಟೋ ಆಗಿರುವುದೇ ಕಾರಣ; Mac ನಲ್ಲಿ Preview ನ Reduce File Size ಅಥವಾ iPhone ನಲ್ಲಿ Preview ನ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಆಯ್ಕೆಗಳಿಂದ ಕುಗ್ಗಿಸಿ, ಕಡಿಮೆ ಮತ್ತು ಸರಳ ಪುಟಗಳನ್ನು ಸ್ಕ್ಯಾನ್ ಮಾಡಿ, ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಮೊದಲು ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯಿರಿ.

ವೀಸಾ, ಪಾಸ್‌ಪೋರ್ಟ್, ಪರೀಕ್ಷೆ ಮತ್ತು ಸಾಲದ ಪೋರ್ಟಲ್‌ಗಳು ಒಂದು ಫೈಲ್‌ಗೆ ಕೆಲವು ನೂರು ಕಿಲೋಬೈಟ್ ಅಥವಾ ಒಂದೆರಡು ಮೆಗಾಬೈಟ್‌ಗಳ ಮಿತಿ ಹಾಕುವುದು ಸಾಮಾನ್ಯ. ಸ್ಕ್ಯಾನ್ ಮಾಡಿದ PDF ಗಳಲ್ಲಿ ಪ್ರತಿ ಪುಟವೂ ಫೋಟೋ ರೂಪದಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿರುವುದರಿಂದ ಅವು ಈ ಮಿತಿಯನ್ನು ಸುಲಭವಾಗಿ ಮೀರುತ್ತವೆ. ಸುಲಭ ಪರಿಹಾರಗಳು: PDF ಅನ್ನು ಚಿತ್ರ ಕಂಪ್ರೆಷನ್‌ನೊಂದಿಗೆ ಮತ್ತೆ ಸೇವ್ ಮಾಡುವುದು (Mac ಅಥವಾ iPhone ನ Preview ಇದನ್ನು ಉಚಿತವಾಗಿ ಮಾಡುತ್ತದೆ), ಬೇಕಾದ ಪುಟಗಳನ್ನು ಮಾತ್ರ ಸ್ಕ್ಯಾನ್ ಮಾಡುವುದು, ಮತ್ತು ಮೊದಲು ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು. ಏಕೆಂದರೆ ಅನೇಕ ಪೋರ್ಟಲ್‌ಗಳು ರಕ್ಷಿತ ಫೈಲ್‌ಗಳನ್ನು ಓದಲಾರವು.

ಕುಗ್ಗಿಸುವ ಮೊದಲು

  • ನಿಖರವಾದ ಮಿತಿ ಮತ್ತು ಫಾರ್ಮ್ಯಾಟ್ ಪರಿಶೀಲಿಸಿ. ಪೋರ್ಟಲ್ ಪುಟದಲ್ಲಿ ಗರಿಷ್ಠ ಗಾತ್ರ ಎಷ್ಟು, ಅದು ಒಂದು ಫೈಲ್‌ಗೋ ಅಥವಾ ಒಟ್ಟಿಗೋ, PDF ಬೇಕೋ JPEG ಬೇಕೋ ನೋಡಿ. ನಿಯಮಗಳು ಪೋರ್ಟಲ್‌ನಿಂದ ಪೋರ್ಟಲ್‌ಗೆ ಬದಲಾಗುತ್ತವೆ; ಅಪ್‌ಲೋಡ್ ಪುಟದಲ್ಲಿ ಹೇಳಿರುವುದನ್ನೇ ಅನುಸರಿಸಿ.
  • ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯಿರಿ. ರಕ್ಷಿತ PDF ಅನ್ನು ಪೋರ್ಟಲ್ ತೆರೆದು ಪರಿಶೀಲಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ. iPhone, Mac, Windows ಅಥವಾ Android ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ.
  • ಮೂಲ ಫೈಲ್ ಇಟ್ಟುಕೊಳ್ಳಿ. ಕಂಪ್ರೆಷನ್‌ನಿಂದ ಚಿತ್ರದ ಗುಣಮಟ್ಟ ಕಡಿಮೆಯಾಗುತ್ತದೆ. ಮಸುಕಾದ ಸ್ಕ್ಯಾನ್ ಅನ್ನು ಪೋರ್ಟಲ್ ತಿರಸ್ಕರಿಸಿದರೆ ಎಂದು ಪೂರ್ಣ ಗುಣಮಟ್ಟದ ಪ್ರತಿಯನ್ನು ಉಳಿಸಿಕೊಳ್ಳಿ.

Mac ನಲ್ಲಿ: Preview

  1. PDF ಅನ್ನು Preview ನಲ್ಲಿ ತೆರೆದು File > Export ಆಯ್ಕೆಮಾಡಿ.
  2. Quartz Filter ಮೆನುವಿನಲ್ಲಿ Reduce File Size ಆಯ್ಕೆಮಾಡಿ.
  3. ಹೊಸ ಹೆಸರು ಕೊಟ್ಟು Save ಕ್ಲಿಕ್ ಮಾಡಿ.

ಕುಗ್ಗಿಸಿದ PDF “ಮೂಲಕ್ಕಿಂತ ಕಡಿಮೆ ಗುಣಮಟ್ಟದ್ದಾಗಿರಬಹುದು” ಎಂದು Apple ಹೇಳುತ್ತದೆ. ಅದೇ Export ವಿಂಡೋದಲ್ಲಿ Optimize images for screen ಮತ್ತು Save images as JPEG ಆಯ್ಕೆಗಳೂ ಇವೆ (Apple: Reduce the size of a PDF in Preview on Mac). ಹೆಚ್ಚು ಅಕ್ಷರಗಳಿರುವ ಸ್ಕ್ಯಾನ್‌ಗಳನ್ನು Reduce File Size ಓದಲಾಗದಂತೆ ಮಾಡಬಹುದು, ಆದ್ದರಿಂದ ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಮೊದಲು ಫಲಿತಾಂಶವನ್ನು ತೆರೆದು ಜೂಮ್ ಮಾಡಿ ನೋಡಿ.

iPhone ಅಥವಾ iPad ನಲ್ಲಿ: Preview (iOS 26 ಮತ್ತು ನಂತರ)

  1. PDF ಅನ್ನು Preview ಆ್ಯಪ್‌ನಲ್ಲಿ ತೆರೆಯಿರಿ.
  2. ಫೈಲ್ ಹೆಸರಿನ ಪಕ್ಕದ ಮೆನು ಒತ್ತಿ, ನಂತರ Export ಒತ್ತಿ.
  3. PDF ಆಯ್ಕೆಮಾಡಿ, ನಂತರ Optimize Images for Screen ಮತ್ತು Save Images as JPEG ಆನ್ ಮಾಡಿ.
  4. ದೃಢೀಕರಣ ಬಟನ್ ಒತ್ತಿ, ಸ್ಥಳ ಆಯ್ಕೆಮಾಡಿ, ಹೆಸರು ಬದಲಿಸಿ ಮತ್ತು Save ಒತ್ತಿ.

Optimize Images for Screen “ಚಿಕ್ಕ ಫೈಲ್ ರಚಿಸುತ್ತದೆ” ಎಂದು Apple ಹೇಳುತ್ತದೆ (Apple: Export or compress PDFs in Preview on iPhone). ಪೋರ್ಟಲ್‌ಗೆ JPEG ಬೇಕಿದ್ದರೆ, ಅದೇ ಪರದೆಯಲ್ಲಿ ಗಾತ್ರದ ಸ್ಲೈಡರ್‌ನೊಂದಿಗೆ JPEG ಆಗಿ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಬಹುದು.

ಮೊದಲಿಂದಲೇ ಚಿಕ್ಕದಾಗಿ ಸ್ಕ್ಯಾನ್ ಮಾಡಿ

  • ಕೇಳಿದ ಪುಟಗಳು ಮಾತ್ರ. ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಮೊದಲು ಹೆಚ್ಚುವರಿ ಪುಟಗಳನ್ನು ಅಳಿಸಿ. iPhone ನ Preview ಪುಟಗಳನ್ನು ಅಳಿಸಲು ಮತ್ತು ಮರುಜೋಡಿಸಲು ಬಿಡುತ್ತದೆ (Apple).
  • ಕ್ಯಾಮೆರಾ ಬದಲು ಡಾಕ್ಯುಮೆಂಟ್ ಸ್ಕ್ಯಾನರ್ ಬಳಸಿ. Notes, Files ಮತ್ತು Preview ಪುಟವನ್ನು ಕ್ರಾಪ್ ಮಾಡಿ ಸಮತಟ್ಟು ಮಾಡುತ್ತವೆ (Apple: How to scan documents on iPhone). ಕ್ರಾಪ್ ಮಾಡಿದ ಸ್ಕ್ಯಾನ್, ಮೇಜಿನ ಮೇಲಿನ ಫೋಟೋಗಿಂತ ಚಿಕ್ಕದಾಗಿರುತ್ತದೆ.
  • ಪೋರ್ಟಲ್ ಒಪ್ಪುವುದಾದರೆ, ಅಕ್ಷರಗಳ ದಾಖಲೆಗಳಿಗೆ ಗ್ರೇಸ್ಕೇಲ್ ಅಥವಾ ಕಪ್ಪು-ಬಿಳುಪು ಬಳಸಿ. Preview ನ ಸ್ಕ್ಯಾನರ್‌ನಲ್ಲಿ ಪ್ರತಿ ಸ್ಕ್ಯಾನ್‌ನ ಬಣ್ಣವನ್ನು ಹೊಂದಿಸಬಹುದು (Apple). ಫೋಟೋಗಳಿಗೆ ಮತ್ತು ಅಧಿಕಾರಿ ನೋಡಬೇಕಾದ ಸ್ಟ್ಯಾಂಪ್ ಅಥವಾ ಮುದ್ರೆಗಳಿಗೆ ಬಣ್ಣ ಉಳಿಸಿ.
  • ಒಂದು ದಾಖಲೆಗೆ ಒಂದು ಫೈಲ್. ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಪ್ರತ್ಯೇಕ ಸ್ಲಾಟ್‌ಗಳಿದ್ದರೆ, ಎಲ್ಲವನ್ನೂ ಒಂದೇ ದೊಡ್ಡ PDF ಗೆ ಸೇರಿಸಬೇಡಿ.

ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

  • ಇನ್ನೂ ದೊಡ್ಡದಾಗಿದೆ: ಎರಡೂ ಆಯ್ಕೆಗಳನ್ನು ಆನ್ ಮಾಡಿ ಮತ್ತೆ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಿ, ಅಥವಾ ಗ್ರೇಸ್ಕೇಲ್‌ನಲ್ಲಿ ಮತ್ತೆ ಸ್ಕ್ಯಾನ್ ಮಾಡಿ.
  • ಅಕ್ಷರಗಳು ಮಸುಕಾಗಿವೆ: ಅತಿಯಾಗಿ ಕುಗ್ಗಿಸಿದ್ದೀರಿ. ಮೂಲ ಫೈಲ್‌ಗೆ ಹಿಂತಿರುಗಿ, ಕೇವಲ ಒಂದು ಆಯ್ಕೆ ಬಳಸಿ.
  • ಪೋರ್ಟಲ್ “file is corrupt” ಅಥವಾ “encrypted” ಎನ್ನುತ್ತದೆ: ಫೈಲ್ ಇನ್ನೂ ಪಾಸ್‌ವರ್ಡ್‌ನಿಂದ ರಕ್ಷಿತ ಅಥವಾ ನಿರ್ಬಂಧಿತವಾಗಿರಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆದು ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.
  • ಫೈಲ್ ದೊಡ್ಡದಾಯಿತು: ಬಹುತೇಕ ನಿಜವಾದ ಅಕ್ಷರಗಳಿರುವ PDF ಗಳು ಈಗಾಗಲೇ ಚಿಕ್ಕದಾಗಿರುತ್ತವೆ. ಮತ್ತೆ ಸೇವ್ ಮಾಡಿದರೆ ಗಾತ್ರ ಹೆಚ್ಚಬಹುದು. ಮೂಲ ಫೈಲ್ ಅನ್ನೇ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.

UnKey ನೊಂದಿಗೆ

iPhone, iPad ಮತ್ತು Mac ನಲ್ಲಿರುವ UnKey Pro ನಲ್ಲಿ ಸ್ಕ್ಯಾನ್‌ಗಳಿಗಾಗಿ ರೂಪಿಸಿದ Compress ಟೂಲ್ ಇದೆ. ಇದು ಫೋಟೋದಂತಹ ಪುಟಗಳನ್ನು ಮರು-ಎನ್‌ಕೋಡ್ ಮಾಡುತ್ತದೆ, ನಿಜವಾದ ಅಕ್ಷರಗಳಿರುವ ಪುಟಗಳನ್ನು ಮುಟ್ಟುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಅಕ್ಷರಗಳು ಸ್ಪಷ್ಟವಾಗಿರುತ್ತವೆ; ನೀವು ಕೊಟ್ಟ ಫೈಲ್‌ಗಿಂತ ದೊಡ್ಡ ಫೈಲ್ ಅನ್ನು ಅದು ಎಂದಿಗೂ ಹಿಂತಿರುಗಿಸುವುದಿಲ್ಲ. ಇದು ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಆದ್ದರಿಂದ ನಿಮ್ಮ ಪಾಸ್‌ಪೋರ್ಟ್ ಅಥವಾ ಬ್ಯಾಂಕ್ ಸ್ಕ್ಯಾನ್ ಯಾವುದೇ ಕಂಪ್ರೆಷನ್ ವೆಬ್‌ಸೈಟ್‌ಗೆ ಅಪ್‌ಲೋಡ್ ಆಗುವುದಿಲ್ಲ. ಅನ್‌ಲಾಕ್ ಮಾಡುವುದು ಉಚಿತ; Compress ಒಮ್ಮೆ ಖರೀದಿಸುವ Pro ಯ ಭಾಗ.

ಪ್ರಶ್ನೆಗಳು

ಕುಗ್ಗಿಸಿದರೆ ನನ್ನ ದಾಖಲೆಗಳು ಓದಲಾಗದಂತಾಗುತ್ತವೆಯೇ?

ಅತಿಯಾಗಿ ಮಾಡಿದರೆ ಆಗಬಹುದು. ಯಾವಾಗಲೂ ಕುಗ್ಗಿಸಿದ ಪ್ರತಿಯನ್ನು ತೆರೆದು, ಚಿಕ್ಕ ಅಕ್ಷರಗಳನ್ನು ಜೂಮ್ ಮಾಡಿ ನೋಡಿ, ಮೂಲ ಫೈಲ್ ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳಿ.

2 ಪುಟಗಳ ಸ್ಕ್ಯಾನ್ ಏಕೆ 8 MB ಇದೆ?

ಸ್ಕ್ಯಾನ್ ಮಾಡಿದ ಪ್ರತಿ ಪುಟವೂ ಹೆಚ್ಚು ರೆಸಲ್ಯೂಶನ್‌ನ ಫೋಟೋ. ಬ್ಯಾಂಕ್‌ನ ಟೆಕ್ಸ್ಟ್ PDF ಗಳು ಚಿತ್ರಗಳನ್ನಲ್ಲ, ಅಕ್ಷರಗಳನ್ನು ಸಂಗ್ರಹಿಸುವುದರಿಂದ ತುಂಬಾ ಚಿಕ್ಕದಾಗಿರುತ್ತವೆ.

ಪೋರ್ಟಲ್‌ಗಳು ಪಾಸ್‌ವರ್ಡ್ ಇರುವ PDF ಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತವೆಯೇ?

ಅನೇಕ ಪೋರ್ಟಲ್‌ಗಳು ಅವನ್ನು ಓದಲಾರವು. ಪೋರ್ಟಲ್ ಬೇರೆ ಹೇಳದ ಹೊರತು ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಮೊದಲು ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯಿರಿ.

ಪಾಸ್‌ಪೋರ್ಟ್ ಮತ್ತು ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳಿಗೆ ಆನ್‌ಲೈನ್ ಕಂಪ್ರೆಸರ್‌ಗಳು ಸುರಕ್ಷಿತವೇ?

ಅವು ನಿಮ್ಮ ಫೈಲ್ ಅನ್ನು ಸರ್ವರ್‌ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿಸಿಕೊಳ್ಳುತ್ತವೆ. ಗುರುತಿನ ಮತ್ತು ಹಣಕಾಸಿನ ದಾಖಲೆಗಳನ್ನು ನಿಮ್ಮ ಸ್ವಂತ ಸಾಧನದಲ್ಲೇ ಕುಗ್ಗಿಸುವುದು ಸುರಕ್ಷಿತ.

ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಬದಲಾಗಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ಕೆಲಸ ಮಾಡದಿದ್ದರೆ, ದಾಖಲೆಯೊಂದಿಗೆ ಬಂದ ಇಮೇಲ್ ನೋಡಿ ಅಥವಾ ನೀಡಿದ ಸಂಸ್ಥೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ. ಇಲ್ಲಿ ಹೆಸರಿಸಿರುವ ಯಾವುದೇ ಬ್ಯಾಂಕ್, ಉದ್ಯೋಗದಾತ ಅಥವಾ ಪ್ರಾಧಿಕಾರದೊಂದಿಗೆ UnKeyಗೆ ಸಂಬಂಧವಿಲ್ಲ.
