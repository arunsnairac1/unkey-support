ಮಾರ್ಗದರ್ಶಿಗಳು · ಹೇಗೆ ಮಾಡುವುದು

Mac ನಲ್ಲಿ PDF ನಿಂದ ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು ಹೇಗೆ (2026)

ಅಕ್ಟೋಬರ್ 2026ರಲ್ಲಿ ನವೀಕರಿಸಲಾಗಿದೆ

ಈ ಭಾಷೆಯಲ್ಲಿ ಓದಿ: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · සිංහල · தமிழ் · తెలుగు

PDF ಅನ್ನು ಪಾಸ್‌ವರ್ಡ್‌ನೊಂದಿಗೆ Preview ನಲ್ಲಿ ತೆರೆದು, File > Export ಆರಿಸಿ, ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಹೊಂದಿಸಿಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸಿ, ಹೊಸ ಪ್ರತಿ ಉಳಿಸಿ.

Mac ನಲ್ಲಿ macOS ಜೊತೆ ಬರುವ Preview ಆ್ಯಪ್‌ನಿಂದ PDF ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು ಉಚಿತವಾಗಿ ತೆಗೆಯಬಹುದು. PDF ತೆರೆದು, ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ, ನಂತರ File > Export ಆರಿಸಿ ಮತ್ತು ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದ ಹೊಸ ಪ್ರತಿ ಉಳಿಸಿ. ನಿಮಗೆ ಪಾಸ್‌ವರ್ಡ್ ತಿಳಿದಿರಬೇಕು. ಅದಿಲ್ಲದೆ Preview ಫೈಲ್ ಅನ್ನು ತೆರೆಯುವುದಿಲ್ಲ.

ವಿಧಾನ 1: Preview, File > Export

  1. PDF ಅನ್ನು ಡಬಲ್-ಕ್ಲಿಕ್ ಮಾಡಿ Preview ನಲ್ಲಿ ತೆರೆದು ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ.
  2. File > Export ಆರಿಸಿ, ಪ್ರತಿಗೆ "Statement-Oct-unlocked" ನಂತಹ ಹೊಸ ಹೆಸರು ಕೊಡಿ.
  3. Permissions ಕ್ಲಿಕ್ ಮಾಡಿ, Require Password To Open Document ಆಯ್ಕೆಯಾಗಿಲ್ಲ ಎಂದು ಖಚಿತಪಡಿಸಿ. ಹಳೆಯ macOS ಆವೃತ್ತಿಗಳಲ್ಲಿ Export ವಿಂಡೋದಲ್ಲಿ ಬದಲಿಗೆ Encrypt ಚೆಕ್‌ಬಾಕ್ಸ್ ಇರುತ್ತದೆ. ಅದನ್ನು ಟಿಕ್ ಮಾಡದೆ ಬಿಡಿ.
  4. Save ಕ್ಲಿಕ್ ಮಾಡಿ.
  5. ಹೊಸ ಫೈಲ್ ಮುಚ್ಚಿ ಮತ್ತೆ ತೆರೆಯಿರಿ. ಅದು ಪಾಸ್‌ವರ್ಡ್ ಕೇಳದೆ ತೆರೆಯಬೇಕು.

Apple ನ ಪ್ರಸ್ತುತ ಮಾರ್ಗದರ್ಶಿ Export ವಿಂಡೋ, Permissions ಬಟನ್ ಮತ್ತು Require Password To Open Document ಆಯ್ಕೆಯನ್ನು ವಿವರಿಸುತ್ತದೆ (Apple: Password-protect a PDF in Preview on Mac). ಅದೇ ಪುಟದ macOS Big Sur ಆವೃತ್ತಿ ನೇರವಾಗಿ ಹೇಳಿತ್ತು: "ನೀವು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡಿದ PDF ನಿಂದ ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯಲು, PDF ತೆರೆದು ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಆಯ್ಕೆಯನ್ನು ಆಫ್ ಮಾಡಿ ಮತ್ತೆ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಿ" (Apple, macOS Big Sur guide).

PDF ಗೆ ಮಾಲೀಕರ (ಅನುಮತಿ) ಪಾಸ್‌ವರ್ಡ್ ಕೂಡ ಇದ್ದು ಅದು ನಿಮಗೆ ತಿಳಿದಿದ್ದರೆ, File > Edit Permissions ಮೂಲಕ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಮತ್ತು ಯಾವ ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ ಪಾಸ್‌ವರ್ಡ್ ಬೇಕು ಎಂಬುದನ್ನು ಬದಲಿಸಬಹುದು.

ವಿಧಾನ 2: Print > Save as PDF

ಪ್ರಿಂಟ್ ಮಾಡಬಲ್ಲ ಯಾವುದೇ Mac ಆ್ಯಪ್ ಹೊಸ PDF ಮಾಡಬಲ್ಲದು (Apple: Save a document as a PDF on Mac):

  1. PDF ಅನ್ನು ಪಾಸ್‌ವರ್ಡ್‌ನೊಂದಿಗೆ ತೆರೆಯಿರಿ.
  2. File > Print ಆರಿಸಿ.
  3. PDF ಪಾಪ್-ಅಪ್ ಮೆನು ಕ್ಲಿಕ್ ಮಾಡಿ Save as PDF ಆರಿಸಿ.
  4. Security Options ಕ್ಲಿಕ್ ಮಾಡಬೇಡಿ, ಏಕೆಂದರೆ ಅಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ಮತ್ತೆ ಸೇರಿಸಲಾಗುತ್ತದೆ.

ಪ್ರಿಂಟ್ ಮಾಡಿದ ಪ್ರತಿಯಲ್ಲಿ ಲಿಂಕ್‌ಗಳು, ಫಾರ್ಮ್ ಕ್ಷೇತ್ರಗಳು ಅಥವಾ ಬುಕ್‌ಮಾರ್ಕ್‌ಗಳು ಕಳೆದುಹೋಗಬಹುದು. ದಾಖಲೆ ಪ್ರಿಂಟ್ ತಡೆದರೆ ಈ ವಿಧಾನ ಮಂದವಾಗಿ ಕಾಣಬಹುದು.

ವಿಧಾನ 3: Mac ಗಾಗಿ UnKey

UnKey Mac ನಲ್ಲೂ ಉಚಿತ. ಒಮ್ಮೆ ಖರೀದಿಸುವ UnKey Pro, iPhone, iPad ಮತ್ತು Mac ನಲ್ಲಿ ಬ್ಯಾಚ್ ಅನ್‌ಲಾಕ್ ಮತ್ತು ಇತರ Pro ಟೂಲ್‌ಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ. PDF ಅನ್ನು ವಿಂಡೋಗೆ ಎಳೆದು ಬಿಡಿ, ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿ, ಅದು ಅನ್‌ಲಾಕ್ ಮಾಡಿದ ಪ್ರತಿ ಉಳಿಸುತ್ತದೆ. UnKey Pro ಹಲವು ಫೈಲ್‌ಗಳನ್ನು ಒಮ್ಮೆಗೇ ಬ್ಯಾಚ್-ಅನ್‌ಲಾಕ್ ಮಾಡಬಲ್ಲದು; ಒಂದೇ ಪಾಸ್‌ವರ್ಡ್ ಹಂಚಿಕೊಳ್ಳುವ ಒಂದು ವರ್ಷದ ಮಾಸಿಕ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳಿಗೆ ಇದು ಉಪಯುಕ್ತ. UnKey ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಏನನ್ನೂ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದಿಲ್ಲ, ಮತ್ತು ನಿಮಗೆ ಈಗಾಗಲೇ ತಿಳಿದಿರುವ ಪಾಸ್‌ವರ್ಡ್‌ಗಳನ್ನು ಮಾತ್ರ ತೆಗೆಯುತ್ತದೆ.

ವಿಧಾನ 4: ಕಮಾಂಡ್ ಲೈನ್ (ತಾಂತ್ರಿಕ ಬಳಕೆದಾರರಿಗೆ)

ಉಚಿತ, ಓಪನ್-ಸೋರ್ಸ್ ಟೂಲ್ qpdf ಇದನ್ನು Terminal ನಲ್ಲಿ ಮಾಡಬಲ್ಲದು: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. ಇನ್‌ಪುಟ್ ಫೈಲ್ ಎನ್‌ಕ್ರಿಪ್ಟ್ ಆಗಿದ್ದರೂ --decrypt "ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಇಲ್ಲದ ಔಟ್‌ಪುಟ್ ಫೈಲ್" ರಚಿಸುತ್ತದೆ ಎಂದು ಅದರ ದಾಖಲೆ ವಿವರಿಸುತ್ತದೆ (qpdf documentation). ಇದನ್ನು ನೀವೇ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬೇಕು, ಉದಾಹರಣೆಗೆ Homebrew ಮೂಲಕ. ಕಮಾಂಡ್ ಲೈನ್‌ನಲ್ಲಿ ಪಾಸ್‌ವರ್ಡ್ ಟೈಪ್ ಮಾಡಿದರೆ ಅದು ನಿಮ್ಮ ಶೆಲ್ ಹಿಸ್ಟರಿಯಲ್ಲಿ ಉಳಿಯಬಹುದು.

ಇನ್ನೂ ಪಾಸ್‌ವರ್ಡ್ ಕೇಳಿದರೆ

  • ಪ್ರತಿಯ ಬದಲು ಮೂಲ ಫೈಲ್ ಅನ್ನು ತೆರೆದಿರಬಹುದು. ಫೈಲ್ ಹೆಸರು ಪರಿಶೀಲಿಸಿ.
  • ಮತ್ತೆ ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಿ, Permissions ನಲ್ಲಿ Require Password To Open Document ಆಫ್ ಆಗಿದೆ ಎಂದು ಪರಿಶೀಲಿಸಿ.
  • ಬದಲಿಗೆ Print > Save as PDF ಪ್ರಯತ್ನಿಸಿ.
  • Preview ಪಾಸ್‌ವರ್ಡ್ ತಿರಸ್ಕರಿಸಿದರೆ, ದೊಡ್ಡಕ್ಷರಗಳು ಮತ್ತು ದಿನಾಂಕ ಫಾರ್ಮ್ಯಾಟ್ ಪರಿಶೀಲಿಸಿ, ದಾಖಲೆ ಜೊತೆ ಬಂದ ಇಮೇಲ್ ಓದಿ.

ಮೂಲ ಫೈಲ್ ಅಳಿಸುವ ಮೊದಲು

ಅನ್‌ಲಾಕ್ ಮಾಡಿದ PDF ಫೈಲ್ ಇರುವ ಯಾರಿಗಾದರೂ ತೆರೆಯುತ್ತದೆ. ಕುಟುಂಬದೊಂದಿಗೆ ಹಂಚಿಕೊಂಡ iCloud Drive ಫೋಲ್ಡರ್‌ಗಳು ಮತ್ತು ನಿಮ್ಮ Mac ಅನ್ನು ಎರವಲು ಪಡೆದವರು ಇದರಲ್ಲಿ ಸೇರುತ್ತಾರೆ. ಅನ್‌ಲಾಕ್ ಮಾಡಿದ ಸ್ಟೇಟ್‌ಮೆಂಟ್‌ಗಳನ್ನು ಖಾಸಗಿ ಸ್ಥಳದಲ್ಲಿ ಇಡಿ. ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗೆ PDF ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆಯುವುದು ಸುರಕ್ಷಿತವೇ ಎಂಬುದನ್ನು ನೋಡಿ.

ಪ್ರಶ್ನೆಗಳು

Preview ನಿಜವಾಗಿಯೂ ಉಚಿತವೇ?

ಹೌದು. Preview ಪ್ರತಿ Mac ಜೊತೆ ಬರುತ್ತದೆ, ಮತ್ತು ನೀವು ಪಾಸ್‌ವರ್ಡ್ ನಮೂದಿಸಿದ ನಂತರ ಓಪನ್ ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದ PDF ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಬಲ್ಲದು.

ತಿಳಿಯದ ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು Preview ತೆಗೆಯಬಹುದೇ?

ಇಲ್ಲ. Preview ಫೈಲ್ ತೆರೆಯುವ ಮೊದಲು ಪಾಸ್‌ವರ್ಡ್ ಕೇಳುತ್ತದೆ, ಅದನ್ನು ಬಳಸದೆ ಮುಂದೆ ಹೋಗಲು ನ್ಯಾಯಬದ್ಧ ದಾರಿ ಇಲ್ಲ.

Mac ನಲ್ಲಿ ಹಲವು PDF ಗಳನ್ನು ಒಮ್ಮೆಗೇ ಅನ್‌ಲಾಕ್ ಮಾಡುವುದು ಹೇಗೆ?

Preview ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದು ಫೈಲ್ ಅನ್ನು ನಿಭಾಯಿಸುತ್ತದೆ. ಒಂದೇ ಪಾಸ್‌ವರ್ಡ್ ಇರುವ ಹಲವು PDF ಗಳನ್ನು UnKey Pro ಬ್ಯಾಚ್-ಅನ್‌ಲಾಕ್ ಮಾಡಬಲ್ಲದು, ಮತ್ತು ತಾಂತ್ರಿಕ ಬಳಕೆದಾರರು qpdf ಅನ್ನು ಸ್ಕ್ರಿಪ್ಟ್ ಮಾಡಬಹುದು. ಹಲವು PDF ಗಳನ್ನು ಒಮ್ಮೆಗೇ ಅನ್‌ಲಾಕ್ ಮಾಡುವ ನಮ್ಮ ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ.

Print > Save as PDF ಏಕೆ ಮಂದವಾಗಿದೆ?

PDF ಗೆ ಪ್ರಿಂಟ್ ತಡೆಯುವ ಅನುಮತಿ ಪಾಸ್‌ವರ್ಡ್ ಇರಬಹುದು. ಮಾಲೀಕರ ಪಾಸ್‌ವರ್ಡ್ ತಿಳಿದಿದ್ದರೆ File > Edit Permissions ಅಡಿಯಲ್ಲಿ ನಮೂದಿಸಿ. ಇಲ್ಲದಿದ್ದರೆ Export ವಿಧಾನ ಬಳಸಿ.

ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಬದಲಾಗಬಹುದು. ಪಾಸ್‌ವರ್ಡ್ ಕೆಲಸ ಮಾಡದಿದ್ದರೆ, ದಾಖಲೆಯೊಂದಿಗೆ ಬಂದ ಇಮೇಲ್ ನೋಡಿ ಅಥವಾ ನೀಡಿದ ಸಂಸ್ಥೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ. ಇಲ್ಲಿ ಹೆಸರಿಸಿರುವ ಯಾವುದೇ ಬ್ಯಾಂಕ್, ಉದ್ಯೋಗದಾತ ಅಥವಾ ಪ್ರಾಧಿಕಾರದೊಂದಿಗೆ UnKeyಗೆ ಸಂಬಂಧವಿಲ್ಲ.

ಇಂಗ್ಲಿಷ್‌ನಿಂದ ಅನುವಾದಿಸಲಾಗಿದೆ. ಏನಾದರೂ ವ್ಯತ್ಯಾಸವಿದ್ದರೆ ಇಂಗ್ಲಿಷ್ ಪುಟವೇ ಆಧಾರ.

ಒಮ್ಮೆ ಅನ್‌ಲಾಕ್ ಮಾಡಿ.

ನೀವು ಈಗಾಗಲೇ ತೆರೆಯಬಲ್ಲ PDFಗಳಿಂದ UnKey ಪಾಸ್‌ವರ್ಡ್ ತೆಗೆದುಹಾಕುತ್ತದೆ, iPhone, iPad ಮತ್ತು Macನಲ್ಲಿ. ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಏನೂ ಅಪ್‌ಲೋಡ್ ಆಗುವುದಿಲ್ಲ. ಪಾಸ್‌ವರ್ಡ್ ಒಮ್ಮೆ ಉಳಿಸಿ, ಮುಂದಿನ ತಿಂಗಳ ಸ್ಟೇಟ್‌ಮೆಂಟ್ ಅನ್ನು Face ID ತೆರೆಯುತ್ತದೆ.
