Cara Membuang Kata Laluan daripada PDF di Mac (2026)

Dikemas kini Oktober 2026

Buka PDF dalam Preview dengan kata laluannya, pilih File > Export, pastikan tiada kata laluan buka ditetapkan, dan simpan salinan baharu.

Di Mac, anda boleh membuang kata laluan PDF secara percuma dengan Preview, aplikasi yang disertakan bersama macOS. Buka PDF, masukkan kata laluan, kemudian pilih File > Export dan simpan salinan baharu tanpa kata laluan buka. Anda perlu tahu kata laluannya. Preview tidak akan membuka fail tanpanya.

Kaedah 1: Preview, File > Export

  1. Klik dua kali PDF untuk membukanya dalam Preview dan masukkan kata laluan.
  2. Pilih File > Export dan beri nama baharu kepada salinan, seperti "Statement-Oct-unlocked".
  3. Klik Permissions dan pastikan Require Password To Open Document tidak dipilih. Pada versi macOS yang lebih lama, tetingkap Export mempunyai kotak semak Encrypt. Biarkan ia tidak ditandakan.
  4. Klik Save.
  5. Tutup fail baharu dan buka semula. Ia sepatutnya terbuka tanpa meminta kata laluan.

Panduan semasa Apple menerangkan tetingkap Export, butang Permissions dan pilihan Require Password To Open Document (Apple: Password-protect a PDF in Preview on Mac). Versi macOS Big Sur bagi halaman yang sama menyatakannya secara langsung: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide).

Jika PDF turut mempunyai kata laluan pemilik (kebenaran) dan anda tahu kata laluan itu, File > Edit Permissions membolehkan anda menukar kata laluan membuka dan ciri mana yang memerlukan kata laluan.

Kaedah 2: Print > Save as PDF

Mana-mana aplikasi Mac yang boleh mencetak boleh membuat PDF baharu (Apple: Save a document as a PDF on Mac):

  1. Buka PDF dengan kata laluannya.
  2. Pilih File > Print.
  3. Klik menu timbul PDF dan pilih Save as PDF.
  4. Jangan klik Security Options, kerana di situlah anda akan menambah semula kata laluan.

Salinan yang dicetak mungkin kehilangan pautan, medan borang atau penanda halaman. Jika dokumen menyekat pencetakan, kaedah ini mungkin berwarna kelabu.

Kaedah 4: Baris arahan (untuk pengguna teknikal)

Alat sumber terbuka percuma qpdf boleh melakukannya dalam Terminal: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. Dokumentasinya menerangkan --decrypt sebagai mencipta "an output file with no encryption even if the input file is encrypted" (qpdf documentation). Anda memasangnya sendiri, contohnya dengan Homebrew. Menaip kata laluan pada baris arahan boleh meninggalkannya dalam sejarah shell anda.

Jika ia masih meminta kata laluan

  • Anda mungkin telah membuka fail asal dan bukannya salinan. Semak nama fail.
  • Eksport semula dan pastikan Require Password To Open Document dimatikan dalam Permissions.
  • Cuba Print > Save as PDF sebaliknya.
  • Jika Preview menolak kata laluan, semak huruf besar dan format tarikh, dan baca e-mel yang disertakan bersama dokumen.

Sebelum anda memadam fail asal

PDF tanpa kunci terbuka untuk sesiapa yang memiliki fail itu. Ini termasuk folder iCloud Drive yang dikongsi dengan keluarga dan sesiapa yang meminjam Mac anda. Simpan penyata tanpa kunci di tempat yang peribadi. Lihat adakah selamat membuang kata laluan PDF untuk maklumat lanjut.

Soalan

Adakah Preview benar-benar percuma?

Ya. Preview disertakan dengan setiap Mac dan boleh mengeksport PDF tanpa kata laluan buka setelah anda memasukkan kata laluan.

Bolehkah Preview membuang kata laluan yang saya tidak tahu?

Tidak. Preview meminta kata laluan sebelum membuka fail, dan tiada cara sah untuk mengelaknya.

Bagaimana membuka kunci banyak PDF sekaligus di Mac?

Preview mengendalikan satu fail pada satu masa. UnKey Pro boleh membuka kunci beberapa PDF yang berkongsi kata laluan, dan pengguna teknikal boleh membuat skrip qpdf. Lihat panduan kami tentang membuka kunci banyak PDF sekaligus.

Mengapa Print > Save as PDF berwarna kelabu?

PDF itu mungkin mempunyai kata laluan kebenaran yang menyekat pencetakan. Jika anda tahu kata laluan pemilik, masukkannya di bawah File > Edit Permissions. Jika tidak, guna kaedah Export.
