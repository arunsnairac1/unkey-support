Cara Membuang Kata Laluan PDF di Windows (2026)

Dikemas kini Oktober 2026

Buka PDF dalam Microsoft Edge atau Chrome dengan kata laluannya, tekan Ctrl+P, pilih Save as PDF (atau Microsoft Print to PDF) dan simpan salinan baharu; Acrobat berbayar boleh membuang keselamatan terus.

Di Windows 10 dan 11 anda boleh membuang kata laluan PDF secara percuma dengan pelayar yang sudah anda ada. Buka PDF dalam Microsoft Edge atau Google Chrome, taip kata laluan, tekan Ctrl + P, pilih Save as PDF (atau Microsoft Print to PDF) sebagai pencetak, dan simpan. Fail baharu terbuka tanpa kata laluan. Anda perlu tahu kata laluannya dahulu.

Kaedah 1: Microsoft Edge (terbina dalam)

  1. Klik kanan PDF dalam File Explorer dan pilih Open with > Microsoft Edge.
  2. Taip kata laluan apabila Edge memintanya.
  3. Tekan Ctrl + P, atau buka menu More (tiga titik) dan pilih Print.
  4. Di bawah Printer, pilih Save as PDF atau Microsoft Print to PDF.
  5. Klik Save (atau Print), pilih folder dan beri nama baharu kepada salinan.
  6. Buka fail baharu untuk menyemak ia tidak lagi meminta kata laluan.

Panduan Microsoft untuk pembaca PDF terbina dalamnya menunjukkan laluan Edge: cari Print di bawah menu More, pilih pilihan anda, kemudian cetak (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF ialah pencetak yang disertakan bersama Windows. Jika ia tiada dalam senarai, Microsoft menyatakan ia boleh dihidupkan semula di bawah Windows Optional Features (Microsoft: KB5058499 known issue).

Kaedah 2: Google Chrome

Jika anda guna Chrome, langkahnya hampir sama: buka PDF dalam Chrome, masukkan kata laluan, tekan Ctrl + P, tetapkan Destination kepada Save as PDF, dan klik Save (Google: Print from Chrome). Terdapat butiran lanjut dalam panduan Chrome kami.

Kaedah 3: Adobe Acrobat Pro atau Standard (berbayar)

Acrobat berbayar membuang penyulitan itu sendiri dan bukannya mencetak semula fail, jadi pautan dan medan borang kekal utuh. Adobe mendokumenkan dua laluan (Adobe: Remove passwords from PDFs):

  • Alat Protect: buka PDF, pergi ke alat Protect dan pilih Remove Security. Jika fail hanya mempunyai kata laluan buka, sahkan dengan OK. Jika ia juga mempunyai kata laluan kebenaran, Acrobat meminta kata laluan itu dahulu.
  • Tetapan keselamatan: buka sifat keselamatan dokumen, pergi ke tab Security, pilih Change Settings, kosongkan pilihan kata laluan dan simpan.

Menu Adobe berubah antara versi, jadi jika anda tidak nampak nama yang tepat ini, cari “Remove Security” dalam carian alat Acrobat. Acrobat Reader percuma boleh membuka PDF yang dilindungi tetapi bukan alat untuk membuang keselamatan. Guna Kaedah 1 atau 2 sebaliknya.

Kaedah 4: qpdf (pengguna teknikal)

Alat sumber terbuka percuma qpdf berjalan di Windows. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf menulis salinan tanpa penyulitan (qpdf documentation). Kata laluan mungkin tersimpan dalam sejarah arahan anda, jadi kosongkannya selepas itu pada PC yang dikongsi.

Perkara untuk disemak

  • Print berwarna kelabu? PDF mungkin mempunyai kata laluan kebenaran yang menyekat pencetakan. Lihat sekatan pencetakan dan penyalinan.
  • Kata laluan ditolak? Semak Caps Lock, format tarikh dan butiran yang dipegang bank anda. Lihat mengapa kata laluan PDF tidak berfungsi.
  • PC kongsi atau pejabat? Salinan tanpa kunci terbuka untuk sesiapa yang menjumpainya. Simpan di folder peribadi dan padamkan daripada Downloads.

Soalan

Adakah saya perlu memasang apa-apa di Windows?

Tidak. Microsoft Edge dan pencetak Microsoft Print to PDF disertakan bersama Windows 10 dan 11.

Adakah laman “unlock PDF” dalam talian lebih berkesan?

Ia melakukan kerja yang sama tetapi memuat naik dokumen anda ke pelayan orang lain. Untuk penyata bank dan kertas cukai, kaedah luar talian di sini lebih selamat.

Bolehkah mana-mana kaedah ini membuang kata laluan yang saya sudah lupa?

Tidak. Edge, Chrome, Acrobat dan qpdf semuanya memerlukan kata laluan yang betul. Semak e-mel yang disertakan bersama PDF untuk formatnya.

Mengapa pautan berhenti berfungsi dalam salinan?

Mencetak ke PDF membina semula halaman, yang boleh menghilangkan pautan dan medan borang. Remove Security Acrobat atau qpdf mengekalkannya.
