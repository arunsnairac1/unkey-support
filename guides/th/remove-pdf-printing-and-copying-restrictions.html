รหัสผ่านเปิดไฟล์ป้องกันไม่ให้ใครอ่าน PDF ส่วนรหัสผ่านเจ้าของ (สิทธิ์) จำกัดเฉพาะการกระทำ เช่น การพิมพ์ คัดลอก และแก้ไข

PDF มีรหัสผ่านได้สองแบบที่ต่างกัน รหัสผ่านเปิดไฟล์ (เรียกอีกอย่างว่ารหัสผ่านผู้ใช้) จำเป็นต่อการดูไฟล์เลย ส่วน รหัสผ่านเจ้าของ (เรียกอีกอย่างว่ารหัสผ่านสิทธิ์) ให้คุณเปิดไฟล์ได้ แต่จำกัดสิ่งต่าง ๆ เช่น การพิมพ์ คัดลอกข้อความ หรือแก้ไข หากต้องการยกเลิกข้อจำกัดอย่างถูกต้อง คุณต้องมีรหัสผ่านเจ้าของ

รหัสผ่านสองแบบแบบเข้าใจง่าย

รหัสผ่านเปิดไฟล์ (ผู้ใช้)รหัสผ่านเจ้าของ (สิทธิ์)
สิ่งที่คุณเห็นหน้าต่างขอรหัสผ่านก่อนแสดงอะไรทั้งนั้นไฟล์เปิดได้ แต่ Print หรือ Copy กดไม่ได้
สิ่งที่ปกป้องเนื้อหาทั้งหมด ซึ่งถูกเข้ารหัสการกระทำ เช่น การพิมพ์ คัดลอก แก้ไข และแสดงความคิดเห็น
การใช้งานทั่วไปใบแจ้งยอดธนาคาร เอกสารภาษีรายงานที่เผยแพร่ ฟอร์ม สัญญา

Adobe อธิบายการแบ่งแบบเดียวกัน รหัสผ่านเปิดเอกสารจำเป็นต่อการเปิด PDF ส่วนรหัสผ่านสิทธิ์จำกัดฟีเจอร์ เช่น การพิมพ์ แก้ไข และคัดลอก (Adobe: Password security overview) เอกสารของ qpdf เพิ่มรายละเอียดสำคัญว่า โปรแกรมอ่าน "apply security restrictions to files opened with the user password" และ "allow security restrictions to be changed or overridden when files are opened with the owner password" (qpdf)

ข้อจำกัดบังคับใช้อย่างไร

ข้อจำกัดขึ้นอยู่กับว่าโปรแกรมอ่าน PDF เลือกที่จะทำตามหรือไม่ Adobe ระบุว่าผลิตภัณฑ์ของตนบังคับใช้ แต่ถ้าผลิตภัณฑ์ของบริษัทอื่นไม่รองรับการตั้งค่าเหล่านี้ ผู้รับอาจข้ามข้อจำกัดบางส่วนหรือทั้งหมดได้ (Adobe) รหัสผ่านสิทธิ์จึงเป็นเพียงคำขอร้องอย่างสุภาพว่า "กรุณาอย่า" มากกว่าจะเป็นกุญแจล็อก แต่ก็ไม่ใช่เหตุผลให้เพิกเฉยต่อเจตนาของผู้เขียน ถ้ามีคนจำกัดการคัดลอกก็มักมีเหตุผล เช่น ลิขสิทธิ์หรือสัญญา

เปลี่ยนข้อจำกัดเมื่อคุณมีรหัสผ่านเจ้าของ

บน Mac (Preview): เปิด PDF เลือก File > Edit Permissions แล้วใส่รหัสผ่านเจ้าของ จากนั้นเลือกการกระทำที่ต้องการให้ทำได้โดยไม่ต้องใช้รหัสผ่าน แล้วคลิก Apply (Apple: Password-protect a PDF in Preview on Mac) แผง Permissions เดียวกันนี้ปรากฏใต้ File > Export ถ้าต้องการสำเนาใหม่

ใน Adobe Acrobat: คำแนะนำของ Adobe สำหรับการลบรหัสผ่านสิทธิ์ให้พิมพ์รหัสผ่านในช่อง Enter Password (Adobe: How to remove a PDF password)

บนบรรทัดคำสั่ง: qpdf กับ --password=OWNERPASSWORD --decrypt เขียนสำเนาที่ไม่มีการเข้ารหัส เอกสารของ qpdf ระบุว่าตัวเลือกนี้ไม่ได้มีไว้เพื่อหลีกเลี่ยงข้อจำกัดที่ผู้สร้างไฟล์กำหนด (qpdf)

เอกสารของคุณเองที่มีรหัสผ่านทั้งสองแบบ

ใบแจ้งยอดธนาคารปกติใช้เฉพาะรหัสผ่านเปิดไฟล์ เมื่อเปิดแล้ว คุณมักพิมพ์และคัดลอกได้อย่างอิสระ ถ้าคุณสร้าง PDF เองใน Preview หรือ Acrobat และตั้งรหัสผ่านทั้งสองแบบ ให้ใช้รหัสผ่านเจ้าของเปลี่ยนสิทธิ์หรือ export สำเนาที่ไม่มีข้อจำกัด

หากต้องการลบรหัสผ่านเปิดไฟล์จากไฟล์ของคุณเอง เช่น ใบแจ้งยอดรายเดือน คุณใช้ Preview บน Mac หรือ UnKey บน iPhone, iPad หรือ Mac ได้ UnKey ทำงานออฟไลน์และใช้ได้เฉพาะกับรหัสผ่านที่คุณรู้อยู่แล้ว

เมื่อคุณไม่มีรหัสผ่านเจ้าของ

  • ขอสำเนาที่ไม่มีข้อจำกัดจากผู้เขียนหรือผู้ส่ง หรือขออนุญาตพิมพ์หรือคัดลอก
  • สำหรับฟอร์มที่ต้องกรอก ตรวจดูว่าอนุญาตให้กรอกอยู่แล้วหรือไม่ PDF ที่มีข้อจำกัดหลายไฟล์ยังให้กรอกฟอร์มได้
  • สำหรับเอกสารการทำงานหรือเอกสารทางกฎหมาย ให้ถือว่าข้อจำกัดนั้นตั้งใจไว้

คำถาม

รหัสผ่านเจ้าของ PDF คืออะไร

คือรหัสผ่านที่ควบคุมสิทธิ์ เช่น การพิมพ์ คัดลอก และแก้ไข ไฟล์เปิดได้โดยไม่ต้องใช้ แต่การกระทำที่ถูกจำกัดจะถูกบล็อกในโปรแกรมอ่านที่เคารพการตั้งค่า

ทำไมเปิด PDF ได้แต่พิมพ์ไม่ได้

ไฟล์มีรหัสผ่านเจ้าของ (สิทธิ์) ที่ไม่อนุญาตให้พิมพ์ ใส่รหัสผ่านเจ้าของใน Preview ที่ File > Edit Permissions หรือขอสำเนาที่ไม่มีข้อจำกัดจากผู้ส่ง

ใบแจ้งยอดธนาคารมีข้อจำกัดการพิมพ์ไหม

โดยปกติไม่มี มักใช้เฉพาะรหัสผ่านเปิดไฟล์ เมื่อเปิดไฟล์แล้วก็พิมพ์ได้

การลบข้อจำกัดการคัดลอก PDF ถูกกฎหมายไหม

การเปลี่ยนสิทธิ์ของไฟล์ของคุณเองด้วยรหัสผ่านเจ้าของของคุณเองทำได้ ส่วนการข้ามข้อจำกัดของเอกสารคนอื่นอาจละเมิดลิขสิทธิ์หรือข้อกำหนดในสัญญา จึงควรถามเจ้าของ
