วิธีลบรหัสผ่าน PDF ใน Chrome (2026)

อัปเดตเมื่อ ตุลาคม 2026

เปิด PDF ใน Chrome ด้วยรหัสผ่าน กด Ctrl+P หรือ Cmd+P ตั้งปลายทางเป็น Save as PDF แล้วบันทึกสำเนาใหม่ที่ไม่มีรหัสผ่าน

Google Chrome บันทึกสำเนาของ PDF ที่มีรหัสผ่านโดยไม่มีรหัสผ่านได้ฟรี บน Windows, Mac และ Linux เปิด PDF ใน Chrome พิมพ์รหัสผ่าน กด Ctrl + P (Cmd + P บน Mac) ตั้งปลายทางเป็น Save as PDF แล้วบันทึก คุณต้องรู้รหัสผ่านอยู่แล้ว เพราะ Chrome เปิดไฟล์ไม่ได้ถ้าไม่มีรหัสผ่าน

ทีละขั้นตอน (คอมพิวเตอร์)

  1. ลาก PDF เข้าไปในหน้าต่าง Chrome หรือคลิกขวาที่ไฟล์แล้วเลือก Open with > Google Chrome
  2. Chrome จะขอรหัสผ่าน พิมพ์แล้วกด Enter
  3. กด Ctrl + P บน Windows หรือ Linux หรือ Cmd + P บน Mac หรือใช้เมนู: File > Print
  4. ในหน้าต่างพิมพ์ ตั้ง Destination เป็น Save as PDF
  5. คลิก Save ตั้งชื่อไฟล์ใหม่ให้ชัดเจน เช่น Statement-Sep-2026-unlocked.pdf
  6. ปิดแล้วเปิดไฟล์ใหม่อีกครั้ง ควรเปิดได้ทันทีโดยไม่ถามรหัสผ่าน

หน้าช่วยเหลือของ Google อธิบายคีย์ลัด การเลือกปลายทางในหน้าต่างพิมพ์ และตัวเลือก Save as PDF (Google: Print from Chrome)

บนมือถือ Android

Chrome บน Android มีตัวเลือกเดียวกัน ขั้นตอนของ Google คือ แตะ More > Share แตะ Print แล้วแตะ Save as PDF และเลือกที่บันทึกไฟล์ (Google: Print from Chrome on Android) การที่ Chrome เปิด PDF ที่เก็บในมือถือได้หรือไม่ขึ้นอยู่กับเวอร์ชันของ Chrome ถ้าเปิดไม่ได้ ดูคู่มือการเปิด PDF ที่มีรหัสผ่านบน Android

สิ่งที่คุณเสียไปกับวิธีนี้

การบันทึกผ่านหน้าต่างพิมพ์สร้าง PDF ใหม่ทั้งฉบับจากสิ่งที่อยู่บนหน้าจอ ซึ่งไม่เป็นไรสำหรับการอ่าน เก็บถาวร หรืออัปโหลดใบแจ้งยอด แต่ควรตรวจสำเนาก่อนลบต้นฉบับ:

  • ลิงก์และบุ๊กมาร์กอาจใช้ไม่ได้
  • ช่องฟอร์มอาจถูกรวมเป็นภาพเรียบ ทำให้พิมพ์ลงไปไม่ได้อีก
  • ลายเซ็นดิจิทัลไม่ถูกนำมาด้วย ถ้าเว็บต้องการต้นฉบับที่ลงลายเซ็น ให้อัปโหลดต้นฉบับ
  • ขนาดหน้าเป็นไปตามการตั้งค่าการพิมพ์ ใต้ More settings ตรวจว่าขนาดกระดาษและสเกลไม่ได้ทำให้หน้าเล็กลงหรือถูกตัด

ถ้า Save as PDF ใช้ไม่ได้

  • การพิมพ์ถูกบล็อก PDF บางไฟล์มีรหัสผ่านสิทธิ์ที่ห้ามพิมพ์ รหัสผ่านสิทธิ์แยกจากรหัสผ่านเปิดไฟล์ ดูข้อจำกัดการพิมพ์และการคัดลอก PDF อธิบาย
  • Chrome ปฏิเสธรหัสผ่าน ตรวจตัวพิมพ์ใหญ่ รูปแบบวันที่ และข้อมูลที่ธนาคารมีในบันทึก ดูทำไมรหัสผ่าน PDF ใช้ไม่ได้
  • ไฟล์เปิดในแอปอื่น คอมพิวเตอร์บางเครื่องเปิด PDF ด้วยโปรแกรมอ่านตัวอื่นโดยปริยาย ให้ลากไฟล์เข้าแท็บ Chrome แทน

วิธีอื่นในการลบรหัสผ่าน

Microsoft Edge ทำงานแบบเดียวกันบน Windows (ดูการลบรหัสผ่าน PDF บน Windows) บน Mac, Preview export สำเนาที่ไม่มีรหัสผ่านได้ (คู่มือ Mac) บน iPhone, iPad และ Mac UnKey บันทึกสำเนาที่ปลดล็อกแบบออฟไลน์ และเก็บข้อความ ลิงก์ และหน้าไว้ตามเดิม เพราะลบการเข้ารหัสออกแทนการพิมพ์ไฟล์ใหม่ เช่นเดียวกับ Chrome ใช้ได้เฉพาะกับรหัสผ่านที่คุณรู้อยู่แล้ว

คำถาม

Chrome อัปโหลด PDF ของฉันเมื่อทำแบบนี้ไหม

ไม่ การเปิดไฟล์ PDF จากคอมพิวเตอร์แล้วบันทึกด้วย Save as PDF เกิดขึ้นในเบราว์เซอร์บนคอมพิวเตอร์ของคุณ ใช้ปลายทาง "Save to Google Drive" แยกต่างหากเมื่อต้องการสำเนาใน Drive เท่านั้น

Chrome ลบรหัสผ่านที่ฉันไม่รู้ได้ไหม

ไม่ได้ Chrome ขอรหัสผ่านก่อนแสดงอะไรทั้งนั้น ถ้าทำหาย ดูว่าต้องทำอย่างไรเมื่อลืมรหัสผ่าน PDF

ทำไมสำเนาที่บันทึกต่างจากต้นฉบับ

Save as PDF พิมพ์หน้าต่าง ๆ ลงไฟล์ใหม่ ลิงก์ ช่องฟอร์ม และลายเซ็นจึงอาจไม่ติดมา ส่วนข้อความและเลย์เอาต์มักดูเหมือนเดิม

ทำแบบนี้ได้ไหม

สำหรับเอกสารของคุณเอง เช่น ใบแจ้งยอดธนาคารของคุณ ได้ อย่าลบการป้องกันจากไฟล์ที่คุณไม่มีสิทธิ์เปิดได้อย่างเสรี

แหล่งข้อมูล

  • Google Chrome Help – Print from Chrome (computer)
  • Google Chrome Help – Print from Chrome (Android)

รูปแบบอาจเปลี่ยนแปลงได้ หากรหัสผ่านใช้ไม่ได้ ให้ตรวจสอบอีเมลที่ส่งมาพร้อมเอกสาร หรือติดต่อผู้ออกเอกสาร UnKey ไม่มีส่วนเกี่ยวข้องกับธนาคาร นายจ้าง หรือหน่วยงานใดที่กล่าวถึงในที่นี้

แปลจากภาษาอังกฤษ หากมีข้อแตกต่าง ให้ถือตามหน้าภาษาอังกฤษ

ปลดล็อก ได้ในครั้งเดียว

UnKey ลบรหัสผ่านออกจาก PDF ที่คุณเปิดได้อยู่แล้ว บน iPhone, iPad และ Mac ทำงานออฟไลน์ ไม่มีการอัปโหลดใดๆ บันทึกรหัสผ่านครั้งเดียว แล้ว Face ID จะเปิดใบแจ้งยอดเดือนหน้าให้
