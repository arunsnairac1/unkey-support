วิธีลบรหัสผ่าน PDF บน Windows (2026)

อัปเดตเมื่อ ตุลาคม 2026

เปิด PDF ใน Microsoft Edge หรือ Chrome ด้วยรหัสผ่าน กด Ctrl+P เลือก Save as PDF (หรือ Microsoft Print to PDF) แล้วบันทึกสำเนาใหม่ Acrobat แบบเสียเงินลบการป้องกันได้โดยตรง

บน Windows 10 และ 11 คุณลบรหัสผ่าน PDF ได้ฟรีด้วยเบราว์เซอร์ที่มีอยู่แล้ว เปิด PDF ใน Microsoft Edge หรือ Google Chrome พิมพ์รหัสผ่าน กด Ctrl + P เลือก Save as PDF (หรือ Microsoft Print to PDF) เป็นเครื่องพิมพ์ แล้วบันทึก ไฟล์ใหม่จะเปิดได้โดยไม่ต้องใช้รหัสผ่าน คุณต้องรู้รหัสผ่านก่อน

วิธีที่ 1: Microsoft Edge (มีในตัว)

  1. คลิกขวาที่ PDF ใน File Explorer แล้วเลือก Open with > Microsoft Edge
  2. พิมพ์รหัสผ่านเมื่อ Edge ถาม
  3. กด Ctrl + P หรือเปิดเมนู More (จุดสามจุด) แล้วเลือก Print
  4. ใต้ Printer เลือก Save as PDF หรือ Microsoft Print to PDF
  5. คลิก Save (หรือ Print) เลือกโฟลเดอร์ และตั้งชื่อสำเนาใหม่
  6. เปิดไฟล์ใหม่เพื่อตรวจว่าไม่ถามรหัสผ่านอีกแล้ว

คู่มือของ Microsoft เกี่ยวกับตัวอ่าน PDF ในตัวแสดงเส้นทางของ Edge ไว้ว่า หา Print ใต้เมนู More เลือกตัวเลือก แล้วพิมพ์ (Microsoft: View, print, and edit PDFs in a PDF reader) Microsoft Print to PDF เป็นเครื่องพิมพ์ที่มากับ Windows ถ้าไม่มีในรายการ Microsoft ระบุว่าเปิดกลับมาได้ใน Windows Optional Features (Microsoft: KB5058499 known issue)

วิธีที่ 2: Google Chrome

ถ้าคุณใช้ Chrome ขั้นตอนเกือบเหมือนกัน: เปิด PDF ใน Chrome ใส่รหัสผ่าน กด Ctrl + P ตั้ง Destination เป็น Save as PDF แล้วคลิก Save (Google: Print from Chrome) รายละเอียดเพิ่มเติมอยู่ในคู่มือ Chrome

วิธีที่ 3: Adobe Acrobat Pro หรือ Standard (เสียเงิน)

Acrobat แบบเสียเงินลบการเข้ารหัสเอง แทนการพิมพ์ไฟล์ใหม่ ลิงก์และช่องฟอร์มจึงยังอยู่ครบ Adobe ระบุไว้สองเส้นทาง (Adobe: Remove passwords from PDFs):

  • เครื่องมือ Protect: เปิด PDF ไปที่เครื่องมือ Protect แล้วเลือก Remove Security ถ้าไฟล์มีแค่รหัสผ่านเปิดไฟล์ ให้กด OK เพื่อยืนยัน ถ้ามีรหัสผ่านสิทธิ์ด้วย Acrobat จะขอรหัสผ่านนั้นก่อน
  • Security settings: เปิดคุณสมบัติด้านความปลอดภัยของเอกสาร ไปที่แท็บ Security เลือก Change Settings ล้างตัวเลือกรหัสผ่าน แล้วบันทึก

เมนูของ Adobe ย้ายที่ไปมาตามเวอร์ชัน ถ้าไม่เห็นชื่อตรงตามนี้ ให้ค้นหา "Remove Security" ในช่องค้นหาเครื่องมือของ Acrobat Acrobat Reader ฟรีเปิด PDF ที่มีรหัสผ่านได้ แต่ไม่ใช่เครื่องมือสำหรับลบการป้องกัน ให้ใช้วิธีที่ 1 หรือ 2 แทน

วิธีที่ 4: qpdf (ผู้ใช้ที่ชำนาญ)

qpdf เครื่องมือโอเพนซอร์สฟรีทำงานบน Windows ได้ qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf เขียนสำเนาที่ไม่มีการเข้ารหัส (qpdf documentation) รหัสผ่านอาจถูกเก็บในประวัติคำสั่ง ดังนั้นให้ล้างออกหลังใช้บนพีซีที่ใช้ร่วมกัน

สิ่งที่ควรตรวจ

  • Print กดไม่ได้? PDF อาจมีรหัสผ่านสิทธิ์ที่ห้ามพิมพ์ ดูข้อจำกัดการพิมพ์และการคัดลอก
  • รหัสผ่านถูกปฏิเสธ? ตรวจ Caps Lock รูปแบบวันที่ และข้อมูลที่ธนาคารมี ดูทำไมรหัสผ่าน PDF ใช้ไม่ได้
  • พีซีที่ใช้ร่วมกันหรือที่ออฟฟิศ? สำเนาที่ปลดล็อกเปิดได้สำหรับใครก็ตามที่เจอ บันทึกไว้ในโฟลเดอร์ส่วนตัวและลบออกจาก Downloads

ถ้าคุณมี iPhone, iPad หรือ Mac ด้วย UnKey ลบรหัสผ่านแบบออฟไลน์บนอุปกรณ์เหล่านั้น และบันทึกรหัสผ่านไว้สำหรับใบแจ้งยอดเดือนหน้าได้ ไม่มีแอป UnKey สำหรับ Windows

คำถาม

ต้องติดตั้งอะไรบน Windows ไหม

ไม่ต้อง Microsoft Edge และเครื่องพิมพ์ Microsoft Print to PDF มากับ Windows 10 และ 11

เว็บ "ปลดล็อก PDF" ออนไลน์ใช้ได้ดีกว่าไหม

ทำงานเดียวกัน แต่อัปโหลดเอกสารของคุณไปยังเซิร์ฟเวอร์ของคนอื่น สำหรับใบแจ้งยอดธนาคารและเอกสารภาษี วิธีออฟไลน์ในที่นี้ปลอดภัยกว่า

วิธีเหล่านี้ลบรหัสผ่านที่ลืมได้ไหม

ไม่ได้ Edge, Chrome, Acrobat และ qpdf ต้องมีรหัสผ่านที่ถูกต้องทั้งหมด ดูรูปแบบจากอีเมลที่ส่ง PDF มา

ทำไมลิงก์ในสำเนาใช้ไม่ได้

การพิมพ์เป็น PDF สร้างหน้าใหม่ทั้งหมด ซึ่งอาจทำให้ลิงก์และช่องฟอร์มหายไป Remove Security ของ Acrobat หรือ qpdf เก็บไว้ได้

แหล่งข้อมูล

  • Microsoft Support – View, print, and edit PDFs in a PDF reader
  • Microsoft Support – KB5058499 (Microsoft Print to PDF known issue)
  • Google Chrome Help – Print from Chrome
  • Adobe – Remove passwords from PDFs in Acrobat
  • qpdf – Command-line options

รูปแบบอาจเปลี่ยนแปลงได้ หากรหัสผ่านใช้ไม่ได้ ให้ตรวจสอบอีเมลที่ส่งมาพร้อมเอกสาร หรือติดต่อผู้ออกเอกสาร UnKey ไม่มีส่วนเกี่ยวข้องกับธนาคาร นายจ้าง หรือหน่วยงานใดที่กล่าวถึงในที่นี้

แปลจากภาษาอังกฤษ หากมีข้อแตกต่าง ให้ถือตามหน้าภาษาอังกฤษ

ปลดล็อก ได้ในครั้งเดียว

UnKey ลบรหัสผ่านออกจาก PDF ที่คุณเปิดได้อยู่แล้ว บน iPhone, iPad และ Mac ทำงานออฟไลน์ ไม่มีการอัปโหลดใดๆ บันทึกรหัสผ่านครั้งเดียว แล้ว Face ID จะเปิดใบแจ้งยอดเดือนหน้าให้
