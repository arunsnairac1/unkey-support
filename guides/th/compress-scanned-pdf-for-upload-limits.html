ลดขนาดไฟล์ PDF สแกนให้อัปโหลดได้ตามขีดจำกัด

อัปเดตเมื่อ ตุลาคม 2026

อ่านเป็นภาษา: English · العربية · বাংলা · Deutsch · Español · Filipino · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · Italiano · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · ไทย · اردو · Tiếng Việt

PDF ที่สแกนมีขนาดใหญ่เพราะทุกหน้าเป็นรูปถ่าย ลดขนาดได้ด้วย Reduce File Size ของ Preview บน Mac หรือตัวเลือกส่งออกของ Preview บน iPhone สแกนให้น้อยหน้าและเรียบง่ายขึ้น และลบรหัสผ่านก่อนอัปโหลด

เว็บยื่นวีซ่า หนังสือเดินทาง สอบ และสินเชื่อ มักจำกัดขนาดไฟล์อัปโหลดไว้ที่ไม่กี่ร้อยกิโลไบต์ หรือไม่กี่เมกะไบต์ต่อไฟล์ PDF ที่สแกนมักใหญ่เกินกว่านั้น เพราะแต่ละหน้าถูกเก็บเป็นรูปถ่าย วิธีที่เร็วที่สุดคือบันทึก PDF ใหม่พร้อมบีบอัดรูปภาพ (Preview บน Mac หรือ iPhone ทำได้ฟรี) สแกนเฉพาะหน้าที่จำเป็น และลบรหัสผ่านออกก่อน เพราะหลายเว็บอ่านไฟล์ที่มีรหัสผ่านไม่ได้

ก่อนบีบอัดไฟล์

  • ตรวจขีดจำกัดและรูปแบบไฟล์ที่แน่นอนในหน้าเว็บ ได้แก่ ขนาดสูงสุด จำกัดต่อไฟล์หรือรวมทั้งหมด และต้องการ PDF หรือ JPEG กฎของแต่ละเว็บไม่เหมือนกันและเปลี่ยนได้ ให้ยึดตามที่หน้าอัปโหลดระบุ
  • ลบรหัสผ่านออก เว็บเปิดตรวจ PDF ที่มีรหัสผ่านไม่ได้ ดูวิธีบน iPhone, Mac, Windows หรือ Android
  • เก็บไฟล์ต้นฉบับไว้ การบีบอัดทำให้คุณภาพภาพลดลง เก็บสำเนาคุณภาพเต็มไว้เผื่อเว็บปฏิเสธไฟล์ที่ภาพเบลอ

บน Mac: ใช้ Preview

  1. เปิด PDF ใน Preview แล้วเลือก File > Export
  2. ในเมนู Quartz Filter เลือก Reduce File Size
  3. ตั้งชื่อใหม่ แล้วคลิก Save

Apple ระบุว่า PDF ที่บีบอัดแล้ว "อาจมีคุณภาพต่ำกว่าต้นฉบับ" หน้าต่าง Export เดียวกันยังมีตัวเลือก Optimize images for screen และ Save images as JPEG ด้วย (Apple: Reduce the size of a PDF in Preview on Mac) Reduce File Size อาจทำให้ไฟล์สแกนที่มีตัวหนังสือเยอะอ่านยาก จึงควรเปิดผลลัพธ์และซูมดูก่อนอัปโหลด

บน iPhone หรือ iPad: ใช้ Preview (iOS 26 ขึ้นไป)

  1. เปิด PDF ในแอป Preview
  2. แตะเมนูข้างชื่อไฟล์ แล้วแตะ Export
  3. เลือก PDF แล้วเปิด Optimize Images for Screen และ Save Images as JPEG
  4. แตะปุ่มยืนยัน เลือกตำแหน่งที่จะบันทึก ตั้งชื่อใหม่ แล้วแตะ Save

Apple ระบุว่า Optimize Images for Screen "สร้างไฟล์ที่เล็กลง" (Apple: Export or compress PDFs in Preview on iPhone) ถ้าเว็บต้องการ JPEG แทน หน้าจอเดียวกันนี้ส่งออกเป็น JPEG ได้และมีแถบเลื่อนปรับขนาด

สแกนให้ไฟล์เล็กตั้งแต่แรก

  • เฉพาะหน้าที่ขอ ลบหน้าที่ไม่จำเป็นก่อนอัปโหลด Preview บน iPhone ลบและจัดลำดับหน้าได้ (Apple)
  • ใช้ตัวสแกนเอกสาร ไม่ใช่กล้องถ่ายรูป Notes, Files และ Preview จะครอบตัดและปรับหน้ากระดาษให้เรียบ (Apple: How to scan documents on iPhone) ไฟล์สแกนที่ครอบตัดแล้วเล็กกว่ารูปถ่ายที่เห็นโต๊ะด้วย
  • เป็นขาวดำหรือโทนสีเทาสำหรับเอกสารที่เป็นตัวหนังสือ ถ้าเว็บอนุญาต ตัวสแกนใน Preview ให้ปรับโทนสีของแต่ละหน้าได้ (Apple) เก็บสีไว้สำหรับรูปถ่ายและเอกสารที่มีตราประทับซึ่งเจ้าหน้าที่ต้องเห็น
  • หนึ่งไฟล์ต่อหนึ่งเอกสาร ถ้าเว็บแยกช่องอัปโหลดไว้ อย่ารวมทุกอย่างเป็น PDF ไฟล์ใหญ่ไฟล์เดียว

ปัญหาที่พบบ่อย

  • ยังใหญ่เกินไป: ส่งออกอีกครั้งโดยเปิดทั้งสองตัวเลือก หรือสแกนใหม่เป็นโทนสีเทา
  • ตัวหนังสือเบลอ: บีบอัดมากเกินไป กลับไปที่ต้นฉบับแล้วใช้เพียงตัวเลือกเดียว
  • เว็บแจ้งว่า "ไฟล์เสียหาย" หรือ "เข้ารหัส": ไฟล์น่าจะยังมีรหัสผ่านหรือถูกจำกัดสิทธิ์อยู่ ลบรหัสผ่านแล้วลองใหม่
  • ไฟล์ใหญ่ขึ้น: PDF ที่เป็นข้อความจริงส่วนใหญ่มีขนาดเล็กอยู่แล้ว การบันทึกใหม่อาจทำให้ใหญ่ขึ้น ให้อัปโหลดไฟล์ต้นฉบับ

ใช้ UnKey

UnKey Pro บน iPhone, iPad และ Mac มีเครื่องมือ Compress สำหรับไฟล์สแกนโดยเฉพาะ เครื่องมือนี้เข้ารหัสภาพของหน้าที่เป็นรูปถ่ายใหม่ และไม่แตะหน้าที่เป็นข้อความจริง ตัวหนังสือจึงยังคมชัด และจะไม่ให้ไฟล์ที่ใหญ่กว่าไฟล์ที่คุณใส่เข้าไป ทำงานแบบออฟไลน์ สแกนหนังสือเดินทางหรือใบแจ้งยอดธนาคารของคุณจึงไม่ถูกอัปโหลดไปยังเว็บบีบอัดไฟล์ การปลดล็อกใช้ได้ฟรี ส่วน Compress อยู่ในการซื้อ Pro ครั้งเดียว

คำถาม

บีบอัดแล้วเอกสารจะอ่านไม่ออกไหม

อาจเป็นได้ถ้าบีบอัดมากเกินไป ควรเปิดไฟล์ที่บีบอัดแล้วดู ซูมดูตัวหนังสือเล็ก ๆ และเก็บไฟล์ต้นฉบับไว้เสมอ

ทำไมสแกนแค่ 2 หน้าถึงมี 8 MB

เพราะแต่ละหน้าที่สแกนเป็นรูปถ่ายความละเอียดสูง ส่วน PDF แบบข้อความจากธนาคารมีขนาดเล็กมากเพราะเก็บเป็นตัวอักษร ไม่ใช่รูปภาพ

เว็บรับ PDF ที่มีรหัสผ่านไหม

หลายเว็บอ่านไม่ได้ ให้ลบรหัสผ่านก่อนอัปโหลด เว้นแต่เว็บจะระบุไว้เป็นอย่างอื่น

เว็บบีบอัดไฟล์ออนไลน์ปลอดภัยสำหรับหนังสือเดินทางและใบแจ้งยอดไหม

เว็บเหล่านั้นอัปโหลดไฟล์ของคุณไปยังเซิร์ฟเวอร์ สำหรับเอกสารยืนยันตัวตนและเอกสารการเงิน การบีบอัดบนอุปกรณ์ของคุณเองปลอดภัยกว่า
