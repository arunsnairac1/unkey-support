วิธีลบรหัสผ่านออกจาก PDF บน Mac (2026)

อัปเดตเมื่อ ตุลาคม 2026

เปิด PDF ใน Preview ด้วยรหัสผ่าน เลือก File > Export ตรวจว่าไม่ได้ตั้งรหัสผ่านเปิดไฟล์ แล้วบันทึกสำเนาใหม่

บน Mac คุณลบรหัสผ่าน PDF ได้ฟรีด้วย Preview แอปที่มากับ macOS เปิด PDF ใส่รหัสผ่าน แล้วเลือก File > Export และบันทึกสำเนาใหม่ที่ไม่มีรหัสผ่านเปิดไฟล์ คุณต้องรู้รหัสผ่าน เพราะ Preview จะไม่เปิดไฟล์ถ้าไม่มีรหัสผ่าน

วิธีที่ 1: Preview, File > Export

  1. ดับเบิลคลิก PDF เพื่อเปิดใน Preview แล้วใส่รหัสผ่าน
  2. เลือก File > Export และตั้งชื่อสำเนาใหม่ เช่น "Statement-Oct-unlocked"
  3. คลิก Permissions และตรวจว่า Require Password To Open Document ไม่ได้ถูกเลือก ใน macOS รุ่นเก่า หน้าต่าง Export จะมีช่องทำเครื่องหมาย Encrypt แทน ให้เว้นไว้ไม่ติ๊ก
  4. คลิก Save
  5. ปิดไฟล์ใหม่แล้วเปิดอีกครั้ง ควรเปิดได้โดยไม่ถามรหัสผ่าน

คู่มือปัจจุบันของ Apple อธิบายหน้าต่าง Export ปุ่ม Permissions และตัวเลือก Require Password To Open Document (Apple: Password-protect a PDF in Preview on Mac) หน้าเดียวกันฉบับ macOS Big Sur ของ Apple เขียนไว้ตรง ๆ ว่า "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide)

ถ้า PDF มีรหัสผ่านเจ้าของ (รหัสผ่านสิทธิ์) ด้วยและคุณรู้รหัสนั้น File > Edit Permissions ให้คุณเปลี่ยนรหัสผ่านเปิดไฟล์ และกำหนดว่าฟีเจอร์ไหนต้องใช้รหัสผ่าน

วิธีที่ 2: Print > Save as PDF

แอปบน Mac ทุกตัวที่พิมพ์ได้สร้าง PDF ใหม่ได้ (Apple: Save a document as a PDF on Mac):

  1. เปิด PDF ด้วยรหัสผ่าน
  2. เลือก File > Print
  3. คลิกเมนูป๊อปอัป PDF แล้วเลือก Save as PDF
  4. อย่าคลิก Security Options เพราะเป็นที่ที่ใช้ใส่รหัสผ่านกลับเข้าไป

สำเนาที่พิมพ์อาจสูญเสียลิงก์ ช่องฟอร์ม หรือบุ๊กมาร์ก ถ้าเอกสารห้ามพิมพ์ วิธีนี้อาจกดไม่ได้

วิธีที่ 3: UnKey สำหรับ Mac

UnKey ใช้ฟรีบน Mac เช่นกัน UnKey Pro ซื้อครั้งเดียว เพิ่มการปลดล็อกเป็นชุดและเครื่องมือ Pro อื่น ๆ บน iPhone, iPad และ Mac ลาก PDF ไปวางบนหน้าต่าง ใส่รหัสผ่าน แล้วจะบันทึกสำเนาที่ปลดล็อก UnKey Pro ยังปลดล็อกหลายไฟล์พร้อมกันได้ ซึ่งมีประโยชน์กับใบแจ้งยอดรายเดือนทั้งปีที่ใช้รหัสผ่านเดียวกัน UnKey ทำงานออฟไลน์ ไม่อัปโหลดอะไร และลบได้เฉพาะรหัสผ่านที่คุณรู้อยู่แล้ว

วิธีที่ 4: บรรทัดคำสั่ง (สำหรับผู้ใช้ที่ชำนาญ)

qpdf เครื่องมือโอเพนซอร์สฟรีทำได้ใน Terminal: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf เอกสารของ qpdf อธิบาย --decrypt ว่าสร้าง "an output file with no encryption even if the input file is encrypted" (qpdf documentation) คุณต้องติดตั้งเอง เช่นผ่าน Homebrew การพิมพ์รหัสผ่านบนบรรทัดคำสั่งอาจทำให้รหัสผ่านค้างอยู่ในประวัติของเชลล์

ถ้ายังถามรหัสผ่านอยู่

  • คุณอาจเปิดต้นฉบับแทนสำเนา ตรวจชื่อไฟล์
  • Export ใหม่ และตรวจว่า Require Password To Open Document ปิดอยู่ใน Permissions
  • ลองใช้ Print > Save as PDF แทน
  • ถ้า Preview ปฏิเสธรหัสผ่าน ให้ตรวจตัวพิมพ์ใหญ่และรูปแบบวันที่ และอ่านอีเมลที่ส่งเอกสารมา

ก่อนลบต้นฉบับ

PDF ที่ปลดล็อกเปิดได้สำหรับทุกคนที่มีไฟล์ รวมถึงโฟลเดอร์ iCloud Drive ที่แชร์กับครอบครัว และคนที่ยืม Mac ของคุณ เก็บใบแจ้งยอดที่ปลดล็อกไว้ในที่ส่วนตัว ดู การลบรหัสผ่าน PDF ปลอดภัยไหม สำหรับรายละเอียดเพิ่มเติม

คำถาม

Preview ฟรีจริงไหม

จริง Preview มากับ Mac ทุกเครื่อง และ export PDF โดยไม่มีรหัสผ่านเปิดไฟล์ได้หลังจากที่คุณใส่รหัสผ่านแล้ว

Preview ลบรหัสผ่านที่ฉันไม่รู้ได้ไหม

ไม่ได้ Preview ขอรหัสผ่านก่อนเปิดไฟล์ และไม่มีวิธีที่ถูกต้องตามกฎหมายที่จะข้ามขั้นนั้นได้

จะปลดล็อก PDF หลายไฟล์พร้อมกันบน Mac ได้อย่างไร

Preview ทำได้ทีละไฟล์ UnKey Pro ปลดล็อก PDF หลายไฟล์ที่ใช้รหัสผ่านเดียวกันเป็นชุดได้ และผู้ใช้ที่ชำนาญเขียนสคริปต์ qpdf ได้ ดูคู่มือการปลดล็อก PDF หลายไฟล์พร้อมกัน

ทำไม Print > Save as PDF กดไม่ได้

PDF อาจมีรหัสผ่านสิทธิ์ที่ห้ามพิมพ์ ถ้ารู้รหัสผ่านเจ้าของ ให้ใส่ที่ File > Edit Permissions ถ้าไม่ ให้ใช้วิธี Export

  • Apple – Save a document as a PDF on Mac

รูปแบบอาจเปลี่ยนแปลงได้ หากรหัสผ่านใช้ไม่ได้ ให้ตรวจสอบอีเมลที่ส่งมาพร้อมเอกสาร หรือติดต่อผู้ออกเอกสาร UnKey ไม่มีส่วนเกี่ยวข้องกับธนาคาร นายจ้าง หรือหน่วยงานใดที่กล่าวถึงในที่นี้

แปลจากภาษาอังกฤษ หากมีข้อแตกต่าง ให้ถือตามหน้าภาษาอังกฤษ

ปลดล็อก ได้ในครั้งเดียว

UnKey ลบรหัสผ่านออกจาก PDF ที่คุณเปิดได้อยู่แล้ว บน iPhone, iPad และ Mac ทำงานออฟไลน์ ไม่มีการอัปโหลดใดๆ บันทึกรหัสผ่านครั้งเดียว แล้ว Face ID จะเปิดใบแจ้งยอดเดือนหน้าให้
