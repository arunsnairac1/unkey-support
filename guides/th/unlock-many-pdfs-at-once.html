Preview จัดการ PDF ได้ทีละไฟล์ หากต้องการปลดล็อกใบแจ้งยอดหลายฉบับที่ใช้รหัสผ่านเดียวกัน ให้ใช้เครื่องมือแบบชุด เช่น UnKey Pro หรือสคริปต์ qpdf

ถ้าคุณมีใบแจ้งยอดกองหนึ่ง สมมติ 12 เดือนจากธนาคารเดียวกัน ที่ใช้รหัสผ่านเดียวกันทั้งหมด คุณไม่ต้องปลดล็อกทีละไฟล์ เครื่องมือในตัวอย่าง Preview ทำงานทีละไฟล์ เครื่องมือแบบชุดอย่าง UnKey Pro หรือสคริปต์ qpdf สั้น ๆ บน Mac ทำทั้งหมดพร้อมกันได้ คุณยังต้องรู้รหัสผ่าน

ทำไมการปลดล็อกเป็นชุดจึงช่วยได้

ผู้ออกเอกสารส่วนใหญ่ป้องกันใบแจ้งยอดทุกฉบับด้วยรูปแบบรหัสผ่านเดียวกันที่อิงข้อมูลของคุณ รหัสผ่านของเดือนตุลาคมจึงมักเปิดมกราคมถึงกันยายนได้ด้วย นั่นคือตอนที่เครื่องมือแบบชุดช่วยประหยัดเวลา โดยทั่วไปคือช่วงยื่นภาษี ยื่นสมัครสินเชื่อ หรือตอนส่งใบแจ้งยอดทั้งปีให้นักบัญชี

ตัวเลือกฟรี: Preview บน Mac ทีละไฟล์

Preview เปิด PDF หลายไฟล์พร้อมกันได้ แต่การลบรหัสผ่านต้องทำทีละไฟล์ สำหรับ PDF แต่ละไฟล์ คุณใส่รหัสผ่าน เลือก File > Export ตรวจว่า Require Password To Open Document ปิดอยู่ใต้ Permissions แล้วบันทึก (Apple: Password-protect a PDF in Preview) สำหรับสามสี่ไฟล์ก็ไม่เป็นไร แต่สามสิบไฟล์น่าเบื่อและพลาดไฟล์ได้ง่าย

บน iPhone และ iPad วิธีฟรี (การตั้งค่า Lock ของ Preview หรือวิธีพิมพ์เป็น PDF) ก็ทำได้ทีละไฟล์เช่นกัน

UnKey Pro: ปลดล็อกเป็นชุดบน iPhone, iPad และ Mac

  1. รวมใบแจ้งยอดไว้ในโฟลเดอร์เดียวใน Files หรือ Finder
  2. ใน UnKey ใช้การปลดล็อกเป็นชุดแล้วเลือกไฟล์ บน Mac ลากไฟล์ไปวางบนหน้าต่างได้
  3. ใส่รหัสผ่าน หรือให้ UnKey ใช้รหัสผ่านที่คุณบันทึกไว้ก่อนหน้าด้วย Face ID หรือ Touch ID
  4. UnKey บันทึกสำเนาที่ปลดล็อกของแต่ละไฟล์ ตรวจผลลัพธ์ และปลดล็อกไฟล์ที่ใช้รหัสผ่านต่างออกไปแยกต่างหาก

การปลดล็อกเป็นชุดเป็นส่วนหนึ่งของ UnKey Pro ซื้อครั้งเดียว (₹249 ในอินเดีย $5.99 ในสหรัฐฯ) Pro ยังเพิ่มการสแกน การเซ็นและกรอกเอกสาร การล็อก การบีบอัด และการปิดบังข้อมูล และการซื้อครั้งเดียวครอบคลุม iPhone, iPad และ Mac การปลดล็อกไฟล์เดี่ยวใช้ได้ฟรี ทุกอย่างเกิดขึ้นบนอุปกรณ์ของคุณ และไม่มีอะไรถูกอัปโหลด

ตัวเลือกฟรีสำหรับผู้ใช้ที่ชำนาญ: qpdf

qpdf เป็นเครื่องมือบรรทัดคำสั่งโอเพนซอร์สฟรี เมื่อใช้ --password และ --decrypt จะเขียนสำเนาที่ไม่เข้ารหัสของไฟล์ (qpdf documentation) ใน Terminal ลูปวนทั้งโฟลเดอร์หน้าตาแบบนี้:

for f in *.pdf; do qpdf --decrypt --password="$PDFPASS" "$f" "unlocked-$f"; done

ตั้งค่า PDFPASS ก่อน โดยควรไม่ให้ค้างอยู่ในประวัติของเชลล์ ไฟล์ที่ใช้รหัสผ่านต่างออกไปจะล้มเหลวพร้อมข้อผิดพลาด ไม่ถูกข้ามไปเงียบ ๆ คุณต้องติดตั้ง qpdf เอง เช่นผ่าน Homebrew

เมื่อไฟล์ไม่ได้ใช้รหัสผ่านเดียวกัน

  • คนละบัญชี: บัญชีออมทรัพย์และบัตรเครดิตจากธนาคารเดียวกันมักใช้รูปแบบต่างกัน แยกไว้คนละโฟลเดอร์
  • รูปแบบเปลี่ยน: ผู้ออกเอกสารบางครั้งเปลี่ยนรูปแบบ ใบแจ้งยอดเก่าอาจต้องใช้รูปแบบเดิม
  • บัญชีร่วมหรือบัญชีธุรกิจ: รหัสผ่านอาจอิงข้อมูลของผู้ถือบัญชีหลักหรือของบริษัท

หลังปลดล็อกเป็นชุด

  • เปิดสำเนาสองสามไฟล์เพื่อตรวจก่อนลบต้นฉบับ
  • ใช้ชื่อที่ชัดเจน เช่น "2026-04-statement-unlocked.pdf"
  • เก็บโฟลเดอร์ที่ปลดล็อกไว้เป็นส่วนตัว ใบแจ้งยอดทั้งปีคือภาพรวมการเงินของคุณอย่างละเอียด
  • ถ้าจะส่งให้นักบัญชี ลองส่งต้นฉบับที่มีรหัสผ่านแล้วแจ้งรหัสผ่านแยกต่างหาก
