Windows पर PDF का पासवर्ड कैसे हटाएँ (2026)

अक्टूबर 2026 में अपडेट किया गया

इस भाषा में पढ़ें: English · العربية · বাংলা · Deutsch · Español · Filipino · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · Italiano · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · ไทย · اردو · Tiếng Việt

PDF को पासवर्ड से Microsoft Edge या Chrome में खोलें, Ctrl+P दबाएँ, Save as PDF (या Microsoft Print to PDF) चुनें और नई कॉपी सेव करें; भुगतान वाला Acrobat सीधे सिक्योरिटी हटा सकता है।

Windows 10 और 11 पर आप अपने पास मौजूद ब्राउज़र से ही PDF का पासवर्ड मुफ़्त हटा सकते हैं। PDF को Microsoft Edge या Google Chrome में खोलें, पासवर्ड डालें, Ctrl + P दबाएँ, प्रिंटर के रूप में Save as PDF (या Microsoft Print to PDF) चुनें और सेव करें। नई फ़ाइल बिना पासवर्ड खुलती है। पहले आपको पासवर्ड पता होना चाहिए।

तरीका 1: Microsoft Edge (पहले से मौजूद)

  1. File Explorer में PDF पर राइट-क्लिक करें और Open with > Microsoft Edge चुनें।
  2. Edge के माँगने पर पासवर्ड टाइप करें।
  3. Ctrl + P दबाएँ, या More मेनू (तीन बिंदु) खोलकर Print चुनें।
  4. Printer के नीचे Save as PDF या Microsoft Print to PDF चुनें।
  5. Save (या Print) पर क्लिक करें, फ़ोल्डर चुनें और कॉपी को नया नाम दें।
  6. नई फ़ाइल खोलकर जाँचें कि वह अब पासवर्ड नहीं माँगती।

Microsoft की बिल्ट-इन PDF रीडर वाली गाइड Edge का रास्ता दिखाती है: More मेनू में Print ढूँढें, विकल्प चुनें, फिर प्रिंट करें (Microsoft: View, print, and edit PDFs in a PDF reader)। Microsoft Print to PDF Windows के साथ आने वाला प्रिंटर है। अगर वह सूची में न दिखे, तो Microsoft के अनुसार उसे Windows Optional Features में फिर से चालू किया जा सकता है (Microsoft: KB5058499 known issue)।

तरीका 2: Google Chrome

अगर आप Chrome इस्तेमाल करते हैं, तो कदम लगभग वही हैं: PDF को Chrome में खोलें, पासवर्ड डालें, Ctrl + P दबाएँ, Destination को Save as PDF करें, और Save पर क्लिक करें (Google: Print from Chrome)। ज़्यादा ब्योरा हमारी Chrome गाइड में है।

तरीका 3: Adobe Acrobat Pro या Standard (भुगतान वाला)

भुगतान वाला Acrobat फ़ाइल को दोबारा प्रिंट करने की जगह एन्क्रिप्शन खुद हटाता है, इसलिए लिंक और फ़ॉर्म फ़ील्ड बने रहते हैं। Adobe दो रास्ते बताता है (Adobe: Remove passwords from PDFs):

  • Protect टूल: PDF खोलें, Protect टूल में जाएँ और Remove Security चुनें। अगर फ़ाइल में सिर्फ़ ओपन पासवर्ड है, तो OK से पुष्टि करें। अगर अनुमति वाला पासवर्ड भी है, तो Acrobat पहले वह पासवर्ड माँगता है।
  • Security सेटिंग: दस्तावेज़ के security properties खोलें, Security टैब पर जाएँ, Change Settings चुनें, पासवर्ड वाले विकल्प हटाएँ और सेव करें।

Adobe के मेनू संस्करण के साथ बदलते रहते हैं, इसलिए ये नाम ठीक वैसे न दिखें तो Acrobat के टूल सर्च में “Remove Security” खोजें। मुफ़्त Acrobat Reader सुरक्षित PDF खोल सकता है, पर सिक्योरिटी हटाने का टूल नहीं है। उसकी जगह तरीका 1 या 2 अपनाएँ।

तरीका 4: qpdf (तकनीकी लोगों के लिए)

मुफ़्त, ओपन-सोर्स qpdf टूल Windows पर चलता है। qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf बिना एन्क्रिप्शन की कॉपी लिख देता है (qpdf documentation)। पासवर्ड आपकी कमांड हिस्ट्री में सेव हो सकता है, इसलिए साझा PC पर बाद में उसे साफ़ कर दें।

जाँचने लायक बातें

  • Print धुंधला है? हो सकता है PDF में अनुमति वाला पासवर्ड हो जो प्रिंटिंग रोकता है। देखें प्रिंटिंग और कॉपी की पाबंदियाँ।
  • पासवर्ड नकार दिया गया? Caps Lock, तारीख़ का फ़ॉर्मेट और बैंक के पास दर्ज जानकारी जाँचें। देखें PDF पासवर्ड क्यों काम नहीं कर रहा।
  • साझा या दफ़्तर का PC? खुली कॉपी उसे पाने वाले हर व्यक्ति के लिए खुलती है। उसे निजी फ़ोल्डर में रखें और Downloads से मिटा दें।

अगर आपके पास iPhone, iPad या Mac भी है, तो UnKey उन डिवाइसों पर ऑफ़लाइन पासवर्ड हटाता है और अगले महीने के स्टेटमेंट के लिए पासवर्ड सेव भी कर सकता है। Windows के लिए UnKey ऐप नहीं है।

सवाल

क्या Windows पर कुछ इंस्टॉल करना पड़ेगा?

नहीं। Microsoft Edge और Microsoft Print to PDF प्रिंटर Windows 10 और 11 के साथ आते हैं।

क्या ऑनलाइन “unlock PDF” साइटें बेहतर काम करेंगी?

वे वही काम करती हैं, पर आपका दस्तावेज़ किसी और के सर्वर पर अपलोड करती हैं। बैंक स्टेटमेंट और टैक्स कागज़ात के लिए यहाँ बताए ऑफ़लाइन तरीके ज़्यादा सुरक्षित हैं।

क्या इनमें से कोई भूला हुआ पासवर्ड हटा सकता है?

नहीं। Edge, Chrome, Acrobat और qpdf, सभी को सही पासवर्ड चाहिए। फ़ॉर्मेट के लिए PDF के साथ आया ईमेल देखें।

कॉपी में लिंक काम क्यों नहीं करते?

PDF में प्रिंट करने से पन्ने दोबारा बनते हैं, जिसमें लिंक और फ़ॉर्म फ़ील्ड छूट सकते हैं। Acrobat का Remove Security या qpdf उन्हें बनाए रखते हैं।
