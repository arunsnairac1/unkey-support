PDF එක Preview හි මුරපදය සමඟ විවෘත කර, File > Export තෝරා, විවෘත කිරීමේ මුරපදයක් සකසා නොමැති බව තහවුරු කර, නව පිටපතක් සුරකින්න.

Mac එකක macOS සමඟ එන Preview යෙදුමෙන් PDF මුරපදයක් නොමිලේ ඉවත් කළ හැක. PDF එක විවෘත කර, මුරපදය ඇතුළත් කර, ඉන්පසු File > Export තෝරා විවෘත කිරීමේ මුරපදයක් නැති නව පිටපතක් සුරකින්න. ඔබ මුරපදය දැන සිටිය යුතුය. එය නැතිව Preview ගොනුව විවෘත නොකරයි.

ක්‍රමය 1: Preview, File > Export

  1. PDF එක Preview හි විවෘත කිරීමට දෙවරක් ක්ලික් කර මුරපදය ඇතුළත් කරන්න.
  2. File > Export තෝරා පිටපතට "Statement-Oct-unlocked" වැනි අලුත් නමක් දෙන්න.
  3. Permissions ක්ලික් කර Require Password To Open Document තෝරා නොමැති බව තහවුරු කරන්න. පැරණි macOS අනුවාදවල, Export කවුළුවේ ඒ වෙනුවට Encrypt checkbox එකක් ඇත. එය ටික් නොකර තබන්න.
  4. Save ක්ලික් කරන්න.
  5. නව ගොනුව වසා නැවත විවෘත කරන්න. එය මුරපදයක් නොඉල්ලා විවෘත විය යුතුය.

Apple ගේ වත්මන් මාර්ගෝපදේශය Export කවුළුව, Permissions බොත්තම සහ Require Password To Open Document විකල්පය විස්තර කරයි (Apple: Password-protect a PDF in Preview on Mac). එම පිටුවේම macOS Big Sur අනුවාදය කෙලින්ම මෙසේ පැවසීය: "ඔබ encrypt කළ PDF එකකින් මුරපදයක් ඉවත් කිරීමට, PDF එක විවෘත කර නැවත export කරන්න, මෙවර encryption විකල්පය ක්‍රියාවිරහිත කර" (Apple, macOS Big Sur guide).

PDF එකට owner (අවසර) මුරපදයක් ද ඇත්නම් සහ ඔබ එය දන්නේ නම්, File > Edit Permissions මගින් විවෘත කිරීමේ මුරපදය සහ කුමන පහසුකම් වලට මුරපදයක් අවශ්‍යද යන්න වෙනස් කළ හැක.

ක්‍රමය 2: Print > Save as PDF

print කළ හැකි ඕනෑම Mac යෙදුමකට නව PDF එකක් සෑදිය හැක (Apple: Save a document as a PDF on Mac):

  1. PDF එක එහි මුරපදය සමඟ විවෘත කරන්න.
  2. File > Print තෝරන්න.
  3. PDF pop-up මෙනුව ක්ලික් කර Save as PDF තෝරන්න.
  4. Security Options ක්ලික් නොකරන්න, මන්ද එහිදී ඔබ මුරපදයක් නැවත එක් කරයි.

print කළ පිටපතට සබැඳි, පෝරම ක්ෂේත්‍ර හෝ පොත් සලකුණු අහිමි විය හැක. ලේඛනය print කිරීම අවහිර කරන්නේ නම්, මෙම ක්‍රමය අළු පැහැයෙන් පෙනෙන්නට පුළුවන.

ක්‍රමය 3: Mac සඳහා UnKey

UnKey Mac හි ද නොමිලේ. එක්වරක් ගෙවන UnKey Pro මගින් iPhone, iPad සහ Mac හි batch unlocking සහ අනෙකුත් Pro මෙවලම් එක් වේ. PDF එක කවුළුවට ඇද දමා, මුරපදය ඇතුළත් කළ විට, එය අගුළු ඇරි පිටපතක් සුරකියි. UnKey Pro හට එකවර ගොනු කිහිපයක් batch-unlock කළ හැකි අතර, එකම මුරපදය ඇති මාසික ප්‍රකාශන වසරක් සඳහා එය ප්‍රයෝජනවත්. UnKey offline ක්‍රියා කරයි, කිසිවක් උඩුගත නොකරයි, සහ ඔබ දැනටමත් දන්නා මුරපද පමණක් ඉවත් කරයි.

ක්‍රමය 4: Command line (තාක්ෂණික පරිශීලකයන් සඳහා)

නොමිලේ, open-source මෙවලමක් වන qpdf හට Terminal හි මෙය කළ හැක: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. එහි ලේඛන --decrypt විස්තර කරන්නේ "input ගොනුව encrypt කර තිබුණත් encryption නැති output ගොනුවක්" සාදන ලෙසයි (qpdf documentation). ඔබම එය ස්ථාපනය කරගත යුතුය, උදාහරණයක් ලෙස Homebrew සමඟ. command line එකේ මුරපදයක් ටයිප් කිරීමෙන් එය ඔබේ shell history හි ඉතිරි විය හැක.

තවමත් මුරපදයක් ඉල්ලන්නේ නම්

  • ඔබ පිටපත වෙනුවට මුල් පිටපත විවෘත කර ඇති විය හැක. ගොනු නම පරීක්ෂා කරන්න.
  • නැවත export කර Permissions හි Require Password To Open Document ක්‍රියාවිරහිතව ඇති බව පරීක්ෂා කරන්න.
  • ඒ වෙනුවට Print > Save as PDF උත්සාහ කරන්න.
  • Preview මුරපදය ප්‍රතික්ෂේප කරන්නේ නම්, ලොකු අකුරු සහ දින ආකෘතිය පරීක්ෂා කර, ලේඛනය සමඟ ආ ඊමේල් එක කියවන්න.

මුල් පිටපත මැකීමට පෙර

අගුළු ඇරි PDF එකක් ගොනුව ඇති ඕනෑම කෙනෙකුට විවෘත වේ. පවුලේ අය සමඟ බෙදාගත් iCloud Drive ෆෝල්ඩර සහ ඔබේ Mac එක ඉල්ලා ගන්නා ඕනෑම කෙනෙක් ඊට ඇතුළත්. අගුළු ඇරි ප්‍රකාශන පෞද්ගලික තැනක තබා ගන්න. වැඩි විස්තර සඳහා PDF මුරපදයක් ඉවත් කිරීම ආරක්ෂිතද යන්න බලන්න.

ප්‍රශ්න

Preview ඇත්තටම නොමිලේද?

ඔව්. Preview සෑම Mac එකක්ම සමඟ එන අතර, ඔබ මුරපදය ඇතුළත් කළ පසු විවෘත කිරීමේ මුරපදයක් නැතිව PDF එකක් export කළ හැක.

මා නොදන්නා මුරපදයක් Preview හට ඉවත් කළ හැකිද?

නැත. Preview ගොනුව විවෘත කිරීමට පෙර මුරපදය අසන අතර, ඒ වටා යාමට නීත්‍යානුකූල ක්‍රමයක් නැත.

Mac එකක PDF බොහොමයක් එකවර අගුළු අරින්නේ කෙසේද?
