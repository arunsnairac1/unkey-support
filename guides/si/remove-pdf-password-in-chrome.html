PDF එක Chrome හි මුරපදය සමඟ විවෘත කර, Ctrl+P හෝ Cmd+P ඔබා, ගමනාන්තය Save as PDF ලෙස සකසා, මුරපදයක් නැති නව පිටපතක් සුරකින්න.

Google Chrome හට Windows, Mac සහ Linux හි නොමිලේ, මුරපද සහිත PDF එකක මුරපදයක් නැති පිටපතක් සුරැකිය හැක. PDF එක Chrome හි විවෘත කර, මුරපදය ටයිප් කර, Ctrl + P (Mac හි Cmd + P) ඔබා, ගමනාන්තය Save as PDF ලෙස සකසා, සුරකින්න. ඔබ දැනටමත් මුරපදය දැන සිටිය යුතුය. එය නැතිව Chrome ගොනුව විවෘත කළ නොහැක.

පියවරෙන් පියවර (පරිගණකය)

  1. PDF එක Chrome කවුළුවකට ඇද දමන්න, නැතහොත් ගොනුව මත right-click කර Open with > Google Chrome තෝරන්න.
  2. Chrome මුරපදය අසයි. එය ටයිප් කර Enter ඔබන්න.
  3. Windows හෝ Linux හි Ctrl + P, හෝ Mac හි Cmd + P ඔබන්න. මෙනුව ද භාවිතා කළ හැක: File > Print.
  4. print කවුළුවේ, Destination Save as PDF ලෙස සකසන්න.
  5. Save ක්ලික් කරන්න. නව ගොනුවට Statement-Sep-2026-unlocked.pdf වැනි පැහැදිලි නමක් දෙන්න.
  6. එය වසා නව ගොනුව නැවත විවෘත කරන්න. එය මුරපද ඉල්ලීමකින් තොරව, වහාම විවෘත විය යුතුය.

Google හි උදව් පිටුව යතුරුපුවරු කෙටිමං, print කවුළුවේ ගමනාන්තයක් තේරීම, සහ Save as PDF විකල්පය විස්තර කරයි (Google: Print from Chrome).

Android දුරකථනයක

Android හි Chrome හි එම විකල්පයම ඇත. Google ගේ පියවර: More > Share ඔබා, Print ඔබා, ඉන්පසු Save as PDF ඔබා ගොනුව සුරකින ස්ථානය තෝරන්න (Google: Print from Chrome on Android). ඔබේ දුරකථනයේ ගබඩා කළ PDF එකක් Chrome විවෘත කරන්නේද යන්න Chrome අනුවාදය මත රඳා පවතී. එසේ නොවේ නම්, අපගේ Android හි මුරපද සහිත PDF එකක් විවෘත කිරීම මාර්ගෝපදේශය බලන්න.

මෙම ක්‍රමයෙන් ඔබට අහිමි වන දේ

print කවුළුව හරහා සුරැකීමෙන්, තිරයේ ඇති දේ වලින් සම්පූර්ණයෙන්ම නව PDF එකක් සෑදේ. ප්‍රකාශනයක් කියවීමට, සංරක්ෂණයට හෝ උඩුගත කිරීමට එය හොඳය. නමුත් මුල් පිටපත මකා දැමීමට පෙර පිටපත පරීක්ෂා කරන්න:

  • සබැඳි සහ පොත් සලකුණු ක්‍රියා නොකරන්නට පුළුවන.
  • පෝරම ක්ෂේත්‍ර පැතලි විය හැකි අතර, ඔබට තවදුරටත් ඒවායේ ටයිප් කළ නොහැක.
  • ඩිජිටල් අත්සන් රැගෙන නොයයි. portal එකකට අත්සන් කළ මුල් පිටපත අවශ්‍ය නම්, මුල් පිටපත උඩුගත කරන්න.
  • පිටු ප්‍රමාණය print සැකසුම් අනුගමනය කරයි. More settings යටතේ, කඩදාසි ප්‍රමාණය සහ scale එක පිටු කුඩා කර හෝ කපා නොමැති බව පරීක්ෂා කරන්න.

Save as PDF ක්‍රියා නොකරන්නේ නම්

  • Print කිරීම අවහිරයි. සමහර PDF වල print කිරීම නවත්වන අවසර මුරපදයක් ඇත. අවසර මුරපදය විවෘත කිරීමේ මුරපදයෙන් වෙනස්ය. PDF print සහ පිටපත් කිරීමේ සීමාවන් පැහැදිලි කිරීම බලන්න.
  • Chrome මුරපදය ප්‍රතික්ෂේප කරයි. ලොකු අකුරු, දින ආකෘතිය සහ ඔබේ බැංකුව සතු විස්තර පරීක්ෂා කරන්න. PDF මුරපදයක් ක්‍රියා නොකරන්නේ ඇයි බලන්න.
  • ගොනුව වෙනත් යෙදුමක විවෘත විය. සමහර පරිගණක පෙරනිමියෙන් PDF වෙනත් reader එකක විවෘත කරයි. ඒ වෙනුවට ගොනුව Chrome tab එකකට ඇද දමන්න.

මුරපදය ඉවත් කිරීමේ වෙනත් ක්‍රම

Windows හි Microsoft Edge එලෙසම ක්‍රියා කරයි (Windows හි PDF මුරපදයක් ඉවත් කිරීම බලන්න). Mac එකක, Preview හට මුරපදයක් නැති පිටපතක් export කළ හැක (Mac මාර්ගෝපදේශය). iPhone, iPad සහ Mac හි, UnKey අගුළු ඇරි පිටපතක් offline සුරකින අතර, ගොනුව නැවත print කරනවා වෙනුවට encryption ඉවත් කරන බැවින් අකුරු, සබැඳි සහ පිටු තිබූ ආකාරයටම තබයි. Chrome මෙන්ම, එය ක්‍රියා කරන්නේ ඔබ දැනටමත් දන්නා මුරපදයකින් පමණි.

ප්‍රශ්න

මෙය කරන විට Chrome මගේ PDF එක උඩුගත කරයිද?

නැත. ඔබේ පරිගණකයෙන් PDF ගොනුවක් විවෘත කර Save as PDF සමඟ සුරැකීම සිදු වන්නේ ඔබේ පරිගණකයේ browser එක තුළ ය. Drive හි පිටපතක් අවශ්‍ය නම් පමණක් වෙනම “Save to Google Drive” ගමනාන්තය භාවිතා කරන්න.

මා නොදන්නා මුරපදයක් Chrome හට ඉවත් කළ හැකිද?

නැත. Chrome කිසිවක් පෙන්වීමට පෙර මුරපදය අසයි. එය නැති වී ඇත්නම්, PDF මුරපදය අමතක වුණොත් කළ යුතු දේ බලන්න.

සුරැකි පිටපත මුල් පිටපතට වඩා වෙනස් වන්නේ ඇයි?

Save as PDF පිටු නව ගොනුවකට print කරන බැවින්, සබැඳි, පෝරම ක්ෂේත්‍ර සහ අත්සන් නොපවතින්නට පුළුවන. අකුරු සහ පිරිසැලසුම සාමාන්‍යයෙන් එලෙසම පෙනේ.

මෙය අවසර ඇත්ද?

ඔබේම ලේඛන සඳහා, උදාහරණයක් ලෙස ඔබේ බැංකු ප්‍රකාශනය සඳහා, ඔව්. නිදහසේ විවෘත කිරීමට ඔබට අයිතියක් නැති ගොනු වල ආරක්ෂාව ඉවත් නොකරන්න.
