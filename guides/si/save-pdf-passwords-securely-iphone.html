විකල්පය 1: Apple ගේ Passwords යෙදුම

Passwords යෙදුම ඇතුළත් කිරීම් encrypt කළ ආකාරයෙන් ගබඩා කරන අතර, iCloud Keychain ඒවා ඔබ අනුමත කළ උපාංග හරහා යාවත්කාලීනව තබයි (Apple: View your passwords). එය නිර්මාණය කර ඇත්තේ වෙබ් අඩවි ලොගින් සඳහා වුවත්, ලේඛනයක් සඳහා ඇතුළත් කිරීමක් එක් කළ හැක:

  1. Passwords විවෘත කර, All ඔබා, ඉන්පසු add බොත්තම ඔබන්න (Apple: Create a password).
  2. website හෝ app ක්ෂේත්‍රයේ "Bank statement PDF" වැනි දෙයක් දමා, user name ලෙස label එකක් එක් කර, PDF මුරපදය ටයිප් කරන්න.
  3. සුරකින්න. පසුව, "format: නමේ මුල් අකුරු 4 + DDMM" වැනි විස්තර එක් කිරීමට Edit > Notes ඔබන්න. PIN අංක සහ ආරක්ෂක ප්‍රශ්න වැනි notes මෙහි ආරක්ෂිතව තබා ගත හැකි බව Apple පවසයි.

ඔබේ විස්තර භාවිතා කරන ප්‍රකාශන සඳහා, මුරපදයම නොව ආකෘතිය ගබඩා කිරීම හොඳ උපක්‍රමයකි. ඊළඟ වසරේ ප්‍රකාශනයද එම නීතියම භාවිතා කරයි.

විකල්පය 2: Lock කළ note එකක්

Notes හි note එකක් ඔබේ උපාංග passcode එකෙන් හෝ වෙනම මුරපදයකින් lock කර Face ID හෝ Touch ID සමඟ විවෘත කළ හැක (Apple: Lock your notes on iPhone). දැනගත යුතු දේ:

  • ඔබට lock කළ හැක්කේ උපාංගයේ හෝ iCloud හි ගබඩා කළ notes පමණි, Gmail හෝ වෙනත් ගිණුම් සමඟ sync කළ notes නොවේ.
  • PDF එකක් ඇමිණූ note එකක් lock කළ නොහැක, එබැවින් මුරපද note එක ගොනුවෙන් වෙන්ව තබා ගන්න.
  • note එකේ මාතෘකාව ලැයිස්තුවේ පෙනෙන බැවින්, සරල මාතෘකාවක් දෙන්න.
  • ඔබ custom Notes මුරපදයක් භාවිතා කර එය අමතක කළොත්, ඒ notes වෙත ආපසු යාමට උදව් කළ නොහැකි බව Apple පවසයි.

විකල්පය 3: PDF එක විවෘත කරන යෙදුමේම සුරකින්න

ඔබ ප්‍රකාශනයක් අගුළු අරින විට UnKey හට මුරපදය සුරැකිය හැකි අතර, එවිට ඊළඟ මාසයේ එම ආකෘතියේම PDF එක Face ID හෝ Touch ID සමඟ විවෘත වේ. සුරැකි මුරපද ඒ උපාංගයේ iPhone Keychain හි පවතී. ඒවා කොතැනකටවත් උඩුගත නොවේ. ඒවා උපාංගයට පමණක් සීමා වන බැවින් ඒවා ඔබේ අලුත් දුරකථනයට නොපැමිණෙන අතර, වැදගත් ඕනෑම දෙයක උපස්ථයක් Passwords යෙදුමේ තබා ගන්න.

දුරකථන මාරු කළොත් UnKey හි සුරැකි මුරපදවලට කුමක් වේද?
