ස්කෑන් කළ PDF විශාල වන්නේ සෑම පිටුවක්ම ඡායාරූපයක් නිසාය. Mac හි Preview හි Reduce File Size හෝ iPhone හි Preview හි export විකල්ප භාවිතා කර, අඩු හා සරල පිටු ස්කෑන් කර, උඩුගත කිරීමට පෙර මුරපදය ඉවත් කරන්න.

වීසා, ගමන් බලපත්‍ර, විභාග සහ ණය portal බොහෝ විට එක් ගොනුවකට කිලෝබයිට් සිය ගණනක හෝ මෙගාබයිට් දෙකක පමණ සීමාවක් පනවයි. ස්කෑන් කළ PDF එකක සෑම පිටුවක්ම ඡායාරූපයක් ලෙස ගබඩා වන නිසා එය ඒ සීමාව පහසුවෙන් ඉක්මවයි. වේගවත්ම විසඳුම් නම් රූප සම්පීඩනය සහිතව PDF එක නැවත සුරකින එක (Mac හෝ iPhone හි Preview මගින් නොමිලේ කළ හැක), අවශ්‍ය පිටු පමණක් ස්කෑන් කරන එක, සහ මුලින්ම මුරපදය ඉවත් කරන එකයි. මන්ද බොහෝ portal වලට ආරක්ෂිත ගොනු කියවිය නොහැක.

සම්පීඩනය කිරීමට පෙර

  • නිශ්චිත සීමාව සහ ආකෘතිය පරීක්ෂා කරන්න portal පිටුවේ: උපරිම ප්‍රමාණය, එය එක් ගොනුවකටද මුළු එකතුවටද යන්න, සහ අවශ්‍ය වන්නේ PDF ද JPEG ද යන්න. නීති portal අනුව වෙනස් වන අතර වෙනස් වෙයි, එබැවින් උඩුගත කිරීමේ පිටුවේ සඳහන් දේ අනුව යන්න.
  • මුරපදය ඉවත් කරන්න. ආරක්ෂිත PDF එකක් portal එකට විවෘත කර පරීක්ෂා කළ නොහැක. බලන්න: iPhone, Mac, Windows හෝ Android.
  • මුල් පිටපත තබා ගන්න. සම්පීඩනය රූපයේ ගුණාත්මකභාවය අඩු කරයි. portal එක බොඳ වූ ස්කෑන් එකක් ප්‍රතික්ෂේප කළහොත් භාවිතා කිරීමට පූර්ණ ගුණාත්මක පිටපතක් තබා ගන්න.

Mac එකක: Preview

  1. Preview හි PDF එක විවෘත කර File > Export තෝරන්න.
  2. Quartz Filter මෙනුවෙන් Reduce File Size තෝරන්න.
  3. එයට අලුත් නමක් දී Save ක්ලික් කරන්න.

සම්පීඩිත PDF එක “මුල් පිටපතට වඩා අඩු ගුණාත්මකභාවයකින් යුක්ත විය හැකි” බව Apple සඳහන් කරයි. එම Export කවුළුවේම Optimize images for screen සහ Save images as JPEG යන විකල්ප ද ඇත (Apple: Reduce the size of a PDF in Preview on Mac). Reduce File Size නිසා අකුරු බහුල ස්කෑන් කියවීමට අපහසු විය හැකි බැවින්, උඩුගත කිරීමට පෙර ප්‍රතිඵලය විවෘත කර zoom කර බලන්න.

iPhone හෝ iPad එකක: Preview (iOS 26 සහ ඊට පසු)

  1. Preview යෙදුමේ PDF එක විවෘත කරන්න.
  2. ගොනු නමට යාබද මෙනුව ඔබා Export ඔබන්න.
  3. PDF තෝරා, Optimize Images for Screen සහ Save Images as JPEG සක්‍රිය කරන්න.
  4. තහවුරු කිරීමේ බොත්තම ඔබා, ස්ථානයක් තෝරා, නම වෙනස් කර Save ඔබන්න.

Optimize Images for Screen මගින් “කුඩා ගොනුවක් සාදන” බව Apple පවසයි (Apple: Export or compress PDFs in Preview on iPhone). portal එකට JPEG අවශ්‍ය නම්, එම තිරයෙන්ම ප්‍රමාණ slider එකක් සහිතව JPEG ලෙස export කළ හැක.

මුල සිටම කුඩාවට ස්කෑන් කරන්න

  • ඉල්ලූ පිටු පමණක්. උඩුගත කිරීමට පෙර අමතර පිටු මකන්න. iPhone හි Preview හට පිටු මැකීමට සහ පිළිවෙළ වෙනස් කිරීමට හැක (Apple).
  • කැමරාව නොව document scanner භාවිතා කරන්න. Notes, Files සහ Preview පිටුව crop කර පැතලි කරයි (Apple: How to scan documents on iPhone). crop කළ ස්කෑන් එකක් මේසයක් සමඟ ගත් ඡායාරූපයකට වඩා කුඩාය.
  • portal එක ඉඩ දෙන්නේ නම් අකුරු ලේඛන සඳහා ග්‍රේස්කේල් හෝ කළු සුදු භාවිතා කරන්න. Preview ස්කෑනරයට එක් එක් ස්කෑන් එකේ වර්ණ සැකසුම් වෙනස් කිරීමට ඉඩ දේ (Apple). ඡායාරූප සහ නිලධාරියාට පෙනිය යුතු මුද්‍රා ඇති දේ සඳහා වර්ණ තබා ගන්න.
  • එක් ලේඛනයකට එක් ගොනුවක්. portal එකේ වෙන වෙනම ස්ථාන තිබේ නම්, සියල්ල එක් විශාල PDF එකකට එකතු නොකරන්න.

පොදු ගැටලු

  • තවමත් විශාලයි: විකල්ප දෙකම සක්‍රිය කර නැවත export කරන්න, නැතහොත් ග්‍රේස්කේල් වලින් නැවත ස්කෑන් කරන්න.
  • අකුරු බොඳයි: ඔබ වැඩියෙන් සම්පීඩනය කර ඇත. මුල් පිටපතට ගොස් එක් විකල්පයක් පමණක් භාවිතා කරන්න.
  • portal එක “ගොනුව දූෂිතයි” හෝ “encrypted” යැයි කියයි: ගොනුව තවමත් මුරපදයකින් හෝ සීමාවන්ගෙන් ආරක්ෂිත විය හැක. මුරපදය ඉවත් කර නැවත උත්සාහ කරන්න.
