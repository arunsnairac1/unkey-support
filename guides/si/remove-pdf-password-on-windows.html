PDF එක Microsoft Edge හෝ Chrome හි මුරපදය සමඟ විවෘත කර, Ctrl+P ඔබා, Save as PDF (හෝ Microsoft Print to PDF) තෝරා නව පිටපතක් සුරකින්න; ගෙවන Acrobat හට security කෙලින්ම ඉවත් කළ හැක.

Windows 10 සහ 11 හි ඔබ දැනටමත් භාවිතා කරන browser එකෙන් PDF මුරපදයක් නොමිලේ ඉවත් කළ හැක. PDF එක Microsoft Edge හෝ Google Chrome හි විවෘත කර, මුරපදය ටයිප් කර, Ctrl + P ඔබා, printer ලෙස Save as PDF (හෝ Microsoft Print to PDF) තෝරා, සුරකින්න. නව ගොනුව මුරපදයක් නැතිව විවෘත වේ. මුලින්ම ඔබ මුරපදය දැන සිටිය යුතුය.

ක්‍රමය 1: Microsoft Edge (ඇතුළත් කර ඇත)

  1. File Explorer හි PDF එක මත right-click කර Open with > Microsoft Edge තෝරන්න.
  2. Edge අසන විට මුරපදය ටයිප් කරන්න.
  3. Ctrl + P ඔබන්න, නැතහොත් More මෙනුව (තිත් තුන) විවෘත කර Print තෝරන්න.
  4. Printer යටතේ Save as PDF හෝ Microsoft Print to PDF තෝරන්න.
  5. Save (හෝ Print) ක්ලික් කර, ෆෝල්ඩරයක් තෝරා පිටපතට අලුත් නමක් දෙන්න.
  6. නව ගොනුව තවදුරටත් මුරපදයක් නොඉල්ලන බව බැලීමට එය විවෘත කරන්න.

Microsoft හි ඇතුළත් PDF reader මාර්ගෝපදේශය Edge මග පෙන්වයි: More මෙනුව යටතේ Print සොයා, ඔබේ විකල්ප තෝරා, ඉන්පසු print කරන්න (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF යනු Windows සමඟ එන printer එකකි. එය ලැයිස්තුවේ නැත්නම්, Windows Optional Features යටතේ එය නැවත සක්‍රිය කළ හැකි බව Microsoft පවසයි (Microsoft: KB5058499 known issue).

ක්‍රමය 2: Google Chrome

ඔබ Chrome භාවිතා කරන්නේ නම්, පියවර ආසන්න වශයෙන් එකමයි: PDF එක Chrome හි විවෘත කර, මුරපදය ඇතුළත් කර, Ctrl + P ඔබා, Destination Save as PDF ලෙස සකසා, Save ක්ලික් කරන්න (Google: Print from Chrome). අපගේ Chrome මාර්ගෝපදේශයේ වැඩි විස්තර ඇත.

ක්‍රමය 3: Adobe Acrobat Pro හෝ Standard (ගෙවන)

ගෙවන Acrobat ගොනුව නැවත print කරනවා වෙනුවට encryption ම ඉවත් කරයි, එබැවින් සබැඳි සහ පෝරම ක්ෂේත්‍ර නොවෙනස්ව පවතී. Adobe මාර්ග දෙකක් ලේඛනගත කර ඇත (Adobe: Remove passwords from PDFs):

  • Protect මෙවලම්: PDF එක විවෘත කර, Protect මෙවලම් වෙත ගොස් Remove Security තෝරන්න. ගොනුවට ඇත්තේ විවෘත කිරීමේ මුරපදයක් පමණක් නම්, OK මගින් තහවුරු කරන්න. එයට අවසර මුරපදයක් ද ඇත්නම්, Acrobat මුලින්ම ඒ මුරපදය අසයි.
  • Security සැකසුම්: ලේඛනයේ security ගුණාංග විවෘත කර, Security tab එක වෙත ගොස්, Change Settings තෝරා, මුරපද විකල්ප ඉවත් කර සුරකින්න.

Adobe හි මෙනු අනුවාද අතර මාරු වන බැවින්, මෙම නිශ්චිත නම් ඔබට නොපෙනේ නම්, Acrobat හි මෙවලම් සෙවුමේ “Remove Security” සොයන්න. නොමිලේ Acrobat Reader හට ආරක්ෂිත PDF විවෘත කළ හැකි නමුත් security ඉවත් කිරීමට එය සුදුසු මෙවලම නොවේ. ඒ වෙනුවට ක්‍රමය 1 හෝ 2 භාවිතා කරන්න.

ක්‍රමය 4: qpdf (තාක්ෂණික පරිශීලකයන්)

නොමිලේ, open-source qpdf මෙවලම Windows හි ක්‍රියා කරයි. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf encryption නැති පිටපතක් ලියයි (qpdf documentation). මුරපදය ඔබේ command history හි සුරැකිය හැකි බැවින්, බෙදාගත් PC එකක පසුව එය මකා දමන්න.

  • Print අළු පැහැයෙන්ද? PDF එකේ print කිරීම අවහිර කරන අවසර මුරපදයක් තිබිය හැක. print සහ පිටපත් කිරීමේ සීමාවන් බලන්න.
  • මුරපදය ප්‍රතික්ෂේප වේද? Caps Lock, දින ආකෘතිය සහ ඔබේ බැංකුව සතු විස්තර පරීක්ෂා කරන්න. PDF මුරපදයක් ක්‍රියා නොකරන්නේ ඇයි බලන්න.
  • බෙදාගත් හෝ කාර්යාල PC එකක්ද? අගුළු ඇරි පිටපත එය සොයාගන්නා ඕනෑම කෙනෙකුට විවෘත වේ. එය පෞද්ගලික ෆෝල්ඩරයක සුරකින්න සහ Downloads වෙතින් මකන්න.

ඔබට iPhone, iPad හෝ Mac ද ඇත්නම්, UnKey එම උපාංගවල මුරපදය offline ඉවත් කරන අතර, ඊළඟ මාසයේ ප්‍රකාශනය සඳහා මුරපදය සුරැකිය හැක. Windows සඳහා UnKey යෙදුමක් නැත.
