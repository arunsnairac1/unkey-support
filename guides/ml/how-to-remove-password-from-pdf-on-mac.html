Mac-ൽ PDF-ൽ നിന്ന് പാസ്‌വേഡ് നീക്കം ചെയ്യാം (2026)

2026 ഒക്ടോബറിൽ അപ്‌ഡേറ്റ് ചെയ്തത്

ഈ ഭാഷയിൽ വായിക്കുക: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · සිංහල · தமிழ் · తెలుగు

Preview-ൽ പാസ്‌വേഡ് നൽകി PDF തുറക്കുക, File > Export തിരഞ്ഞെടുക്കുക, ഓപ്പൺ പാസ്‌വേഡ് സെറ്റ് ചെയ്തിട്ടില്ലെന്ന് ഉറപ്പാക്കി പുതിയ കോപ്പി സേവ് ചെയ്യുക.

Mac-ൽ macOS-നൊപ്പം വരുന്ന Preview ആപ്പ് ഉപയോഗിച്ച് PDF പാസ്‌വേഡ് സൗജന്യമായി നീക്കം ചെയ്യാം. PDF തുറന്ന് പാസ്‌വേഡ് നൽകി, File > Export തിരഞ്ഞെടുത്ത് ഓപ്പൺ പാസ്‌വേഡ് ഇല്ലാത്ത പുതിയ കോപ്പി സേവ് ചെയ്യുക. പാസ്‌വേഡ് അറിഞ്ഞിരിക്കണം. അത് ഇല്ലാതെ Preview ഫയൽ തുറക്കില്ല.

രീതി 1: Preview, File > Export

  1. PDF-ൽ ഡബിൾ ക്ലിക്ക് ചെയ്ത് Preview-ൽ തുറന്ന് പാസ്‌വേഡ് നൽകുക.
  2. File > Export തിരഞ്ഞെടുത്ത്, "Statement-Oct-unlocked" പോലൊരു പുതിയ പേര് കോപ്പിക്ക് നൽകുക.
  3. Permissions ക്ലിക്ക് ചെയ്ത് Require Password To Open Document തിരഞ്ഞെടുത്തിട്ടില്ല (not selected) എന്ന് ഉറപ്പാക്കുക. പഴയ macOS പതിപ്പുകളിൽ Export വിൻഡോയിൽ പകരം Encrypt ചെക്ക്ബോക്സ് ഉണ്ടാകും; അത് ടിക്ക് ചെയ്യാതെ വിടുക.
  4. Save ക്ലിക്ക് ചെയ്യുക.
  5. പുതിയ ഫയൽ അടച്ച് വീണ്ടും തുറക്കുക. പാസ്‌വേഡ് ചോദിക്കാതെ തുറക്കണം.

Apple-ന്റെ ഇപ്പോഴത്തെ ഗൈഡ് Export വിൻഡോ, Permissions ബട്ടൺ, Require Password To Open Document ഓപ്ഷൻ എന്നിവ വിവരിക്കുന്നു (Apple: Password-protect a PDF in Preview on Mac). ഇതേ പേജിന്റെ macOS Big Sur പതിപ്പിൽ നേരിട്ട് ഇങ്ങനെ പറഞ്ഞിരുന്നു: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide).

PDF-ൽ ഒരു ഓണർ (പെർമിഷൻ) പാസ്‌വേഡും ഉണ്ടെങ്കിലും അത് നിങ്ങൾക്കറിയാമെങ്കിൽ, File > Edit Permissions ഉപയോഗിച്ച് ഓപ്പണിങ് പാസ്‌വേഡും ഏതൊക്കെ ഫീച്ചറുകൾക്ക് പാസ്‌വേഡ് വേണമെന്നതും മാറ്റാം.

രീതി 2: Print > Save as PDF

പ്രിന്റ് ചെയ്യാനാകുന്ന ഏത് Mac ആപ്പിനും പുതിയ PDF ഉണ്ടാക്കാം (Apple: Save a document as a PDF on Mac):

  1. PDF പാസ്‌വേഡ് നൽകി തുറക്കുക.
  2. File > Print തിരഞ്ഞെടുക്കുക.
  3. PDF പോപ്പ്-അപ്പ് മെനു ക്ലിക്ക് ചെയ്ത് Save as PDF തിരഞ്ഞെടുക്കുക.
  4. Security Options ക്ലിക്ക് ചെയ്യരുത്, കാരണം പാസ്‌വേഡ് തിരികെ ചേർക്കുന്നത് അവിടെയാണ്.

പ്രിന്റ് ചെയ്ത കോപ്പിയിൽ ലിങ്കുകൾ, ഫോം ഫീൽഡുകൾ, ബുക്ക്മാർക്കുകൾ എന്നിവ നഷ്ടപ്പെട്ടേക്കാം. ഡോക്യുമെന്റ് പ്രിന്റിങ് തടയുന്നതാണെങ്കിൽ ഈ രീതി ചാരനിറത്തിലായിരിക്കും.

രീതി 3: Mac-ൽ UnKey

UnKey Mac-ലും സൗജന്യമാണ്. ഒറ്റത്തവണ പർച്ചേസായ UnKey Pro iPhone, iPad, Mac എന്നിവയിൽ ബാച്ച് അൺലോക്കിങ്ങും മറ്റ് Pro ടൂളുകളും ചേർക്കുന്നു. PDF വിൻഡോയിലേക്ക് വലിച്ചിട്ട് പാസ്‌വേഡ് നൽകിയാൽ അൺലോക്ക് ചെയ്ത കോപ്പി സേവ് ചെയ്യും. ഒരേ പാസ്‌വേഡുള്ള ഒരു വർഷത്തെ മാസംതോറുമുള്ള സ്റ്റേറ്റ്മെന്റുകൾക്ക് ഉപകരിക്കുന്ന വിധം, UnKey Pro-ക്ക് പല ഫയലുകൾ ഒരുമിച്ച് ബാച്ച് അൺലോക്ക് ചെയ്യാനും കഴിയും. UnKey ഓഫ്‌ലൈനായി പ്രവർത്തിക്കുന്നു, ഒന്നും അപ്‌ലോഡ് ചെയ്യുന്നില്ല, നിങ്ങൾക്കറിയാവുന്ന പാസ്‌വേഡുകൾ മാത്രം നീക്കം ചെയ്യുന്നു.

രീതി 4: കമാൻഡ് ലൈൻ (സാങ്കേതിക പരിജ്ഞാനമുള്ളവർക്ക്)

സൗജന്യ ഓപ്പൺ-സോഴ്സ് ടൂളായ qpdf ഉപയോഗിച്ച് Terminal-ൽ ഇത് ചെയ്യാം: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. ഇൻപുട്ട് ഫയൽ എൻക്രിപ്റ്റ് ചെയ്തതാണെങ്കിലും എൻക്രിപ്ഷൻ ഇല്ലാത്ത ഔട്ട്പുട്ട് ഫയൽ ഉണ്ടാക്കുന്നത് എന്നാണ് ഡോക്യുമെന്റേഷൻ --decrypt വിവരിക്കുന്നത് (qpdf documentation). Homebrew പോലുള്ളവ വഴി നിങ്ങൾ തന്നെ ഇൻസ്റ്റാൾ ചെയ്യണം. കമാൻഡ് ലൈനിൽ പാസ്‌വേഡ് ടൈപ്പ് ചെയ്താൽ അത് ഷെൽ ഹിസ്റ്ററിയിൽ അവശേഷിച്ചേക്കാം.

ഇപ്പോഴും പാസ്‌വേഡ് ചോദിക്കുന്നെങ്കിൽ

  • കോപ്പിക്ക് പകരം ഒറിജിനൽ ആകും തുറന്നത്. ഫയലിന്റെ പേര് പരിശോധിക്കുക.
  • വീണ്ടും എക്സ്പോർട്ട് ചെയ്ത്, Permissions-ൽ Require Password To Open Document ഓഫ് ആണെന്ന് ഉറപ്പാക്കുക.
  • പകരം Print > Save as PDF പരീക്ഷിക്കുക.
  • Preview പാസ്‌വേഡ് നിരസിക്കുന്നെങ്കിൽ, വലിയ അക്ഷരങ്ങളും തീയതി ഫോർമാറ്റും പരിശോധിക്കുക, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ വായിക്കുക.

ഒറിജിനൽ ഡിലീറ്റ് ചെയ്യുംമുമ്പ്

അൺലോക്ക് ചെയ്ത PDF ഫയൽ ഉള്ള ആർക്കും തുറക്കാം. വീട്ടുകാരുമായി പങ്കിട്ട iCloud Drive ഫോൾഡറുകളും നിങ്ങളുടെ Mac കടം വാങ്ങുന്നവരും ഇതിൽ ഉൾപ്പെടും. അൺലോക്ക് ചെയ്ത സ്റ്റേറ്റ്മെന്റുകൾ സ്വകാര്യമായ ഒരിടത്ത് സൂക്ഷിക്കുക. കൂടുതലറിയാൻ PDF പാസ്‌വേഡ് നീക്കം ചെയ്യുന്നത് സുരക്ഷിതമാണോ എന്ന ലേഖനം കാണുക.

ചോദ്യങ്ങൾ

Preview ശരിക്കും സൗജന്യമാണോ?

അതെ. Preview എല്ലാ Mac-ലും ഉണ്ട്, പാസ്‌വേഡ് നൽകിക്കഴിഞ്ഞാൽ ഓപ്പൺ പാസ്‌വേഡ് ഇല്ലാതെ PDF എക്സ്പോർട്ട് ചെയ്യാനും കഴിയും.

എനിക്കറിയാത്ത പാസ്‌വേഡ് Preview-ന് നീക്കം ചെയ്യാനാകുമോ?

ഇല്ല. ഫയൽ തുറക്കുംമുമ്പ് Preview പാസ്‌വേഡ് ചോദിക്കും, അത് മറികടക്കാൻ നിയമാനുസൃത വഴിയൊന്നുമില്ല.

Mac-ൽ ഒരുപാട് PDF-കൾ ഒരുമിച്ച് എങ്ങനെ അൺലോക്ക് ചെയ്യാം?

Preview ഒരു സമയം ഒരു ഫയലേ കൈകാര്യം ചെയ്യൂ. ഒരേ പാസ്‌വേഡുള്ള പല PDF-കളും UnKey Pro ബാച്ച് അൺലോക്ക് ചെയ്യും, സാങ്കേതിക പരിജ്ഞാനമുള്ളവർക്ക് qpdf സ്ക്രിപ്റ്റ് ചെയ്യാം. ഒരുപാട് PDF-കൾ ഒരുമിച്ച് അൺലോക്ക് ചെയ്യുന്നതിനുള്ള ഞങ്ങളുടെ ഗൈഡ് കാണുക.

Print > Save as PDF ചാരനിറത്തിൽ ആകുന്നത് എന്തുകൊണ്ട്?

PDF-ൽ പ്രിന്റിങ് തടയുന്ന പെർമിഷൻ പാസ്‌വേഡ് ഉണ്ടാകാം. ഓണർ പാസ്‌വേഡ് അറിയാമെങ്കിൽ File > Edit Permissions-ൽ നൽകുക. അല്ലെങ്കിൽ Export രീതി ഉപയോഗിക്കുക.

ഫോർമാറ്റുകൾ മാറിയേക്കാം. പാസ്‌വേഡ് പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ പരിശോധിക്കുക അല്ലെങ്കിൽ ഇഷ്യൂ ചെയ്ത സ്ഥാപനത്തെ ബന്ധപ്പെടുക. ഇവിടെ പേര് പറഞ്ഞിട്ടുള്ള ഒരു ബാങ്കുമായോ തൊഴിലുടമയുമായോ അധികാരസ്ഥാപനവുമായോ UnKeyക്ക് ബന്ധമില്ല.

ഇംഗ്ലീഷിൽ നിന്ന് വിവർത്തനം ചെയ്തത്. എന്തെങ്കിലും വ്യത്യാസമുണ്ടെങ്കിൽ ഇംഗ്ലീഷ് പേജാണ് അടിസ്ഥാനം.

ഒരിക്കൽ അൺലോക്ക് ചെയ്യൂ.

നിങ്ങൾക്ക് ഇതിനകം തുറക്കാൻ കഴിയുന്ന PDFകളിൽ നിന്ന് UnKey പാസ്‌വേഡ് നീക്കം ചെയ്യുന്നു, iPhone, iPad, Mac എന്നിവയിൽ. ഓഫ്‌ലൈനായി പ്രവർത്തിക്കും, ഒന്നും അപ്‌ലോഡ് ചെയ്യില്ല. പാസ്‌വേഡ് ഒരിക്കൽ സേവ് ചെയ്താൽ, അടുത്ത മാസത്തെ സ്റ്റേറ്റ്‌മെന്റ് Face ID തുറക്കും.
