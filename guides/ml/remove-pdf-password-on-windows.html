Windows-ൽ PDF പാസ്‌വേഡ് നീക്കം ചെയ്യാം (2026)

2026 ഒക്ടോബറിൽ അപ്‌ഡേറ്റ് ചെയ്തത്

ഈ ഭാഷയിൽ വായിക്കുക: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · नेपाली · Português · සිංහල · தமிழ் · తెలుగు

പാസ്‌വേഡ് നൽകി Microsoft Edge അല്ലെങ്കിൽ Chrome-ൽ PDF തുറക്കുക, Ctrl+P അമർത്തുക, Save as PDF (അല്ലെങ്കിൽ Microsoft Print to PDF) തിരഞ്ഞെടുത്ത് പുതിയ കോപ്പി സേവ് ചെയ്യുക; പണം കൊടുക്കുന്ന Acrobat-ന് സെക്യൂരിറ്റി നേരിട്ട് നീക്കാം.

Windows 10, 11 എന്നിവയിൽ നിങ്ങളുടെ കൈയിലുള്ള ബ്രൗസർ ഉപയോഗിച്ച് PDF പാസ്‌വേഡ് സൗജന്യമായി നീക്കം ചെയ്യാം. PDF Microsoft Edge അല്ലെങ്കിൽ Google Chrome-ൽ തുറന്ന് പാസ്‌വേഡ് ടൈപ്പ് ചെയ്ത്, Ctrl + P അമർത്തി, പ്രിന്ററായി Save as PDF (അല്ലെങ്കിൽ Microsoft Print to PDF) തിരഞ്ഞെടുത്ത് സേവ് ചെയ്യുക. പുതിയ ഫയൽ പാസ്‌വേഡ് ഇല്ലാതെ തുറക്കും. പാസ്‌വേഡ് ആദ്യം അറിഞ്ഞിരിക്കണം.

രീതി 1: Microsoft Edge (ബിൽറ്റ്-ഇൻ)

  1. File Explorer-ൽ PDF-ൽ റൈറ്റ് ക്ലിക്ക് ചെയ്ത് Open with > Microsoft Edge തിരഞ്ഞെടുക്കുക.
  2. Edge ചോദിക്കുമ്പോൾ പാസ്‌വേഡ് ടൈപ്പ് ചെയ്യുക.
  3. Ctrl + P അമർത്തുക, അല്ലെങ്കിൽ More മെനു (മൂന്ന് ഡോട്ട്) തുറന്ന് Print തിരഞ്ഞെടുക്കുക.
  4. Printer എന്നതിന് കീഴിൽ Save as PDF അല്ലെങ്കിൽ Microsoft Print to PDF തിരഞ്ഞെടുക്കുക.
  5. Save (അല്ലെങ്കിൽ Print) ക്ലിക്ക് ചെയ്ത്, ഫോൾഡർ തിരഞ്ഞെടുത്ത് കോപ്പിക്ക് പുതിയ പേര് നൽകുക.
  6. പുതിയ ഫയൽ തുറന്ന് അത് ഇനി പാസ്‌വേഡ് ചോദിക്കുന്നില്ലെന്ന് പരിശോധിക്കുക.

Microsoft-ന്റെ ബിൽറ്റ്-ഇൻ PDF റീഡർ ഗൈഡ് Edge വഴി കാണിക്കുന്നു: More മെനുവിൽ Print കണ്ടെത്തി, ഓപ്ഷനുകൾ തിരഞ്ഞെടുത്ത്, പ്രിന്റ് ചെയ്യുക (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF Windows-നൊപ്പം വരുന്ന ഒരു പ്രിന്ററാണ്. ലിസ്റ്റിൽ ഇല്ലെങ്കിൽ Windows Optional Features-ൽ നിന്ന് വീണ്ടും ഓണാക്കാമെന്ന് Microsoft പറയുന്നു (Microsoft: KB5058499 known issue).

രീതി 2: Google Chrome

Chrome ഉപയോഗിക്കുന്നെങ്കിൽ ഘട്ടങ്ങൾ ഏതാണ്ട് അതുതന്നെ: Chrome-ൽ PDF തുറക്കുക, പാസ്‌വേഡ് നൽകുക, Ctrl + P അമർത്തുക, Destination Save as PDF ആക്കുക, Save ക്ലിക്ക് ചെയ്യുക (Google: Print from Chrome). കൂടുതൽ വിവരങ്ങൾ ഞങ്ങളുടെ Chrome ഗൈഡിൽ ഉണ്ട്.

രീതി 3: Adobe Acrobat Pro അല്ലെങ്കിൽ Standard (പണം കൊടുത്തുള്ളത്)

പണം കൊടുത്തുള്ള Acrobat ഫയൽ വീണ്ടും പ്രിന്റ് ചെയ്യുന്നതിന് പകരം എൻക്രിപ്ഷൻ തന്നെ നീക്കം ചെയ്യുന്നു, അതിനാൽ ലിങ്കുകളും ഫോം ഫീൽഡുകളും കേടുകൂടാതെ നിൽക്കും. Adobe രണ്ട് വഴികൾ രേഖപ്പെടുത്തിയിട്ടുണ്ട് (Adobe: Remove passwords from PDFs):

  • Protect ടൂളുകൾ: PDF തുറന്ന് Protect ടൂളുകളിൽ പോയി Remove Security തിരഞ്ഞെടുക്കുക. ഫയലിന് ഓപ്പൺ പാസ്‌വേഡ് മാത്രമേ ഉള്ളൂ എങ്കിൽ OK നൽകി സ്ഥിരീകരിക്കുക. പെർമിഷൻ പാസ്‌വേഡും ഉണ്ടെങ്കിൽ Acrobat ആദ്യം ആ പാസ്‌വേഡ് ചോദിക്കും.
  • സെക്യൂരിറ്റി സെറ്റിങ്ങുകൾ: ഡോക്യുമെന്റിന്റെ സെക്യൂരിറ്റി പ്രോപ്പർട്ടികൾ തുറന്ന്, Security ടാബിൽ Change Settings തിരഞ്ഞെടുത്ത്, പാസ്‌വേഡ് ഓപ്ഷനുകൾ ഒഴിവാക്കി സേവ് ചെയ്യുക.

Adobe-യുടെ മെനുകൾ പതിപ്പുകൾക്കനുസരിച്ച് മാറും; ഈ പേരുകൾ കാണുന്നില്ലെങ്കിൽ Acrobat-ന്റെ ടൂൾ സെർച്ചിൽ "Remove Security" തിരയുക. സൗജന്യ Acrobat Reader-ന് സംരക്ഷിത PDF-കൾ തുറക്കാം, പക്ഷേ സെക്യൂരിറ്റി നീക്കാനുള്ള ടൂൾ അതല്ല. രീതി 1 അല്ലെങ്കിൽ 2 ഉപയോഗിക്കുക.

രീതി 4: qpdf (സാങ്കേതിക ഉപയോക്താക്കൾക്ക്)

സൗജന്യ ഓപ്പൺ-സോഴ്സ് ടൂൾ qpdf Windows-ൽ പ്രവർത്തിക്കും. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf എൻക്രിപ്ഷൻ ഇല്ലാത്ത കോപ്പി എഴുതും (qpdf documentation). പാസ്‌വേഡ് കമാൻഡ് ഹിസ്റ്ററിയിൽ സേവ് ആയേക്കാം, അതിനാൽ പങ്കിട്ട PC-യിൽ പിന്നീട് അത് നീക്കം ചെയ്യുക.

പരിശോധിക്കേണ്ട കാര്യങ്ങൾ

  • Print ചാരനിറത്തിലാണോ? PDF-ൽ പ്രിന്റിങ് തടയുന്ന പെർമിഷൻ പാസ്‌വേഡ് ഉണ്ടാകാം. പ്രിന്റിങ്, കോപ്പി നിയന്ത്രണങ്ങൾ കാണുക.
  • പാസ്‌വേഡ് നിരസിക്കപ്പെട്ടോ? Caps Lock, തീയതി ഫോർമാറ്റ്, ബാങ്കിന്റെ കൈയിലുള്ള വിവരങ്ങൾ എന്നിവ പരിശോധിക്കുക. PDF പാസ്‌വേഡ് പ്രവർത്തിക്കാത്തത് എന്തുകൊണ്ട് കാണുക.
  • പങ്കിട്ട അല്ലെങ്കിൽ ഓഫീസ് PC ആണോ? അൺലോക്ക് ചെയ്ത കോപ്പി അത് കണ്ടെത്തുന്ന ആർക്കും തുറക്കാം. സ്വകാര്യ ഫോൾഡറിൽ സേവ് ചെയ്ത് Downloads-ൽ നിന്ന് ഡിലീറ്റ് ചെയ്യുക.

നിങ്ങൾക്ക് iPhone, iPad അല്ലെങ്കിൽ Mac കൂടി ഉണ്ടെങ്കിൽ, UnKey ആ ഉപകരണങ്ങളിൽ ഓഫ്‌ലൈനായി പാസ്‌വേഡ് നീക്കം ചെയ്യുകയും അടുത്ത മാസത്തെ സ്റ്റേറ്റ്മെന്റിനായി പാസ്‌വേഡ് സേവ് ചെയ്യുകയും ചെയ്യും. Windows-ന് UnKey ആപ്പ് ഇല്ല.

ചോദ്യങ്ങൾ

Windows-ൽ എനിക്ക് ഒന്നും ഇൻസ്റ്റാൾ ചെയ്യണോ?

വേണ്ട. Microsoft Edge-ഉം Microsoft Print to PDF പ്രിന്ററും Windows 10, 11 എന്നിവയ്ക്കൊപ്പം വരുന്നു.

ഓൺലൈൻ "unlock PDF" സൈറ്റുകൾ കൂടുതൽ നന്നായി പ്രവർത്തിക്കുമോ?

അവ ഇതേ ജോലി തന്നെ ചെയ്യും, പക്ഷേ നിങ്ങളുടെ ഡോക്യുമെന്റ് മറ്റൊരാളുടെ സെർവറിലേക്ക് അപ്‌ലോഡ് ചെയ്യും. ബാങ്ക് സ്റ്റേറ്റ്മെന്റുകൾക്കും നികുതി രേഖകൾക്കും ഇവിടെയുള്ള ഓഫ്‌ലൈൻ രീതികളാണ് സുരക്ഷിതം.

ഇവയിലേതെങ്കിലും മറന്നുപോയ പാസ്‌വേഡ് നീക്കം ചെയ്യുമോ?

ഇല്ല. Edge, Chrome, Acrobat, qpdf എന്നിവയ്ക്കെല്ലാം ശരിയായ പാസ്‌വേഡ് വേണം. ഫോർമാറ്റിനായി PDF-ഒപ്പം വന്ന ഇമെയിൽ നോക്കുക.

കോപ്പിയിൽ ലിങ്കുകൾ പ്രവർത്തിക്കാത്തത് എന്തുകൊണ്ട്?

PDF-ലേക്ക് പ്രിന്റ് ചെയ്യുമ്പോൾ പേജുകൾ പുനർനിർമ്മിക്കപ്പെടും, അപ്പോൾ ലിങ്കുകളും ഫോം ഫീൽഡുകളും നഷ്ടപ്പെട്ടേക്കാം. Acrobat-ന്റെ Remove Security അല്ലെങ്കിൽ qpdf അവ നിലനിർത്തും.

സ്രോതസ്സുകൾ

  • Microsoft Support – View, print, and edit PDFs in a PDF reader
  • Microsoft Support – KB5058499 (Microsoft Print to PDF known issue)
  • Google Chrome Help – Print from Chrome
  • Adobe – Remove passwords from PDFs in Acrobat
  • qpdf – Command-line options

ഫോർമാറ്റുകൾ മാറിയേക്കാം. പാസ്‌വേഡ് പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ പരിശോധിക്കുക അല്ലെങ്കിൽ ഇഷ്യൂ ചെയ്ത സ്ഥാപനത്തെ ബന്ധപ്പെടുക. ഇവിടെ പേര് പറഞ്ഞിട്ടുള്ള ഒരു ബാങ്കുമായോ തൊഴിലുടമയുമായോ അധികാരസ്ഥാപനവുമായോ UnKeyക്ക് ബന്ധമില്ല.

ഇംഗ്ലീഷിൽ നിന്ന് വിവർത്തനം ചെയ്തത്. എന്തെങ്കിലും വ്യത്യാസമുണ്ടെങ്കിൽ ഇംഗ്ലീഷ് പേജാണ് അടിസ്ഥാനം.

ഒരിക്കൽ അൺലോക്ക് ചെയ്യൂ.

നിങ്ങൾക്ക് ഇതിനകം തുറക്കാൻ കഴിയുന്ന PDFകളിൽ നിന്ന് UnKey പാസ്‌വേഡ് നീക്കം ചെയ്യുന്നു, iPhone, iPad, Mac എന്നിവയിൽ. ഓഫ്‌ലൈനായി പ്രവർത്തിക്കും, ഒന്നും അപ്‌ലോഡ് ചെയ്യില്ല. പാസ്‌വേഡ് ഒരിക്കൽ സേവ് ചെയ്താൽ, അടുത്ത മാസത്തെ സ്റ്റേറ്റ്‌മെന്റ് Face ID തുറക്കും.
