ഗൈഡുകൾ · എങ്ങനെ ചെയ്യാം

അപ്‌ലോഡ് പരിധിക്കായി സ്കാൻ ചെയ്ത PDF ചെറുതാക്കാം

2026 ഒക്ടോബറിൽ അപ്‌ഡേറ്റ് ചെയ്തത്

ഈ ഭാഷയിൽ വായിക്കുക: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · नेपाली · Português · සිංහල · தமிழ் · తెలుగు

സ്കാൻ ചെയ്ത PDF വലുതാകുന്നത് ഓരോ പേജും ഫോട്ടോ ആയതുകൊണ്ടാണ്; Mac-ൽ Preview-ന്റെ Reduce File Size, iPhone-ൽ Preview-ന്റെ എക്സ്പോർട്ട് ഓപ്ഷനുകൾ എന്നിവകൊണ്ട് ചെറുതാക്കാം, കുറച്ചു പേജുകൾ മാത്രം സ്കാൻ ചെയ്യുക, അപ്‌ലോഡിന് മുമ്പ് പാസ്‌വേഡ് നീക്കം ചെയ്യുക.

വിസ, പാസ്പോർട്ട്, പരീക്ഷ, ലോൺ പോർട്ടലുകൾ പലപ്പോഴും ഒരു ഫയലിന് ഏതാനും നൂറ് കിലോബൈറ്റോ രണ്ട് മെഗാബൈറ്റോ വരെയേ അപ്‌ലോഡ് അനുവദിക്കൂ. സ്കാൻ ചെയ്ത PDF-ൽ ഓരോ പേജും ഒരു ഫോട്ടോ ആയി സൂക്ഷിക്കുന്നതുകൊണ്ട് അത് ആ പരിധി കടക്കും. ഏറ്റവും വേഗത്തിലുള്ള വഴികൾ: PDF ഇമേജ് കംപ്രഷനോടെ വീണ്ടും സേവ് ചെയ്യുക (Mac-ലെയോ iPhone-ലെയോ Preview ഇത് സൗജന്യമായി ചെയ്യും), ആവശ്യമുള്ള പേജുകൾ മാത്രം സ്കാൻ ചെയ്യുക, ആദ്യം പാസ്‌വേഡ് നീക്കം ചെയ്യുക (പല പോർട്ടലുകൾക്കും പാസ്‌വേഡ് ഉള്ള ഫയൽ വായിക്കാനാവില്ല).

കംപ്രസ് ചെയ്യുംമുമ്പ്

  • കൃത്യമായ പരിധിയും ഫോർമാറ്റും നോക്കുക. പോർട്ടൽ പേജിൽ പരമാവധി വലുപ്പം, അത് ഓരോ ഫയലിനുമാണോ ആകെയാണോ, PDF വേണോ JPEG വേണോ എന്നിവ കാണും. നിയമങ്ങൾ പോർട്ടലുകൾ തമ്മിൽ വ്യത്യസ്തമാണ്, മാറുകയും ചെയ്യും; അപ്‌ലോഡ് പേജ് പറയുന്നത് പിന്തുടരുക.
  • പാസ്‌വേഡ് നീക്കം ചെയ്യുക. സംരക്ഷിത PDF പോർട്ടലിന് തുറന്ന് പരിശോധിക്കാനാവില്ല. iPhone, Mac, Windows, Android എന്നിവ കാണുക.
  • ഒറിജിനൽ സൂക്ഷിക്കുക. കംപ്രഷൻ ചിത്രത്തിന്റെ നിലവാരം കുറയ്ക്കും. മങ്ങിയ സ്കാൻ പോർട്ടൽ നിരസിച്ചാൽ ഉപയോഗിക്കാൻ പൂർണ്ണ നിലവാരമുള്ള ഒരു കോപ്പി വെക്കുക.

Mac-ൽ: Preview

  1. Preview-ൽ PDF തുറന്ന് File > Export തിരഞ്ഞെടുക്കുക.
  2. Quartz Filter മെനുവിൽ Reduce File Size തിരഞ്ഞെടുക്കുക.
  3. പുതിയ പേര് നൽകി Save ക്ലിക്ക് ചെയ്യുക.

കംപ്രസ് ചെയ്ത PDF-ന്റെ നിലവാരം ഒറിജിനലിനെക്കാൾ കുറവായേക്കാമെന്ന് Apple പറയുന്നു. അതേ Export വിൻഡോയിൽ Optimize images for screen, Save images as JPEG എന്നിവയും ഉണ്ട് (Apple: Reduce the size of a PDF in Preview on Mac). ടെക്സ്റ്റ് കൂടുതലുള്ള സ്കാനുകൾ Reduce File Size ചെയ്താൽ വായിക്കാൻ പ്രയാസമായേക്കാം, അതിനാൽ അപ്‌ലോഡ് ചെയ്യുംമുമ്പ് ഫലം തുറന്ന് സൂം ചെയ്ത് നോക്കുക.

iPhone അല്ലെങ്കിൽ iPad-ൽ: Preview (iOS 26-ലും അതിനുശേഷവും)

  1. Preview ആപ്പിൽ PDF തുറക്കുക.
  2. ഫയൽ പേരിനടുത്തുള്ള മെനു ടാപ്പ് ചെയ്ത് Export ടാപ്പ് ചെയ്യുക.
  3. PDF തിരഞ്ഞെടുത്ത് Optimize Images for Screen, Save Images as JPEG എന്നിവ ഓണാക്കുക.
  4. കൺഫേം ബട്ടൺ ടാപ്പ് ചെയ്ത്, സേവ് ചെയ്യാനുള്ള സ്ഥലം തിരഞ്ഞെടുത്ത്, പേര് മാറ്റി Save ടാപ്പ് ചെയ്യുക.

Optimize Images for Screen "ചെറിയ ഫയൽ ഉണ്ടാക്കും" എന്ന് Apple പറയുന്നു (Apple: Export or compress PDFs in Preview on iPhone). പോർട്ടലിന് JPEG ആണ് വേണ്ടതെങ്കിൽ, അതേ സ്ക്രീൻ വലുപ്പം ക്രമീകരിക്കാനുള്ള സ്ലൈഡറോടെ JPEG ആയും എക്സ്പോർട്ട് ചെയ്യും.

തുടക്കത്തിലേ ചെറുതായി സ്കാൻ ചെയ്യുക

  • ചോദിച്ച പേജുകൾ മാത്രം. അപ്‌ലോഡിന് മുമ്പ് അധിക പേജുകൾ ഒഴിവാക്കുക. iPhone-ലെ Preview-ൽ പേജുകൾ ഡിലീറ്റ് ചെയ്യാനും ക്രമം മാറ്റാനും കഴിയും (Apple).
  • ക്യാമറയ്ക്ക് പകരം ഡോക്യുമെന്റ് സ്കാനർ ഉപയോഗിക്കുക. Notes, Files, Preview എന്നിവ പേജ് ക്രോപ്പ് ചെയ്ത് നിരപ്പാക്കും (Apple: How to scan documents on iPhone). ക്രോപ്പ് ചെയ്ത സ്കാൻ, മേശ ഉൾപ്പെടെയുള്ള ഫോട്ടോയെക്കാൾ ചെറുതാണ്.
  • ഗ്രേസ്കെയിൽ അല്ലെങ്കിൽ ബ്ലാക്ക് ആൻഡ് വൈറ്റ് ടെക്സ്റ്റ് ഡോക്യുമെന്റുകൾക്ക്, പോർട്ടൽ അനുവദിക്കുന്നെങ്കിൽ. ഓരോ സ്കാനിന്റെയും നിറം ക്രമീകരിക്കാൻ Preview-ന്റെ സ്കാനർ അനുവദിക്കുന്നു (Apple). ഫോട്ടോകൾക്കും ഉദ്യോഗസ്ഥൻ കാണേണ്ട സ്റ്റാമ്പ്, സീൽ എന്നിവയ്ക്കും നിറം നിലനിർത്തുക.
  • ഒരു ഫയലിൽ ഒരു ഡോക്യുമെന്റ്. പോർട്ടലിൽ വെവ്വേറെ സ്ലോട്ടുകൾ ഉണ്ടെങ്കിൽ എല്ലാം ചേർത്ത് ഒരു ഭീമൻ PDF ആക്കരുത്.

സാധാരണ പ്രശ്നങ്ങൾ

  • ഇപ്പോഴും വലുത്: രണ്ട് ഓപ്ഷനുകളും ഓണാക്കി വീണ്ടും എക്സ്പോർട്ട് ചെയ്യുക, അല്ലെങ്കിൽ ഗ്രേസ്കെയിലിൽ വീണ്ടും സ്കാൻ ചെയ്യുക.
  • ടെക്സ്റ്റ് മങ്ങിയിരിക്കുന്നു: കൂടുതൽ കംപ്രസ് ചെയ്തു പോയി. ഒറിജിനലിലേക്ക് മടങ്ങി ഒരു ഓപ്ഷൻ മാത്രം ഉപയോഗിക്കുക.
  • പോർട്ടൽ "file is corrupt" അല്ലെങ്കിൽ "encrypted" എന്ന് പറയുന്നു: ഫയലിൽ ഇപ്പോഴും പാസ്‌വേഡോ നിയന്ത്രണങ്ങളോ ഉണ്ടാകാം. പാസ്‌വേഡ് നീക്കം ചെയ്ത് വീണ്ടും ശ്രമിക്കുക.
  • ഫയൽ വലുതായിപ്പോയി: മിക്കവാറും യഥാർത്ഥ ടെക്സ്റ്റ് ഉള്ള PDF-കൾ ഇതിനകം ചെറുതാണ്. വീണ്ടും സേവ് ചെയ്താൽ വലുപ്പം കൂടാം. ഒറിജിനൽ അപ്‌ലോഡ് ചെയ്യുക.

UnKey ഉപയോഗിച്ച്

iPhone, iPad, Mac എന്നിവയിലെ UnKey Pro-യിൽ സ്കാനുകൾക്കായുള്ള Compress ടൂൾ ഉണ്ട്. ഫോട്ടോ പോലുള്ള പേജുകൾ വീണ്ടും എൻകോഡ് ചെയ്യും, യഥാർത്ഥ ടെക്സ്റ്റ് ഉള്ള പേജുകളിൽ തൊടില്ല, അതിനാൽ അക്ഷരങ്ങൾ വ്യക്തമായി നിൽക്കും; നിങ്ങൾ കൊടുത്തതിനെക്കാൾ വലിയ ഫയൽ ഒരിക്കലും തിരിച്ചുതരില്ല. ഇത് ഓഫ്‌ലൈനിൽ പ്രവർത്തിക്കുന്നതിനാൽ പാസ്പോർട്ടോ ബാങ്ക് സ്കാനോ ഒരു കംപ്രഷൻ വെബ്സൈറ്റിലേക്ക് അപ്‌ലോഡ് ചെയ്യപ്പെടുന്നില്ല. അൺലോക്ക് ചെയ്യുന്നത് സൗജന്യമാണ്; Compress ഒറ്റത്തവണ Pro പർച്ചേസിന്റെ ഭാഗമാണ്.

ചോദ്യങ്ങൾ

കംപ്രസ് ചെയ്താൽ എന്റെ ഡോക്യുമെന്റുകൾ വായിക്കാൻ പറ്റാതാകുമോ?

അമിതമായി ചെയ്താൽ ആകാം. കംപ്രസ് ചെയ്ത കോപ്പി എപ്പോഴും തുറന്ന് ചെറിയ അക്ഷരങ്ങൾ സൂം ചെയ്ത് നോക്കുക, ഒറിജിനൽ സൂക്ഷിക്കുക.

2 പേജ് സ്കാൻ 8 MB ആകുന്നത് എന്തുകൊണ്ട്?

സ്കാൻ ചെയ്ത ഓരോ പേജും ഉയർന്ന റെസല്യൂഷനുള്ള ഫോട്ടോയാണ്. ബാങ്കിൽ നിന്നുള്ള ടെക്സ്റ്റ് PDF-കൾ ചിത്രങ്ങളല്ല ടെക്സ്റ്റ് ആണ് സൂക്ഷിക്കുന്നത്, അതുകൊണ്ട് അവ വളരെ ചെറുതാണ്.

പോർട്ടലുകൾ പാസ്‌വേഡ് ഉള്ള PDF സ്വീകരിക്കുമോ?

പലതിനും അവ വായിക്കാനാവില്ല. പോർട്ടൽ മറ്റൊന്ന് പറയുന്നില്ലെങ്കിൽ അപ്‌ലോഡ് ചെയ്യുംമുമ്പ് പാസ്‌വേഡ് നീക്കം ചെയ്യുക.

പാസ്പോർട്ടിനും സ്റ്റേറ്റ്മെന്റിനും ഓൺലൈൻ കംപ്രസറുകൾ സുരക്ഷിതമാണോ?

അവ നിങ്ങളുടെ ഫയൽ ഒരു സെർവറിലേക്ക് അപ്‌ലോഡ് ചെയ്യും. തിരിച്ചറിയൽ, സാമ്പത്തിക ഡോക്യുമെന്റുകൾ സ്വന്തം ഉപകരണത്തിൽ തന്നെ കംപ്രസ് ചെയ്യുന്നതാണ് സുരക്ഷിതം.

ഫോർമാറ്റുകൾ മാറിയേക്കാം. പാസ്‌വേഡ് പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ പരിശോധിക്കുക അല്ലെങ്കിൽ ഇഷ്യൂ ചെയ്ത സ്ഥാപനത്തെ ബന്ധപ്പെടുക. ഇവിടെ പേര് പറഞ്ഞിട്ടുള്ള ഒരു ബാങ്കുമായോ തൊഴിലുടമയുമായോ അധികാരസ്ഥാപനവുമായോ UnKeyക്ക് ബന്ധമില്ല.

ഇംഗ്ലീഷിൽ നിന്ന് വിവർത്തനം ചെയ്തത്. എന്തെങ്കിലും വ്യത്യാസമുണ്ടെങ്കിൽ ഇംഗ്ലീഷ് പേജാണ് അടിസ്ഥാനം.
