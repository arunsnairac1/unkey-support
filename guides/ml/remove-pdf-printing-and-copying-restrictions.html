ഗൈഡുകൾ · എങ്ങനെ ചെയ്യാം

PDF പ്രിന്റിങ്, കോപ്പി നിയന്ത്രണങ്ങൾ വിശദീകരണം

2026 ഒക്ടോബറിൽ അപ്‌ഡേറ്റ് ചെയ്തത്

ഓപ്പൺ പാസ്‌വേഡ് PDF വായിക്കുന്നതിൽ നിന്ന് ആരെയും തടയുന്നു; ഓണർ (പെർമിഷൻ) പാസ്‌വേഡ് പ്രിന്റിങ്, കോപ്പി, എഡിറ്റിങ് പോലുള്ള പ്രവൃത്തികളെ മാത്രം നിയന്ത്രിക്കുന്നു.

PDF-കൾക്ക് രണ്ട് വ്യത്യസ്ത പാസ്‌വേഡുകൾ ഉണ്ടാകാം. ഫയൽ കാണാൻ തന്നെ ഓപ്പൺ പാസ്‌വേഡ് (യൂസർ പാസ്‌വേഡ് എന്നും പറയും) വേണം. ഓണർ പാസ്‌വേഡ് (പെർമിഷൻ പാസ്‌വേഡ് എന്നും പറയും) ഫയൽ തുറക്കാൻ അനുവദിക്കും, പക്ഷേ പ്രിന്റിങ്, ടെക്സ്റ്റ് കോപ്പി, എഡിറ്റിങ് തുടങ്ങിയവ നിയന്ത്രിക്കും. നിയന്ത്രണങ്ങൾ ശരിയായി നീക്കാൻ ഓണർ പാസ്‌വേഡ് വേണം.

രണ്ട് പാസ്‌വേഡുകൾ ലളിതമായി

ഓപ്പൺ (യൂസർ) പാസ്‌വേഡ്ഓണർ (പെർമിഷൻ) പാസ്‌വേഡ്
നിങ്ങൾ കാണുന്നത്എന്തെങ്കിലും കാണിക്കുംമുമ്പ് പാസ്‌വേഡ് ചോദിക്കുംഫയൽ തുറക്കും, പക്ഷേ Print അല്ലെങ്കിൽ Copy ചാരനിറത്തിലായിരിക്കും
എന്തിനെ സംരക്ഷിക്കുന്നുഎൻക്രിപ്റ്റ് ചെയ്ത മുഴുവൻ ഉള്ളടക്കത്തെപ്രിന്റിങ്, കോപ്പി, എഡിറ്റിങ്, കമന്റിങ് പോലുള്ള പ്രവൃത്തികളെ
സാധാരണ ഉപയോഗംബാങ്ക് സ്റ്റേറ്റ്മെന്റുകൾ, നികുതി ഡോക്യുമെന്റുകൾപ്രസിദ്ധീകരിച്ച റിപ്പോർട്ടുകൾ, ഫോമുകൾ, കരാറുകൾ

Adobe ഈ വേർതിരിവ് ഇതേ രീതിയിൽ വിവരിക്കുന്നു. PDF തുറക്കാൻ Document Open പാസ്‌വേഡ് വേണം, പെർമിഷൻ പാസ്‌വേഡ് പ്രിന്റിങ്, എഡിറ്റിങ്, കോപ്പി തുടങ്ങിയ ഫീച്ചറുകളെ നിയന്ത്രിക്കുന്നു (Adobe: Password security overview). ഒരു പ്രധാന വിശദാംശം qpdf-ന്റെ ഡോക്യുമെന്റേഷൻ ചേർക്കുന്നു: റീഡറുകൾ "apply security restrictions to files opened with the user password" എന്നും "allow security restrictions to be changed or overridden when files are opened with the owner password" എന്നും (qpdf).

നിയന്ത്രണങ്ങൾ എങ്ങനെ നടപ്പാക്കുന്നു

നിയന്ത്രണങ്ങൾ പ്രവർത്തിക്കുന്നത് PDF റീഡർ അവ മാനിക്കാൻ തീരുമാനിക്കുന്നതിനെ ആശ്രയിച്ചാണ്. തങ്ങളുടെ സ്വന്തം ഉൽപ്പന്നങ്ങൾ അവ നടപ്പാക്കുമെന്നും, മൂന്നാം കക്ഷി ഉൽപ്പന്നങ്ങൾ ഈ സെറ്റിങ്ങുകൾ പിന്തുണയ്ക്കുന്നില്ലെങ്കിൽ സ്വീകർത്താക്കൾക്ക് ചില നിയന്ത്രണങ്ങളോ എല്ലാമോ മറികടക്കാനായേക്കാമെന്നും Adobe പറയുന്നു (Adobe). അതായത് പെർമിഷൻ പാസ്‌വേഡ് പൂട്ടല്ല, "ദയവായി ചെയ്യരുത്" എന്ന മര്യാദയുള്ള അഭ്യർത്ഥന മാത്രമാണ്. എങ്കിലും ഉടമയുടെ ആഗ്രഹം അവഗണിക്കാനുള്ള കാരണമല്ല അത്. ആരെങ്കിലും കോപ്പി തടഞ്ഞിട്ടുണ്ടെങ്കിൽ, പകർപ്പവകാശം അല്ലെങ്കിൽ കരാർ പോലെ സാധാരണയായി ഒരു കാരണം ഉണ്ടാകും.

ഓണർ പാസ്‌വേഡ് ഉള്ളപ്പോൾ നിയന്ത്രണങ്ങൾ മാറ്റുന്നത്

Mac-ൽ (Preview): PDF തുറന്ന്, File > Edit Permissions തിരഞ്ഞെടുത്ത്, ഓണർ പാസ്‌വേഡ് നൽകുക. പാസ്‌വേഡ് ഇല്ലാതെ അനുവദിക്കേണ്ട പ്രവൃത്തികൾ തിരഞ്ഞെടുത്ത് Apply ക്ലിക്ക് ചെയ്യാം (Apple: Password-protect a PDF in Preview on Mac). പുതിയ കോപ്പി വേണമെങ്കിൽ File > Export എന്നതിന് കീഴിലും ഇതേ Permissions പാനൽ കാണാം.

Adobe Acrobat-ൽ: പെർമിഷൻ പാസ്‌വേഡ് നീക്കം ചെയ്യാനുള്ള Adobe-യുടെ നിർദ്ദേശങ്ങൾ അത് Enter Password ബോക്സിൽ ടൈപ്പ് ചെയ്യാൻ പറയുന്നു (Adobe: How to remove a PDF password).

കമാൻഡ് ലൈനിൽ: --password=OWNERPASSWORD --decrypt ഉപയോഗിച്ചുള്ള qpdf എൻക്രിപ്ഷൻ ഇല്ലാത്ത കോപ്പി എഴുതും. ഫയൽ നിർമ്മാതാക്കൾ ഏർപ്പെടുത്തിയ നിയന്ത്രണങ്ങൾ മറികടക്കാനല്ല ഈ ഓപ്ഷൻ എന്ന് അതിന്റെ ഡോക്യുമെന്റേഷൻ കുറിക്കുന്നു (qpdf).

രണ്ട് പാസ്‌വേഡും ഉള്ള നിങ്ങളുടെ സ്വന്തം ഡോക്യുമെന്റുകൾ

ബാങ്ക് സ്റ്റേറ്റ്മെന്റുകൾ സാധാരണയായി ഓപ്പൺ പാസ്‌വേഡ് മാത്രമേ ഉപയോഗിക്കൂ. തുറന്നുകഴിഞ്ഞാൽ സാധാരണയായി നിങ്ങൾക്ക് സ്വതന്ത്രമായി പ്രിന്റ് ചെയ്യാനും കോപ്പി ചെയ്യാനും കഴിയും. Preview അല്ലെങ്കിൽ Acrobat-ൽ നിങ്ങൾ തന്നെ PDF ഉണ്ടാക്കി രണ്ട് പാസ്‌വേഡും സെറ്റ് ചെയ്തിട്ടുണ്ടെങ്കിൽ, പെർമിഷനുകൾ മാറ്റാനോ നിയന്ത്രണമില്ലാത്ത കോപ്പി എക്സ്പോർട്ട് ചെയ്യാനോ ഓണർ പാസ്‌വേഡ് ഉപയോഗിക്കുക.

മാസംതോറുമുള്ള സ്റ്റേറ്റ്മെന്റുകൾ പോലുള്ള സ്വന്തം ഫയലുകളിൽ നിന്ന് ഓപ്പൺ പാസ്‌വേഡ് നീക്കാൻ Mac-ലെ Preview അല്ലെങ്കിൽ iPhone, iPad, Mac എന്നിവയിലെ UnKey ഉപയോഗിക്കാം. UnKey ഓഫ്‌ലൈനായി പ്രവർത്തിക്കുന്നു, നിങ്ങൾക്ക് ഇതിനകം അറിയാവുന്ന പാസ്‌വേഡുകൾക്കേ അത് പ്രവർത്തിക്കൂ.

ഓണർ പാസ്‌വേഡ് ഇല്ലാത്തപ്പോൾ

  • നിയന്ത്രണമില്ലാത്ത കോപ്പിക്കായി, അല്ലെങ്കിൽ പ്രിന്റ് ചെയ്യാനോ കോപ്പി ചെയ്യാനോ ഉള്ള അനുമതിക്കായി, എഴുതിയവരോടോ അയച്ചവരോടോ ചോദിക്കുക.
  • പൂരിപ്പിക്കേണ്ട ഫോമാണെങ്കിൽ, പൂരിപ്പിക്കൽ ഇതിനകം അനുവദിച്ചിട്ടുണ്ടോ എന്ന് നോക്കുക. നിയന്ത്രിത PDF-കൾ പലതും ഫോം പൂരിപ്പിക്കൽ അനുവദിക്കും.
  • ജോലി സംബന്ധമായതോ നിയമപരമോ ആയ ഡോക്യുമെന്റാണെങ്കിൽ, നിയന്ത്രണം മനഃപൂർവമാണെന്ന് കരുതുക.

ചോദ്യങ്ങൾ

PDF ഓണർ പാസ്‌വേഡ് എന്നാൽ എന്താണ്?

പ്രിന്റിങ്, കോപ്പി, എഡിറ്റിങ് പോലുള്ള പെർമിഷനുകൾ നിയന്ത്രിക്കുന്ന പാസ്‌വേഡ് ആണ്. അത് ഇല്ലാതെ ഫയൽ തുറക്കാം, പക്ഷേ ക്രമീകരണങ്ങൾ മാനിക്കുന്ന റീഡറുകളിൽ നിയന്ത്രിത പ്രവൃത്തികൾ തടയപ്പെടും.

PDF തുറക്കാൻ പറ്റുന്നു, പക്ഷേ പ്രിന്റ് ചെയ്യാൻ പറ്റുന്നില്ല, എന്തുകൊണ്ട്?

ഫയലിന് പ്രിന്റിങ് അനുവദിക്കാത്ത ഓണർ (പെർമിഷൻ) പാസ്‌വേഡ് ഉണ്ട്. Preview-ൽ File > Edit Permissions-ൽ ഓണർ പാസ്‌വേഡ് നൽകുക, അല്ലെങ്കിൽ അയച്ചവരോട് നിയന്ത്രണമില്ലാത്ത കോപ്പി ചോദിക്കുക.

ബാങ്ക് സ്റ്റേറ്റ്മെന്റുകൾക്ക് പ്രിന്റിങ് നിയന്ത്രണങ്ങൾ ഉണ്ടോ?

സാധാരണയായി ഇല്ല. അവ ഓപ്പൺ പാസ്‌വേഡ് മാത്രമേ ഉപയോഗിക്കൂ, അതിനാൽ ഫയൽ തുറന്നാൽ പ്രിന്റ് ചെയ്യാം.

PDF കോപ്പി നിയന്ത്രണങ്ങൾ നീക്കം ചെയ്യുന്നത് നിയമപരമാണോ?

സ്വന്തം ഫയലിന്റെ പെർമിഷനുകൾ സ്വന്തം ഓണർ പാസ്‌വേഡ് ഉപയോഗിച്ച് മാറ്റുന്നതിൽ കുഴപ്പമില്ല. മറ്റൊരാളുടെ ഡോക്യുമെന്റിലെ നിയന്ത്രണങ്ങൾ മറികടക്കുന്നത് പകർപ്പവകാശമോ കരാർ വ്യവസ്ഥകളോ ലംഘിച്ചേക്കാം, അതിനാൽ ഉടമയോട് ചോദിക്കുക.

ഫോർമാറ്റുകൾ മാറിയേക്കാം. പാസ്‌വേഡ് പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ പരിശോധിക്കുക അല്ലെങ്കിൽ ഇഷ്യൂ ചെയ്ത സ്ഥാപനത്തെ ബന്ധപ്പെടുക. ഇവിടെ പേര് പറഞ്ഞിട്ടുള്ള ഒരു ബാങ്കുമായോ തൊഴിലുടമയുമായോ അധികാരസ്ഥാപനവുമായോ UnKeyക്ക് ബന്ധമില്ല.
