Chrome-ൽ PDF പാസ്‌വേഡ് നീക്കം ചെയ്യാം (2026)

2026 ഒക്ടോബറിൽ അപ്‌ഡേറ്റ് ചെയ്തത്

ഈ ഭാഷയിൽ വായിക്കുക: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

പാസ്‌വേഡ് നൽകി Chrome-ൽ PDF തുറക്കുക, Ctrl+P അല്ലെങ്കിൽ Cmd+P അമർത്തുക, Destination Save as PDF ആക്കി, പാസ്‌വേഡ് ഇല്ലാത്ത പുതിയ കോപ്പി സേവ് ചെയ്യുക.

Windows, Mac, Linux എന്നിവയിൽ Google Chrome-ന് പാസ്‌വേഡ് ഉള്ള PDF-ന്റെ പാസ്‌വേഡ് ഇല്ലാത്ത കോപ്പി സൗജന്യമായി സേവ് ചെയ്യാം. Chrome-ൽ PDF തുറന്ന് പാസ്‌വേഡ് ടൈപ്പ് ചെയ്ത്, Ctrl + P (Mac-ൽ Cmd + P) അമർത്തി, Destination Save as PDF ആക്കി സേവ് ചെയ്യുക. പാസ്‌വേഡ് നിങ്ങൾക്ക് മുൻകൂട്ടി അറിയണം. അത് ഇല്ലാതെ Chrome ഫയൽ തുറക്കില്ല.

ഘട്ടം ഘട്ടമായി (കമ്പ്യൂട്ടർ)

  1. PDF ഒരു Chrome വിൻഡോയിലേക്ക് വലിച്ചിടുക, അല്ലെങ്കിൽ ഫയലിൽ റൈറ്റ് ക്ലിക്ക് ചെയ്ത് Open with > Google Chrome തിരഞ്ഞെടുക്കുക.
  2. Chrome പാസ്‌വേഡ് ചോദിക്കും. ടൈപ്പ് ചെയ്ത് Enter അമർത്തുക.
  3. Windows അല്ലെങ്കിൽ Linux-ൽ Ctrl + P, Mac-ൽ Cmd + P അമർത്തുക. മെനു വഴിയും ചെയ്യാം: File > Print.
  4. പ്രിന്റ് വിൻഡോയിൽ Destination Save as PDF ആയി സെറ്റ് ചെയ്യുക.
  5. Save ക്ലിക്ക് ചെയ്യുക. പുതിയ ഫയലിന് Statement-Sep-2026-unlocked.pdf പോലെ വ്യക്തമായ പേര് നൽകുക.
  6. അത് അടച്ച് പുതിയ ഫയൽ വീണ്ടും തുറക്കുക. പാസ്‌വേഡ് ചോദിക്കാതെ ഉടൻ തുറക്കണം.

കീബോർഡ് ഷോർട്ട്കട്ടുകൾ, പ്രിന്റ് വിൻഡോയിൽ Destination തിരഞ്ഞെടുക്കൽ, Save as PDF ഓപ്ഷൻ എന്നിവ Google-ന്റെ സഹായ പേജ് വിവരിക്കുന്നു (Google: Print from Chrome).

Android ഫോണിൽ

Android-ലെ Chrome-ലും ഇതേ ഓപ്ഷൻ ഉണ്ട്. Google പറയുന്ന ഘട്ടങ്ങൾ: More > Share ടാപ്പ് ചെയ്യുക, Print ടാപ്പ് ചെയ്യുക, പിന്നെ Save as PDF ടാപ്പ് ചെയ്ത് ഫയൽ എവിടെ സേവ് ചെയ്യണമെന്ന് തിരഞ്ഞെടുക്കുക (Google: Print from Chrome on Android). ഫോണിൽ സൂക്ഷിച്ചിരിക്കുന്ന PDF Chrome തുറക്കുമോ എന്നത് Chrome പതിപ്പിനെ ആശ്രയിച്ചിരിക്കും. തുറക്കുന്നില്ലെങ്കിൽ ഞങ്ങളുടെ Android-ൽ പാസ്‌വേഡ് ഉള്ള PDF തുറക്കാം എന്ന ഗൈഡ് കാണുക.

ഈ രീതിയിൽ നഷ്ടപ്പെടുന്നത്

പ്രിന്റ് വിൻഡോ വഴി സേവ് ചെയ്യുന്നത് സ്ക്രീനിലുള്ളതിൽ നിന്ന് തികച്ചും പുതിയ PDF ഉണ്ടാക്കുന്നു. സ്റ്റേറ്റ്മെന്റ് വായിക്കാനും ആർക്കൈവ് ചെയ്യാനും അപ്‌ലോഡ് ചെയ്യാനും ഇത് മതി. പക്ഷേ ഒറിജിനൽ ഡിലീറ്റ് ചെയ്യുംമുമ്പ് കോപ്പി പരിശോധിക്കുക:

  • ലിങ്കുകളും ബുക്ക്മാർക്കുകളും പ്രവർത്തിക്കാതായേക്കാം.
  • ഫോം ഫീൽഡുകൾ പരത്തപ്പെട്ടേക്കാം, അതിൽ പിന്നെ ടൈപ്പ് ചെയ്യാനാവില്ല.
  • ഡിജിറ്റൽ ഒപ്പുകൾ കൈമാറ്റം ചെയ്യപ്പെടില്ല. പോർട്ടലിന് ഒപ്പിട്ട ഒറിജിനൽ വേണമെങ്കിൽ ഒറിജിനൽ അപ്‌ലോഡ് ചെയ്യുക.
  • പേജ് വലുപ്പം പ്രിന്റ് സെറ്റിങ്ങുകളെ പിന്തുടരും. More settings-ൽ പേപ്പർ വലുപ്പവും സ്കെയിലും പേജുകൾ ചെറുതാക്കുകയോ ക്രോപ്പ് ചെയ്യുകയോ ചെയ്തിട്ടില്ലെന്ന് പരിശോധിക്കുക.

Save as PDF പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ

  • പ്രിന്റിങ് തടഞ്ഞിരിക്കുന്നു. ചില PDF-കളിൽ പ്രിന്റിങ് തടയുന്ന പെർമിഷൻ പാസ്‌വേഡ് ഉണ്ട്. പെർമിഷൻ പാസ്‌വേഡ് ഓപ്പൺ പാസ്‌വേഡിൽ നിന്ന് വേറെയാണ്. PDF പ്രിന്റിങ്, കോപ്പി നിയന്ത്രണങ്ങൾ വിശദീകരണം കാണുക.
  • Chrome പാസ്‌വേഡ് നിരസിക്കുന്നു. വലിയ അക്ഷരങ്ങൾ, തീയതി ഫോർമാറ്റ്, ബാങ്കിന്റെ രേഖയിലുള്ള വിവരങ്ങൾ എന്നിവ പരിശോധിക്കുക. PDF പാസ്‌വേഡ് പ്രവർത്തിക്കാത്തത് എന്തുകൊണ്ട് കാണുക.
  • ഫയൽ മറ്റൊരു ആപ്പിൽ തുറന്നു. ചില കമ്പ്യൂട്ടറുകൾ PDF-കൾ ഡിഫോൾട്ടായി വേറൊരു റീഡറിൽ തുറക്കും. പകരം ഫയൽ ഒരു Chrome ടാബിലേക്ക് വലിച്ചിടുക.

പാസ്‌വേഡ് നീക്കാനുള്ള മറ്റ് വഴികൾ

Windows-ൽ Microsoft Edge ഇതേപോലെ പ്രവർത്തിക്കും (Windows-ൽ PDF പാസ്‌വേഡ് നീക്കം ചെയ്യൽ കാണുക). Mac-ൽ Preview-ന് പാസ്‌വേഡ് ഇല്ലാത്ത കോപ്പി എക്സ്പോർട്ട് ചെയ്യാം (Mac ഗൈഡ്). iPhone, iPad, Mac എന്നിവയിൽ UnKey ഓഫ്‌ലൈനായി അൺലോക്ക് ചെയ്ത കോപ്പി സേവ് ചെയ്യുകയും ടെക്സ്റ്റ്, ലിങ്കുകൾ, പേജുകൾ എന്നിവ അതേപടി നിലനിർത്തുകയും ചെയ്യും, കാരണം ഇത് ഫയൽ വീണ്ടും പ്രിന്റ് ചെയ്യുന്നതിന് പകരം എൻക്രിപ്ഷൻ നീക്കം ചെയ്യുകയാണ്. Chrome പോലെ, ഇതും നിങ്ങൾക്ക് ഇതിനകം അറിയാവുന്ന പാസ്‌വേഡിനേ പ്രവർത്തിക്കൂ.

ചോദ്യങ്ങൾ

ഇത് ചെയ്യുമ്പോൾ Chrome എന്റെ PDF അപ്‌ലോഡ് ചെയ്യുമോ?

ഇല്ല. കമ്പ്യൂട്ടറിൽ നിന്ന് PDF ഫയൽ തുറന്ന് Save as PDF ഉപയോഗിച്ച് സേവ് ചെയ്യുന്നത് നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ ബ്രൗസറിൽ തന്നെയാണ് നടക്കുന്നത്. Drive-ൽ കോപ്പി വേണമെങ്കിൽ മാത്രം വേറെയുള്ള "Save to Google Drive" ഡെസ്റ്റിനേഷൻ ഉപയോഗിക്കുക.

എനിക്കറിയാത്ത പാസ്‌വേഡ് Chrome-ന് നീക്കം ചെയ്യാനാകുമോ?

ഇല്ല. എന്തെങ്കിലും കാണിക്കുംമുമ്പ് Chrome പാസ്‌വേഡ് ചോദിക്കും. നഷ്ടപ്പെട്ടെങ്കിൽ PDF പാസ്‌വേഡ് മറന്നാൽ എന്തുചെയ്യണം എന്ന് കാണുക.

സേവ് ചെയ്ത കോപ്പി ഒറിജിനലിൽ നിന്ന് വ്യത്യസ്തമാകുന്നത് എന്തുകൊണ്ട്?

Save as PDF പേജുകൾ പ്രിന്റ് ചെയ്ത് പുതിയ ഫയൽ ഉണ്ടാക്കുന്നു, അതിനാൽ ലിങ്കുകൾ, ഫോം ഫീൽഡുകൾ, ഒപ്പുകൾ എന്നിവ നിലനിന്നേക്കില്ല. ടെക്സ്റ്റും ലേഔട്ടും സാധാരണയായി ഒരുപോലെ കാണും.

ഇത് അനുവദനീയമാണോ?

നിങ്ങളുടെ ബാങ്ക് സ്റ്റേറ്റ്മെന്റ് പോലെ സ്വന്തം ഡോക്യുമെന്റുകൾക്ക് അതെ. സ്വതന്ത്രമായി തുറക്കാൻ അവകാശമില്ലാത്ത ഫയലുകളുടെ സംരക്ഷണം നീക്കരുത്.

സ്രോതസ്സുകൾ

  • Google Chrome Help – Print from Chrome (computer)
  • Google Chrome Help – Print from Chrome (Android)

ഫോർമാറ്റുകൾ മാറിയേക്കാം. പാസ്‌വേഡ് പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ പരിശോധിക്കുക അല്ലെങ്കിൽ ഇഷ്യൂ ചെയ്ത സ്ഥാപനത്തെ ബന്ധപ്പെടുക. ഇവിടെ പേര് പറഞ്ഞിട്ടുള്ള ഒരു ബാങ്കുമായോ തൊഴിലുടമയുമായോ അധികാരസ്ഥാപനവുമായോ UnKeyക്ക് ബന്ധമില്ല.

ഇംഗ്ലീഷിൽ നിന്ന് വിവർത്തനം ചെയ്തത്. എന്തെങ്കിലും വ്യത്യാസമുണ്ടെങ്കിൽ ഇംഗ്ലീഷ് പേജാണ് അടിസ്ഥാനം.

ഒരിക്കൽ അൺലോക്ക് ചെയ്യൂ.

നിങ്ങൾക്ക് ഇതിനകം തുറക്കാൻ കഴിയുന്ന PDFകളിൽ നിന്ന് UnKey പാസ്‌വേഡ് നീക്കം ചെയ്യുന്നു, iPhone, iPad, Mac എന്നിവയിൽ. ഓഫ്‌ലൈനായി പ്രവർത്തിക്കും, ഒന്നും അപ്‌ലോഡ് ചെയ്യില്ല. പാസ്‌വേഡ് ഒരിക്കൽ സേവ് ചെയ്താൽ, അടുത്ത മാസത്തെ സ്റ്റേറ്റ്‌മെന്റ് Face ID തുറക്കും.
