iPhone-ൽ PDF പാസ്‌വേഡുകൾ സുരക്ഷിതമായി സൂക്ഷിക്കാം

PDF പാസ്‌വേഡുകൾ സാധാരണ നോട്ടിൽ ഒരിക്കലും വേണ്ട; Apple-ന്റെ Passwords ആപ്പിലോ ലോക്ക് ചെയ്ത നോട്ടിലോ Face ID സംരക്ഷണത്തിൽ Keychain-ൽ സൂക്ഷിക്കുന്ന ആപ്പിലോ സൂക്ഷിക്കുക.

iPhone-ൽ PDF പാസ്‌വേഡുകൾ സൂക്ഷിക്കാൻ ഏറ്റവും സുരക്ഷിതമായ സ്ഥലങ്ങൾ Apple-ന്റെ Passwords ആപ്പ്, ലോക്ക് ചെയ്ത നോട്ട്, അല്ലെങ്കിൽ Face ID അല്ലെങ്കിൽ Touch ID സംരക്ഷണത്തിൽ iPhone Keychain-ൽ സൂക്ഷിക്കുന്ന ആപ്പ് എന്നിവയാണ്. സാധാരണ നോട്ടോ WhatsApp-ലെ "note to self" ചാറ്റോ നല്ല സ്ഥലമല്ല, കാരണം അൺലോക്ക് ചെയ്ത നിങ്ങളുടെ ഫോൺ എടുക്കുന്ന ആർക്കും അത് വായിക്കാം.

സാധാരണ നോട്ടോ ചാറ്റോ വേണ്ടാത്തത് എന്തുകൊണ്ട്?

  • അധിക ലോക്ക് ഇല്ല. ഫോൺ അൺലോക്ക് ചെയ്താൽ സാധാരണ നോട്ട് ഉടൻ തുറക്കും.
  • സെർച്ചിൽ വരും. iPhone സെർച്ചിൽ "password" എന്ന് ടൈപ്പ് ചെയ്താൽ അത് പൊങ്ങിവരാം.
  • പലയിടത്തേക്കും പടരും. Gmail പോലുള്ള സിങ്ക് ചെയ്ത അക്കൗണ്ടുകളിലെ നോട്ടുകൾ, ചാറ്റ് ബാക്കപ്പുകൾ, സ്ക്രീൻഷോട്ടുകൾ എന്നിവ നിങ്ങൾ കരുതുന്നതിലും കൂടുതൽ സ്ഥലങ്ങളിൽ എത്തും.
  • പാസ്‌വേഡുകൾ ഫയലുകൾക്കടുത്ത്. സ്റ്റേറ്റ്മെന്റുകളും അവയുടെ പാസ്‌വേഡുകളും ഒരേ ചാറ്റിലാണെങ്കിൽ PDF പാസ്‌വേഡ് ഒന്നിനെയും സംരക്ഷിക്കുന്നില്ല.

ഓപ്ഷൻ 1: Apple-ന്റെ Passwords ആപ്പ്

Passwords ആപ്പ് എൻട്രികൾ എൻക്രിപ്റ്റ് ചെയ്ത രൂപത്തിൽ സൂക്ഷിക്കുന്നു, iCloud Keychain നിങ്ങൾ അംഗീകരിച്ച ഉപകരണങ്ങളിലെല്ലാം അവ ഏറ്റവും പുതിയതായി നിലനിർത്തുന്നു (Apple: View your passwords). ഇത് വെബ്സൈറ്റ് ലോഗിനുകൾക്കായി ഉണ്ടാക്കിയതാണെങ്കിലും ഒരു ഡോക്യുമെന്റിനായും എൻട്രി ചേർക്കാം:

  1. Passwords തുറന്ന്, All ടാപ്പ് ചെയ്യുക, പിന്നെ ആഡ് ബട്ടൺ ടാപ്പ് ചെയ്യുക (Apple: Create a password).
  2. വെബ്സൈറ്റ് അല്ലെങ്കിൽ ആപ്പ് ഫീൽഡിൽ "Bank statement PDF" പോലൊരു പേര് നൽകുക, യൂസർ നെയിമായി ഒരു ലേബൽ ചേർക്കുക, PDF പാസ്‌വേഡ് ടൈപ്പ് ചെയ്യുക.
  3. സേവ് ചെയ്യുക. പിന്നീട് Edit > Notes ടാപ്പ് ചെയ്ത് "format: first 4 letters of name + DDMM" പോലുള്ള വിവരങ്ങൾ ചേർക്കാം. PIN നമ്പറുകളും സെക്യൂരിറ്റി ചോദ്യങ്ങളും പോലുള്ള കുറിപ്പുകൾ ഇവിടെ സുരക്ഷിതമായി സൂക്ഷിക്കാമെന്ന് Apple പറയുന്നു.

നിങ്ങളുടെ വിവരങ്ങൾ ഉപയോഗിക്കുന്ന സ്റ്റേറ്റ്മെന്റുകൾക്ക് പാസ്‌വേഡിന് പകരം ഫോർമാറ്റ് സൂക്ഷിക്കുന്നത് നല്ലൊരു വിദ്യയാണ്. അടുത്ത വർഷത്തെ സ്റ്റേറ്റ്മെന്റും ഇതേ നിയമം തന്നെ ഉപയോഗിക്കും.

ഓപ്ഷൻ 2: ലോക്ക് ചെയ്ത നോട്ട്

Notes-ൽ ഒരു നോട്ട് ഉപകരണത്തിന്റെ പാസ്‌കോഡ് ഉപയോഗിച്ചോ വേറെ പാസ്‌വേഡ് ഉപയോഗിച്ചോ ലോക്ക് ചെയ്ത് Face ID അല്ലെങ്കിൽ Touch ID കൊണ്ട് തുറക്കാം (Apple: Lock your notes on iPhone). അറിയേണ്ട കാര്യങ്ങൾ:

  • ഉപകരണത്തിലോ iCloud-ലോ സൂക്ഷിച്ച നോട്ടുകൾ മാത്രമേ ലോക്ക് ചെയ്യാനാകൂ, Gmail പോലുള്ള അക്കൗണ്ടുകളുമായി സിങ്ക് ചെയ്തവ പറ്റില്ല.
  • PDF അറ്റാച്ച് ചെയ്ത നോട്ട് ലോക്ക് ചെയ്യാനാവില്ല, അതിനാൽ പാസ്‌വേഡ് നോട്ട് ഫയലിൽ നിന്ന് വേറെ വെക്കുക.
  • നോട്ടിന്റെ തലക്കെട്ട് ലിസ്റ്റിൽ കാണും, അതിനാൽ ലളിതമായ തലക്കെട്ട് നൽകുക.
  • Notes-ന് സ്വന്തം പാസ്‌വേഡ് സെറ്റ് ചെയ്ത് മറന്നുപോയാൽ, ആ നോട്ടുകളിൽ തിരികെ കയറാൻ Apple-ന് സഹായിക്കാനാവില്ല.

ഓപ്ഷൻ 3: PDF തുറക്കുന്ന ആപ്പിൽ തന്നെ സേവ് ചെയ്യുക

സ്റ്റേറ്റ്മെന്റ് അൺലോക്ക് ചെയ്യുമ്പോൾ UnKey പാസ്‌വേഡ് സേവ് ചെയ്യും, അതിനാൽ അതേ ഫോർമാറ്റിലുള്ള അടുത്ത മാസത്തെ PDF Face ID അല്ലെങ്കിൽ Touch ID ഉപയോഗിച്ച് തുറക്കും. സേവ് ചെയ്ത പാസ്‌വേഡുകൾ ആ ഉപകരണത്തിലെ iPhone Keychain-ൽ തന്നെ ഇരിക്കും, ഒരിടത്തേക്കും അപ്‌ലോഡ് ചെയ്യപ്പെടില്ല. അവ ഉപകരണത്തിൽ മാത്രമായതിനാൽ പുതിയ ഫോണിലേക്ക് വരില്ല; അതിനാൽ പ്രധാനപ്പെട്ടവയുടെ ബാക്കപ്പ് Passwords ആപ്പിൽ സൂക്ഷിക്കുക.

നല്ല ശീലങ്ങൾ

  • ശക്തമായ ഉപകരണ പാസ്‌കോഡ് ഉപയോഗിക്കുക. Face ID-ക്ക് പിന്നിലുള്ള പാസ്‌കോഡിന്റെ അത്രയേ അത് സുരക്ഷിതമാകൂ.
  • പാസ്‌വേഡുകളുടെ സ്ക്രീൻഷോട്ട് എടുക്കരുത്. സ്ക്രീൻഷോട്ടുകൾ Photos-ലേക്ക് സിങ്ക് ആകുകയും അബദ്ധത്തിൽ ഷെയർ ചെയ്യപ്പെടുകയും ചെയ്യും.
  • സംരക്ഷിത PDF പങ്കിടുമ്പോൾ പാസ്‌വേഡ് ഫോൺ വിളി പോലുള്ള മറ്റൊരു വഴിയിലൂടെ അയയ്ക്കുക.
  • ഇനി വേണ്ടാത്ത എൻട്രികൾ നീക്കം ചെയ്യുക. Passwords-ൽ എൻട്രി തുറന്ന് Edit ടാപ്പ് ചെയ്ത് Delete തിരഞ്ഞെടുക്കുക.

ചോദ്യങ്ങൾ

iPhone-ലെ Passwords ആപ്പിൽ PDF പാസ്‌വേഡ് സൂക്ഷിക്കാമോ?

സൂക്ഷിക്കാം. വിവരണാത്മക ലേബലും പാസ്‌വേഡും ഉള്ള പുതിയ എൻട്രി ചേർക്കുക, ഫോർമാറ്റിന് Notes ഫീൽഡ് ഉപയോഗിക്കുക. Apple ഈ എൻട്രികൾ എൻക്രിപ്റ്റ് ചെയ്യുകയും, iCloud Keychain ഓണാക്കിയിട്ടുണ്ടെങ്കിൽ അതുമായി സിങ്ക് ചെയ്യുകയും ചെയ്യും.

PDF പാസ്‌വേഡുകൾക്ക് ലോക്ക് ചെയ്ത നോട്ട് സുരക്ഷിതമാണോ?

സുരക്ഷിതമാണ്, നോട്ട് iCloud-ലോ ഉപകരണത്തിലോ സൂക്ഷിക്കുകയും ലോക്ക് ചെയ്യുകയും ചെയ്താൽ. PDF അറ്റാച്ച് ചെയ്ത നോട്ട് ലോക്ക് ചെയ്യാനാവില്ല, അതിനാൽ അവ വേറിട്ട് സൂക്ഷിക്കുക.

UnKey എന്റെ സേവ് ചെയ്ത പാസ്‌വേഡുകൾ അപ്‌ലോഡ് ചെയ്യുമോ?

ഇല്ല. UnKey സേവ് ചെയ്ത പാസ്‌വേഡുകൾ Face ID അല്ലെങ്കിൽ Touch ID സംരക്ഷണത്തിൽ ഉപകരണത്തിന്റെ Keychain-ൽ സൂക്ഷിക്കുന്നു, അവ ആ ഉപകരണത്തിൽ തന്നെ നിൽക്കും.

ഫോൺ മാറ്റിയാൽ UnKey-യിൽ സേവ് ചെയ്ത പാസ്‌വേഡുകൾക്ക് എന്ത് സംഭവിക്കും?

അവ ഉപകരണത്തിൽ മാത്രം സൂക്ഷിച്ചതാണ്, അതിനാൽ പുതിയ ഫോണിൽ വീണ്ടും നൽകേണ്ടി വരും. പ്രധാനപ്പെട്ടവയുടെ കോപ്പി Passwords ആപ്പിൽ സൂക്ഷിക്കുന്നത് സഹായിക്കും.

ഫോർമാറ്റുകൾ മാറിയേക്കാം. പാസ്‌വേഡ് പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ഡോക്യുമെന്റിനൊപ്പം വന്ന ഇമെയിൽ പരിശോധിക്കുക അല്ലെങ്കിൽ ഇഷ്യൂ ചെയ്ത സ്ഥാപനത്തെ ബന്ധപ്പെടുക. ഇവിടെ പേര് പറഞ്ഞിട്ടുള്ള ഒരു ബാങ്കുമായോ തൊഴിലുടമയുമായോ അധികാരസ്ഥാപനവുമായോ UnKeyക്ക് ബന്ധമില്ല.

ഇംഗ്ലീഷിൽ നിന്ന് വിവർത്തനം ചെയ്തത്. എന്തെങ്കിലും വ്യത്യാസമുണ്ടെങ്കിൽ ഇംഗ്ലീഷ് പേജാണ് അടിസ്ഥാനം.

ഒരിക്കൽ അൺലോക്ക് ചെയ്യൂ.

നിങ്ങൾക്ക് ഇതിനകം തുറക്കാൻ കഴിയുന്ന PDFകളിൽ നിന്ന് UnKey പാസ്‌വേഡ് നീക്കം ചെയ്യുന്നു, iPhone, iPad, Mac എന്നിവയിൽ. ഓഫ്‌ലൈനായി പ്രവർത്തിക്കും, ഒന്നും അപ്‌ലോഡ് ചെയ്യില്ല. പാസ്‌വേഡ് ഒരിക്കൽ സേവ് ചെയ്താൽ, അടുത്ത മാസത്തെ സ്റ്റേറ്റ്‌മെന്റ് Face ID തുറക്കും.
