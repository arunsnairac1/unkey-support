Windows-এ PDF পাসওয়ার্ড সরানোর উপায় (2026)

অক্টোবর ২০২৬-এ আপডেট করা হয়েছে

এই ভাষায় পড়ুন: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

পাসওয়ার্ড দিয়ে Microsoft Edge বা Chrome-এ PDF খুলুন, Ctrl+P চেপে Save as PDF (বা Microsoft Print to PDF) বেছে নতুন কপি সেভ করুন; পেইড Acrobat সরাসরি সিকিউরিটি সরাতে পারে।

Windows 10 ও 11-এ আপনার আগে থেকে থাকা ব্রাউজার দিয়েই বিনামূল্যে PDF পাসওয়ার্ড সরানো যায়। Microsoft Edge বা Google Chrome-এ PDF খুলুন, পাসওয়ার্ড টাইপ করুন, Ctrl + P চাপুন, প্রিন্টার হিসেবে Save as PDF (বা Microsoft Print to PDF) বাছুন, আর সেভ করুন। নতুন ফাইল পাসওয়ার্ড ছাড়াই খোলে। আগে পাসওয়ার্ডটি আপনার জানা থাকতে হবে।

পদ্ধতি 1: Microsoft Edge (বিল্ট-ইন)

  1. File Explorer-এ PDF-এ রাইট-ক্লিক করে Open with > Microsoft Edge বাছুন।
  2. Edge পাসওয়ার্ড চাইলে টাইপ করুন।
  3. Ctrl + P চাপুন, অথবা More মেনু (তিন-ডট) খুলে Print বাছুন।
  4. Printer-এর নিচে Save as PDF বা Microsoft Print to PDF বাছুন।
  5. Save (বা Print) ক্লিক করুন, ফোল্ডার বাছুন, এবং কপির নতুন নাম দিন।
  6. নতুন ফাইল খুলে দেখুন সেটি আর পাসওয়ার্ড চায় না।

Microsoft-এর বিল্ট-ইন PDF রিডারের গাইড Edge-এর পথ দেখায়: More মেনুর নিচে Print খুঁজুন, অপশন বাছুন, তারপর প্রিন্ট করুন (Microsoft: View, print, and edit PDFs in a PDF reader)। Microsoft Print to PDF Windows-এর সঙ্গে আসা একটি প্রিন্টার। তালিকায় না থাকলে Microsoft বলছে Windows Optional Features থেকে আবার চালু করা যায় (Microsoft: KB5058499 known issue)।

পদ্ধতি 2: Google Chrome

Chrome ব্যবহার করলে ধাপ প্রায় একই: Chrome-এ PDF খুলুন, পাসওয়ার্ড দিন, Ctrl + P চাপুন, Destination Save as PDF করুন, আর Save ক্লিক করুন (Google: Print from Chrome)। আরও বিস্তারিত আমাদের Chrome গাইডে আছে।

পদ্ধতি 3: Adobe Acrobat Pro বা Standard (পেইড)

পেইড Acrobat ফাইল আবার প্রিন্ট না করে এনক্রিপশনটাই সরায়, তাই লিংক ও ফর্মের ঘর অক্ষত থাকে। Adobe দুটি পথ নথিবদ্ধ করেছে (Adobe: Remove passwords from PDFs):

  • Protect টুল: PDF খুলে Protect টুলে গিয়ে Remove Security বাছুন। ফাইলে শুধু খোলার পাসওয়ার্ড থাকলে OK দিয়ে নিশ্চিত করুন। permissions পাসওয়ার্ডও থাকলে Acrobat আগে সেটি চাইবে।
  • Security সেটিংস: ডকুমেন্টের সিকিউরিটি প্রপার্টি খুলে Security ট্যাবে গিয়ে Change Settings বাছুন, পাসওয়ার্ড অপশনগুলো মুছে সেভ করুন।

Adobe-র মেনু সংস্করণভেদে সরে যায়, তাই ঠিক এই নামগুলো না দেখলে Acrobat-এর টুল সার্চে “Remove Security” খুঁজুন। বিনামূল্যের Acrobat Reader সুরক্ষিত PDF খুলতে পারে, কিন্তু সিকিউরিটি সরানোর টুল নয়। তার বদলে পদ্ধতি 1 বা 2 নিন।

পদ্ধতি 4: qpdf (প্রযুক্তিগত ব্যবহারকারীদের জন্য)

বিনামূল্যের ওপেন-সোর্স টুল qpdf Windows-এ চলে। qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf এনক্রিপশনহীন একটি কপি লেখে (qpdf documentation)। পাসওয়ার্ড আপনার কমান্ড হিস্ট্রিতে সেভ হয়ে যেতে পারে, তাই শেয়ার করা পিসিতে পরে তা মুছে দিন।

যা যাচাই করবেন

  • Print ধূসর? PDF-এ প্রিন্ট আটকানো permissions পাসওয়ার্ড থাকতে পারে। দেখুন প্রিন্ট ও কপির নিষেধাজ্ঞা।
  • পাসওয়ার্ড নিচ্ছে না? Caps Lock, তারিখের ফরম্যাট এবং ব্যাংকের কাছে থাকা তথ্য দেখুন। দেখুন PDF পাসওয়ার্ড কেন কাজ করছে না।
  • শেয়ার করা বা অফিসের পিসি? আনলক করা কপি যার চোখে পড়বে সে-ই খুলতে পারবে। ব্যক্তিগত ফোল্ডারে সেভ করুন এবং Downloads থেকে মুছে দিন।

আপনার iPhone, iPad বা Mac থাকলে UnKey সেসব ডিভাইসে অফলাইনে পাসওয়ার্ড সরায় এবং পরের মাসের স্টেটমেন্টের জন্য পাসওয়ার্ড সেভ করে রাখতে পারে। Windows-এর জন্য UnKey অ্যাপ নেই।

প্রশ্ন

Windows-এ কি কিছু ইনস্টল করতে হবে?

না। Microsoft Edge ও Microsoft Print to PDF প্রিন্টার Windows 10 ও 11-এর সঙ্গেই আসে।

অনলাইন “unlock PDF” সাইট কি ভালো কাজ করবে?

একই কাজ করে, তবে আপনার ডকুমেন্ট অন্যের সার্ভারে আপলোড করে। ব্যাংক স্টেটমেন্ট ও ট্যাক্সের কাগজের জন্য এখানকার অফলাইন পদ্ধতি নিরাপদ।

এগুলোর কোনোটি কি ভুলে যাওয়া পাসওয়ার্ড সরাতে পারে?

না। Edge, Chrome, Acrobat ও qpdf সবকটিতেই সঠিক পাসওয়ার্ড লাগে। ফরম্যাটের জন্য PDF-এর সঙ্গে আসা ইমেইল দেখুন।

কপিতে লিংক কাজ করে না কেন?

PDF-এ প্রিন্ট করলে পাতাগুলো নতুন করে তৈরি হয়, ফলে লিংক ও ফর্মের ঘর বাদ যেতে পারে। Acrobat-এর Remove Security বা qpdf সেগুলো রেখে দেয়।

ফরম্যাট বদলাতে পারে। পাসওয়ার্ড কাজ না করলে ডকুমেন্টের সঙ্গে আসা ইমেইল দেখুন অথবা প্রদানকারী প্রতিষ্ঠানের সঙ্গে যোগাযোগ করুন। এখানে উল্লেখ করা কোনো ব্যাংক, নিয়োগকর্তা বা কর্তৃপক্ষের সঙ্গে UnKey-এর কোনো সম্পর্ক নেই।

ইংরেজি থেকে অনূদিত। কোনো পার্থক্য থাকলে ইংরেজি পেজই চূড়ান্ত।

একবারেই আনলক করুন।

আপনি যে PDF আগে থেকেই খুলতে পারেন, UnKey তা থেকে পাসওয়ার্ড সরিয়ে দেয়, iPhone, iPad ও Mac-এ। অফলাইনে কাজ করে, কিছু আপলোড হয় না। পাসওয়ার্ড একবার সেভ করুন, আগামী মাসের স্টেটমেন্ট Face ID-ই খুলে দেবে।
