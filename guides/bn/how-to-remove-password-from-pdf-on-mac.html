Mac-এ PDF থেকে পাসওয়ার্ড সরানোর উপায় (2026)

অক্টোবর ২০২৬-এ আপডেট করা হয়েছে

এই ভাষায় পড়ুন: English · العربية · বাংলা · Deutsch · Español · Filipino · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · Italiano · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · ไทย · اردو · Tiếng Việt

পাসওয়ার্ড দিয়ে Preview-তে PDF খুলুন, File > Export বাছুন, খোলার পাসওয়ার্ড দেওয়া নেই নিশ্চিত করুন, এবং নতুন কপি সেভ করুন।

Mac-এ macOS-এর সঙ্গে আসা Preview অ্যাপ দিয়ে বিনামূল্যে PDF পাসওয়ার্ড সরানো যায়। PDF খুলুন, পাসওয়ার্ড দিন, তারপর File > Export বেছে খোলার পাসওয়ার্ড নেই এমন একটি নতুন কপি সেভ করুন। পাসওয়ার্ড আপনার জানা থাকতে হবে। এটি ছাড়া Preview ফাইল খুলবে না।

পদ্ধতি 1: Preview, File > Export

  1. PDF-এ ডাবল-ক্লিক করে Preview-তে খুলুন এবং পাসওয়ার্ড দিন।
  2. File > Export বেছে কপিটির একটি নতুন নাম দিন, যেমন “Statement-Oct-unlocked”।
  3. Permissions-এ ক্লিক করে নিশ্চিত করুন Require Password To Open Document নির্বাচিত নেই। macOS-এর পুরনো সংস্করণে Export উইন্ডোতে এর বদলে Encrypt চেকবক্স থাকে। সেটি টিক না দিয়ে রাখুন।
  4. Save ক্লিক করুন।
  5. নতুন ফাইলটি বন্ধ করে আবার খুলুন। এটি পাসওয়ার্ড না চেয়েই খোলার কথা।

Apple-এর বর্তমান গাইডে Export উইন্ডো, Permissions বোতাম ও Require Password To Open Document অপশনের বর্ণনা আছে (Apple: Password-protect a PDF in Preview on Mac)। একই পাতার macOS Big Sur সংস্করণে সরাসরি বলা ছিল: “আপনার এনক্রিপ্ট করা PDF থেকে পাসওয়ার্ড সরাতে PDF খুলে আবার এক্সপোর্ট করুন, এবার এনক্রিপশন অপশন বন্ধ রেখে” (Apple, macOS Big Sur guide)।

PDF-এ owner (permissions) পাসওয়ার্ডও থাকলে এবং তা জানা থাকলে File > Edit Permissions দিয়ে খোলার পাসওয়ার্ড এবং কোন সুবিধায় পাসওয়ার্ড লাগবে তা বদলানো যায়।

পদ্ধতি 2: Print > Save as PDF

প্রিন্ট করা যায় এমন যেকোনো Mac অ্যাপ নতুন PDF বানাতে পারে (Apple: Save a document as a PDF on Mac):

  1. পাসওয়ার্ড দিয়ে PDF খুলুন।
  2. File > Print বাছুন।
  3. PDF পপ-আপ মেনুতে ক্লিক করে Save as PDF বাছুন।
  4. Security Options-এ ক্লিক করবেন না, কারণ সেখানেই পাসওয়ার্ড আবার বসানো হয়।

প্রিন্ট করা কপিতে লিংক, ফর্মের ঘর বা বুকমার্ক হারাতে পারে। ডকুমেন্টে প্রিন্ট আটকানো থাকলে এই পদ্ধতি ধূসর থাকতে পারে।

পদ্ধতি 3: Mac-এর UnKey

UnKey Mac-এও বিনামূল্যে। একবারের কেনা UnKey Pro iPhone, iPad ও Mac-এ ব্যাচ আনলক এবং Pro-র অন্য টুল যোগ করে। উইন্ডোতে PDF টেনে আনুন, পাসওয়ার্ড দিন, এটি আনলক করা কপি সেভ করবে। UnKey Pro একসঙ্গে অনেক ফাইলও ব্যাচ আনলক করতে পারে, যা এক পাসওয়ার্ডের এক বছরের মাসিক স্টেটমেন্টে কাজে লাগে। UnKey অফলাইনে চলে, কিছু আপলোড করে না, এবং শুধু আপনার জানা পাসওয়ার্ড সরায়।

পদ্ধতি 4: কমান্ড লাইন (প্রযুক্তিগতদের জন্য)

বিনামূল্যের ওপেন-সোর্স টুল qpdf Terminal-এ এটি করতে পারে: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf। এর ডকুমেন্টেশনে --decrypt-কে বর্ণনা করা হয়েছে “ইনপুট ফাইল এনক্রিপ্ট করা থাকলেও এনক্রিপশনহীন আউটপুট ফাইল তৈরি করে” (qpdf documentation)। এটি নিজে ইনস্টল করতে হয়, যেমন Homebrew দিয়ে। কমান্ড লাইনে পাসওয়ার্ড টাইপ করলে তা শেল হিস্ট্রিতে থেকে যেতে পারে।

তবুও পাসওয়ার্ড চাইলে

  • কপির বদলে আসলটি খুলে থাকতে পারেন। ফাইলের নাম দেখুন।
  • আবার এক্সপোর্ট করুন এবং Permissions-এ Require Password To Open Document বন্ধ আছে কি না দেখুন।
  • তার বদলে Print > Save as PDF চেষ্টা করুন।
  • Preview পাসওয়ার্ড না নিলে বড় হাতের অক্ষর ও তারিখের ফরম্যাট দেখুন, আর ডকুমেন্টের সঙ্গে আসা ইমেইল পড়ুন।

আসল ফাইল মোছার আগে

আনলক করা PDF ফাইলটি যার কাছে আছে সে-ই খুলতে পারে। পরিবারের সঙ্গে শেয়ার করা iCloud Drive ফোল্ডার এবং যে কেউ আপনার Mac ধার নেয়, সবাই এর আওতায়। আনলক করা স্টেটমেন্ট কোনো ব্যক্তিগত জায়গায় রাখুন। আরও জানতে দেখুন PDF পাসওয়ার্ড সরানো কি নিরাপদ।

প্রশ্ন

Preview কি সত্যিই বিনামূল্যে?

হ্যাঁ। Preview প্রতিটি Mac-এর সঙ্গেই আসে এবং পাসওয়ার্ড দেওয়ার পর খোলার পাসওয়ার্ডছাড়া PDF এক্সপোর্ট করতে পারে।

না জানা পাসওয়ার্ড কি Preview সরাতে পারে?

না। ফাইল খোলার আগে Preview পাসওয়ার্ড চায়, এড়ানোর কোনো বৈধ উপায় নেই।

Mac-এ একসঙ্গে অনেক PDF আনলক করব কীভাবে?

Preview একবারে একটি ফাইল সামলায়। একই পাসওয়ার্ডের কয়েকটি PDF একসঙ্গে আনলক করতে পারে UnKey Pro, আর প্রযুক্তিগত ব্যবহারকারীরা qpdf স্ক্রিপ্ট করতে পারেন। দেখুন একসঙ্গে অনেক PDF আনলক করার গাইড।

Print > Save as PDF ধূসর কেন?

PDF-এ প্রিন্ট আটকানো permissions পাসওয়ার্ড থাকতে পারে। owner পাসওয়ার্ড জানা থাকলে File > Edit Permissions-এ দিন। না হলে Export পদ্ধতি নিন।

ফরম্যাট বদলাতে পারে। পাসওয়ার্ড কাজ না করলে ডকুমেন্টের সঙ্গে আসা ইমেইল দেখুন অথবা প্রদানকারী প্রতিষ্ঠানের সঙ্গে যোগাযোগ করুন। এখানে উল্লেখ করা কোনো ব্যাংক, নিয়োগকর্তা বা কর্তৃপক্ষের সঙ্গে UnKey-এর কোনো সম্পর্ক নেই।

ইংরেজি থেকে অনূদিত। কোনো পার্থক্য থাকলে ইংরেজি পেজই চূড়ান্ত।

একবারেই আনলক করুন।

আপনি যে PDF আগে থেকেই খুলতে পারেন, UnKey তা থেকে পাসওয়ার্ড সরিয়ে দেয়, iPhone, iPad ও Mac-এ। অফলাইনে কাজ করে, কিছু আপলোড হয় না। পাসওয়ার্ড একবার সেভ করুন, আগামী মাসের স্টেটমেন্ট Face ID-ই খুলে দেবে।
