How to Remove a PDF Password in Chrome (2026)

Updated October 2026

Open the PDF in Chrome with its password, press Ctrl+P or Cmd+P, set the destination to Save as PDF, and save a new copy without a password.

Google Chrome can save a copy of a password-protected PDF without the password, for free, on Windows, Mac and Linux. Open the PDF in Chrome, type the password, press Ctrl + P (Cmd + P on a Mac), set the destination to Save as PDF, and save. You must already know the password. Chrome can't open the file without it.

Step by step (computer)

  1. Drag the PDF into a Chrome window, or right-click the file and choose Open with > Google Chrome.
  2. Chrome asks for the password. Type it and press Enter.
  3. Press Ctrl + P on Windows or Linux, or Cmd + P on a Mac. You can also use the menu: File > Print.
  4. In the print window, set Destination to Save as PDF.
  5. Click Save. Give the new file a clear name, such as Statement-Sep-2026-unlocked.pdf.
  6. Close it and open the new file again. It should open straight away, with no password prompt.

Google's help page describes the keyboard shortcuts, choosing a destination in the print window, and the Save as PDF option (Google: Print from Chrome).

On an Android phone

Chrome on Android has the same option. Google's steps are: tap More > Share, tap Print, then tap Save as PDF and choose where to save the file (Google: Print from Chrome on Android). Whether Chrome opens a PDF stored on your phone depends on the Chrome version. If it doesn't, see our guide to opening a password-protected PDF on Android.

What you lose with this method

Saving through the print window creates a brand-new PDF from what's on screen. That's fine for reading, archiving or uploading a statement. But check the copy before you delete the original:

  • Links and bookmarks may stop working.
  • Form fields may be flattened, so you can't type in them any more.
  • Digital signatures aren't carried over. If a portal needs the signed original, upload the original.
  • Page size follows the print settings. Under More settings, check that the paper size and scale haven't shrunk or cropped the pages.

If Save as PDF doesn't work

  • Printing is blocked. Some PDFs have a permissions password that stops printing. A permissions password is separate from the open password. See PDF printing and copying restrictions explained.
  • Chrome rejects the password. Check capital letters, the date format and the details your bank has on record. See why a PDF password isn’t working.
  • The file opened in another app. Some computers open PDFs in a different reader by default. Drag the file into a Chrome tab instead.

Other ways to remove the password

Microsoft Edge works the same way on Windows (see removing a PDF password on Windows). On a Mac, Preview can export a copy without a password (Mac guide). On iPhone, iPad and Mac, UnKey saves an unlocked copy offline and keeps text, links and pages as they were, because it removes the encryption rather than re-printing the file. Like Chrome, it only works with a password you already know.

Questions

Does Chrome upload my PDF when I do this?

No. Opening a PDF file from your computer and saving it with Save as PDF happens in the browser on your computer. Only use the separate “Save to Google Drive” destination if you want a copy in Drive.

Can Chrome remove a password I don't know?

No. Chrome asks for the password before it shows anything. If you've lost it, see what to do if you forgot a PDF password.

Why is the saved copy different from the original?

Save as PDF prints the pages into a new file, so links, form fields and signatures may not survive. The text and layout usually look the same.

Is this allowed?

For your own documents, such as your bank statement, yes. Don't remove protection from files you aren't entitled to open freely.
