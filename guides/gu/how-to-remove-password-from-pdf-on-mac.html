Mac પર PDFમાંથી પાસવર્ડ કેવી રીતે કાઢવો (2026)

ઑક્ટોબર 2026માં અપડેટ કર્યું

આ ભાષામાં વાંચો: English · العربية · বাংলা · Deutsch · Español · Filipino · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · Italiano · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · ไทย · اردو · Tiếng Việt

PDFને Previewમાં પાસવર્ડથી ખોલો, File > Export પસંદ કરો, ખોલવા માટેનો પાસવર્ડ સેટ ન હોય તેની ખાતરી કરો અને નવી નકલ સાચવો.

Mac પર macOSમાં આવતી Preview ઍપ વડે તમે PDF પાસવર્ડ મફતમાં કાઢી શકો. PDF ખોલો, પાસવર્ડ આપો, પછી File > Export પસંદ કરો અને ખોલવા માટે પાસવર્ડ વગરની નવી નકલ સાચવો. પાસવર્ડ તમને ખબર હોવો જોઈએ. તેના વગર Preview ફાઇલ ખોલશે નહીં.

રીત 1: Preview, File > Export

  1. PDF પર ડબલ-ક્લિક કરીને Previewમાં ખોલો અને પાસવર્ડ આપો.
  2. File > Export પસંદ કરો અને નકલને નવું નામ આપો, જેમ કે "Statement-Oct-unlocked".
  3. Permissions પર ક્લિક કરો અને ખાતરી કરો કે Require Password To Open Document પસંદ કરેલું નથી. macOSની જૂની આવૃત્તિઓમાં Export વિન્ડોમાં તેની જગ્યાએ Encrypt ચેકબૉક્સ હોય છે. તેને ટિક વગરનું રાખો.
  4. Save પર ક્લિક કરો.
  5. નવી ફાઇલ બંધ કરીને ફરી ખોલો. તે પાસવર્ડ પૂછ્યા વગર ખૂલવી જોઈએ.

Appleની હાલની માર્ગદર્શિકા Export વિન્ડો, Permissions બટન અને Require Password To Open Document વિકલ્પનું વર્ણન કરે છે (Apple: Password-protect a PDF in Preview on Mac). આ જ પેજની macOS Big Sur આવૃત્તિમાં સીધું લખ્યું હતું: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide).

PDFમાં માલિક (permissions) પાસવર્ડ પણ હોય અને તમને ખબર હોય, તો File > Edit Permissions વડે ખોલવાનો પાસવર્ડ અને કઈ સુવિધાઓ માટે પાસવર્ડ જોઈએ તે બદલી શકાય છે.

રીત 2: Print > Save as PDF

પ્રિન્ટ કરી શકે તેવી Macની કોઈ પણ ઍપ નવી PDF બનાવી શકે (Apple: Save a document as a PDF on Mac):

  1. PDFને તેના પાસવર્ડથી ખોલો.
  2. File > Print પસંદ કરો.
  3. PDF પૉપ-અપ મેનુ પર ક્લિક કરો અને Save as PDF પસંદ કરો.
  4. Security Options પર ક્લિક ન કરો, કારણ કે ત્યાંથી પાસવર્ડ પાછો ઉમેરાય છે.

પ્રિન્ટ કરેલી નકલમાં લિંક, ફોર્મ ફીલ્ડ કે બુકમાર્ક જતા રહી શકે. દસ્તાવેજ પ્રિન્ટ અટકાવતો હોય, તો આ રીત ગ્રે દેખાઈ શકે.

રીત 3: Mac માટે UnKey

UnKey Mac પર પણ મફત છે. UnKey Pro, એકવારની ખરીદી, iPhone, iPad અને Mac પર બેચ અનલૉકિંગ અને બીજાં Pro ટૂલ ઉમેરે છે. PDFને વિન્ડો પર ખેંચો, પાસવર્ડ આપો, અને તે અનલૉક કરેલી નકલ સાચવે છે. UnKey Pro એકસાથે અનેક ફાઇલ બેચમાં અનલૉક પણ કરી શકે, જે એક જ પાસવર્ડવાળા આખા વર્ષના માસિક સ્ટેટમેન્ટ માટે ઉપયોગી છે. UnKey ઑફલાઇન ચાલે છે, કંઈ અપલોડ કરતું નથી અને ફક્ત તમને ખબર હોય તેવા પાસવર્ડ કાઢે છે.

રીત 4: કમાન્ડ લાઇન (ટેકનિકલ વપરાશકર્તાઓ માટે)

મફત, ઓપન-સોર્સ ટૂલ qpdf Terminalમાં આ કરી શકે: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. તેનું દસ્તાવેજીકરણ --decryptનું વર્ણન "an output file with no encryption even if the input file is encrypted" તરીકે કરે છે (qpdf documentation). તમારે તેને જાતે ઇન્સ્ટૉલ કરવું પડે, દા.ત. Homebrew વડે. કમાન્ડ લાઇનમાં પાસવર્ડ ટાઇપ કરવાથી તે તમારી shell હિસ્ટરીમાં રહી શકે છે.

હજી પાસવર્ડ માગે તો

  • તમે નકલને બદલે મૂળ ફાઇલ ખોલી હોઈ શકે. ફાઇલનું નામ તપાસો.
  • ફરી Export કરો અને Permissionsમાં Require Password To Open Document બંધ છે તે ચકાસો.
  • તેની જગ્યાએ Print > Save as PDF અજમાવો.
  • Preview પાસવર્ડ નકારે, તો કેપિટલ અક્ષર અને તારીખ ફોર્મેટ તપાસો, અને દસ્તાવેજ સાથે આવેલો ઇમેઇલ વાંચો.

મૂળ ફાઇલ ડિલીટ કરતા પહેલાં

અનલૉક કરેલી PDF ફાઇલ જેની પાસે હોય તે બધા માટે ખૂલે છે. તેમાં પરિવાર સાથે શેર કરેલા iCloud Drive ફોલ્ડર અને તમારું Mac ઉછીનું લેનાર કોઈ પણ આવે. અનલૉક કરેલા સ્ટેટમેન્ટ ખાનગી જગ્યાએ રાખો. વધુ માટે PDF પાસવર્ડ કાઢવો સલામત છે કે નહીં તે જુઓ.

પ્રશ્નો

શું Preview ખરેખર મફત છે?

હા. Preview દરેક Macમાં આવે છે અને પાસવર્ડ આપ્યા પછી ખોલવાના પાસવર્ડ વગરની PDF એક્સપોર્ટ કરી શકે છે.

શું Preview મને ખબર ન હોય તેવો પાસવર્ડ કાઢી શકે?

ના. Preview ફાઇલ ખોલતા પહેલાં પાસવર્ડ માગે છે, અને તેને ટાળવાનો કોઈ યોગ્ય રસ્તો નથી.

Mac પર એકસાથે ઘણી PDF કેવી રીતે અનલૉક કરવી?

Preview એક સમયે એક ફાઇલ સંભાળે છે. એક જ પાસવર્ડવાળી ઘણી PDF UnKey Pro બેચમાં અનલૉક કરી શકે, અને ટેકનિકલ વપરાશકર્તાઓ qpdfની સ્ક્રિપ્ટ બનાવી શકે. અમારી એકસાથે ઘણી PDF અનલૉક કરવાની માર્ગદર્શિકા જુઓ.

Print > Save as PDF ગ્રે કેમ છે?

PDFમાં પ્રિન્ટિંગ અટકાવતો પરવાનગી પાસવર્ડ હોઈ શકે. માલિક પાસવર્ડ ખબર હોય તો તે File > Edit Permissionsમાં આપો. નહીંતર Export રીત વાપરો.

ફોર્મેટ બદલાઈ શકે છે. પાસવર્ડ ન ચાલે તો દસ્તાવેજ સાથે આવેલો ઇમેઇલ જુઓ અથવા જારીકર્તાનો સંપર્ક કરો. અહીં જણાવેલી કોઈ બેંક, નોકરીદાતા કે સત્તામંડળ સાથે UnKeyને કોઈ સંબંધ નથી.

અંગ્રેજીમાંથી અનુવાદિત. કોઈ તફાવત હોય તો અંગ્રેજી પેજ જ આધારભૂત ગણાય.

એક જ વાર અનલૉક કરો.

તમે પહેલેથી ખોલી શકો તેવી PDFમાંથી UnKey પાસવર્ડ દૂર કરે છે, iPhone, iPad અને Mac પર. ઑફલાઇન ચાલે છે, કંઈ અપલોડ થતું નથી. પાસવર્ડ એક વાર સેવ કરો, આવતા મહિનાનું સ્ટેટમેન્ટ Face ID ખોલી દેશે.
