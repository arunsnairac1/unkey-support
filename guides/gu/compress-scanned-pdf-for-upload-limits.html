માર્ગદર્શિકાઓ · કેવી રીતે કરવું

અપલોડ સાઇઝ લિમિટ માટે સ્કેન કરેલી PDF નાની કરો

ઑક્ટોબર 2026માં અપડેટ કર્યું

સ્કેન કરેલી PDF મોટી એટલે હોય છે કે દરેક પેજ ફોટો હોય છે; Macમાં Previewનું Reduce File Size કે iPhoneમાં Previewના એક્સપોર્ટ વિકલ્પોથી નાની કરો, ઓછા અને સરળ પેજ સ્કેન કરો, અને અપલોડ પહેલાં પાસવર્ડ કાઢી નાખો.

વિઝા, પાસપોર્ટ, પરીક્ષા અને લોનના પોર્ટલ ઘણી વાર દરેક ફાઇલ માટે થોડાક સો કિલોબાઇટ કે બે-એક મેગાબાઇટની મર્યાદા રાખે છે. સ્કેન કરેલી PDF આ મર્યાદા ઓળંગી જાય છે, કારણ કે દરેક પેજ ફોટો તરીકે સચવાય છે. સૌથી ઝડપી ઉપાય: PDFને ઇમેજ કમ્પ્રેશન સાથે ફરી સેવ કરો (Mac કે iPhone પરનું Preview આ મફતમાં કરે છે), ફક્ત જરૂરી પેજ જ સ્કેન કરો, અને પહેલા પાસવર્ડ કાઢી નાખો, કારણ કે ઘણા પોર્ટલ પાસવર્ડવાળી ફાઇલ વાંચી શકતા નથી.

કમ્પ્રેસ કરતા પહેલાં

  • ચોક્કસ મર્યાદા અને ફોર્મેટ તપાસો પોર્ટલના પેજ પર: મહત્તમ સાઇઝ કેટલી, તે દરેક ફાઇલ માટે છે કે કુલ માટે, અને PDF જોઈએ કે JPEG. નિયમો પોર્ટલ પ્રમાણે જુદા હોય છે અને બદલાતા રહે છે, એટલે અપલોડ પેજ પર લખ્યા પ્રમાણે ચાલો.
  • પાસવર્ડ કાઢી નાખો. પોર્ટલ પાસવર્ડવાળી PDF ખોલીને તપાસી શકતું નથી. જુઓ iPhone, Mac, Windows કે Android.
  • મૂળ ફાઇલ રાખી મૂકો. કમ્પ્રેશનથી ઇમેજની ક્વૉલિટી ઘટે છે. પોર્ટલ ઝાંખું સ્કેન નકારે તો કામ આવે તે માટે પૂરી ક્વૉલિટીવાળી નકલ સાચવી રાખો.

Mac પર: Preview

  1. Previewમાં PDF ખોલો અને File > Export પસંદ કરો.
  2. Quartz Filter મેનુમાંથી Reduce File Size પસંદ કરો.
  3. નવું નામ આપો અને Save પર ક્લિક કરો.

Apple જણાવે છે કે કમ્પ્રેસ કરેલી PDF “મૂળ કરતાં ઓછી ક્વૉલિટીની હોઈ શકે” (“may be of lower quality than the original”). આ જ Export વિન્ડોમાં Optimize images for screen અને Save images as JPEG વિકલ્પો પણ છે (Apple: Reduce the size of a PDF in Preview on Mac). Reduce File Size વધુ લખાણવાળા સ્કેનને વાંચવામાં અઘરા બનાવી શકે છે, એટલે અપલોડ પહેલાં પરિણામ ખોલીને ઝૂમ કરી જુઓ.

iPhone કે iPad પર: Preview (iOS 26 અને પછીના)

  1. Preview ઍપમાં PDF ખોલો.
  2. ફાઇલના નામની બાજુના મેનુ પર ટૅપ કરો, પછી Export પર ટૅપ કરો.
  3. PDF પસંદ કરો, પછી Optimize Images for Screen અને Save Images as JPEG ચાલુ કરો.
  4. કન્ફર્મ બટન પર ટૅપ કરો, જગ્યા પસંદ કરો, નામ બદલો અને Save પર ટૅપ કરો.

Apple કહે છે કે Optimize Images for Screen “નાની ફાઇલ બનાવે છે” (“creates a smaller file”) (Apple: Export or compress PDFs in Preview on iPhone). પોર્ટલને PDFને બદલે JPEG જોઈતી હોય, તો આ જ સ્ક્રીન પરથી સાઇઝ સ્લાઇડર સાથે JPEGમાં એક્સપોર્ટ કરી શકાય છે.

શરૂઆતથી જ નાનું સ્કેન કરો

  • માગ્યા હોય તે જ પેજ. અપલોડ પહેલાં વધારાના પેજ ડિલીટ કરો. iPhoneનું Preview પેજ ડિલીટ કરી શકે છે અને ક્રમ બદલી શકે છે (Apple).
  • કૅમેરાને બદલે ડૉક્યુમેન્ટ સ્કેનર વાપરો. Notes, Files અને Preview પેજને ક્રૉપ કરીને સપાટ બનાવે છે (Apple: How to scan documents on iPhone). ક્રૉપ કરેલું સ્કેન ટેબલ સહિતના ફોટા કરતાં નાનું હોય છે.
  • ગ્રેસ્કેલ કે બ્લેક ઍન્ડ વ્હાઇટ લખાણવાળા દસ્તાવેજ માટે, જો પોર્ટલ મંજૂરી આપે. Previewનું સ્કેનર દરેક સ્કેનના રંગ ગોઠવવા દે છે (Apple). ફોટા અને જે સ્ટૅમ્પ કે મહોર અધિકારીએ જોવી જરૂરી હોય તે માટે રંગ રાખો.
  • એક ફાઇલમાં એક દસ્તાવેજ. પોર્ટલમાં અલગ અલગ સ્લૉટ હોય તો બધું ભેગું કરીને એક મોટી PDF ન બનાવો.

સામાન્ય સમસ્યાઓ

  • હજી પણ બહુ મોટી: બંને વિકલ્પો ચાલુ રાખીને ફરી એક્સપોર્ટ કરો, અથવા ગ્રેસ્કેલમાં ફરી સ્કેન કરો.
  • લખાણ ઝાંખું છે: તમે વધુ પડતું કમ્પ્રેસ કર્યું છે. મૂળ ફાઇલ પર પાછા જાઓ અને ફક્ત એક જ વિકલ્પ વાપરો.
  • પોર્ટલ કહે છે “file is corrupt” કે “encrypted”: ફાઇલ કદાચ હજી પાસવર્ડથી સુરક્ષિત કે પ્રતિબંધિત છે. પાસવર્ડ કાઢીને ફરી પ્રયત્ન કરો.
  • ફાઇલ ઊલટી મોટી થઈ: જે PDF મોટે ભાગે સાચા લખાણની હોય તે પહેલેથી નાની હોય છે. ફરી સેવ કરવાથી સાઇઝ વધી શકે છે. મૂળ ફાઇલ જ અપલોડ કરો.

UnKey સાથે

iPhone, iPad અને Mac પરના UnKey Proમાં સ્કેન માટેનું Compress ટૂલ છે. તે ફોટા જેવા પેજને ફરી એન્કોડ કરે છે અને સાચા લખાણવાળા પેજને અડતું નથી, એટલે લખાણ તીક્ષ્ણ રહે છે, અને તમે આપેલી ફાઇલ કરતાં મોટી ફાઇલ તે ક્યારેય પાછી આપતું નથી. તે ઑફલાઇન ચાલે છે, એટલે તમારું પાસપોર્ટ કે બેંકનું સ્કેન કમ્પ્રેશન વેબસાઇટ પર અપલોડ થતું નથી. અનલૉક કરવું મફત છે; Compress એકવારની Pro ખરીદીનો ભાગ છે.

પ્રશ્નો

કમ્પ્રેસ કરવાથી મારા દસ્તાવેજ વાંચી ન શકાય એવા થઈ જશે?

વધુ પડતું કરો તો થઈ શકે. કમ્પ્રેસ કરેલી નકલ હંમેશાં ખોલો, નાના અક્ષરો પર ઝૂમ કરીને જુઓ અને મૂળ ફાઇલ સાચવી રાખો.

2 પેજનું સ્કેન 8 MB કેમ છે?

દરેક સ્કેન કરેલું પેજ ઊંચા રિઝોલ્યુશનનો ફોટો હોય છે. બેંકની લખાણવાળી PDF બહુ નાની હોય છે કારણ કે તેમાં ચિત્રો નહીં, લખાણ સચવાયેલું હોય છે.

શું પોર્ટલ પાસવર્ડવાળી PDF સ્વીકારે છે?

ઘણા તે વાંચી શકતા નથી. પોર્ટલ બીજું કહે નહીં ત્યાં સુધી અપલોડ પહેલાં પાસવર્ડ કાઢી નાખો.

પાસપોર્ટ અને સ્ટેટમેન્ટ માટે ઓનલાઇન કમ્પ્રેસર સલામત છે?

તેઓ તમારી ફાઇલ સર્વર પર અપલોડ કરે છે. ઓળખ અને નાણાકીય દસ્તાવેજો માટે તમારા પોતાના ડિવાઇસ પર કમ્પ્રેસ કરવું વધુ સલામત છે.

ફોર્મેટ બદલાઈ શકે છે. પાસવર્ડ ન ચાલે તો દસ્તાવેજ સાથે આવેલો ઇમેઇલ જુઓ અથવા જારીકર્તાનો સંપર્ક કરો. અહીં જણાવેલી કોઈ બેંક, નોકરીદાતા કે સત્તામંડળ સાથે UnKeyને કોઈ સંબંધ નથી.

અંગ્રેજીમાંથી અનુવાદિત. કોઈ તફાવત હોય તો અંગ્રેજી પેજ જ આધારભૂત ગણાય.

એક જ વાર અનલૉક કરો.

તમે પહેલેથી ખોલી શકો તેવી PDFમાંથી UnKey પાસવર્ડ દૂર કરે છે, iPhone, iPad અને Mac પર. ઑફલાઇન ચાલે છે, કંઈ અપલોડ થતું નથી. પાસવર્ડ એક વાર સેવ કરો, આવતા મહિનાનું સ્ટેટમેન્ટ Face ID ખોલી દેશે.
