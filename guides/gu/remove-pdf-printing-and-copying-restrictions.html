માર્ગદર્શિકાઓ · કેવી રીતે કરવું

PDF પ્રિન્ટિંગ અને કૉપી પરના પ્રતિબંધોની સમજૂતી

ઑક્ટોબર 2026માં અપડેટ કર્યું

ખોલવાનો પાસવર્ડ PDF વાંચવા જ દેતો નથી; ઓનર (પરવાનગી) પાસવર્ડ ફક્ત પ્રિન્ટિંગ, કૉપી અને એડિટિંગ જેવી ક્રિયાઓ મર્યાદિત કરે છે.

PDFમાં બે અલગ પાસવર્ડ હોઈ શકે. ખોલવાનો પાસવર્ડ (open password) (યુઝર પાસવર્ડ પણ કહેવાય) ફાઇલ જોવા માટે જ જોઈએ. ઓનર પાસવર્ડ (owner password) (પરવાનગી પાસવર્ડ પણ કહેવાય) ફાઇલ ખોલવા દે છે, પણ પ્રિન્ટિંગ, લખાણ કૉપી કરવું કે એડિટિંગ જેવી બાબતો મર્યાદિત કરે છે. પ્રતિબંધો યોગ્ય રીતે હટાવવા માટે ઓનર પાસવર્ડ જોઈએ.

બે પાસવર્ડ સરળ ભાષામાં

ખોલવાનો (યુઝર) પાસવર્ડઓનર (પરવાનગી) પાસવર્ડ
તમને શું દેખાયકંઈ દેખાય તે પહેલાં પાસવર્ડ માગતી સ્ક્રીનફાઇલ ખૂલે છે, પણ Print કે Copy ગ્રે હોય છે
તે શું રક્ષે છેઆખી સામગ્રી, જે એન્ક્રિપ્ટ થયેલી હોય છેપ્રિન્ટિંગ, કૉપી, એડિટિંગ અને કમેન્ટિંગ જેવી ક્રિયાઓ
સામાન્ય ઉપયોગબેંક સ્ટેટમેન્ટ, ટેક્સ દસ્તાવેજોપ્રકાશિત રિપોર્ટ, ફોર્મ, કરાર

Adobe પણ ભેદ આમ જ વર્ણવે છે. Document Open પાસવર્ડ PDF ખોલવા જોઈએ, અને પરવાનગી પાસવર્ડ પ્રિન્ટિંગ, એડિટિંગ અને કૉપી જેવી સુવિધાઓ મર્યાદિત કરે છે (Adobe: Password security overview). qpdfનું દસ્તાવેજીકરણ એક મહત્વની વિગત ઉમેરે છે: રીડર "apply security restrictions to files opened with the user password" અને "allow security restrictions to be changed or overridden when files are opened with the owner password" (qpdf).

પ્રતિબંધો કેવી રીતે લાગુ થાય છે

પ્રતિબંધો ત્યારે જ કામ કરે જ્યારે PDF રીડર તેમનું પાલન કરવાનું પસંદ કરે. Adobe જણાવે છે કે તેની પોતાની પ્રોડક્ટ્સ તે લાગુ કરે છે, પણ થર્ડ-પાર્ટી પ્રોડક્ટ્સ આ સેટિંગ્સને સપોર્ટ ન કરે, તો મેળવનાર કેટલાક કે બધા પ્રતિબંધો ટાળી શકે (Adobe). એટલે પરવાનગી પાસવર્ડ તાળા કરતાં નમ્ર “મહેરબાની કરીને નહીં” જેવો છે. છતાં લેખકની ઇચ્છા અવગણવાનું તે કારણ નથી. કોઈએ કૉપી અટકાવી હોય, તો સામાન્ય રીતે કારણ હોય છે, જેમ કે કૉપીરાઇટ કે કરાર.

ઓનર પાસવર્ડ હોય ત્યારે પ્રતિબંધો બદલવા

Mac પર (Preview): PDF ખોલો, File > Edit Permissions પસંદ કરો અને ઓનર પાસવર્ડ આપો. પછી પાસવર્ડ વગર જે ક્રિયાઓ મંજૂર કરવી હોય તે પસંદ કરો અને Apply પર ક્લિક કરો (Apple: Password-protect a PDF in Preview on Mac). નવી નકલ જોઈતી હોય તો આ જ Permissions પૅનલ File > Export હેઠળ પણ આવે છે.

Adobe Acrobatમાં: પરવાનગી પાસવર્ડ કાઢવા માટે Adobeની સૂચનાઓ તેને Enter Password બૉક્સમાં ટાઇપ કરવાનું કહે છે (Adobe: How to remove a PDF password).

કમાન્ડ લાઇન પર: --password=OWNERPASSWORD --decrypt સાથે qpdf એન્ક્રિપ્શન વગરની નકલ લખે છે. તેનું દસ્તાવેજીકરણ નોંધે છે કે આ વિકલ્પ ફાઇલો પર પ્રોડ્યુસરે મૂકેલા પ્રતિબંધો ટાળવા માટે નથી (qpdf).

બંને પાસવર્ડવાળા તમારા પોતાના દસ્તાવેજો

બેંક સ્ટેટમેન્ટ સામાન્ય રીતે ફક્ત ખોલવાનો પાસવર્ડ વાપરે છે. એક વાર ખોલ્યા પછી તમે સામાન્ય રીતે મુક્તપણે પ્રિન્ટ અને કૉપી કરી શકો. Preview કે Acrobatમાં તમે જાતે PDF બનાવી હોય અને બંને પાસવર્ડ મૂક્યા હોય, તો પરવાનગીઓ બદલવા કે પ્રતિબંધ વગરની નકલ એક્સપોર્ટ કરવા ઓનર પાસવર્ડ વાપરો.

તમારી પોતાની ફાઇલોમાંથી, જેમ કે માસિક સ્ટેટમેન્ટ, ખોલવાનો પાસવર્ડ કાઢવા તમે Macમાં Preview અથવા iPhone, iPad કે Mac પર UnKey વાપરી શકો. UnKey ઑફલાઇન ચાલે છે અને ફક્ત તમને ખબર હોય તેવા પાસવર્ડથી જ કામ કરે છે.

ઓનર પાસવર્ડ ન હોય ત્યારે

  • લેખક કે મોકલનારને પ્રતિબંધ વગરની નકલ માટે, અથવા પ્રિન્ટ કે કૉપી કરવાની પરવાનગી માટે કહો.
  • તમારે ભરવાના ફોર્મ માટે, ફોર્મ ભરવાની છૂટ પહેલેથી છે કે નહીં તે તપાસો. ઘણી પ્રતિબંધિત PDF પણ ફોર્મ ભરવા દે છે.
  • કામ કે કાયદા સંબંધી દસ્તાવેજ માટે, ધારી લો કે પ્રતિબંધ જાણી જોઈને મૂક્યો છે.

પ્રશ્નો

PDF ઓનર પાસવર્ડ એટલે શું?

તે પ્રિન્ટિંગ, કૉપી અને એડિટિંગ જેવી પરવાનગીઓ નક્કી કરતો પાસવર્ડ છે. તેના વગર ફાઇલ ખુલી શકે, પણ સેટિંગ્સનું પાલન કરતા રીડરમાં પ્રતિબંધિત ક્રિયાઓ અટકે છે.

હું PDF ખોલી શકું પણ પ્રિન્ટ કેમ ન કરી શકું?

ફાઇલમાં પ્રિન્ટિંગ ન થવા દેતો ઓનર (પરવાનગી) પાસવર્ડ છે. Previewમાં File > Edit Permissionsમાં ઓનર પાસવર્ડ આપો, અથવા મોકલનાર પાસેથી પ્રતિબંધ વગરની નકલ માગો.

શું બેંક સ્ટેટમેન્ટમાં પ્રિન્ટિંગ પ્રતિબંધ હોય છે?

સામાન્ય રીતે નહીં. તેઓ સામાન્યતઃ ફક્ત ખોલવાનો પાસવર્ડ વાપરે છે, એટલે ફાઇલ ખુલી જાય પછી તમે પ્રિન્ટ કરી શકો.

શું PDFના કૉપી પ્રતિબંધો હટાવવા કાયદેસર છે?

તમારી પોતાની ફાઇલ પર તમારા પોતાના ઓનર પાસવર્ડથી પરવાનગીઓ બદલવી ઠીક છે. બીજાના દસ્તાવેજ પરના પ્રતિબંધો ટાળવાથી કૉપીરાઇટ કે કરારની શરતોનો ભંગ થઈ શકે, એટલે માલિકને પૂછો.

ફોર્મેટ બદલાઈ શકે છે. પાસવર્ડ ન ચાલે તો દસ્તાવેજ સાથે આવેલો ઇમેઇલ જુઓ અથવા જારીકર્તાનો સંપર્ક કરો. અહીં જણાવેલી કોઈ બેંક, નોકરીદાતા કે સત્તામંડળ સાથે UnKeyને કોઈ સંબંધ નથી.

અંગ્રેજીમાંથી અનુવાદિત. કોઈ તફાવત હોય તો અંગ્રેજી પેજ જ આધારભૂત ગણાય.

એક જ વાર અનલૉક કરો.

તમે પહેલેથી ખોલી શકો તેવી PDFમાંથી UnKey પાસવર્ડ દૂર કરે છે, iPhone, iPad અને Mac પર. ઑફલાઇન ચાલે છે, કંઈ અપલોડ થતું નથી. પાસવર્ડ એક વાર સેવ કરો, આવતા મહિનાનું સ્ટેટમેન્ટ Face ID ખોલી દેશે.
