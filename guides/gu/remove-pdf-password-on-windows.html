Windows પર PDF પાસવર્ડ કેવી રીતે કાઢવો (2026)

ઑક્ટોબર 2026માં અપડેટ કર્યું

આ ભાષામાં વાંચો: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · नेपाली · Português · සිංහල · தமிழ் · తెలుగు

PDFને Microsoft Edge કે Chromeમાં પાસવર્ડથી ખોલો, Ctrl+P દબાવો, Save as PDF (અથવા Microsoft Print to PDF) પસંદ કરી નવી નકલ સાચવો; પેઇડ Acrobat સીધો સિક્યોરિટી કાઢી શકે.

Windows 10 અને 11 પર તમારી પાસે પહેલેથી હોય તે બ્રાઉઝરથી PDF પાસવર્ડ મફતમાં કાઢી શકાય. PDFને Microsoft Edge કે Google Chromeમાં ખોલો, પાસવર્ડ ટાઇપ કરો, Ctrl + P દબાવો, પ્રિન્ટર તરીકે Save as PDF (અથવા Microsoft Print to PDF) પસંદ કરો અને સાચવો. નવી ફાઇલ પાસવર્ડ વગર ખૂલે છે. પહેલા પાસવર્ડ તમને ખબર હોવો જોઈએ.

રીત 1: Microsoft Edge (બિલ્ટ-ઇન)

  1. File Explorerમાં PDF પર રાઇટ-ક્લિક કરો અને Open with > Microsoft Edge પસંદ કરો.
  2. Edge પૂછે ત્યારે પાસવર્ડ ટાઇપ કરો.
  3. Ctrl + P દબાવો, અથવા More મેનુ (ત્રણ ટપકાં) ખોલીને Print પસંદ કરો.
  4. Printer હેઠળ Save as PDF કે Microsoft Print to PDF પસંદ કરો.
  5. Save (અથવા Print) પર ક્લિક કરો, ફોલ્ડર પસંદ કરો અને નકલને નવું નામ આપો.
  6. નવી ફાઇલ ખોલીને ચકાસો કે તે હવે પાસવર્ડ માગતી નથી.

Microsoftની બિલ્ટ-ઇન PDF રીડરની માર્ગદર્શિકા Edgeનો રસ્તો બતાવે છે: More મેનુ હેઠળ Print શોધો, વિકલ્પો પસંદ કરો, પછી પ્રિન્ટ કરો (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF Windows સાથે આવતું પ્રિન્ટર છે. સૂચિમાં ન દેખાય, તો Microsoft કહે છે કે તેને Windows Optional Features હેઠળ ફરી ચાલુ કરી શકાય (Microsoft: KB5058499 known issue).

રીત 2: Google Chrome

Chrome વાપરતા હો તો પગલાં લગભગ એ જ છે: PDFને Chromeમાં ખોલો, પાસવર્ડ આપો, Ctrl + P દબાવો, Destination Save as PDF પર સેટ કરો અને Save પર ક્લિક કરો (Google: Print from Chrome). વધુ વિગતો અમારી Chrome માર્ગદર્શિકામાં છે.

રીત 3: Adobe Acrobat Pro કે Standard (પેઇડ)

પેઇડ Acrobat ફાઇલ ફરી પ્રિન્ટ કરવાને બદલે એન્ક્રિપ્શન જ કાઢે છે, એટલે લિંક અને ફોર્મ ફીલ્ડ જેમના તેમ રહે છે. Adobe બે રસ્તા દસ્તાવેજીકૃત કરે છે (Adobe: Remove passwords from PDFs):

  • Protect ટૂલ્સ: PDF ખોલો, Protect ટૂલ્સમાં જઈને Remove Security પસંદ કરો. ફાઇલમાં ફક્ત ખોલવાનો પાસવર્ડ હોય, તો OK દબાવીને પુષ્ટિ કરો. તેમાં પરવાનગી પાસવર્ડ પણ હોય, તો Acrobat પહેલા તે પાસવર્ડ માગે છે.
  • Security સેટિંગ્સ: દસ્તાવેજની સિક્યોરિટી પ્રોપર્ટીઝ ખોલો, Security ટૅબ પર જાઓ, Change Settings પસંદ કરો, પાસવર્ડ વિકલ્પો સાફ કરો અને સાચવો.

Adobeનાં મેનુ આવૃત્તિ પ્રમાણે ખસે છે, એટલે આ ચોક્કસ નામ ન દેખાય, તો Acrobatના ટૂલ સર્ચમાં “Remove Security” શોધો. મફત Acrobat Reader સુરક્ષિત PDF ખોલી શકે, પણ સિક્યોરિટી કાઢવાનું ટૂલ નથી. તેના માટે રીત 1 કે 2 વાપરો.

રીત 4: qpdf (ટેકનિકલ વપરાશકર્તાઓ માટે)

મફત, ઓપન-સોર્સ qpdf ટૂલ Windows પર ચાલે છે. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf એન્ક્રિપ્શન વગરની નકલ લખે છે (qpdf documentation). પાસવર્ડ તમારી કમાન્ડ હિસ્ટરીમાં સચવાઈ શકે, એટલે શેર થતા PC પર પછી તેને સાફ કરો.

તપાસવા જેવી બાબતો

  • Print ગ્રે છે? PDFમાં પ્રિન્ટ અટકાવતો પરવાનગી પાસવર્ડ હોઈ શકે. જુઓ પ્રિન્ટિંગ અને કૉપી પરના પ્રતિબંધો.
  • પાસવર્ડ નકારાયો? Caps Lock, તારીખનું ફોર્મેટ અને બેંક પાસે રહેલી તમારી વિગતો તપાસો. જુઓ PDF પાસવર્ડ કેમ કામ કરતો નથી.
  • શેર થતું કે ઑફિસનું PC? અનલૉક નકલ જેને મળે તેના માટે ખૂલે છે. તેને ખાનગી ફોલ્ડરમાં સાચવો અને Downloadsમાંથી ડિલીટ કરો.

તમારી પાસે iPhone, iPad કે Mac પણ હોય, તો UnKey તે ડિવાઇસ પર પાસવર્ડ ઑફલાઇન કાઢે છે અને આવતા મહિનાના સ્ટેટમેન્ટ માટે પાસવર્ડ સાચવી શકે છે. Windows માટે UnKey ઍપ નથી.

પ્રશ્નો

શું Windows પર કંઈ ઇન્સ્ટૉલ કરવું પડે?

ના. Microsoft Edge અને Microsoft Print to PDF પ્રિન્ટર Windows 10 અને 11 સાથે આવે છે.

શું ઓનલાઇન “unlock PDF” સાઇટ વધુ સારી ચાલે?

તેઓ એ જ કામ કરે છે પણ તમારો દસ્તાવેજ બીજાના સર્વર પર અપલોડ કરે છે. બેંક સ્ટેટમેન્ટ અને ટેક્સ કાગળિયાં માટે અહીંની ઑફલાઇન રીતો વધુ સલામત છે.

શું આમાંથી કોઈ રીત ભૂલી ગયેલો પાસવર્ડ કાઢી શકે?

ના. Edge, Chrome, Acrobat અને qpdf બધાને સાચો પાસવર્ડ જોઈએ. ફોર્મેટ માટે PDF સાથે આવેલો ઇમેઇલ તપાસો.

નકલમાં લિંક કેમ કામ કરતી બંધ થઈ જાય છે?

PDFમાં પ્રિન્ટ કરવાથી પેજ ફરી બને છે, જેમાં લિંક અને ફોર્મ ફીલ્ડ જતા રહી શકે. Acrobatનું Remove Security કે qpdf તેમને જાળવે છે.

ફોર્મેટ બદલાઈ શકે છે. પાસવર્ડ ન ચાલે તો દસ્તાવેજ સાથે આવેલો ઇમેઇલ જુઓ અથવા જારીકર્તાનો સંપર્ક કરો. અહીં જણાવેલી કોઈ બેંક, નોકરીદાતા કે સત્તામંડળ સાથે UnKeyને કોઈ સંબંધ નથી.

અંગ્રેજીમાંથી અનુવાદિત. કોઈ તફાવત હોય તો અંગ્રેજી પેજ જ આધારભૂત ગણાય.

એક જ વાર અનલૉક કરો.

તમે પહેલેથી ખોલી શકો તેવી PDFમાંથી UnKey પાસવર્ડ દૂર કરે છે, iPhone, iPad અને Mac પર. ઑફલાઇન ચાલે છે, કંઈ અપલોડ થતું નથી. પાસવર્ડ એક વાર સેવ કરો, આવતા મહિનાનું સ્ટેટમેન્ટ Face ID ખોલી દેશે.
