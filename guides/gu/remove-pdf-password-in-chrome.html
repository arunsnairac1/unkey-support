Chromeમાં PDF પાસવર્ડ કેવી રીતે કાઢવો (2026)

ઑક્ટોબર 2026માં અપડેટ કર્યું

આ ભાષામાં વાંચો: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

PDFને Chromeમાં પાસવર્ડથી ખોલો, Ctrl+P કે Cmd+P દબાવો, ડેસ્ટિનેશન Save as PDF કરો અને પાસવર્ડ વગરની નવી નકલ સાચવો.

Google Chrome પાસવર્ડવાળી PDFની પાસવર્ડ વગરની નકલ મફતમાં સાચવી શકે છે, Windows, Mac અને Linux પર. PDFને Chromeમાં ખોલો, પાસવર્ડ ટાઇપ કરો, Ctrl + P (Macમાં Cmd + P) દબાવો, ડેસ્ટિનેશન Save as PDF રાખો અને સાચવો. પાસવર્ડ તમને ખબર હોવો જોઈએ. તેના વગર Chrome ફાઇલ ખોલી શકતું નથી.

પગલે પગલે (કમ્પ્યુટર)

  1. PDFને Chrome વિન્ડોમાં ખેંચો, અથવા ફાઇલ પર રાઇટ-ક્લિક કરી Open with > Google Chrome પસંદ કરો.
  2. Chrome પાસવર્ડ માગે છે. તે ટાઇપ કરો અને Enter દબાવો.
  3. Windows કે Linux પર Ctrl + P દબાવો, અથવા Macમાં Cmd + P. મેનુથી પણ થાય: File > Print.
  4. પ્રિન્ટ વિન્ડોમાં Destination Save as PDF પર સેટ કરો.
  5. Save પર ક્લિક કરો. નવી ફાઇલને સ્પષ્ટ નામ આપો, જેમ કે Statement-Sep-2026-unlocked.pdf.
  6. તેને બંધ કરીને નવી ફાઇલ ફરી ખોલો. તે તરત ખૂલવી જોઈએ, પાસવર્ડ માગ્યા વગર.

Googleનું મદદ પેજ કીબોર્ડ શૉર્ટકટ, પ્રિન્ટ વિન્ડોમાં ડેસ્ટિનેશન પસંદ કરવું અને Save as PDF વિકલ્પનું વર્ણન કરે છે (Google: Print from Chrome).

Android ફોન પર

Android પરના Chromeમાં પણ આ જ વિકલ્પ છે. Googleના પગલાં: More > Share પર ટૅપ કરો, Print પર ટૅપ કરો, પછી Save as PDF પર ટૅપ કરો અને ફાઇલ ક્યાં સાચવવી તે પસંદ કરો (Google: Print from Chrome on Android). તમારા ફોનમાં સંગ્રહેલી PDF Chrome ખોલે કે નહીં તે Chromeની આવૃત્તિ પર આધાર રાખે છે. ન ખોલે, તો અમારી Android પર પાસવર્ડવાળી PDF ખોલવાની માર્ગદર્શિકા જુઓ.

આ રીતમાં તમે શું ગુમાવો છો

પ્રિન્ટ વિન્ડોથી સાચવવાથી સ્ક્રીન પર જે દેખાય છે તેમાંથી તદ્દન નવી PDF બને છે. વાંચવા, આર્કાઇવ કરવા કે સ્ટેટમેન્ટ અપલોડ કરવા માટે તે ઠીક છે. પણ મૂળ ફાઇલ ડિલીટ કરતા પહેલાં નકલ તપાસો:

  • લિંક અને બુકમાર્ક કામ કરતા બંધ થઈ શકે.
  • ફોર્મ ફીલ્ડ સપાટ થઈ જઈ શકે, એટલે તેમાં હવે ટાઇપ ન થાય.
  • ડિજિટલ સહી સાથે આવતી નથી. પોર્ટલને સહી કરેલી મૂળ ફાઇલ જોઈતી હોય, તો મૂળ અપલોડ કરો.
  • પેજ સાઇઝ પ્રિન્ટ સેટિંગને અનુસરે છે. More settings હેઠળ તપાસો કે પેપર સાઇઝ અને સ્કેલથી પેજ નાના કે કપાયેલા તો નથી થયા.

Save as PDF કામ ન કરે તો

  • પ્રિન્ટિંગ અટકાવેલું છે. કેટલીક PDFમાં પ્રિન્ટ અટકાવતો પરવાનગી પાસવર્ડ હોય છે. પરવાનગી પાસવર્ડ ખોલવાના પાસવર્ડથી અલગ છે. જુઓ PDF પ્રિન્ટિંગ અને કૉપી પરના પ્રતિબંધોની સમજૂતી.
  • Chrome પાસવર્ડ નકારે છે. કેપિટલ અક્ષર, તારીખનું ફોર્મેટ અને બેંક પાસે રહેલી તમારી વિગતો તપાસો. જુઓ PDF પાસવર્ડ કેમ કામ કરતો નથી.
  • ફાઇલ બીજી ઍપમાં ખુલી. કેટલાક કમ્પ્યુટર PDFને ડિફૉલ્ટ રૂપે બીજા રીડરમાં ખોલે છે. તેની જગ્યાએ ફાઇલ Chromeના ટૅબમાં ખેંચો.

પાસવર્ડ કાઢવાની બીજી રીતો

Microsoft Edge Windows પર એ જ રીતે કામ કરે છે (જુઓ Windows પર PDF પાસવર્ડ કાઢવો). Macમાં Preview પાસવર્ડ વગરની નકલ એક્સપોર્ટ કરી શકે (Mac માર્ગદર્શિકા). iPhone, iPad અને Mac પર UnKey અનલૉક કરેલી નકલ ઑફલાઇન સાચવે છે અને લખાણ, લિંક અને પેજ જેમના તેમ રાખે છે, કારણ કે તે ફાઇલ ફરી પ્રિન્ટ કરવાને બદલે એન્ક્રિપ્શન કાઢે છે. Chromeની જેમ, તે પણ ફક્ત તમને ખબર હોય તેવા પાસવર્ડથી જ કામ કરે છે.

પ્રશ્નો

આ કરું ત્યારે શું Chrome મારી PDF અપલોડ કરે છે?

ના. તમારા કમ્પ્યુટરમાંથી PDF ફાઇલ ખોલીને Save as PDFથી સાચવવાનું કામ તમારા કમ્પ્યુટર પરના બ્રાઉઝરમાં જ થાય છે. Driveમાં નકલ જોઈતી હોય તો જ અલગ “Save to Google Drive” ડેસ્ટિનેશન વાપરો.

શું Chrome મને ખબર ન હોય તેવો પાસવર્ડ કાઢી શકે?

ના. Chrome કંઈ પણ બતાવતા પહેલાં પાસવર્ડ માગે છે. ખોવાઈ ગયો હોય, તો PDF પાસવર્ડ ભૂલી જાઓ ત્યારે શું કરવું તે જુઓ.

સાચવેલી નકલ મૂળ કરતાં અલગ કેમ છે?

Save as PDF પેજને નવી ફાઇલમાં પ્રિન્ટ કરે છે, એટલે લિંક, ફોર્મ ફીલ્ડ અને સહી ટકી ન શકે. લખાણ અને લેઆઉટ સામાન્ય રીતે એવા જ દેખાય છે.

શું આ કરવાની છૂટ છે?

તમારા પોતાના દસ્તાવેજો, જેમ કે બેંક સ્ટેટમેન્ટ, માટે હા. જે ફાઇલો મુક્તપણે ખોલવાનો તમને અધિકાર નથી તેમાંથી રક્ષણ ન કાઢો.

ફોર્મેટ બદલાઈ શકે છે. પાસવર્ડ ન ચાલે તો દસ્તાવેજ સાથે આવેલો ઇમેઇલ જુઓ અથવા જારીકર્તાનો સંપર્ક કરો. અહીં જણાવેલી કોઈ બેંક, નોકરીદાતા કે સત્તામંડળ સાથે UnKeyને કોઈ સંબંધ નથી.

અંગ્રેજીમાંથી અનુવાદિત. કોઈ તફાવત હોય તો અંગ્રેજી પેજ જ આધારભૂત ગણાય.

એક જ વાર અનલૉક કરો.

તમે પહેલેથી ખોલી શકો તેવી PDFમાંથી UnKey પાસવર્ડ દૂર કરે છે, iPhone, iPad અને Mac પર. ઑફલાઇન ચાલે છે, કંઈ અપલોડ થતું નથી. પાસવર્ડ એક વાર સેવ કરો, આવતા મહિનાનું સ્ટેટમેન્ટ Face ID ખોલી દેશે.
