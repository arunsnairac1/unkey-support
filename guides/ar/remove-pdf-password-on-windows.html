كيف تزيل كلمة مرور PDF على ويندوز (2026)

تم التحديث في أكتوبر 2026

القراءة بـ: English · العربية · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · Português · தமிழ்

افتح الملف في Microsoft Edge أو Chrome بكلمة مروره، واضغط Ctrl+P، واختر Save as PDF (أو Microsoft Print to PDF) واحفظ نسخة جديدة؛ ويستطيع Acrobat المدفوع إزالة الحماية مباشرة.

على ويندوز 10 و11 يمكنك إزالة كلمة مرور PDF مجانًا بالمتصفح الذي لديك أصلًا. افتح الملف في Microsoft Edge أو Google Chrome، واكتب كلمة المرور، واضغط Ctrl + P، واختر Save as PDF (أو Microsoft Print to PDF) طابعةً، ثم احفظ. يُفتح الملف الجديد دون كلمة مرور. يجب أن تعرف كلمة المرور أولًا.

الطريقة 1: Microsoft Edge (مدمج)

  1. انقر الملف بزر الفأرة الأيمن في File Explorer واختر Open with > Microsoft Edge.
  2. اكتب كلمة المرور حين يطلبها Edge.
  3. اضغط Ctrl + P، أو افتح قائمة More (النقاط الثلاث) واختر Print.
  4. تحت Printer اختر Save as PDF أو Microsoft Print to PDF.
  5. انقر Save (أو Print) واختر مجلدًا وسمِّ النسخة اسمًا جديدًا.
  6. افتح الملف الجديد وتأكد أنه لم يعد يطلب كلمة مرور.

يعرض دليل Microsoft لقارئ PDF المدمج طريق Edge: ابحث عن Print تحت قائمة More، واختر خياراتك ثم اطبع (Microsoft: View, print, and edit PDFs in a PDF reader). وMicrosoft Print to PDF طابعة تأتي مع ويندوز. وإن كانت مفقودة من القائمة فتقول Microsoft إنه يمكن إعادة تشغيلها من Windows Optional Features (Microsoft: KB5058499 known issue).

الطريقة 2: Google Chrome

إن كنت تستخدم Chrome فالخطوات متقاربة جدًا: افتح الملف في Chrome، وأدخل كلمة المرور، واضغط Ctrl + P، واجعل Destination هو Save as PDF، وانقر Save (Google: Print from Chrome). وتفاصيل أكثر في دليل Chrome.

الطريقة 3: Adobe Acrobat Pro أو Standard (مدفوع)

يزيل Acrobat المدفوع التشفير نفسه بدل إعادة طباعة الملف، فتبقى الروابط وحقول النماذج سليمة. توثّق Adobe طريقين (Adobe: Remove passwords from PDFs):

  • أدوات Protect: افتح الملف، وانتقل إلى أدوات Protect واختر Remove Security. إن كان في الملف كلمة مرور فتح فقط فأكّد بـ OK. وإن كانت فيه كلمة مرور أذونات أيضًا فسيطلبها Acrobat أولًا.
  • إعدادات الأمان: افتح خصائص الأمان للمستند، وانتقل إلى علامة التبويب Security، واختر Change Settings، وامسح خيارات كلمة المرور واحفظ.

تتنقل قوائم Adobe بين الإصدارات، فإن لم تجد هذه الأسماء بالضبط فابحث عن «Remove Security» في بحث الأدوات داخل Acrobat. يستطيع Acrobat Reader المجاني فتح الملفات المحمية لكنه ليس أداة إزالة الحماية. استخدم الطريقة 1 أو 2 بدلًا منه.

الطريقة 4: qpdf (للمستخدمين التقنيين)

تعمل أداة qpdf المجانية مفتوحة المصدر على ويندوز. الأمر qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf يكتب نسخة بلا تشفير (qpdf documentation). وقد تُحفظ كلمة المرور في سجل الأوامر، فامسحه بعد ذلك على جهاز مشترك.

أمور للتحقق منها

  • خيار Print باهت؟ قد يحتوي الملف على كلمة مرور أذونات تمنع الطباعة. راجع قيود الطباعة والنسخ.
  • رُفضت كلمة المرور؟ تحقق من Caps Lock وصيغة التاريخ والبيانات المسجلة لدى بنكك. راجع لماذا لا تعمل كلمة مرور PDF.
  • جهاز مشترك أو في المكتب؟ تُفتح النسخة المفتوحة لكل من يجدها. احفظها في مجلد خاص واحذفها من Downloads.

وإن كان لديك أيضًا آيفون أو آيباد أو ماك، فإن UnKey يزيل كلمة المرور دون اتصال على تلك الأجهزة ويستطيع حفظ كلمة المرور لكشف الشهر القادم. لا يوجد تطبيق UnKey لويندوز.

الأسئلة

هل أحتاج إلى تثبيت شيء على ويندوز؟

لا. يأتي Microsoft Edge وطابعة Microsoft Print to PDF مع ويندوز 10 و11.

هل تعمل مواقع «فتح قفل PDF» عبر الإنترنت بشكل أفضل؟

تؤدي العمل نفسه لكنها ترفع مستندك إلى خادم غيرك. بالنسبة للكشوف البنكية والأوراق الضريبية، الطرق دون اتصال هنا أسلم.

هل تستطيع أي من هذه إزالة كلمة مرور نسيتها؟

لا. يحتاج Edge وChrome وAcrobat وqpdf كلها إلى كلمة المرور الصحيحة. راجع الرسالة التي جاء بها ملف PDF لمعرفة الصيغة.

لماذا تتوقف الروابط عن العمل في النسخة؟

الطباعة إلى PDF تعيد بناء الصفحات، وقد يُسقط ذلك الروابط وحقول النماذج. أما Remove Security في Acrobat أو qpdf فيحافظان عليها.

قد تتغير الصيغ. إذا لم تعمل كلمة المرور، فراجع البريد الإلكتروني المرفق بالمستند أو تواصل مع الجهة المُصدِرة. UnKey غير تابع لأي بنك أو جهة عمل أو سلطة مذكورة هنا.

مترجم من الإنجليزية. عند وجود أي اختلاف، تُعتمد الصفحة الإنجليزية.

افتح القفل مرة واحدة.
