Mac پر PDF سے پاس ورڈ کیسے ہٹائیں (2026)

اکتوبر 2026 میں اپ ڈیٹ کیا گیا

Mac پر Preview سے مفت: پاس ورڈ ڈال کر کھولیں، File > Export میں اوپن پاس ورڈ نہ رکھیں؛ یا Print > Save as PDF، یا UnKey for Mac استعمال کریں۔

Mac پر آپ macOS کے ساتھ آنے والی ایپ Preview سے PDF کا پاس ورڈ مفت ہٹا سکتے ہیں۔ PDF کھولیں، پاس ورڈ ڈالیں، پھر File > Export چنیں اور ایسی نئی کاپی محفوظ کریں جس میں اوپن پاس ورڈ نہ ہو۔ آپ کو پاس ورڈ معلوم ہونا چاہیے۔ اس کے بغیر Preview فائل نہیں کھولے گا۔

طریقہ 1: Preview، File > Export

  1. PDF پر ڈبل کلک کر کے اسے Preview میں کھولیں اور پاس ورڈ ڈالیں۔
  2. File > Export چنیں اور کاپی کو نیا نام دیں، جیسے "Statement-Oct-unlocked"۔
  3. Permissions پر کلک کریں اور یقینی بنائیں کہ Require Password To Open Document منتخب نہ ہو۔ پرانے macOS ورژنز میں Export ونڈو میں اس کی جگہ Encrypt کا چیک باکس ہوتا ہے۔ اسے خالی رہنے دیں۔
  4. Save پر کلک کریں۔
  5. نئی فائل بند کر کے دوبارہ کھولیں۔ اسے پاس ورڈ مانگے بغیر کھلنا چاہیے۔

Apple کی موجودہ گائیڈ Export ونڈو، Permissions بٹن اور Require Password To Open Document آپشن بیان کرتی ہے (Apple: Password-protect a PDF in Preview on Mac)۔ اسی صفحے کے macOS Big Sur ورژن میں Apple نے صاف لکھا تھا: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide)۔

اگر PDF پر مالک (اجازتوں) کا پاس ورڈ بھی ہو اور آپ اسے جانتے ہوں تو File > Edit Permissions سے آپ اوپننگ پاس ورڈ بدل سکتے ہیں اور یہ بھی طے کر سکتے ہیں کہ کون سی سہولتوں کے لیے پاس ورڈ درکار ہے۔

طریقہ 2: Print > Save as PDF

Mac کی ہر وہ ایپ جو پرنٹ کر سکتی ہے نئی PDF بنا سکتی ہے (Apple: Save a document as a PDF on Mac):

  1. PDF کو اس کے پاس ورڈ سے کھولیں۔
  2. File > Print چنیں۔
  3. PDF پاپ اپ مینو پر کلک کریں اور Save as PDF چنیں۔
  4. Security Options پر کلک نہ کریں، کیونکہ وہیں پاس ورڈ دوبارہ لگایا جاتا ہے۔

پرنٹ کی ہوئی کاپی میں لنکس، فارم فیلڈز یا بک مارکس ضائع ہو سکتے ہیں۔ اگر دستاویز پرنٹنگ روکتی ہو تو یہ طریقہ دھندلا (غیر فعال) ہو سکتا ہے۔

طریقہ 3: Mac کے لیے UnKey

UnKey Mac پر بھی مفت ہے۔ UnKey Pro، جو ایک بار کی خریداری ہے، iPhone، iPad اور Mac پر بیچ ان لاکنگ اور دوسرے Pro ٹولز شامل کرتا ہے۔ PDF کو ونڈو پر ڈریگ کریں، پاس ورڈ ڈالیں، اور وہ بغیر پاس ورڈ کی کاپی محفوظ کر دیتا ہے۔ UnKey Pro ایک ساتھ کئی فائلیں بھی ان لاک کر سکتا ہے، جو ایک سال کی ماہانہ اسٹیٹمنٹس کے لیے کارآمد ہے جن کا پاس ورڈ ایک ہی ہو۔ UnKey آف لائن چلتا ہے، کچھ اپ لوڈ نہیں کرتا، اور صرف وہی پاس ورڈ ہٹاتا ہے جو آپ پہلے سے جانتے ہیں۔

طریقہ 4: کمانڈ لائن (تکنیکی صارفین کے لیے)

مفت اور اوپن سورس ٹول qpdf یہ Terminal میں کر سکتا ہے: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf۔ اس کی دستاویزات --decrypt کو یوں بیان کرتی ہیں کہ یہ ایسی آؤٹ پٹ فائل بناتا ہے جس میں کوئی انکرپشن نہیں ہوتی چاہے ان پٹ فائل انکرپٹڈ ہو (qpdf documentation)۔ اسے آپ کو خود انسٹال کرنا ہوگا، مثلاً Homebrew سے۔ کمانڈ لائن پر پاس ورڈ ٹائپ کرنے سے وہ آپ کی shell ہسٹری میں رہ سکتا ہے۔

اگر پھر بھی پاس ورڈ مانگے

  • ہو سکتا ہے آپ نے کاپی کے بجائے اصل فائل کھولی ہو۔ فائل کا نام دیکھیں۔
  • دوبارہ Export کریں اور Permissions میں دیکھیں کہ Require Password To Open Document بند ہے۔
  • اس کے بجائے Print > Save as PDF آزمائیں۔
  • اگر Preview پاس ورڈ رد کر دے تو کیپٹل حروف اور تاریخ کا فارمیٹ دیکھیں، اور دستاویز کے ساتھ آنے والی ای میل پڑھیں۔

اصل فائل حذف کرنے سے پہلے

بغیر پاس ورڈ کی PDF ہر اس شخص کے لیے کھل جاتی ہے جس کے پاس فائل ہو۔ اس میں گھر والوں کے ساتھ شیئر کیے گئے iCloud Drive فولڈرز اور آپ کا Mac ادھار لینے والا کوئی بھی شامل ہے۔ بغیر پاس ورڈ کی اسٹیٹمنٹس کسی نجی جگہ رکھیں۔ مزید کے لیے دیکھیں: کیا PDF پاس ورڈ ہٹانا محفوظ ہے۔

Mac پر بہت سی PDF ایک ساتھ کیسے ان لاک کروں؟

Preview ایک وقت میں ایک فائل سنبھالتا ہے۔ UnKey Pro ایک ہی پاس ورڈ والی کئی PDF بیچ میں ان لاک کر سکتا ہے، اور تکنیکی صارفین qpdf کی اسکرپٹ بنا سکتے ہیں۔ دیکھیں ہماری گائیڈ: بہت سی PDF ایک ساتھ ان لاک کرنا۔

Print > Save as PDF دھندلا کیوں ہے؟

ممکن ہے PDF پر اجازتوں کا پاس ورڈ ہو جو پرنٹنگ روکتا ہے۔ اگر آپ مالک کا پاس ورڈ جانتے ہیں تو اسے File > Edit Permissions میں ڈالیں۔ ورنہ Export والا طریقہ استعمال کریں۔
