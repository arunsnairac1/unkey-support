اپ لوڈ کی حد کے لیے اسکین شدہ PDF کا سائز کم کریں

اکتوبر 2026 میں اپ ڈیٹ کیا گیا

اسکین شدہ PDF اس لیے بھاری ہوتی ہے کہ ہر صفحہ تصویر ہوتا ہے۔ Mac پر Preview کے Reduce File Size یا iPhone پر ایکسپورٹ آپشنز سے سائز کم کریں، کم اور سادہ صفحات اسکین کریں، اور اپ لوڈ سے پہلے پاس ورڈ ہٹا دیں۔

ویزا، پاسپورٹ، امتحان اور قرض کے پورٹلز اکثر ہر فائل کے لیے چند سو کلوبائٹ یا ایک دو میگابائٹ کی حد رکھتے ہیں۔ اسکین شدہ PDF اس حد سے بہت بڑی ہو جاتی ہے کیونکہ ہر صفحہ تصویر کی شکل میں محفوظ ہوتا ہے۔ سب سے تیز حل یہ ہیں: PDF کو امیج کمپریشن کے ساتھ دوبارہ محفوظ کریں (Mac یا iPhone پر Preview یہ مفت کر دیتا ہے)، صرف ضروری صفحات اسکین کریں، اور پہلے پاس ورڈ ہٹا دیں، کیونکہ بہت سے پورٹل محفوظ فائلیں پڑھ نہیں پاتے۔

کمپریس کرنے سے پہلے

  • پورٹل کے صفحے پر درست حد اور فارمیٹ دیکھیں: زیادہ سے زیادہ سائز کتنا ہے، یہ حد ہر فائل کی ہے یا کل کی، اور PDF چاہیے یا JPEG۔ پورٹلز کے اصول مختلف ہوتے ہیں اور بدلتے رہتے ہیں، اس لیے اپ لوڈ صفحے کی بات مانیں۔
  • پاس ورڈ ہٹائیں۔ پورٹل محفوظ PDF کھول کر جانچ نہیں سکتا۔ دیکھیں: iPhone، Mac، Windows یا Android۔
  • اصل فائل سنبھال کر رکھیں۔ کمپریشن سے تصویر کا معیار گھٹتا ہے۔ اگر پورٹل دھندلی اسکین رد کر دے تو آپ کے پاس پورے معیار والی کاپی موجود ہونی چاہیے۔

Mac پر: Preview

  1. PDF کو Preview میں کھولیں اور File > Export منتخب کریں۔
  2. Quartz Filter مینو میں Reduce File Size چنیں۔
  3. نیا نام دیں اور Save پر کلک کریں۔

Apple کے مطابق کمپریس شدہ PDF کا معیار اصل سے کم ہو سکتا ہے۔ اسی Export ونڈو میں Optimize images for screen اور Save images as JPEG کے آپشنز بھی ملتے ہیں (Apple: Reduce the size of a PDF in Preview on Mac)۔ Reduce File Size سے زیادہ تحریر والی اسکین پڑھنا مشکل ہو سکتا ہے، لہٰذا اپ لوڈ سے پہلے نتیجہ کھول کر زوم کر کے دیکھ لیں۔

iPhone یا iPad پر: Preview (iOS 26 اور بعد کے ورژن)

  1. PDF کو Preview ایپ میں کھولیں۔
  2. فائل کے نام کے ساتھ والے مینو پر ٹیپ کریں، پھر Export پر ٹیپ کریں۔
  3. PDF چنیں، پھر Optimize Images for Screen اور Save Images as JPEG آن کریں۔
  4. تصدیقی بٹن دبائیں، جگہ منتخب کریں، نام بدلیں اور Save پر ٹیپ کریں۔

Apple کے مطابق Optimize Images for Screen سے چھوٹی فائل بنتی ہے (Apple: Export or compress PDFs in Preview on iPhone)۔ اگر پورٹل کو PDF کے بجائے JPEG چاہیے تو اسی اسکرین سے سائز سلائیڈر کے ساتھ JPEG ایکسپورٹ کی جا سکتی ہے۔

شروع ہی سے چھوٹی اسکین بنائیں

  • صرف مطلوبہ صفحات۔ اپ لوڈ سے پہلے فالتو صفحات حذف کریں۔ iPhone پر Preview صفحات حذف اور ترتیب دے سکتا ہے (Apple)۔
  • کیمرے کے بجائے ڈاکیومنٹ اسکینر استعمال کریں۔ Notes، Files اور Preview صفحے کو کراپ اور سیدھا کر دیتے ہیں (Apple: How to scan documents on iPhone)۔ کراپ کی ہوئی اسکین میز سمیت کھینچی گئی تصویر سے چھوٹی ہوتی ہے۔
  • اگر پورٹل اجازت دے تو تحریری دستاویزات کے لیے گرے اسکیل یا بلیک اینڈ وائٹ۔ Preview کا اسکینر ہر اسکین کے رنگ ایڈجسٹ کرنے دیتا ہے (Apple)۔ تصاویر اور مہر یا اسٹیمپ والی چیزوں کے لیے، جو افسر کو نظر آنی چاہئیں، رنگ برقرار رکھیں۔
  • ہر دستاویز کی الگ فائل۔ اگر پورٹل میں الگ الگ خانے ہیں تو سب کچھ ملا کر ایک بھاری PDF نہ بنائیں۔

عام مسائل

  • پھر بھی بہت بڑی ہے: دونوں آپشنز آن کر کے دوبارہ ایکسپورٹ کریں، یا گرے اسکیل میں دوبارہ اسکین کریں۔
  • تحریر دھندلی ہے: کمپریشن حد سے زیادہ ہو گیا۔ اصل فائل پر واپس جائیں اور صرف ایک آپشن استعمال کریں۔
  • پورٹل کہتا ہے “file is corrupt” یا “encrypted”: غالباً فائل پر اب بھی پاس ورڈ یا پابندی ہے۔ پاس ورڈ ہٹا کر دوبارہ کوشش کریں۔
  • فائل الٹا بڑی ہو گئی: جو PDF زیادہ تر اصل تحریر پر مشتمل ہوں وہ پہلے ہی چھوٹی ہوتی ہیں۔ دوبارہ محفوظ کرنے سے سائز بڑھ سکتا ہے۔ اصل فائل اپ لوڈ کریں۔
