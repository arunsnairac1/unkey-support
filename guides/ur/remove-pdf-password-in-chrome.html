Chrome میں PDF کا پاس ورڈ کیسے ہٹائیں (2026)

اکتوبر 2026 میں اپ ڈیٹ کیا گیا

اس زبان میں پڑھیں: English · العربية · বাংলা · Deutsch · Español · Filipino · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · Italiano · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · ไทย · اردو · Tiếng Việt

PDF کو Chrome میں کھول کر پاس ورڈ ڈالیں، Ctrl+P دبائیں اور منزل کے طور پر Save as PDF چن کر محفوظ کریں؛ نئی کاپی بغیر پاس ورڈ کھلتی ہے۔

Google Chrome Windows، Mac اور Linux پر مفت میں پاس ورڈ والی PDF کی بغیر پاس ورڈ کاپی محفوظ کر سکتا ہے۔ PDF کو Chrome میں کھولیں، پاس ورڈ ٹائپ کریں، Ctrl + P دبائیں (Mac پر Cmd + P)، منزل کو Save as PDF پر رکھیں اور محفوظ کریں۔ آپ کو پاس ورڈ پہلے سے معلوم ہونا چاہیے۔ اس کے بغیر Chrome فائل نہیں کھول سکتا۔

مرحلہ وار (کمپیوٹر پر)

  1. PDF کو Chrome ونڈو میں ڈریگ کریں، یا فائل پر رائٹ کلک کر کے Open with > Google Chrome چنیں۔
  2. Chrome پاس ورڈ مانگے گا۔ اسے ٹائپ کریں اور Enter دبائیں۔
  3. Windows یا Linux پر Ctrl + P دبائیں، یا Mac پر Cmd + P۔ آپ مینو سے بھی جا سکتے ہیں: File > Print۔
  4. پرنٹ ونڈو میں Destination کو Save as PDF پر سیٹ کریں۔
  5. Save پر کلک کریں۔ نئی فائل کو واضح نام دیں، جیسے Statement-Sep-2026-unlocked.pdf۔
  6. اسے بند کریں اور نئی فائل دوبارہ کھولیں۔ وہ فوراً کھل جانی چاہیے، بغیر پاس ورڈ مانگے۔

Google کا مدد صفحہ کی بورڈ شارٹ کٹس، پرنٹ ونڈو میں منزل چننے اور Save as PDF آپشن کو بیان کرتا ہے (Google: Print from Chrome)۔

Android فون پر

Android پر Chrome میں بھی یہی آپشن ہے۔ Google کے مراحل یہ ہیں: More > Share پر ٹیپ کریں، Print پر ٹیپ کریں، پھر Save as PDF پر ٹیپ کر کے فائل محفوظ کرنے کی جگہ چنیں (Google: Print from Chrome on Android)۔ آپ کے فون میں رکھی PDF کو Chrome کھولتا ہے یا نہیں، یہ Chrome کے ورژن پر منحصر ہے۔ اگر نہ کھولے تو ہماری گائیڈ دیکھیں: Android پر پاس ورڈ والی PDF کھولنا۔

اس طریقے میں آپ کیا کھوتے ہیں

پرنٹ ونڈو سے محفوظ کرنے پر اسکرین پر نظر آنے والے مواد سے بالکل نئی PDF بنتی ہے۔ پڑھنے، آرکائیو کرنے یا اسٹیٹمنٹ اپ لوڈ کرنے کے لیے یہ ٹھیک ہے۔ لیکن اصل فائل حذف کرنے سے پہلے کاپی جانچ لیں:

  • لنکس اور بک مارکس کام کرنا بند کر سکتے ہیں۔
  • فارم فیلڈز چپٹے ہو سکتے ہیں، یعنی آپ ان میں مزید ٹائپ نہیں کر سکتے۔
  • ڈیجیٹل دستخط منتقل نہیں ہوتے۔ اگر پورٹل کو دستخط شدہ اصل چاہیے تو اصل اپ لوڈ کریں۔
  • صفحے کا سائز پرنٹ سیٹنگز کے مطابق ہوتا ہے۔ More settings میں دیکھیں کہ کاغذ کا سائز اور اسکیل نے صفحات چھوٹے یا کٹے ہوئے تو نہیں کیے۔

اگر Save as PDF کام نہ کرے

  • پرنٹنگ بلاک ہے۔ کچھ PDF پر اجازتوں کا پاس ورڈ ہوتا ہے جو پرنٹنگ روکتا ہے۔ اجازتوں کا پاس ورڈ اوپن پاس ورڈ سے الگ ہوتا ہے۔ دیکھیں PDF پرنٹنگ اور کاپی کی پابندیوں کی وضاحت۔
  • Chrome پاس ورڈ رد کرتا ہے۔ کیپٹل حروف، تاریخ کا فارمیٹ اور بینک کے ریکارڈ میں موجود تفصیلات دیکھیں۔ دیکھیں PDF پاس ورڈ کیوں کام نہیں کر رہا۔
  • فائل کسی اور ایپ میں کھل گئی۔ کچھ کمپیوٹرز PDF کو بطور ڈیفالٹ کسی دوسرے ریڈر میں کھولتے ہیں۔ اس کے بجائے فائل کو Chrome ٹیب میں ڈریگ کریں۔

پاس ورڈ ہٹانے کے دوسرے طریقے

Windows پر Microsoft Edge بھی ایسے ہی کام کرتا ہے (دیکھیں Windows پر PDF پاس ورڈ ہٹانا)۔ Mac پر Preview بغیر پاس ورڈ کی کاپی ایکسپورٹ کر سکتا ہے (Mac گائیڈ)۔ iPhone، iPad اور Mac پر UnKey آف لائن بغیر پاس ورڈ کی کاپی محفوظ کرتا ہے اور تحریر، لنکس اور صفحات جوں کے توں رکھتا ہے، کیونکہ وہ فائل کو دوبارہ پرنٹ کرنے کے بجائے انکرپشن ہٹاتا ہے۔ Chrome کی طرح وہ بھی صرف اسی پاس ورڈ کے ساتھ کام کرتا ہے جو آپ پہلے سے جانتے ہیں۔

سوالات

کیا ایسا کرنے پر Chrome میری PDF اپ لوڈ کرتا ہے؟

نہیں۔ اپنے کمپیوٹر سے PDF کھول کر Save as PDF سے محفوظ کرنے کا عمل آپ کے کمپیوٹر کے براؤزر ہی میں ہوتا ہے۔ الگ “Save to Google Drive” منزل صرف تب چنیں جب آپ Drive میں کاپی چاہتے ہوں۔

کیا Chrome وہ پاس ورڈ ہٹا سکتا ہے جو مجھے معلوم نہیں؟

نہیں۔ Chrome کچھ دکھانے سے پہلے پاس ورڈ مانگتا ہے۔ اگر آپ اسے کھو بیٹھے ہیں تو دیکھیں: PDF کا پاس ورڈ بھول جائیں تو کیا کریں۔

محفوظ کی ہوئی کاپی اصل سے مختلف کیوں ہے؟

Save as PDF صفحات کو نئی فائل میں پرنٹ کرتا ہے، اس لیے لنکس، فارم فیلڈز اور دستخط برقرار نہ رہ سکیں۔ تحریر اور ترتیب عموماً ویسی ہی نظر آتی ہے۔

کیا یہ جائز ہے؟

اپنی دستاویزات، جیسے اپنی بینک اسٹیٹمنٹ کے لیے، جی ہاں۔ ایسی فائلوں کا تحفظ نہ ہٹائیں جنہیں آزادانہ کھولنے کا آپ کو حق نہیں۔
