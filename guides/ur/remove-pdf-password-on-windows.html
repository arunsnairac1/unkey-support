Windows پر PDF کا پاس ورڈ کیسے ہٹائیں (2026)

اکتوبر 2026 میں اپ ڈیٹ کیا گیا

Windows پر Edge یا Chrome میں PDF کھول کر پاس ورڈ ڈالیں، Ctrl+P دبائیں اور Save as PDF یا Microsoft Print to PDF سے بغیر پاس ورڈ کی کاپی محفوظ کریں۔

Windows 10 اور 11 پر آپ اپنے موجودہ براؤزر سے مفت میں PDF کا پاس ورڈ ہٹا سکتے ہیں۔ PDF کو Microsoft Edge یا Google Chrome میں کھولیں، پاس ورڈ ٹائپ کریں، Ctrl + P دبائیں، پرنٹر کے طور پر Save as PDF (یا Microsoft Print to PDF) چنیں اور محفوظ کریں۔ نئی فائل بغیر پاس ورڈ کھلتی ہے۔ پہلے آپ کو پاس ورڈ معلوم ہونا چاہیے۔

طریقہ 1: Microsoft Edge (بلٹ اِن)

  1. File Explorer میں PDF پر رائٹ کلک کریں اور Open with > Microsoft Edge چنیں۔
  2. Edge مانگے تو پاس ورڈ ٹائپ کریں۔
  3. Ctrl + P دبائیں، یا More مینو (تین نقطے) کھول کر Print چنیں۔
  4. Printer کے تحت Save as PDF یا Microsoft Print to PDF چنیں۔
  5. Save (یا Print) پر کلک کریں، فولڈر چنیں اور کاپی کو نیا نام دیں۔
  6. نئی فائل کھول کر دیکھیں کہ وہ اب پاس ورڈ نہیں مانگتی۔

Microsoft کی اپنی PDF ریڈر کی گائیڈ Edge والا راستہ دکھاتی ہے: More مینو کے تحت Print ڈھونڈیں، آپشنز چنیں، پھر پرنٹ کریں (Microsoft: View, print, and edit PDFs in a PDF reader)۔ Microsoft Print to PDF ایک پرنٹر ہے جو Windows کے ساتھ آتا ہے۔ اگر فہرست میں نہ ہو تو Microsoft کے مطابق اسے Windows Optional Features میں دوبارہ آن کیا جا سکتا ہے (Microsoft: KB5058499 known issue)۔

طریقہ 2: Google Chrome

اگر آپ Chrome استعمال کرتے ہیں تو مراحل تقریباً وہی ہیں: PDF کو Chrome میں کھولیں، پاس ورڈ ڈالیں، Ctrl + P دبائیں، Destination کو Save as PDF پر رکھیں، اور Save پر کلک کریں (Google: Print from Chrome)۔ مزید تفصیل ہماری Chrome گائیڈ میں ہے۔

طریقہ 3: Adobe Acrobat Pro یا Standard (ادا شدہ)

ادا شدہ Acrobat فائل کو دوبارہ پرنٹ کرنے کے بجائے خود انکرپشن ہٹاتا ہے، اس لیے لنکس اور فارم فیلڈز برقرار رہتے ہیں۔ Adobe دو راستے بیان کرتا ہے (Adobe: Remove passwords from PDFs):

  • Protect ٹولز: PDF کھولیں، Protect ٹولز میں جائیں اور Remove Security چنیں۔ اگر فائل پر صرف اوپن پاس ورڈ ہے تو OK سے تصدیق کریں۔ اگر اجازتوں کا پاس ورڈ بھی ہے تو Acrobat پہلے وہ پاس ورڈ مانگتا ہے۔
  • Security سیٹنگز: دستاویز کی سکیورٹی پراپرٹیز کھولیں، Security ٹیب میں جائیں، Change Settings چنیں، پاس ورڈ آپشنز ہٹائیں اور محفوظ کریں۔

Adobe کے مینو ورژنز کے ساتھ جگہ بدلتے ہیں، اس لیے اگر یہ نام نہ نظر آئیں تو Acrobat کی ٹول سرچ میں “Remove Security” تلاش کریں۔ مفت Acrobat Reader محفوظ PDF کھول سکتا ہے مگر سکیورٹی ہٹانے کا ٹول نہیں ہے۔ اس کے بجائے طریقہ 1 یا 2 استعمال کریں۔

طریقہ 4: qpdf (تکنیکی صارفین)

مفت اور اوپن سورس ٹول qpdf Windows پر چلتا ہے۔ qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf بغیر انکرپشن کی کاپی لکھ دیتا ہے (qpdf documentation)۔ پاس ورڈ آپ کی کمانڈ ہسٹری میں محفوظ ہو سکتا ہے، اس لیے مشترک PC پر بعد میں اسے صاف کر دیں۔

جانچنے کی باتیں

  • Print دھندلا ہے؟ ہو سکتا ہے PDF پر اجازتوں کا پاس ورڈ ہو جو پرنٹنگ روکتا ہے۔ دیکھیں پرنٹنگ اور کاپی کی پابندیاں۔
  • پاس ورڈ رد ہو رہا ہے؟ Caps Lock، تاریخ کا فارمیٹ اور بینک کے ریکارڈ کی تفصیلات دیکھیں۔ دیکھیں PDF پاس ورڈ کیوں کام نہیں کر رہا۔
  • مشترک یا دفتر کا PC؟ بغیر پاس ورڈ کی کاپی ہر اس شخص کو کھل جاتی ہے جسے مل جائے۔ اسے نجی فولڈر میں محفوظ کریں اور Downloads سے حذف کر دیں۔

اگر آپ کے پاس iPhone، iPad یا Mac بھی ہے تو UnKey ان ڈیوائسز پر آف لائن پاس ورڈ ہٹاتا ہے اور اگلے مہینے کی اسٹیٹمنٹ کے لیے پاس ورڈ محفوظ کر سکتا ہے۔ Windows کے لیے UnKey ایپ نہیں ہے۔

سوالات

کیا Windows پر مجھے کچھ انسٹال کرنا ہوگا؟

نہیں۔ Microsoft Edge اور Microsoft Print to PDF پرنٹر Windows 10 اور 11 کے ساتھ آتے ہیں۔

کیا آن لائن “unlock PDF” سائٹس بہتر کام کریں گی؟

وہ یہی کام کرتی ہیں مگر آپ کی دستاویز کسی اور کے سرور پر اپ لوڈ کرتی ہیں۔ بینک اسٹیٹمنٹس اور ٹیکس کاغذات کے لیے یہاں بیان کیے گئے آف لائن طریقے زیادہ محفوظ ہیں۔

کیا ان میں سے کوئی بھولا ہوا پاس ورڈ ہٹا سکتا ہے؟

نہیں۔ Edge، Chrome، Acrobat اور qpdf سب کو درست پاس ورڈ چاہیے۔ فارمیٹ کے لیے PDF کے ساتھ آنے والی ای میل دیکھیں۔

کاپی میں لنکس کام کیوں نہیں کرتے؟

PDF میں پرنٹ کرنا صفحات کو دوبارہ بناتا ہے، جس سے لنکس اور فارم فیلڈز ضائع ہو سکتے ہیں۔ Acrobat کا Remove Security یا qpdf انہیں برقرار رکھتے ہیں۔
