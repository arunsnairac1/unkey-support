Come togliere la password a un PDF su Windows (2026)

Aggiornato a ottobre 2026

Apri il PDF in Microsoft Edge o Chrome con la sua password, premi Ctrl+P, scegli Salva come PDF (o Microsoft Print to PDF) e salva una nuova copia; Acrobat a pagamento può togliere la protezione direttamente.

Su Windows 10 e 11 puoi togliere gratis la password a un PDF con il browser che hai già. Apri il PDF in Microsoft Edge o Google Chrome, digita la password, premi Ctrl + P, scegli Salva come PDF (o Microsoft Print to PDF) come stampante e salva. Il nuovo file si apre senza password. Prima devi conoscere la password.

Metodo 1: Microsoft Edge (già incluso)

  1. Fai clic destro sul PDF in Esplora file e scegli Apri con > Microsoft Edge.
  2. Digita la password quando Edge la chiede.
  3. Premi Ctrl + P, oppure apri il menu Altro (i tre puntini) e scegli Stampa.
  4. In Stampante scegli Salva come PDF o Microsoft Print to PDF.
  5. Clicca su Salva (o Stampa), scegli una cartella e dai alla copia un nuovo nome.
  6. Apri il nuovo file per verificare che non chieda più la password.

La guida di Microsoft al suo lettore PDF integrato mostra il percorso in Edge: trova Stampa nel menu Altro, scegli le opzioni, poi stampa (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF è una stampante inclusa in Windows. Se manca dall'elenco, Microsoft dice che si può riattivare da Funzionalità facoltative di Windows (Microsoft: KB5058499 known issue).

Metodo 2: Google Chrome

Se usi Chrome, i passaggi sono quasi uguali: apri il PDF in Chrome, inserisci la password, premi Ctrl + P, imposta Destinazione su Salva come PDF e clicca su Salva (Google: Print from Chrome). Trovi più dettagli nella nostra guida per Chrome.

Metodo 3: Adobe Acrobat Pro o Standard (a pagamento)

Acrobat a pagamento rimuove la cifratura stessa invece di ristampare il file, quindi link e campi dei moduli restano intatti. Adobe documenta due strade (Adobe: Remove passwords from PDFs):

  • Strumenti di protezione: apri il PDF, vai agli strumenti Proteggi e scegli Rimuovi sicurezza. Se il file ha solo una password di apertura, conferma con OK. Se ha anche una password dei permessi, Acrobat chiede prima quella password.
  • Impostazioni di sicurezza: apri le proprietà di sicurezza del documento, vai alla scheda Sicurezza, scegli Cambia impostazioni, deseleziona le opzioni di password e salva.

I menu di Adobe cambiano tra le versioni, quindi se non vedi questi nomi esatti, cerca “Rimuovi sicurezza” nella ricerca strumenti di Acrobat. Acrobat Reader gratuito può aprire i PDF protetti ma non è lo strumento per toglierne la sicurezza. Usa invece il Metodo 1 o 2.

Metodo 4: qpdf (utenti esperti)

Lo strumento gratuito e open source qpdf funziona su Windows. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf scrive una copia senza cifratura (documentazione di qpdf). La password può restare nella cronologia dei comandi, quindi cancellala dopo se usi un PC condiviso.

Cose da controllare

  • Stampa disattivata? Il PDF potrebbe avere una password dei permessi che blocca la stampa. Leggi restrizioni di stampa e copia.
  • Password rifiutata? Controlla il Blocco maiuscole, il formato della data e i dati che ha la banca. Leggi perché la password di un PDF non funziona.
  • PC condiviso o d'ufficio? La copia sbloccata si apre per chiunque la trovi. Salvala in una cartella privata ed eliminala da Download.

Se hai anche un iPhone, un iPad o un Mac, UnKey toglie la password offline su quei dispositivi e può salvare la password per l'estratto del mese dopo. Non esiste un'app UnKey per Windows.

Domande

Devo installare qualcosa su Windows?

No. Microsoft Edge e la stampante Microsoft Print to PDF sono incluse in Windows 10 e 11.

I siti online per “sbloccare PDF” funzionano meglio?

Fanno lo stesso lavoro ma caricano il tuo documento sul server di qualcun altro. Per estratti conto e documenti fiscali, i metodi offline qui descritti sono più sicuri.

Qualcuno di questi può togliere una password che ho dimenticato?

No. Edge, Chrome, Acrobat e qpdf richiedono tutti la password giusta. Cerca il formato nell'email con cui è arrivato il PDF.

Perché nella copia i link smettono di funzionare?

Stampare in PDF ricostruisce le pagine e può far perdere link e campi dei moduli. Rimuovi sicurezza di Acrobat o qpdf li mantengono.

Sbloccalo una volta.

UnKey rimuove la password dai PDF che puoi già aprire, su iPhone, iPad e Mac. Offline, senza caricare nulla. Salva la password una volta e Face ID aprirà l’estratto conto del mese prossimo.
