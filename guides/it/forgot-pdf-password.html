Hai dimenticato la password del PDF? Cosa puoi fare (2026)

Una password PDF sconosciuta non si può rimuovere in modo legittimo: cerca il formato nell'email originale, scarica di nuovo il documento o chiedi a chi te l'ha inviato.

Se hai dimenticato la password di un PDF, nessuna app onesta può semplicemente toglierla. Vale anche per Anteprima, Adobe Acrobat e UnKey. La soluzione pratica è scoprire quale dovrebbe essere la password, oppure ottenere una copia nuova del documento. Per gli estratti conto di banche e carte, la password è quasi sempre un formato costruito con i tuoi dati, quindi di solito si riesce a ricavarla.

Perché le app non possono semplicemente toglierla

La password di apertura di un PDF non è un lucchetto messo sopra al file. La password serve a cifrare il contenuto. Senza di essa, l'app ha solo dati illeggibili. Per questo le istruzioni di Adobe per sbloccare i PDF partono dall'apertura del file e, per le password dei permessi, dall'inserimento della password (Adobe: How to remove a PDF password). Anche Anteprima di Apple chiede la password prima di mostrare qualsiasi cosa. Gli strumenti che rimuovono le password, UnKey compreso, hanno bisogno prima della password giusta.

Passo 1: leggi l'email con cui è arrivato il PDF

Banche, emittenti di carte, assicurazioni, fondi comuni e portali fiscali spiegano quasi sempre la password nell'email o nell'SMS che accompagna il documento. Cerca nella posta il mittente e trova una frase come “la password è…” o “per aprire questo estratto conto inserisci…”. Di solito descrive uno schema, ad esempio le prime quattro lettere del tuo nome in maiuscolo seguite dalla data di nascita come DDMM.

Passo 2: prova il formato con i tuoi dati come li ha l'emittente

  • Nome: usa il nome esattamente come appare sul conto, che può includere un'iniziale o un'altra grafia.
  • Maiuscole: le password dei PDF distinguono maiuscole e minuscole.
  • Data di nascita: DDMMYYYY, DDMMYY e DDMM non sono la stessa cosa. Controlla quale chiede l'emittente.
  • Numero di cellulare: usa il numero registrato su quel conto, che potrebbe essere uno vecchio.
  • ID cliente o numero di conto: alcuni emittenti usano questi dati al posto di quelli personali.

Esempio: supponiamo che l'email di un estratto conto dica a Priya Sharma (nata il 15 maggio 1990) che la password è “prime quattro lettere del nome in maiuscolo + DDMM”. La sua password sarebbe PRIY1505. Questo esempio è inventato. Segui sempre il formato che ti indica il tuo emittente.

Passo 3: scarica di nuovo il documento

Se l'email non c'è più, accedi al sito o all'app dell'emittente e scarica lì l'estratto conto. Molte app mostrano gli estratti senza password, oppure indicano il formato della password nella schermata di download. Un nuovo download sostituisce anche un file eventualmente danneggiato.

Passo 4: chiedi a chi te l'ha inviato

Chiama il servizio clienti o usa la messaggistica sicura dell'emittente e chiedi come si formano le password degli estratti conto. Non ti leggeranno la password, ma ti diranno il formato e quali dati hanno in archivio. Per un PDF ricevuto da una persona, come un commercialista o l'ufficio del personale del datore di lavoro, basta chiederglielo.

Perché i “cracker di password PDF” sono una cattiva idea

  • Spesso non funzionano. I PDF moderni usano una cifratura forte, e la documentazione di qpdf consiglia la cifratura a 256 bit per i file nuovi (qpdf). Indovinare una password lunga può richiedere molto più tempo che chiamare la banca.
  • Rischio malware. I download gratuiti di “recupero password” sono un modo comune per far entrare software indesiderato nel computer.
  • Il tuo file lascia il dispositivo. I cracker online richiedono di caricare l'estratto conto, con i dati del tuo conto, sul server di qualcun altro.
  • Potrebbe non essere tuo da aprire. Aprire senza permesso il documento protetto di un altro può essere illegale, qualunque strumento si usi.

Quando hai la password

Salvala in un posto sicuro, come l'app Password di Apple o un'app che la tiene nel Portachiavi del dispositivo. Poi togli la password dalla tua copia, così non dovrai cercarla di nuovo. Le nostre guide per iPhone e Mac spiegano i metodi gratuiti integrati e UnKey.

Domande

UnKey può recuperare una password PDF dimenticata?

No. UnKey rimuove solo le password che già conosci. Non le indovina, non le viola e non le recupera.

La mia banca mi dirà la password dell'estratto conto?

Di solito spiegano il formato, cioè quali parti del nome, della data di nascita o del numero di cellulare usa, invece di leggerti la password.

Esiste una password universale per gli estratti conto?

No. Ogni estratto è protetto da una password costruita con i tuoi dati e non esiste un codice valido per tutti.

I servizi online per togliere la password sono sicuri se l'ho dimenticata?

Ti fanno caricare un documento riservato e spesso non riescono comunque ad aprire i file con cifratura forte. Ottenere il formato dall'emittente è più rapido e sicuro.
