Come salvare in modo sicuro le password dei PDF su iPhone

Aggiornato a ottobre 2026

Salva le password dei PDF nell'app Password di Apple, in una nota bloccata o in un'app che le tiene nel Portachiavi dietro Face ID, mai in una nota normale.

I posti più sicuri per le password dei PDF su iPhone sono l'app Password di Apple, una nota bloccata o un'app che le tiene nel Portachiavi dell'iPhone dietro Face ID o Touch ID. Una nota normale o una "nota per me" su WhatsApp non è un buon posto, perché chiunque prenda in mano il tuo telefono sbloccato può leggerla.

Perché non una nota normale o una chat?

  • Nessun blocco in più. Una nota normale si apre appena il telefono è sbloccato.
  • Compare nella ricerca. Scrivere "password" nella ricerca dell'iPhone può farla comparire.
  • Si diffonde. Le note in Gmail o in altri account sincronizzati, i backup delle chat e gli screenshot finiscono in più posti di quanto pensi.
  • Le password stanno accanto ai file. Se i tuoi estratti conto e le loro password sono nella stessa chat, la password del PDF non protegge nulla.

Opzione 1: l'app Password di Apple

L'app Password conserva le voci in forma cifrata, e il Portachiavi iCloud le tiene aggiornate sui tuoi dispositivi approvati (Apple: View your passwords). È pensata per gli accessi ai siti web, ma puoi aggiungere una voce per un documento:

  1. Apri Password, tocca Tutte, poi tocca il pulsante per aggiungere (Apple: Create a password).
  2. Nel campo sito web o app scrivi qualcosa come "PDF estratto conto", aggiungi un'etichetta come nome utente e digita la password del PDF.
  3. Salva. Più tardi tocca Modifica > Note per aggiungere dettagli come "formato: prime 4 lettere del nome + DDMM". Apple dice che qui puoi conservare in modo sicuro note come PIN e domande di sicurezza.

Salvare il formato invece della password è un trucco utile per gli estratti che usano i tuoi dati. L'estratto dell'anno prossimo seguirà la stessa regola.

Opzione 2: una nota bloccata

In Note puoi bloccare una nota con il codice del dispositivo o con una password a parte e aprirla con Face ID o Touch ID (Apple: Lock your notes on iPhone). Da sapere:

  • Puoi bloccare solo le note salvate sul dispositivo o in iCloud, non quelle sincronizzate con Gmail o altri account.
  • Non puoi bloccare una nota con un PDF allegato, quindi tieni la nota con la password separata dal file.
  • Il titolo della nota resta visibile nell'elenco, quindi dagli un titolo neutro.
  • Se usi una password personalizzata per Note e la dimentichi, Apple dice di non poterti aiutare a rientrare in quelle note.

Opzione 3: salvarla nell'app che apre il PDF

UnKey può salvare la password quando sblocchi un estratto, così il PDF del mese dopo con lo stesso formato si apre con Face ID o Touch ID. Le password salvate restano nel Portachiavi dell'iPhone, su quel dispositivo. Non vengono caricate da nessuna parte. Essendo solo sul dispositivo, non ti seguono su un telefono nuovo, quindi tieni una copia di ciò che è importante nell'app Password.

Buone pratiche

  • Usa un codice del dispositivo robusto. Face ID è sicuro quanto il codice che c'è dietro.
  • Non fare screenshot delle password. Gli screenshot si sincronizzano con Foto e vengono condivisi per sbaglio.
  • Quando condividi un PDF protetto, invia la password in un altro modo, ad esempio per telefono.
  • Elimina le voci che non ti servono più. In Password apri la voce, tocca Modifica, poi Elimina.

Domande

Posso salvare la password di un PDF nell'app Password dell'iPhone?

Sì. Aggiungi una nuova voce con un'etichetta descrittiva e la password, e usa il campo Note per il formato. Apple cifra queste voci e le sincronizza con il Portachiavi iCloud se l'hai attivato.

Una nota bloccata è sicura per le password dei PDF?

Sì, purché la nota sia salvata in iCloud o sul dispositivo e sia bloccata. Non puoi bloccare una nota con un PDF allegato, quindi tienili separati.

UnKey carica le mie password salvate?

No. UnKey tiene le password salvate nel Portachiavi del dispositivo dietro Face ID o Touch ID, e restano su quel dispositivo.

Cosa succede alle password salvate di UnKey se cambio telefono?

Sono salvate sul dispositivo, quindi preparati a reinserirle sul telefono nuovo. Tenere una copia di quelle importanti nell'app Password aiuta.

Fonti

  • Apple – Create a password for a website or app on iPhone
  • Apple – Lock your notes on iPhone

I formati possono cambiare. Se una password non funziona, controlla l’email che accompagnava il documento o contatta l’emittente. UnKey non è affiliata a nessuna banca, datore di lavoro o ente citato qui.

Sbloccalo una volta.

UnKey rimuove la password dai PDF che puoi già aprire, su iPhone, iPad e Mac. Offline, senza caricare nulla. Salva la password una volta e Face ID aprirà l’estratto conto del mese prossimo.
