Come togliere la password a un PDF su Mac (2026)

Aggiornato a ottobre 2026

Apri il PDF in Anteprima con la sua password, scegli File > Esporta, assicurati che non sia impostata una password di apertura e salva una nuova copia.

Su Mac puoi togliere gratis la password a un PDF con Anteprima, l'app inclusa in macOS. Apri il PDF, inserisci la password, poi scegli File > Esporta e salva una nuova copia senza password di apertura. Devi conoscere la password: Anteprima non apre il file senza.

Metodo 1: Anteprima, File > Esporta

  1. Fai doppio clic sul PDF per aprirlo in Anteprima e inserisci la password.
  2. Scegli File > Esporta e dai alla copia un nuovo nome, ad esempio "Estratto-ott-sbloccato".
  3. Clicca su Permessi e assicurati che Richiedi password per aprire il documento non sia selezionato. Nelle versioni più vecchie di macOS la finestra Esporta ha invece una casella Codifica. Lasciala deselezionata.
  4. Clicca su Salva.
  5. Chiudi il nuovo file e riaprilo. Dovrebbe aprirsi senza chiedere la password.

La guida attuale di Apple descrive la finestra Esporta, il pulsante Permessi e l'opzione Richiedi password per aprire il documento (Apple: Password-protect a PDF in Preview on Mac). La versione per macOS Big Sur della stessa pagina lo diceva chiaramente: "Per togliere la password a un PDF che hai cifrato, apri il PDF ed esportalo di nuovo, questa volta disattivando l'opzione di cifratura" (Apple, guida di macOS Big Sur).

Se il PDF ha anche una password del proprietario (dei permessi) e la conosci, File > Modifica permessi ti permette di cambiare la password di apertura e quali funzioni richiedono una password.

Metodo 2: Stampa > Salva come PDF

Qualsiasi app del Mac che può stampare può creare un PDF nuovo (Apple: Save a document as a PDF on Mac):

  1. Apri il PDF con la sua password.
  2. Scegli File > Stampa.
  3. Clicca sul menu a comparsa PDF e scegli Salva come PDF.
  4. Non cliccare su Opzioni di sicurezza, perché è lì che si aggiunge di nuovo una password.

La copia stampata può perdere link, campi dei moduli o segnalibri. Se il documento blocca la stampa, questo metodo può essere disattivato.

Metodo 3: UnKey per Mac

UnKey è gratis anche su Mac. UnKey Pro, un acquisto una tantum, aggiunge lo sblocco in blocco e gli altri strumenti Pro su iPhone, iPad e Mac. Trascina un PDF sulla finestra, inserisci la password e salva una copia sbloccata. Metodo 4: riga di comando (per utenti esperti)

Lo strumento gratuito e open source qpdf può farlo nel Terminale: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. La sua documentazione descrive --decrypt come la creazione di "un file di output senza cifratura anche se il file di input è cifrato" (documentazione di qpdf). Lo installi tu, ad esempio con Homebrew. Digitare una password nella riga di comando può lasciarla nella cronologia della shell.

Se chiede ancora la password

  • Forse hai aperto l'originale invece della copia. Controlla il nome del file.
  • Esporta di nuovo e verifica che Richiedi password per aprire il documento sia disattivato in Permessi.
  • Prova invece Stampa > Salva come PDF.
  • Se Anteprima rifiuta la password, controlla le maiuscole e il formato della data, e leggi l'email con cui è arrivato il documento.

Prima di eliminare l'originale

Un PDF sbloccato si apre per chiunque abbia il file. Vale anche per le cartelle di iCloud Drive condivise con la famiglia e per chiunque ti prenda in prestito il Mac. Tieni gli estratti sbloccati in un posto privato. Per saperne di più, leggi se è sicuro togliere la password a un PDF.

Domande

Anteprima è davvero gratis?

Sì. Anteprima è inclusa in ogni Mac e, dopo che hai inserito la password, può esportare un PDF senza password di apertura.

Anteprima può togliere una password che non conosco?

No. Anteprima chiede la password prima di aprire il file e non esiste un modo legittimo per aggirarla.

Come sblocco molti PDF insieme su Mac?

Anteprima gestisce un file alla volta. UnKey Pro può sbloccare in blocco più PDF che condividono una password, e gli utenti esperti possono usare qpdf in uno script. Leggi la nostra guida per sbloccare molti PDF insieme.

Perché Stampa > Salva come PDF è disattivato?

Il PDF potrebbe avere una password dei permessi che blocca la stampa. Se conosci la password del proprietario, inseriscila in File > Modifica permessi. Altrimenti usa il metodo Esporta.
