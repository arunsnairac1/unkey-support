Come togliere la password a un PDF con Chrome (2026)

Aggiornato a ottobre 2026

Apri il PDF in Chrome con la sua password, premi Ctrl+P o Cmd+P, imposta la destinazione su Salva come PDF e salva una nuova copia senza password.

Google Chrome può salvare gratis una copia senza password di un PDF protetto, su Windows, Mac e Linux. Apri il PDF in Chrome, digita la password, premi Ctrl + P (Cmd + P su Mac), imposta la destinazione su Salva come PDF e salva. Devi già conoscere la password: Chrome non apre il file senza.

Passo per passo (computer)

  1. Trascina il PDF in una finestra di Chrome, oppure fai clic destro sul file e scegli Apri con > Google Chrome.
  2. Chrome chiede la password. Digitala e premi Invio.
  3. Premi Ctrl + P su Windows o Linux, oppure Cmd + P su Mac. Puoi usare anche il menu: File > Stampa.
  4. Nella finestra di stampa imposta Destinazione su Salva come PDF.
  5. Clicca su Salva. Dai al nuovo file un nome chiaro, come Statement-Sep-2026-unlocked.pdf.
  6. Chiudilo e riapri il nuovo file. Dovrebbe aprirsi subito, senza chiedere la password.

La pagina di aiuto di Google descrive le scorciatoie da tastiera, la scelta della destinazione nella finestra di stampa e l'opzione Salva come PDF (Google: Print from Chrome).

Su un telefono Android

Chrome su Android ha la stessa opzione. I passaggi di Google sono: tocca Altro > Condividi, tocca Stampa, poi tocca Salva come PDF e scegli dove salvare il file (Google: Print from Chrome on Android). Se Chrome apre un PDF salvato sul telefono dipende dalla versione di Chrome. In caso contrario, leggi la nostra guida per aprire un PDF protetto da password su Android.

Cosa perdi con questo metodo

Salvare dalla finestra di stampa crea un PDF del tutto nuovo a partire da ciò che c'è sullo schermo. Va bene per leggere, archiviare o caricare un estratto conto. Ma controlla la copia prima di eliminare l'originale:

  • Link e segnalibri potrebbero smettere di funzionare.
  • I campi dei moduli potrebbero essere appiattiti, quindi non potrai più scriverci.
  • Le firme digitali non vengono mantenute. Se un portale richiede l'originale firmato, carica l'originale.
  • Il formato pagina segue le impostazioni di stampa. In Altre impostazioni controlla che formato carta e scala non abbiano rimpicciolito o tagliato le pagine.

Se Salva come PDF non funziona

  • La stampa è bloccata. Alcuni PDF hanno una password dei permessi che impedisce la stampa. Una password dei permessi è diversa dalla password di apertura. Leggi le restrizioni di stampa e copia dei PDF spiegate.
  • Chrome rifiuta la password. Controlla le maiuscole, il formato della data e i dati che la banca ha in archivio. Leggi perché la password di un PDF non funziona.
  • Il file si è aperto in un'altra app. Alcuni computer aprono i PDF di default in un altro lettore. Trascina invece il file in una scheda di Chrome.

Altri modi per togliere la password

Microsoft Edge funziona allo stesso modo su Windows (vedi togliere la password a un PDF su Windows). Su Mac, Anteprima può esportare una copia senza password (guida per Mac). Su iPhone, iPad e Mac, UnKey salva una copia sbloccata offline e mantiene testo, link e pagine com'erano, perché rimuove la cifratura invece di ristampare il file. Come Chrome, funziona solo con una password che già conosci.

Domande

Chrome carica il mio PDF quando faccio così?

No. Aprire un file PDF dal tuo computer e salvarlo con Salva come PDF avviene nel browser sul tuo computer. Usa la destinazione separata “Salva su Google Drive” solo se vuoi una copia su Drive.

Chrome può togliere una password che non conosco?

No. Chrome chiede la password prima di mostrare qualsiasi cosa. Se l'hai persa, leggi cosa fare se hai dimenticato la password di un PDF.

Perché la copia salvata è diversa dall'originale?

Salva come PDF stampa le pagine in un nuovo file, quindi link, campi dei moduli e firme potrebbero non sopravvivere. Testo e impaginazione di solito sembrano uguali.

È consentito?

Per i tuoi documenti, come il tuo estratto conto, sì. Non togliere la protezione a file che non hai il diritto di aprire liberamente.

Sbloccalo una volta.

UnKey rimuove la password dai PDF che puoi già aprire, su iPhone, iPad e Mac. Offline, senza caricare nulla. Salva la password una volta e Face ID aprirà l’estratto conto del mese prossimo.
