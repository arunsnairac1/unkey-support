Come sbloccare tanti PDF in una volta (estratti mensili)

Aggiornato a ottobre 2026

Anteprima gestisce un PDF alla volta; per sbloccare molti estratti con la stessa password usa uno strumento in blocco come UnKey Pro o uno script qpdf.

Se hai una pila di estratti conto, diciamo dodici mesi della stessa banca, che usano tutti la stessa password, non devi sbloccarli uno per uno. Gli strumenti integrati come Anteprima lavorano un file alla volta. Uno strumento in blocco come UnKey Pro, o un breve script qpdf su Mac, può farli tutti insieme. La password devi comunque conoscerla.

Perché lo sblocco in blocco aiuta

La maggior parte degli emittenti protegge ogni estratto con lo stesso formato di password basato sui tuoi dati. Quindi la password di ottobre di solito apre anche da gennaio a settembre. È qui che uno strumento in blocco fa risparmiare tempo, tipicamente nel periodo delle tasse, per una richiesta di prestito o quando consegni un anno di estratti al commercialista.

Opzione gratuita: Anteprima su Mac, uno alla volta

Anteprima può aprire più PDF insieme, ma togliere la password è un lavoro file per file. Per ogni PDF inserisci la password, scegli File > Esporta, controlla che Richiedi password per aprire il documento sia disattivato in Permessi e salva (Apple: Password-protect a PDF in Preview). Per tre o quattro file va bene. Per trenta diventa noioso ed è facile dimenticarne uno.

Su iPhone e iPad anche i metodi gratuiti (l'impostazione Blocca di Anteprima o il trucco Stampa in PDF) funzionano un file alla volta.

UnKey Pro: sblocco in blocco su iPhone, iPad e Mac

  1. Metti gli estratti in un'unica cartella in File o nel Finder.
  2. In UnKey usa lo sblocco in blocco e seleziona i file. Su Mac puoi trascinarli sulla finestra.
  3. Inserisci la password, oppure lascia che UnKey usi una che hai salvato prima con Face ID o Touch ID.
  4. UnKey salva una copia sbloccata di ogni file. Controlla i risultati e sblocca a parte i file che usano una password diversa.

Lo sblocco in blocco fa parte di UnKey Pro, un acquisto una tantum (₹249 in India, $5.99 negli Stati Uniti). Pro aggiunge anche scansione, firma e compilazione, blocco con password, compressione e oscuramento, e un solo acquisto copre iPhone, iPad e Mac. Sbloccare singoli file è gratis. Tutto avviene sul tuo dispositivo e nulla viene caricato.

Opzione gratuita per utenti esperti: qpdf

qpdf è uno strumento gratuito e open source da riga di comando. Con --password e --decrypt scrive una copia non cifrata di un file (documentazione di qpdf). Nel Terminale, un ciclo su una cartella si presenta così:

for f in *.pdf; do qpdf --decrypt --password="$PDFPASS" "$f" "unlocked-$f"; done

Imposta prima PDFPASS, possibilmente senza lasciarla nella cronologia della shell. I file che usano una password diversa daranno un errore e non verranno saltati in silenzio. qpdf lo installi tu, ad esempio con Homebrew.

Quando i file non hanno la stessa password

  • Conti diversi: un conto di risparmio e una carta di credito della stessa banca spesso usano formati diversi. Dividili in cartelle separate.
  • Cambi di formato: gli emittenti a volte cambiano formato. Gli estratti più vecchi possono richiedere quello vecchio.
  • Conti cointestati o aziendali: la password può basarsi sui dati dell'intestatario principale o dell'azienda.

Dopo aver sbloccato un gruppo di file

  • Apri due o tre delle copie per controllarle prima di eliminare qualsiasi originale.
  • Usa nomi chiari, ad esempio "2026-04-estratto-sbloccato.pdf".
  • Tieni privata la cartella sbloccata. Un anno di estratti è un quadro dettagliato delle tue finanze.
  • Se li mandi al commercialista, valuta di inviare gli originali protetti e comunicare la password separatamente.

Domande

Anteprima su Mac può sbloccare più PDF insieme?

No. Puoi aprire molti PDF in Anteprima, ma ognuno va esportato separatamente per togliere la password.

Lo sblocco in blocco funziona se ogni estratto ha una password diversa?

Un gruppo funziona con una password alla volta. Raggruppa i file per password e sblocca a parte quelli diversi.

Lo sblocco in blocco di UnKey è gratis?

Lo sblocco in blocco fa parte di UnKey Pro, un acquisto una tantum. Sbloccare singoli file è gratis.

Lo sblocco in blocco avviene online?

Con UnKey o qpdf, no. Entrambi funzionano sul tuo dispositivo e i file non vengono caricati.
