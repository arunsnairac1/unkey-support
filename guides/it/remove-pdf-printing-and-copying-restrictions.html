Restrizioni di stampa e copia nei PDF: come funzionano

Aggiornato a ottobre 2026

Una password di apertura impedisce di leggere il PDF; una password del proprietario (dei permessi) limita solo azioni come stampare, copiare e modificare.

I PDF possono avere due password diverse. La password di apertura (detta anche password utente) serve per vedere il file. La password del proprietario (detta anche password dei permessi) ti lascia aprire il file ma limita cose come stampare, copiare il testo o modificare. Per togliere davvero le restrizioni serve la password del proprietario.

Le due password in parole semplici

Password di apertura (utente)Password del proprietario (permessi)
Cosa vediUna richiesta di password prima che compaia qualsiasi cosaIl file si apre, ma Stampa o Copia sono disattivati
Cosa proteggeL'intero contenuto, che è cifratoAzioni come stampare, copiare, modificare e commentare
Uso tipicoEstratti conto, documenti fiscaliRapporti pubblicati, moduli, contratti

Adobe descrive la distinzione allo stesso modo. Una password di apertura del documento serve per aprire il PDF, e una password dei permessi limita funzioni come stampa, modifica e copia (Adobe: Password security overview). La documentazione di qpdf aggiunge un dettaglio importante: i lettori "applicano le restrizioni di sicurezza ai file aperti con la password utente" e "permettono di modificare o scavalcare le restrizioni di sicurezza quando i file sono aperti con la password del proprietario" (qpdf).

Come vengono applicate le restrizioni

Le restrizioni dipendono dal fatto che il lettore PDF scelga di rispettarle. Adobe osserva che i suoi prodotti le applicano, ma se prodotti di terze parti non supportano queste impostazioni, i destinatari potrebbero poter aggirare alcune o tutte le restrizioni (Adobe). Quindi una password dei permessi è più un "per favore no" garbato che un lucchetto. Questo però non è una ragione per ignorare la volontà dell'autore. Se qualcuno ha limitato la copia, di solito c'è un motivo, come il diritto d'autore o un contratto.

Modificare le restrizioni se hai la password del proprietario

Su Mac (Anteprima): apri il PDF, scegli File > Modifica permessi e inserisci la password del proprietario. Puoi poi selezionare le azioni da consentire senza password e cliccare su Applica (Apple: Password-protect a PDF in Preview on Mac). Lo stesso pannello Permessi compare in File > Esporta se vuoi una copia nuova.

In Adobe Acrobat: le istruzioni di Adobe per togliere una password dei permessi chiedono di digitarla nella casella Inserisci password (Adobe: How to remove a PDF password).

Da riga di comando: qpdf con --password=OWNERPASSWORD --decrypt scrive una copia senza cifratura. La sua documentazione precisa che questa opzione non serve per aggirare le restrizioni messe sui file da chi li produce (qpdf).

I tuoi documenti con entrambe le password

Gli estratti conto di norma usano solo una password di apertura. Una volta aperto, di solito puoi stampare e copiare liberamente. Se hai creato tu un PDF in Anteprima o Acrobat e hai impostato entrambe le password, usa la password del proprietario per cambiare i permessi o per esportare una copia senza restrizioni.

Per togliere la password di apertura ai tuoi file, come gli estratti mensili, puoi usare Anteprima su Mac o UnKey su iPhone, iPad o Mac. UnKey funziona offline e solo con password che già conosci.

Quando non hai la password del proprietario

  • Chiedi all'autore o a chi te l'ha inviato una copia senza restrizioni, o il permesso di stampare o copiare.
  • Per un modulo da compilare, controlla se la compilazione è già consentita. Molti PDF con restrizioni permettono comunque di compilare i moduli.
  • Per un documento di lavoro o legale, dai per scontato che la restrizione sia voluta.

Domande

Cos'è la password del proprietario di un PDF?

È una password che controlla permessi come stampare, copiare e modificare. Il file si può aprire senza, ma le azioni limitate sono bloccate nei lettori che rispettano le impostazioni.

Perché posso aprire un PDF ma non stamparlo?

Il file ha una password del proprietario (dei permessi) che vieta la stampa. Inserisci la password del proprietario in Anteprima da File > Modifica permessi, oppure chiedi a chi te l'ha inviato una copia senza restrizioni.

Gli estratti conto hanno restrizioni di stampa?

Di solito no. In genere usano solo una password di apertura, quindi una volta aperto il file puoi stamparlo.

È legale togliere le restrizioni di copia a un PDF?

Cambiare i permessi del tuo file, con la tua password del proprietario, va bene. Aggirare le restrizioni sul documento di un altro può violare il diritto d'autore o i termini di un contratto, quindi chiedi al proprietario.
