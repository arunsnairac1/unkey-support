Mot de passe PDF oublié ? Ce que vous pouvez faire (2026)

Mis à jour en octobre 2026

Un mot de passe PDF inconnu ne peut pas être retiré légitimement ; trouvez le format dans l’e-mail d’origine, retéléchargez le document ou demandez à l’expéditeur.

Si vous avez oublié le mot de passe d’un PDF, aucune application honnête ne peut simplement le supprimer. Cela vaut pour Aperçu, Adobe Acrobat et UnKey. La solution pratique consiste à retrouver ce que le mot de passe est censé être, ou à obtenir une nouvelle copie du document. Pour les relevés bancaires et de carte, le mot de passe est presque toujours un format construit à partir de vos propres informations : on peut donc généralement le reconstituer.

Pourquoi les applications ne peuvent pas simplement le retirer

Le mot de passe d’ouverture d’un PDF n’est pas un verrou posé sur le fichier. Il sert à chiffrer le contenu. Sans lui, l’application n’a que des données brouillées. C’est pourquoi les instructions de déverrouillage d’Adobe commencent par ouvrir le fichier et, pour les mots de passe de permissions, saisir le mot de passe (Adobe : Comment supprimer un mot de passe PDF). Aperçu d’Apple demande lui aussi le mot de passe avant d’afficher quoi que ce soit. Les outils qui retirent les mots de passe, dont UnKey, ont d’abord besoin du bon mot de passe.

Étape 1 : lisez l’e-mail qui accompagnait le PDF

Les banques, émetteurs de cartes, assureurs, sociétés de fonds communs et portails fiscaux expliquent presque toujours le mot de passe dans l’e-mail ou le SMS accompagnant le document. Cherchez l’expéditeur dans votre boîte de réception et repérez une phrase du type « le mot de passe est… » ou « pour ouvrir ce relevé, saisissez… ». Elle décrit généralement un schéma, par exemple les quatre premières lettres de votre nom en majuscules suivies de votre date de naissance au format DDMM.

Étape 2 : essayez le format avec vos informations telles que l’émetteur les a enregistrées

  • Nom : utilisez votre nom exactement comme il figure sur le compte, avec éventuellement une initiale ou une autre orthographe.
  • Majuscules : les mots de passe PDF sont sensibles à la casse.
  • Date de naissance : DDMMYYYY, DDMMYY et DDMM ne sont pas la même chose. Vérifiez lequel l’émetteur demande.
  • Numéro de mobile : utilisez le numéro enregistré pour ce compte, qui peut être un ancien numéro.
  • Identifiant client ou numéro de compte : certains émetteurs les utilisent à la place des informations personnelles.

Exemple : l’e-mail d’un relevé indique à Priya Sharma (née le 15 mai 1990) que son mot de passe est « les quatre premières lettres de votre nom en majuscules + DDMM ». Son mot de passe serait PRIY1505. Cet exemple est inventé. Suivez toujours le format que vous donne votre propre émetteur.

Étape 3 : retéléchargez le document

Si l’e-mail a disparu, connectez-vous au site ou à l’app de l’émetteur et téléchargez-y le relevé. Beaucoup d’apps affichent les relevés sans mot de passe, ou indiquent le format du mot de passe sur l’écran de téléchargement. Un nouveau téléchargement remplace aussi un fichier qui aurait été corrompu.

Étape 4 : demandez à l’expéditeur

Appelez le service client ou utilisez la messagerie sécurisée de l’émetteur et demandez comment sont formés les mots de passe des relevés. On ne vous dictera pas votre mot de passe, mais on vous indiquera le format et les informations dont on dispose. Pour un PDF envoyé par une personne, comme un comptable ou le service RH d’un employeur, demandez-lui simplement.

Pourquoi les « logiciels de piratage de mot de passe PDF » sont une mauvaise idée

  • Ils ne fonctionnent souvent pas. Les PDF modernes utilisent un chiffrement robuste, et la documentation de qpdf recommande le chiffrement 256 bits pour les nouveaux fichiers (qpdf). Deviner un long mot de passe peut prendre bien plus de temps que d’appeler votre banque.
  • Risque de logiciels malveillants. Les téléchargements gratuits de « récupération de mot de passe » sont un moyen courant d’installer des logiciels indésirables.
  • Votre fichier quitte votre appareil. Les outils en ligne exigent d’envoyer le relevé, avec vos données de compte, sur le serveur de quelqu’un d’autre.
  • Ce n’est peut-être pas à vous de l’ouvrir. Ouvrir sans autorisation le document protégé d’une autre personne peut être illégal, quel que soit l’outil.

Une fois le mot de passe retrouvé

Conservez-le en lieu sûr, par exemple dans l’app Mots de passe d’Apple ou dans une app qui le garde dans le trousseau de l’appareil. Retirez ensuite le mot de passe de votre propre copie pour ne plus avoir à le rechercher. Nos guides pour iPhone et Mac présentent les méthodes gratuites intégrées et UnKey.

Questions

UnKey peut-il récupérer un mot de passe PDF oublié ?

Non. UnKey ne retire que les mots de passe que vous connaissez déjà. Il ne les devine pas, ne les craque pas et ne les récupère pas.

Ma banque me communiquera-t-elle le mot de passe de mon relevé ?

En général, elle explique le format, par exemple quelles parties de votre nom, de votre date de naissance ou de votre numéro de mobile il utilise, plutôt que de vous dicter le mot de passe.

Existe-t-il un mot de passe universel pour les relevés bancaires ?

Non. Chaque relevé est protégé par un mot de passe construit à partir de vos informations, et il n’existe aucun code universel.

Les outils en ligne de suppression de mot de passe PDF sont-ils sûrs pour un mot de passe oublié ?

Ils exigent d’envoyer un document sensible et ne peuvent souvent pas ouvrir les fichiers fortement chiffrés. Obtenir le format auprès de l’émetteur est plus rapide et plus sûr.
