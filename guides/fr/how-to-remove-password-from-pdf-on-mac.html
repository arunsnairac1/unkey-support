Comment retirer le mot de passe d’un PDF sur Mac (2026)

Mis à jour en octobre 2026

Ouvrez le PDF dans Aperçu avec son mot de passe, choisissez Fichier > Exporter, vérifiez qu’aucun mot de passe d’ouverture n’est défini, puis enregistrez une nouvelle copie.

Sur Mac, vous pouvez retirer gratuitement le mot de passe d’un PDF avec Aperçu, l’app fournie avec macOS. Ouvrez le PDF, saisissez le mot de passe, puis choisissez Fichier > Exporter et enregistrez une nouvelle copie sans mot de passe d’ouverture. Vous devez connaître le mot de passe : Aperçu n’ouvrira pas le fichier sans lui.

Méthode 1 : Aperçu, Fichier > Exporter

  1. Double-cliquez sur le PDF pour l’ouvrir dans Aperçu et saisissez le mot de passe.
  2. Choisissez Fichier > Exporter et donnez à la copie un nouveau nom, par exemple « Releve-oct-deverrouille ».
  3. Cliquez sur Permissions et assurez-vous que Exiger un mot de passe pour ouvrir le document n’est pas coché. Sur les anciennes versions de macOS, la fenêtre d’export comporte à la place une case Chiffrer. Laissez-la décochée.
  4. Cliquez sur Enregistrer.
  5. Fermez le nouveau fichier et rouvrez-le. Il devrait s’ouvrir sans demander de mot de passe.

Le guide actuel d’Apple décrit la fenêtre d’export, le bouton Permissions et l’option Exiger un mot de passe pour ouvrir le document (Apple : Protéger un PDF par mot de passe dans Aperçu sur Mac). La version macOS Big Sur de la même page le disait directement : « Pour retirer un mot de passe d’un PDF que vous avez chiffré, ouvrez le PDF et exportez-le de nouveau, cette fois en désactivant l’option de chiffrement » (Apple, guide macOS Big Sur).

Si le PDF a aussi un mot de passe propriétaire (de permissions) et que vous le connaissez, Fichier > Modifier les permissions vous permet de changer le mot de passe d’ouverture et les fonctions qui exigent un mot de passe.

Méthode 2 : Imprimer > Enregistrer au format PDF

Toute app Mac capable d’imprimer peut créer un nouveau PDF (Apple : Enregistrer un document au format PDF sur Mac) :

  1. Ouvrez le PDF avec son mot de passe.
  2. Choisissez Fichier > Imprimer.
  3. Cliquez sur le menu local PDF et choisissez Enregistrer au format PDF.
  4. Ne cliquez pas sur Options de sécurité, car c’est là qu’on remettrait un mot de passe.

La copie imprimée peut perdre les liens, les champs de formulaire ou les signets. Si le document bloque l’impression, cette méthode peut être grisée.

Méthode 3 : UnKey pour Mac

UnKey est aussi gratuit sur Mac. UnKey Pro, un achat unique, ajoute le déverrouillage par lots et les autres outils Pro sur iPhone, iPad et Mac. Faites glisser un PDF sur la fenêtre, saisissez le mot de passe, et il enregistre une copie déverrouillée. UnKey Pro peut aussi déverrouiller plusieurs fichiers d’un coup, pratique pour un an de relevés mensuels partageant le même mot de passe. UnKey fonctionne hors ligne, n’envoie rien et ne retire que les mots de passe que vous connaissez déjà.

Méthode 4 : ligne de commande (pour les utilisateurs avancés)

L’outil libre et gratuit qpdf peut le faire dans le Terminal : qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. Sa documentation décrit --decrypt comme créant « un fichier de sortie sans chiffrement même si le fichier d’entrée est chiffré » (documentation de qpdf). Vous l’installez vous-même, par exemple avec Homebrew. Saisir un mot de passe en ligne de commande peut le laisser dans l’historique de votre shell.

Si le mot de passe est encore demandé

  • Vous avez peut-être ouvert l’original au lieu de la copie. Vérifiez le nom du fichier.
  • Exportez de nouveau et vérifiez que Exiger un mot de passe pour ouvrir le document est désactivé dans Permissions.
  • Essayez plutôt Imprimer > Enregistrer au format PDF.
  • Si Aperçu rejette le mot de passe, vérifiez les majuscules et le format de date, et lisez l’e-mail qui accompagnait le document.

Avant de supprimer l’original

Un PDF déverrouillé s’ouvre pour quiconque possède le fichier. Cela inclut les dossiers iCloud Drive partagés avec la famille et toute personne qui emprunte votre Mac. Gardez les relevés déverrouillés dans un endroit privé. Voir : est-il sûr de retirer le mot de passe d’un PDF, pour en savoir plus.

Questions

Aperçu est-il vraiment gratuit ?

Oui. Aperçu est fourni avec chaque Mac et peut exporter un PDF sans mot de passe d’ouverture une fois le mot de passe saisi.

Aperçu peut-il retirer un mot de passe que je ne connais pas ?

Non. Aperçu demande le mot de passe avant d’ouvrir le fichier, et il n’existe aucun moyen légitime de contourner cela.

Comment déverrouiller plusieurs PDF à la fois sur Mac ?

Aperçu traite un fichier à la fois. UnKey Pro peut déverrouiller par lots plusieurs PDF partageant un mot de passe, et les utilisateurs avancés peuvent scripter qpdf. Voir notre guide pour déverrouiller plusieurs PDF à la fois.

Pourquoi Imprimer > Enregistrer au format PDF est-il grisé ?

Le PDF a peut-être un mot de passe de permissions qui bloque l’impression. Si vous connaissez le mot de passe propriétaire, saisissez-le dans Fichier > Modifier les permissions. Sinon, utilisez la méthode Exporter.
