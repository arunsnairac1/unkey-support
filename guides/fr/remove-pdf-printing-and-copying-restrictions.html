Restrictions d’impression et de copie des PDF expliquées

Mis à jour en octobre 2026

Lire en: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

Un mot de passe d’ouverture empêche quiconque de lire le PDF ; un mot de passe propriétaire (de permissions) restreint seulement des actions comme l’impression, la copie et la modification.

Les PDF peuvent avoir deux mots de passe différents. Un mot de passe d’ouverture (aussi appelé mot de passe utilisateur) est nécessaire pour afficher le fichier. Un mot de passe propriétaire (aussi appelé mot de passe de permissions) permet d’ouvrir le fichier mais restreint des actions comme l’impression, la copie du texte ou la modification. Pour lever correctement les restrictions, il faut le mot de passe propriétaire.

Les deux mots de passe en termes simples

Mot de passe d’ouverture (utilisateur)Mot de passe propriétaire (permissions)
Ce que vous voyezUne demande de mot de passe avant tout affichageLe fichier s’ouvre, mais Imprimer ou Copier est grisé
Ce qu’il protègeTout le contenu, qui est chiffréDes actions comme l’impression, la copie, la modification et le commentaire
Usage typiqueRelevés bancaires, documents fiscauxRapports publiés, formulaires, contrats

Adobe décrit la distinction de la même façon. Un mot de passe d’ouverture du document est nécessaire pour ouvrir le PDF, et un mot de passe de permissions restreint des fonctions comme l’impression, la modification et la copie (Adobe : Présentation de la sécurité par mot de passe). La documentation de qpdf ajoute un détail important : les lecteurs « appliquent les restrictions de sécurité aux fichiers ouverts avec le mot de passe utilisateur » et « permettent de modifier ou de contourner les restrictions de sécurité lorsque les fichiers sont ouverts avec le mot de passe propriétaire » (qpdf).

Comment les restrictions sont appliquées

Les restrictions dépendent du choix du lecteur PDF de les respecter. Adobe précise que ses propres produits les appliquent, mais que si des produits tiers ne prennent pas en charge ces paramètres, les destinataires peuvent contourner tout ou partie des restrictions (Adobe). Un mot de passe de permissions est donc un « s’il vous plaît, ne le faites pas » poli plutôt qu’un verrou. Ce n’est pas une raison d’ignorer la volonté de l’auteur : si quelqu’un a restreint la copie, il y a généralement une raison, comme le droit d’auteur ou un contrat.

Modifier les restrictions quand vous avez le mot de passe propriétaire

Sur Mac (Aperçu) : ouvrez le PDF, choisissez Fichier > Modifier les permissions et saisissez le mot de passe propriétaire. Vous pouvez alors cocher les actions à autoriser sans mot de passe et cliquer sur Appliquer (Apple : Protéger un PDF par mot de passe dans Aperçu sur Mac). Le même panneau Permissions apparaît sous Fichier > Exporter si vous voulez une copie neuve.

Dans Adobe Acrobat : les instructions d’Adobe pour retirer un mot de passe de permissions demandent de le saisir dans la zone Entrer le mot de passe (Adobe : Comment supprimer un mot de passe PDF).

En ligne de commande : qpdf avec --password=OWNERPASSWORD --decrypt écrit une copie sans chiffrement. Sa documentation précise que cette option n’est pas destinée à contourner les restrictions que les producteurs placent sur les fichiers (qpdf).

Vos propres documents avec les deux mots de passe

Les relevés bancaires n’utilisent normalement qu’un mot de passe d’ouverture. Une fois ouvert, vous pouvez généralement imprimer et copier librement. Si vous avez créé vous-même un PDF dans Aperçu ou Acrobat et défini les deux mots de passe, utilisez le mot de passe propriétaire pour modifier les permissions ou exporter une copie sans restrictions.

Pour retirer le mot de passe d’ouverture de vos propres fichiers, comme des relevés mensuels, vous pouvez utiliser Aperçu sur Mac ou UnKey sur iPhone, iPad ou Mac. UnKey fonctionne hors ligne et uniquement avec des mots de passe que vous connaissez déjà.

Quand vous n’avez pas le mot de passe propriétaire

  • Demandez à l’auteur ou à l’expéditeur une copie sans restrictions, ou l’autorisation d’imprimer ou de copier.
  • Pour un formulaire à remplir, vérifiez si le remplissage est déjà autorisé. Beaucoup de PDF restreints le permettent quand même.
  • Pour un document professionnel ou juridique, partez du principe que la restriction est voulue.

Questions

Qu’est-ce qu’un mot de passe propriétaire de PDF ?

C’est un mot de passe qui contrôle les permissions comme l’impression, la copie et la modification. Le fichier peut s’ouvrir sans lui, mais les actions restreintes sont bloquées dans les lecteurs qui respectent ces réglages.

Pourquoi puis-je ouvrir un PDF mais pas l’imprimer ?

Le fichier a un mot de passe propriétaire (de permissions) qui interdit l’impression. Saisissez le mot de passe propriétaire dans Aperçu sous Fichier > Modifier les permissions, ou demandez une copie sans restrictions à l’expéditeur.

Les relevés bancaires ont-ils des restrictions d’impression ?

Généralement non. Ils n’utilisent en principe qu’un mot de passe d’ouverture : une fois le fichier ouvert, vous pouvez l’imprimer.

Est-il légal de retirer les restrictions de copie d’un PDF ?

Modifier les permissions de votre propre fichier, avec votre propre mot de passe propriétaire, est permis. Contourner les restrictions du document de quelqu’un d’autre peut enfreindre le droit d’auteur ou des conditions contractuelles : demandez au propriétaire.
