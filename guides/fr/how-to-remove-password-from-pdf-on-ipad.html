Comment retirer le mot de passe d’un PDF sur iPad (2026)

Mis à jour en octobre 2026

Lire en: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · Português · தமிழ் · తెలుగు

Ouvrez le PDF avec son mot de passe, puis enregistrez une copie déverrouillée avec Aperçu, l’astuce d’impression en PDF ou une app hors ligne comme UnKey.

Sur iPad, retirer le mot de passe d’un PDF ressemble beaucoup à ce qu’on fait sur iPhone. Ouvrez le PDF, saisissez le mot de passe que vous avez déjà, puis enregistrez une nouvelle copie sans mot de passe. Vous pouvez utiliser l’app Aperçu, l’écran d’impression ou une app hors ligne comme UnKey. Le mot de passe est toujours indispensable.

Mettez d’abord le PDF dans Fichiers

La plupart des relevés arrivent en pièce jointe d’e-mail. Dans Apple Mail, maintenez le doigt sur la pièce jointe et choisissez Enregistrer dans Fichiers (Apple : Télécharger les pièces jointes dans Mail ; les étapes sont identiques sur iPad). Dans Gmail ou WhatsApp, ouvrez le PDF et utilisez le bouton Partager pour l’enregistrer dans Fichiers. Partir d’un fichier dans Fichiers facilite toutes les méthodes ci-dessous.

Option 1 : Aperçu sur iPad

iPadOS comprend une app Aperçu pour les PDF. Apple documente la façon d’ajouter un verrou : ouvrez un PDF, touchez le menu à côté du nom du fichier, touchez Verrouiller, activez Exiger un mot de passe et saisissez un mot de passe (Apple : Verrouiller des PDF dans Aperçu sur iPad ; Premiers pas avec Aperçu sur iPad).

Apple ne documente pas d’étape distincte pour « retirer le mot de passe ». Sur un PDF qui a déjà un mot de passe, vous pouvez essayer de l’ouvrir dans Aperçu, de saisir le mot de passe, de retourner dans Verrouiller et de désactiver Exiger un mot de passe. Fermez ensuite le fichier et rouvrez-le pour voir si le mot de passe a disparu. Le conseil d’Apple pour conserver une version non protégée est de toucher Dupliquer avant de verrouiller un fichier. Si vous avez posé le verrou vous-même, le duplicata est le moyen le plus simple de garder une copie sans mot de passe.

Option 2 : imprimer vers un nouveau PDF

Cette astuce n’est pas documentée par Apple, mais elle fonctionne dans de nombreuses apps :

  1. Ouvrez le PDF et saisissez le mot de passe.
  2. Touchez Partager, puis Imprimer. Aucune imprimante n’est nécessaire.
  3. Dans Options d’impression, écartez les doigts sur la miniature de la page pour ouvrir un aperçu en plein écran.
  4. Touchez Partager et choisissez Enregistrer dans Fichiers.

Vérifiez le résultat : les formulaires et les liens peuvent ne pas survivre, et les PDF qui bloquent l’impression ne proposeront pas Imprimer.

Option 3 : UnKey sur iPad

UnKey fonctionne sur iPad comme sur iPhone et Mac. Partagez le PDF vers UnKey, ou ouvrez-le depuis l’app, et saisissez le mot de passe. UnKey enregistre une copie déverrouillée dans Fichiers. Il fonctionne hors ligne et n’envoie rien. Vous pouvez enregistrer le mot de passe pour que les relevés suivants du même format s’ouvrent avec Face ID ou Touch ID ; le mot de passe enregistré reste dans le trousseau de l’appareil. Le déverrouillage est gratuit. UnKey Pro, un achat unique, ajoute le déverrouillage par lots, pratique sur iPad si vous gardez un dossier de relevés mensuels. Pro ajoute aussi la numérisation, la signature et le remplissage, le verrouillage, la compression et la rédaction (masquage d’informations).

Utiliser Split View

Sur iPad, vous pouvez garder Mail ou Fichiers ouvert à côté d’UnKey ou d’Aperçu et glisser un PDF de l’un à l’autre. Cela économise quelques touches quand vous avez plusieurs relevés à traiter.

Si le mot de passe ne fonctionne pas

  • Les mots de passe sont sensibles à la casse. Essayez votre nom en majuscules si le format utilise votre nom.
  • Vérifiez le format de date de votre banque : DDMMYYYY, DDMMYY ou DDMM.
  • Lisez l’e-mail accompagnant le relevé. Les émetteurs y expliquent généralement le format.
  • Les très anciens relevés peuvent suivre un ancien format. Téléchargez une copie récente depuis la banque en ligne si possible.

Gardez la copie déverrouillée privée

Un PDF sans mot de passe peut être lu par quiconque possède le fichier. Si votre iPad est partagé avec la famille, ou si votre dossier Fichiers se synchronise avec un dossier iCloud partagé, réfléchissez à l’endroit où vous enregistrez la copie déverrouillée.

Questions

Retirer un mot de passe PDF sur iPad est-il différent de l’iPhone ?

Pas vraiment. Les mêmes méthodes Aperçu, Impression et UnKey fonctionnent, et le plus grand écran de l’iPad facilite le glisser-déposer entre apps.

Ai-je besoin du mot de passe ?

Oui. Aucune de ces méthodes ne peut ouvrir un PDF sans son mot de passe. Si vous l’avez oublié, demandez-le à l’expéditeur ou téléchargez de nouveau le document.

UnKey fonctionne-t-il hors ligne sur iPad ?

Oui. UnKey déverrouille le fichier sur l’appareil et rien n’est envoyé.
