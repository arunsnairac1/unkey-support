Mode d’emploi · 10

  1. 01
    Comment retirer le mot de passe d’un PDF sur Mac (2026)Ouvrez le PDF dans Aperçu avec son mot de passe, choisissez Fichier > Exporter, vérifiez qu’aucun mot de passe d’ouverture n’est défini, puis enregistrez une nouvelle copie.
  2. 02
    Comment retirer le mot de passe d’un PDF sur iPad (2026)Ouvrez le PDF avec son mot de passe, puis enregistrez une copie déverrouillée avec Aperçu, l’astuce d’impression en PDF ou une app hors ligne comme UnKey.
  3. 03
    Comment retirer le mot de passe d’un PDF sur iPhone (2026)Ouvrez le PDF avec son mot de passe, puis enregistrez une copie sans mot de passe avec Aperçu, l’astuce d’impression en PDF ou une app hors ligne comme UnKey.
  4. 04
    Comment sont construits les mots de passe des relevés bancaires PDFLa plupart des mots de passe de relevé combinent deux informations que la banque détient déjà, comme les quatre premières lettres de votre nom plus votre date de naissance (DDMM), votre identifiant client, ou les derniers chiffres de votre carte ou de votre mobile.
  5. 05
    Compresser un PDF scanné pour respecter la limite de tailleUn PDF scanné est lourd car chaque page est une photo ; réduisez-le avec Aperçu (Réduire la taille du fichier sur Mac, options d’export sur iPhone), scannez moins de pages, plus simples, et retirez le mot de passe avant l’envoi.
  6. 06
    DDMM, DDMMYY, DDMMYYYY : les formats de date de naissance expliquésDD est le jour sur deux chiffres, MM le mois sur deux chiffres et YY ou YYYY l’année, toujours avec les zéros initiaux : le 7 mars 1994 donne 0703 en DDMM et 07031994 en DDMMYYYY.
  7. 07
    Déverrouilleurs PDF hors ligne ou en ligne : confidentialité comparéeLes outils en ligne traitent votre fichier sur le serveur d’un tiers, alors que les outils hors ligne comme Aperçu, Enregistrer au format PDF de Chrome, qpdf ou UnKey travaillent sur votre appareil ; le mode avion permet de les distinguer rapidement.
  8. 08
    Est-il sûr de retirer le mot de passe d’un PDF ?Retirer le mot de passe de vos propres PDF sur un appareil privé ne pose en général pas de problème, à condition d’éviter les outils en ligne qui envoient le fichier.
  9. 09
    Mot de passe PDF oublié ? Ce que vous pouvez faire (2026)Un mot de passe PDF inconnu ne peut pas être retiré légitimement ; trouvez le format dans l’e-mail d’origine, retéléchargez le document ou demandez à l’expéditeur.
  10. 10
    Ouvrir un PDF protégé par mot de passe sur Android (2026)Ouvrez le PDF dans une visionneuse comme Google Drive, Files by Google ou Adobe Acrobat Reader et saisissez le mot de passe ; pour garder une copie sans mot de passe, imprimez avec « Enregistrer au format PDF ».
