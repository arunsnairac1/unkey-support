Comment retirer le mot de passe d’un PDF sur iPhone (2026)

Mis à jour en octobre 2026

Lire en: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · Português · தமிழ் · తెలుగు

Ouvrez le PDF avec son mot de passe, puis enregistrez une copie sans mot de passe avec Aperçu, l’astuce d’impression en PDF ou une app hors ligne comme UnKey.

Pour retirer le mot de passe d’un PDF sur iPhone, vous devez d’abord le connaître. Ouvrez le fichier, saisissez-le, puis enregistrez une nouvelle copie sans mot de passe. Vous pouvez le faire avec les apps déjà présentes sur votre iPhone ou avec une app hors ligne comme UnKey.

Aucune méthode légitime ne retire un mot de passe que vous ne connaissez pas. Si vous l’avez oublié, voyez ce qu’il faut faire en cas de mot de passe PDF oublié.

Avant de commencer

  • Enregistrez d’abord le PDF dans l’app Fichiers. Dans Mail, maintenez le doigt sur la pièce jointe et choisissez Enregistrer dans Fichiers (voir Apple : Télécharger les pièces jointes dans Mail sur iPhone).
  • Gardez l’original jusqu’à ce que vous ayez vérifié que la nouvelle copie s’ouvre et s’affiche correctement.
  • Ayez le mot de passe sous la main. Pour les relevés bancaires et de carte, l’e-mail accompagnant le relevé explique généralement le format.

Option 1 : l’app Aperçu (iOS 26 et ultérieur)

Les versions récentes d’iOS incluent une app Aperçu pour les PDF. Apple documente la façon d’ajouter un mot de passe : ouvrez un PDF, touchez le menu à côté du nom du fichier, touchez Verrouiller, et le réglage Exiger un mot de passe s’active (Apple : Verrouiller des PDF dans Aperçu sur iPhone).

Le guide d’Apple ne décrit pas comment retirer un mot de passe. Sur un PDF déjà protégé, vous pouvez essayer ceci : ouvrez-le dans Aperçu, saisissez le mot de passe, touchez le menu à côté du nom du fichier, touchez Verrouiller et désactivez Exiger un mot de passe. Aperçu propose aussi une option Exporter qui enregistre un nouveau PDF (Apple : Exporter ou compresser des PDF dans Aperçu sur iPhone). Quelle que soit la voie choisie, fermez le nouveau fichier et rouvrez-le. S’il demande encore un mot de passe, utilisez l’une des options ci-dessous.

Option 2 : l’astuce de l’écran d’impression

C’est une vieille astuce que beaucoup de gens utilisent. Ce n’est pas une fonction documentée par Apple, et les boutons peuvent changer de place d’une version d’iOS à l’autre.

  1. Ouvrez le PDF dans Fichiers et saisissez le mot de passe.
  2. Touchez le bouton Partager, puis Imprimer (Apple : Imprimer depuis l’iPhone). Aucune imprimante n’est nécessaire.
  3. Sur l’écran Options d’impression, écartez deux doigts sur l’aperçu de la page. Cela ouvre un aperçu plein écran, qui est un nouveau PDF.
  4. Touchez le bouton Partager et choisissez Enregistrer dans Fichiers.

À vérifier ensuite : les formulaires, les liens et le texte recherchable peuvent être différents, et si le PDF bloque l’impression, Imprimer peut ne pas apparaître du tout.

Option 3 : UnKey (app hors ligne)

  1. Dans Fichiers, Mail ou une autre app, ouvrez la feuille de partage du PDF et choisissez UnKey, ou ouvrez UnKey et sélectionnez le fichier.
  2. Saisissez le mot de passe que vous avez déjà.
  3. Enregistrez la copie déverrouillée dans Fichiers ou partagez-la.

UnKey fonctionne sur l’appareil et n’envoie pas votre fichier. Il ne craque ni ne devine les mots de passe : il retire seulement un mot de passe que vous connaissez déjà. Le déverrouillage est gratuit. Vous pouvez aussi enregistrer les mots de passe des relevés que vous recevez chaque mois. Ils restent dans le trousseau de l’appareil, derrière Face ID ou Touch ID, si bien que le relevé du mois suivant s’ouvre sans ressaisie. L’achat unique UnKey Pro ajoute le déverrouillage par lots et d’autres outils.

Si le mot de passe est refusé

  • Vérifiez les majuscules. Les mots de passe PDF sont sensibles à la casse. Beaucoup de banques utilisent votre nom en majuscules.
  • Vérifiez le format de date. DDMMYYYY, DDMMYY et DDMM sont tous courants et ne sont pas interchangeables.
  • Vérifiez l’e-mail. Les banques et émetteurs de cartes indiquent généralement le format dans l’e-mail qui accompagnait le relevé.
  • Cherchez une faute de frappe ou une espace ajoutée automatiquement. Tapez le mot de passe à la main plutôt que de le coller.

Faut-il vraiment le retirer ?

Un PDF déverrouillé peut être ouvert par quiconque met la main sur le fichier. Si vous le stockez dans un dossier iCloud partagé ou le transférez, demandez-vous qui peut y accéder. Pour une discussion plus complète, lisez : est-il sûr de retirer le mot de passe d’un PDF.

Questions

Puis-je retirer un mot de passe PDF sur iPhone sans le connaître ?

Non. Toutes les méthodes légitimes, y compris les apps d’Apple et UnKey, exigent d’abord le bon mot de passe pour ouvrir le fichier. Si vous l’avez oublié, demandez-le à l’expéditeur ou téléchargez de nouveau le document.

Existe-t-il un moyen gratuit sans rien installer ?

Oui. Essayez le réglage Verrouiller d’Aperçu ou l’astuce de l’écran d’impression, qui enregistre une nouvelle copie sans mot de passe. Vérifiez que la nouvelle copie s’ouvre normalement avant de supprimer l’original.

UnKey envoie-t-il mon PDF quelque part ?

Non. UnKey déverrouille le fichier sur votre iPhone et rien n’est envoyé.

La copie déverrouillée remplacera-t-elle mon original ?

Pas sauf si vous choisissez de l’écraser. Il est plus prudent d’enregistrer la copie sous un nouveau nom, de la vérifier, puis de décider de garder ou non l’original.
