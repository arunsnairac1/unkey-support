Comment retirer le mot de passe d’un PDF dans Chrome (2026)

Mis à jour en octobre 2026

Lire en: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · Português · தமிழ் · తెలుగు

Ouvrez le PDF dans Chrome avec son mot de passe, appuyez sur Ctrl+P ou Cmd+P, choisissez Enregistrer au format PDF comme destination et enregistrez une nouvelle copie sans mot de passe.

Google Chrome peut enregistrer gratuitement une copie sans mot de passe d’un PDF protégé, sur Windows, Mac et Linux. Ouvrez le PDF dans Chrome, saisissez le mot de passe, appuyez sur Ctrl + P (Cmd + P sur Mac), choisissez Enregistrer au format PDF comme destination et enregistrez. Vous devez déjà connaître le mot de passe : Chrome ne peut pas ouvrir le fichier sans lui.

Pas à pas (ordinateur)

  1. Faites glisser le PDF dans une fenêtre Chrome, ou faites un clic droit sur le fichier et choisissez Ouvrir avec > Google Chrome.
  2. Chrome demande le mot de passe. Saisissez-le et appuyez sur Entrée.
  3. Appuyez sur Ctrl + P sous Windows ou Linux, ou Cmd + P sur Mac. Vous pouvez aussi passer par le menu : Fichier > Imprimer.
  4. Dans la fenêtre d’impression, réglez Destination sur Enregistrer au format PDF.
  5. Cliquez sur Enregistrer. Donnez au nouveau fichier un nom clair, comme Statement-Sep-2026-unlocked.pdf.
  6. Fermez-le et rouvrez le nouveau fichier. Il doit s’ouvrir tout de suite, sans demande de mot de passe.

La page d’aide de Google décrit les raccourcis clavier, le choix d’une destination dans la fenêtre d’impression et l’option Enregistrer au format PDF (Google : Imprimer depuis Chrome).

Sur un téléphone Android

Chrome sur Android propose la même option. Les étapes de Google : touchez Plus > Partager, touchez Imprimer, puis Enregistrer au format PDF et choisissez où enregistrer le fichier (Google : Imprimer depuis Chrome sur Android). Que Chrome ouvre ou non un PDF stocké sur votre téléphone dépend de sa version. Sinon, consultez notre guide pour ouvrir un PDF protégé par mot de passe sur Android.

Ce que vous perdez avec cette méthode

Enregistrer via la fenêtre d’impression crée un tout nouveau PDF à partir de ce qui est affiché. C’est suffisant pour lire, archiver ou envoyer un relevé. Mais vérifiez la copie avant de supprimer l’original :

  • Les liens et signets peuvent ne plus fonctionner.
  • Les champs de formulaire peuvent être aplatis : vous ne pourrez plus y écrire.
  • Les signatures numériques ne sont pas conservées. Si un portail exige l’original signé, envoyez l’original.
  • Le format de page suit les réglages d’impression. Sous Plus de paramètres, vérifiez que le format de papier et l’échelle n’ont pas réduit ou rogné les pages.

Si Enregistrer au format PDF ne fonctionne pas

  • L’impression est bloquée. Certains PDF ont un mot de passe de permissions qui empêche l’impression. Un mot de passe de permissions est distinct du mot de passe d’ouverture. Voir les restrictions d’impression et de copie des PDF expliquées.
  • Chrome rejette le mot de passe. Vérifiez les majuscules, le format de date et les informations que votre banque a enregistrées. Voir pourquoi un mot de passe PDF ne fonctionne pas.
  • Le fichier s’est ouvert dans une autre app. Certains ordinateurs ouvrent les PDF dans une autre visionneuse par défaut. Faites plutôt glisser le fichier dans un onglet Chrome.

Autres façons de retirer le mot de passe

Microsoft Edge fonctionne de la même manière sous Windows (voir retirer un mot de passe PDF sous Windows). Sur Mac, Aperçu peut exporter une copie sans mot de passe (guide Mac). Sur iPhone, iPad et Mac, UnKey enregistre une copie déverrouillée hors ligne et conserve le texte, les liens et les pages tels quels, car il retire le chiffrement au lieu de réimprimer le fichier. Comme Chrome, il ne fonctionne qu’avec un mot de passe que vous connaissez déjà.

Questions

Chrome envoie-t-il mon PDF quelque part quand je fais cela ?

Non. Ouvrir un PDF depuis votre ordinateur et l’enregistrer avec Enregistrer au format PDF se passe dans le navigateur, sur votre ordinateur. N’utilisez la destination distincte « Enregistrer dans Google Drive » que si vous voulez une copie dans Drive.

Chrome peut-il retirer un mot de passe que je ne connais pas ?

Non. Chrome demande le mot de passe avant d’afficher quoi que ce soit. Si vous l’avez perdu, voyez ce qu’il faut faire en cas de mot de passe PDF oublié.

Pourquoi la copie enregistrée est-elle différente de l’original ?

Enregistrer au format PDF imprime les pages dans un nouveau fichier : liens, champs de formulaire et signatures peuvent ne pas survivre. Le texte et la mise en page paraissent en général identiques.

Est-ce autorisé ?

Pour vos propres documents, comme votre relevé bancaire, oui. Ne retirez pas la protection de fichiers que vous n’avez pas le droit d’ouvrir librement.
