Ouvrir un PDF protégé depuis WhatsApp, Gmail ou Mail sur iPhone

Mis à jour en octobre 2026

Touchez le PDF pour l’afficher et saisissez le mot de passe, ou utilisez le bouton Partager pour l’enregistrer dans Fichiers ou l’envoyer vers une app comme UnKey.

Pour ouvrir un PDF protégé par mot de passe sur iPhone, touchez la pièce jointe et saisissez le mot de passe quand on vous le demande. Si la visionneuse de l’app ne le demande pas, ou si vous voulez conserver le fichier, utilisez le bouton Partager pour l’enregistrer dans Fichiers ou l’ouvrir dans une autre app. Toutes les voies ci-dessous exigent quand même le bon mot de passe.

Depuis Apple Mail

  1. Ouvrez l’e-mail et touchez la pièce jointe PDF pour l’afficher. Saisissez le mot de passe si on vous le demande.
  2. Pour la conserver, maintenez le doigt sur la pièce jointe et choisissez Enregistrer dans Fichiers. Pour l’ouvrir dans une autre app, choisissez Partager, puis l’app voulue (Apple : Télécharger les pièces jointes dans Mail sur iPhone).

Astuce : dans Mail, vous pouvez filtrer une boîte pour n’afficher que les messages avec pièces jointes, ce qui aide à retrouver un ancien relevé.

Depuis Gmail

  1. Ouvrez le message et touchez la pièce jointe pour l’ouvrir (Aide Gmail : Ouvrir et télécharger des pièces jointes sur iPhone).
  2. Si la visionneuse de Gmail ne peut pas l’afficher à cause du mot de passe, utilisez l’option de partage ou « ouvrir dans » pour passer le fichier à iOS. Depuis la feuille de partage iOS, vous pouvez choisir Enregistrer dans Fichiers ou une app comme Aperçu ou UnKey.
  3. Gmail propose aussi Enregistrer dans Drive, qui envoie le fichier sur votre Google Drive. C’est pratique, mais cela place le fichier dans le cloud.

Le nom des boutons de Gmail change de temps en temps. Si vous ne les trouvez pas, cherchez une icône Partager (un carré avec une flèche) ou un menu à trois points.

Depuis WhatsApp

  1. Touchez le document dans la conversation. WhatsApp affiche un aperçu, qui pour un PDF protégé peut ne rien montrer d’utile ou demander le mot de passe.
  2. Touchez le bouton Partager dans l’aperçu et choisissez Enregistrer dans Fichiers, ou sélectionnez une app dans la feuille de partage.
  3. Ouvrez-le depuis Fichiers et saisissez le mot de passe.

Si vous avez reçu le PDF de quelqu’un d’autre, demandez-lui le mot de passe dans un message séparé ou par téléphone, pas dans la même conversation que le fichier.

Ouvrir le fichier enregistré

  • Fichiers : touchez le PDF et saisissez le mot de passe quand il est demandé.
  • Aperçu (iOS 26 et ultérieur) : parcourez jusqu’au fichier sous Parcourir ou Récents et touchez-le (Apple : Ouvrir et afficher des PDF dans Aperçu sur iPhone).
  • UnKey : choisissez UnKey dans la feuille de partage de Mail, Gmail, WhatsApp ou Fichiers. Saisissez le mot de passe et vous pouvez afficher le PDF ou enregistrer une copie déverrouillée. Il fonctionne hors ligne : le fichier n’est pas envoyé. Vous pouvez enregistrer le mot de passe pour que les relevés suivants du même format s’ouvrent avec Face ID.

S’il indique que le mot de passe est incorrect

  • Tapez-le à la main. Les mots de passe collés récupèrent parfois une espace à la fin.
  • Vérifiez les majuscules. Les mots de passe sont sensibles à la casse.
  • Vérifiez le format de date : DDMMYYYY, DDMMYY ou DDMM.
  • Lisez l’e-mail ou le SMS d’origine de l’émetteur, qui explique généralement le format.
  • Si le fichier a été transféré sur WhatsApp, l’expéditeur a peut-être le mot de passe, ou a peut-être transféré une copie déjà déverrouillée mais désormais corrompue. Demandez-lui de le renvoyer.

Si le PDF ne s’ouvre pas du tout

Un téléchargement incomplet peut ressembler à un problème de mot de passe. Supprimez la copie, téléchargez-la de nouveau avec une bonne connexion et réessayez. Si l’app de l’expéditeur compresse les fichiers, demandez-lui de l’envoyer comme document plutôt que comme média.

Questions

Pourquoi WhatsApp affiche-t-il une page blanche pour mon PDF ?

L’aperçu de WhatsApp ne gère peut-être pas les PDF protégés par mot de passe. Enregistrez le fichier dans Fichiers ou ouvrez-le dans une autre app depuis la feuille de partage, puis saisissez-y le mot de passe.

Puis-je ouvrir un PDF protégé depuis Gmail sans le télécharger ?

La visionneuse de Gmail peut ne pas ouvrir les fichiers protégés par mot de passe. Enregistrer le fichier dans Fichiers, ou l’ouvrir dans une app via Partager, est la voie fiable.

Est-il sûr d’ouvrir un PDF de relevé dans UnKey ?

UnKey fonctionne hors ligne sur votre iPhone et n’envoie aucun fichier. Il n’ouvre que les PDF dont vous saisissez le mot de passe.

Déverrouillez-le une fois.

UnKey retire le mot de passe des PDF que vous pouvez déjà ouvrir, sur iPhone, iPad et Mac. Hors connexion, rien n’est envoyé. Enregistrez le mot de passe une fois, et Face ID ouvrira le relevé du mois prochain.
