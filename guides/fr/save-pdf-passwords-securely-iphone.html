Comment enregistrer vos mots de passe PDF en sécurité sur iPhone

Mis à jour en octobre 2026

Conservez les mots de passe PDF dans l’app Mots de passe d’Apple, une note verrouillée ou une app qui les garde dans le trousseau derrière Face ID, jamais dans une note simple.

Les endroits les plus sûrs pour les mots de passe PDF sur iPhone sont l’app Mots de passe d’Apple, une note verrouillée, ou une app qui les garde dans le trousseau de l’iPhone derrière Face ID ou Touch ID. Une note ordinaire ou une « note à soi-même » WhatsApp n’est pas un bon endroit, car quiconque prend votre téléphone déverrouillé peut la lire.

Pourquoi pas une note ou une discussion ordinaire ?

  • Aucun verrou supplémentaire. Une note ordinaire s’ouvre dès que le téléphone est déverrouillé.
  • Elle apparaît dans la recherche. Taper « mot de passe » dans la recherche de l’iPhone peut la faire remonter.
  • Elle se propage. Les notes dans Gmail ou d’autres comptes synchronisés, les sauvegardes de discussions et les captures d’écran se retrouvent à plus d’endroits qu’on ne croit.
  • Les mots de passe sont à côté des fichiers. Si vos relevés et leurs mots de passe sont dans la même discussion, le mot de passe du PDF ne protège rien.

Option 1 : l’app Mots de passe d’Apple

L’app Mots de passe stocke les entrées sous forme chiffrée, et le trousseau iCloud les tient à jour sur vos appareils approuvés (Apple : Consulter vos mots de passe). Elle est conçue pour les identifiants de sites web, mais vous pouvez y ajouter une entrée pour un document :

  1. Ouvrez Mots de passe, touchez Tous, puis le bouton d’ajout (Apple : Créer un mot de passe).
  2. Mettez quelque chose comme « PDF relevé bancaire » dans le champ du site web ou de l’app, ajoutez un libellé comme nom d’utilisateur, et saisissez le mot de passe du PDF.
  3. Enregistrez. Plus tard, touchez Modifier > Notes pour ajouter des précisions comme « format : 4 premières lettres du nom + DDMM ». Apple indique qu’on peut y conserver en sécurité des notes telles que des codes PIN et des questions de sécurité.

Enregistrer le format plutôt que le mot de passe lui-même est une astuce pratique pour les relevés qui utilisent vos informations. Le relevé de l’an prochain suivra la même règle.

Option 2 : une note verrouillée

Dans Notes, vous pouvez verrouiller une note avec le code de l’appareil ou un mot de passe distinct, et l’ouvrir avec Face ID ou Touch ID (Apple : Verrouiller vos notes sur iPhone). À savoir :

  • Vous ne pouvez verrouiller que les notes stockées sur l’appareil ou dans iCloud, pas celles synchronisées avec Gmail ou d’autres comptes.
  • Vous ne pouvez pas verrouiller une note à laquelle un PDF est joint : gardez donc la note du mot de passe séparée du fichier.
  • Le titre de la note reste visible dans la liste : donnez-lui un titre neutre.
  • Si vous utilisez un mot de passe Notes personnalisé et l’oubliez, Apple indique ne pas pouvoir vous aider à retrouver l’accès à ces notes.

Option 3 : l’enregistrer dans l’app qui ouvre le PDF

UnKey peut enregistrer le mot de passe quand vous déverrouillez un relevé : le PDF du mois suivant, au même format, s’ouvre alors avec Face ID ou Touch ID. Les mots de passe enregistrés restent dans le trousseau de l’iPhone, sur cet appareil. Ils ne sont envoyés nulle part. Comme ils restent sur l’appareil, ils ne vous suivront pas sur un nouveau téléphone : gardez donc une sauvegarde des plus importants dans l’app Mots de passe.

Bonnes pratiques

  • Utilisez un code d’appareil robuste. Face ID n’est aussi sûr que le code qui se trouve derrière.
  • Ne faites pas de capture d’écran des mots de passe. Les captures se synchronisent dans Photos et se partagent par accident.
  • Quand vous partagez un PDF protégé, envoyez le mot de passe par un autre moyen, par exemple par téléphone.
  • Supprimez les entrées devenues inutiles. Dans Mots de passe, ouvrez l’entrée, touchez Modifier, puis Supprimer.

Questions

Puis-je stocker un mot de passe PDF dans l’app Mots de passe de l’iPhone ?

Oui. Ajoutez une nouvelle entrée avec un libellé descriptif et le mot de passe, et utilisez le champ Notes pour le format. Apple chiffre ces entrées et les synchronise avec le trousseau iCloud si vous l’avez activé.

Une note verrouillée est-elle sûre pour des mots de passe PDF ?

Oui, tant que la note est stockée dans iCloud ou sur l’appareil et qu’elle est verrouillée. Vous ne pouvez pas verrouiller une note à laquelle un PDF est joint : gardez-les séparés.

UnKey envoie-t-il mes mots de passe enregistrés ?

Non. UnKey garde les mots de passe enregistrés dans le trousseau de l’appareil, derrière Face ID ou Touch ID, et ils restent sur cet appareil.

Que deviennent les mots de passe enregistrés dans UnKey si je change de téléphone ?

Ils sont stockés sur l’appareil : prévoyez de les ressaisir sur un nouveau téléphone. En garder une copie des plus importants dans l’app Mots de passe aide.

Déverrouillez-le une fois.

UnKey retire le mot de passe des PDF que vous pouvez déjà ouvrir, sur iPhone, iPad et Mac. Hors connexion, rien n’est envoyé. Enregistrez le mot de passe une fois, et Face ID ouvrira le relevé du mois prochain.
