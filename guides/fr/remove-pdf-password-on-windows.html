Comment retirer le mot de passe d’un PDF sous Windows (2026)

Mis à jour en octobre 2026

Lire en: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · മലയാളം · Português · தமிழ் · తెలుగు

Ouvrez le PDF dans Microsoft Edge ou Chrome avec son mot de passe, appuyez sur Ctrl+P, choisissez Enregistrer au format PDF (ou Microsoft Print to PDF) et enregistrez une nouvelle copie ; Acrobat payant peut retirer la sécurité directement.

Sous Windows 10 et 11, vous pouvez retirer gratuitement le mot de passe d’un PDF avec le navigateur que vous avez déjà. Ouvrez le PDF dans Microsoft Edge ou Google Chrome, saisissez le mot de passe, appuyez sur Ctrl + P, choisissez Enregistrer au format PDF (ou Microsoft Print to PDF) comme imprimante, et enregistrez. Le nouveau fichier s’ouvre sans mot de passe. Vous devez d’abord connaître le mot de passe.

Méthode 1 : Microsoft Edge (intégré)

  1. Faites un clic droit sur le PDF dans l’Explorateur de fichiers et choisissez Ouvrir avec > Microsoft Edge.
  2. Saisissez le mot de passe quand Edge le demande.
  3. Appuyez sur Ctrl + P, ou ouvrez le menu Plus (les trois points) et choisissez Imprimer.
  4. Sous Imprimante, choisissez Enregistrer au format PDF ou Microsoft Print to PDF.
  5. Cliquez sur Enregistrer (ou Imprimer), choisissez un dossier et donnez un nouveau nom à la copie.
  6. Ouvrez le nouveau fichier pour vérifier qu’il ne demande plus de mot de passe.

Le guide de Microsoft sur son lecteur PDF intégré montre la voie Edge : trouver Imprimer dans le menu Plus, choisir ses options, puis imprimer (Microsoft : Afficher, imprimer et modifier des PDF dans un lecteur PDF). Microsoft Print to PDF est une imprimante fournie avec Windows. Si elle manque dans la liste, Microsoft indique qu’on peut la réactiver dans les Fonctionnalités facultatives de Windows (Microsoft : problème connu KB5058499).

Méthode 2 : Google Chrome

Si vous utilisez Chrome, les étapes sont presque les mêmes : ouvrez le PDF dans Chrome, saisissez le mot de passe, appuyez sur Ctrl + P, réglez Destination sur Enregistrer au format PDF et cliquez sur Enregistrer (Google : Imprimer depuis Chrome). Plus de détails dans notre guide Chrome.

Méthode 3 : Adobe Acrobat Pro ou Standard (payant)

Acrobat payant retire le chiffrement lui-même au lieu de réimprimer le fichier : les liens et champs de formulaire restent intacts. Adobe documente deux voies (Adobe : Supprimer les mots de passe des PDF) :

  • Outils de protection : ouvrez le PDF, allez dans les outils Protéger et choisissez Supprimer la sécurité. Si le fichier n’a qu’un mot de passe d’ouverture, confirmez par OK. S’il a aussi un mot de passe de permissions, Acrobat demande d’abord ce mot de passe.
  • Paramètres de sécurité : ouvrez les propriétés de sécurité du document, allez dans l’onglet Sécurité, choisissez Modifier les paramètres, effacez les options de mot de passe et enregistrez.

Les menus d’Adobe changent d’une version à l’autre : si vous ne voyez pas ces noms exacts, cherchez « Supprimer la sécurité » (Remove Security) dans la recherche d’outils d’Acrobat. Acrobat Reader gratuit peut ouvrir les PDF protégés mais n’est pas l’outil pour retirer la sécurité. Utilisez plutôt la méthode 1 ou 2.

Méthode 4 : qpdf (utilisateurs avancés)

L’outil libre et gratuit qpdf fonctionne sous Windows. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf écrit une copie sans chiffrement (documentation de qpdf). Le mot de passe peut rester dans l’historique de commandes : effacez-le ensuite sur un PC partagé.

À vérifier

  • Imprimer est grisé ? Le PDF a peut-être un mot de passe de permissions qui bloque l’impression. Voir restrictions d’impression et de copie.
  • Mot de passe rejeté ? Vérifiez le verrouillage des majuscules, le format de date et les informations de votre banque. Voir pourquoi un mot de passe PDF ne fonctionne pas.
  • PC partagé ou de bureau ? La copie déverrouillée s’ouvre pour quiconque la trouve. Enregistrez-la dans un dossier privé et supprimez-la de Téléchargements.

Si vous avez aussi un iPhone, un iPad ou un Mac, UnKey retire le mot de passe hors ligne sur ces appareils et peut enregistrer le mot de passe pour le relevé du mois suivant. Il n’existe pas d’app UnKey pour Windows.

Questions

Dois-je installer quelque chose sous Windows ?

Non. Microsoft Edge et l’imprimante Microsoft Print to PDF sont fournis avec Windows 10 et 11.

Les sites en ligne « unlock PDF » fonctionneront-ils mieux ?

Ils font le même travail mais envoient votre document sur le serveur d’un tiers. Pour les relevés bancaires et les papiers fiscaux, les méthodes hors ligne présentées ici sont plus sûres.

L’une de ces méthodes peut-elle retirer un mot de passe oublié ?

Non. Edge, Chrome, Acrobat et qpdf ont tous besoin du bon mot de passe. Consultez l’e-mail accompagnant le PDF pour connaître le format.

Pourquoi les liens ne fonctionnent-ils plus dans la copie ?

Imprimer en PDF reconstruit les pages, ce qui peut supprimer liens et champs de formulaire. Supprimer la sécurité dans Acrobat ou qpdf les conserve.
