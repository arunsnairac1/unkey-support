PDF-Passwort in Chrome entfernen (2026)

Aktualisiert im Oktober 2026

Lesen auf: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

Öffne das PDF in Chrome mit seinem Passwort, drücke Strg+P oder Cmd+P, stelle das Ziel auf „Als PDF speichern“ und sichere eine neue Kopie ohne Passwort.

Google Chrome kann kostenlos eine Kopie eines passwortgeschützten PDFs ohne das Passwort speichern, unter Windows, Mac und Linux. Öffne das PDF in Chrome, gib das Passwort ein, drücke Strg + P (Cmd + P am Mac), stelle das Ziel auf Als PDF speichern und speichere. Das Passwort musst du schon kennen. Ohne es kann Chrome die Datei nicht öffnen.

Schritt für Schritt (Computer)

  1. Zieh das PDF in ein Chrome-Fenster oder klicke die Datei mit der rechten Maustaste an und wähle Öffnen mit > Google Chrome.
  2. Chrome fragt nach dem Passwort. Gib es ein und drücke die Eingabetaste.
  3. Drücke Strg + P unter Windows oder Linux bzw. Cmd + P am Mac. Du kannst auch das Menü nutzen: Datei > Drucken.
  4. Stelle im Druckfenster das Ziel auf Als PDF speichern.
  5. Klicke auf Speichern. Gib der neuen Datei einen klaren Namen, etwa Statement-Sep-2026-unlocked.pdf.
  6. Schließe sie und öffne die neue Datei noch einmal. Sie sollte sofort aufgehen, ohne Passwortabfrage.

Googles Hilfeseite beschreibt die Tastenkombinationen, die Wahl eines Ziels im Druckfenster und die Option Als PDF speichern (Google: Print from Chrome).

Auf einem Android-Handy

Chrome auf Android hat dieselbe Option. Googles Schritte: Tippe auf Mehr > Teilen, tippe auf Drucken, dann auf Als PDF speichern und wähle, wo die Datei gespeichert wird (Google: Print from Chrome on Android). Ob Chrome ein auf dem Handy gespeichertes PDF öffnet, hängt von der Chrome-Version ab. Wenn nicht, lies unsere Anleitung zum Öffnen eines passwortgeschützten PDFs auf Android.

Was du bei dieser Methode verlierst

Das Speichern über das Druckfenster erzeugt aus dem, was auf dem Bildschirm steht, ein ganz neues PDF. Zum Lesen, Archivieren oder Hochladen eines Auszugs reicht das. Prüfe die Kopie aber, bevor du das Original löschst:

  • Links und Lesezeichen funktionieren womöglich nicht mehr.
  • Formularfelder werden eventuell geglättet, du kannst dann nichts mehr hineintippen.
  • Digitale Signaturen werden nicht übernommen. Braucht ein Portal das signierte Original, lade das Original hoch.
  • Die Seitengröße folgt den Druckeinstellungen. Prüfe unter Weitere Einstellungen, dass Papiergröße und Skalierung die Seiten nicht verkleinert oder abgeschnitten haben.

Wenn „Als PDF speichern“ nicht klappt

  • Drucken ist gesperrt. Manche PDFs haben ein Berechtigungspasswort, das das Drucken verhindert. Ein Berechtigungspasswort ist etwas anderes als das Öffnen-Passwort. Siehe PDF-Druck- und Kopierbeschränkungen erklärt.
  • Chrome lehnt das Passwort ab. Prüfe Großbuchstaben, das Datumsformat und die Angaben, die deine Bank gespeichert hat. Siehe warum ein PDF-Passwort nicht funktioniert.
  • Die Datei wurde in einer anderen App geöffnet. Manche Computer öffnen PDFs standardmäßig in einem anderen Reader. Zieh die Datei stattdessen in einen Chrome-Tab.

Andere Wege, das Passwort zu entfernen

Microsoft Edge funktioniert unter Windows genauso (siehe PDF-Passwort unter Windows entfernen). Am Mac kann die Vorschau eine Kopie ohne Passwort exportieren (Mac-Anleitung). Auf iPhone, iPad und Mac sichert UnKey offline eine entsperrte Kopie und lässt Text, Links und Seiten unverändert, weil es die Verschlüsselung entfernt, statt die Datei neu zu drucken. Wie Chrome funktioniert es nur mit einem Passwort, das du schon kennst.

Fragen

Lädt Chrome mein PDF dabei hoch?

Nein. Ein PDF von deinem Computer zu öffnen und mit „Als PDF speichern“ zu sichern passiert im Browser auf deinem Computer. Nutze das separate Ziel „In Google Drive speichern“ nur, wenn du eine Kopie in Drive willst.

Kann Chrome ein Passwort entfernen, das ich nicht kenne?

Nein. Chrome fragt nach dem Passwort, bevor es etwas anzeigt. Hast du es verloren, lies, was du tun kannst, wenn du ein PDF-Passwort vergessen hast.

Warum unterscheidet sich die gespeicherte Kopie vom Original?

„Als PDF speichern“ druckt die Seiten in eine neue Datei, daher gehen Links, Formularfelder und Signaturen womöglich verloren. Text und Layout sehen meist gleich aus.

Ist das erlaubt?

Bei deinen eigenen Dokumenten, etwa deinem Kontoauszug, ja. Entferne den Schutz nicht von Dateien, die du nicht frei öffnen darfst.
