Magbukas ng PDF na May Password sa Android (2026)

Buksan ang PDF sa PDF viewer tulad ng Google Drive, Files by Google o Adobe Acrobat Reader at ilagay ang password; para magtabi ng kopyang wala nito, mag-print sa Save as PDF.

Para magbukas ng PDF na may password sa Android phone, buksan ito sa PDF viewer tulad ng Google Drive, Files by Google o Adobe Acrobat Reader, at i-type ang password kapag hiningi. Para mag-save ng kopyang mabubuksan nang walang password, gamitin ang Print ng app at piliin ang Save as PDF bilang printer.

Pagbubukas ng PDF

  1. I-save muna ang file sa phone. Sa Gmail, i-tap ang download icon sa attachment. Sa WhatsApp, buksan nang isang beses ang dokumento para ma-download ito.
  2. Buksan ito sa PDF viewer. I-tap ang file sa Downloads, o gamitin ang Open with at pumili ng app na pinagkakatiwalaan mo. Nabubuksan ng Google Drive, Files by Google at Adobe Acrobat Reader ang mga protektadong PDF kapag na-type mo na ang password.
  3. I-type ang password. Bantayan ang keyboard. Madalas na ginagawang malaki ng mga Android keyboard ang unang titik o nagdaragdag ng espasyo pagkatapos ng suggested na salita. I-off ang suggestions para sa field na ito, o mag-type nang dahan-dahan at suriin ang bawat karakter.

Kung blangkong pahina o error ang ipinapakita ng app sa halip na lagayan ng password, subukan ang ibang viewer. Hindi kayang hawakan ng ilang preview screen, tulad ng nasa loob ng chat o email app, ang mga naka-encrypt na PDF.

Pag-save ng kopyang walang password

May built-in na Save as PDF na printer ang Android. Inilalarawan ito ng help ng Chrome ng Google: sa print screen, i-tap ang listahan ng printer sa itaas, piliin ang Save as PDF, saka pumili kung saan ise-save ang file (Google: Print from Chrome on Android). Lumalabas din ang parehong printer sa ibang app na may kakayahang mag-print:

  1. Buksan ang PDF at ilagay ang password.
  2. Buksan ang menu ng app (madalas ay tatlong tuldok, o Share) at i-tap ang Print.
  3. Sa itaas ng print screen, piliin ang Save as PDF.
  4. I-tap ang PDF button, pumili ng folder, at i-save na may bagong pangalan.
  5. Buksan ang bagong kopya para tiyaking hindi na ito humihingi ng password.

Magkakaiba ang mga menu sa pagitan ng mga app at gumawa ng phone, kaya ang Print ay maaaring nasa ilalim ng Share, More o ⋮. Kung wala o naka-grey ang Print, maaaring may permissions password ang PDF na humaharang sa pag-print (tingnan ang mga restriction sa pag-print at pagkopya).

Mga tip sa Google Drive

  • Mas ligtas na i-upload sa Drive ang protektadong orihinal kaysa sa naka-unlock na kopya. Sinumang kabahagi mo sa folder ay makakabukas ng naka-unlock na kopya.
  • Sa computer, i-download ang file mula sa Drive at buksan sa Chrome para alisin ang password. Tingnan ang pag-alis ng password ng PDF sa Chrome.

Kung hindi gumagana ang password

Ang mga password ng statement ng bangko at card ay binubuo mula sa detalye mo sa isang takdang pattern, at karaniwang ipinapaliwanag ito ng email na kasama ng statement. Suriin ang malalaking titik, ang format ng petsa, at kung aling mobile number ang hawak ng bangko. Saklaw ng mga gabay namin ang SBI, HDFC Bank, ICICI Bank, e-Aadhaar at marami pa, pati ang dahilan kung bakit tinatanggihan ang password.

Iwasan ang mga “unlock” app na nag-a-upload ng file mo

Maraming Android “PDF unlocker” app at website ang nag-a-upload ng dokumento sa isang server. Makikita sa bank statement ang account number, address at gastos mo, kaya manatili sa paraan ng pag-print sa itaas, na gumagana sa mismong phone. Wala pa ang UnKey sa Android. Gumagana ito sa iPhone, iPad at Mac.

Mga tanong

Anong app ang gagamitin ko para magbukas ng protektadong PDF sa Android?

Anumang pinagkakatiwalaang PDF viewer na humihingi ng password, tulad ng Google Drive, Files by Google o Adobe Acrobat Reader. Kung may error sa isang app, subukan ang iba.

Paano ko maiiwasang i-type ang password sa bawat pagkakataon?

Mag-save ng kopyang walang password sa pamamagitan ng pag-print sa Save as PDF, at itago ang kopyang iyon sa pribadong folder.

Mabubuksan ba ng Android ang PDF kung nakalimutan ko ang password?

Hindi. Kailangan mo ang password. Karaniwang ipinapaliwanag ng email o SMS na kasama ng bank statement kung paano ito binubuo.

May UnKey app ba para sa Android?

Wala pa. Gumagana ang UnKey sa iPhone, iPad at Mac.
