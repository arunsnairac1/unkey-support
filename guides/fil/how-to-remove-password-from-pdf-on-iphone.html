Paano Magtanggal ng Password sa PDF sa iPhone (2026)

Na-update noong Oktubre 2026

Buksan ang PDF gamit ang password nito, saka mag-save ng kopyang walang password gamit ang Preview, ang Print-to-PDF na paraan, o offline na app tulad ng UnKey.

Para magtanggal ng password sa PDF sa iPhone, kailangan mo munang alam ang password. Buksan ang file, ilagay ito, at mag-save ng bagong kopyang walang password. Magagawa mo ito gamit ang mga app na nasa iPhone mo na o offline na app tulad ng UnKey.

Walang lehitimong paraan para tanggalin ang password na hindi mo alam. Kung nakalimutan mo ito, tingnan ang gagawin kapag nakalimutan ang password ng PDF.

Bago magsimula

  • I-save muna ang PDF sa Files app. Sa Mail, pindutin nang matagal ang attachment at piliin ang Save to Files (tingnan ang Apple: Download email attachments in Mail on iPhone).
  • Itabi ang orihinal hanggang makumpirma mong bumubukas at maayos ang bagong kopya.
  • Ihanda ang password. Para sa mga statement ng bangko at card, karaniwang ipinapaliwanag ng email na kasama ng statement ang format.

Opsyon 1: Ang Preview app (iOS 26 pataas)

May Preview app para sa mga PDF ang mga bagong bersyon ng iOS. Dokumentado ng Apple kung paano magdagdag ng password: buksan ang PDF, i-tap ang menu sa tabi ng pangalan ng file, i-tap ang Lock, at mao-on ang toggle na Require Password (Apple: Lock PDFs in Preview on iPhone).

Hindi inilalarawan ng gabay ng Apple ang pagtanggal ng password. Sa PDF na protektado na, maaari mong subukan ito: buksan sa Preview, ilagay ang password, i-tap ang menu sa tabi ng pangalan ng file, i-tap ang Lock, at i-off ang Require Password. May Export option din ang Preview na nagse-save ng bagong PDF (Apple: Export or compress PDFs in Preview on iPhone). Anuman ang piliin mong ruta, isara ang bagong file at buksan ulit. Kung humihingi pa rin ito ng password, gamitin ang isa sa mga opsyon sa ibaba.

Opsyon 2: Ang paraan gamit ang Print screen

Lumang trick ito na ginagamit ng marami. Hindi ito feature na dokumentado ng Apple, at maaaring lumipat ang mga button sa pagitan ng mga bersyon ng iOS.

  1. Buksan ang PDF sa Files at ilagay ang password.
  2. I-tap ang Share button, saka i-tap ang Print (Apple: Print from iPhone). Hindi mo kailangan ng printer.
  3. Sa Print Options screen, ibuka ang dalawang daliri sa preview ng pahina. Magbubukas ito ng full-screen preview, na isang bagong PDF.
  4. I-tap ang Share button at piliin ang Save to Files.

Suriin pagkatapos: maaaring iba ang lumabas sa mga form, link at searchable na teksto, at kung humaharang sa pag-print ang PDF, maaaring hindi lumabas ang Print.

Opsyon 3: UnKey (offline na app)

  1. Sa Files, Mail o ibang app, buksan ang Share sheet ng PDF at piliin ang UnKey, o buksan ang UnKey at piliin ang file.
  2. Ilagay ang password na hawak mo na.
  3. I-save ang naka-unlock na kopya sa Files o i-share ito.

Gumagana ang UnKey sa device at hindi ina-upload ang file mo. Hindi ito nag-crack o humuhula ng password. Inaalis lang nito ang password na alam mo na. Libre ang pag-unlock. Puwede mo ring i-save ang mga password para sa statement na natatanggap mo buwan-buwan. Nananatili ang mga ito sa Keychain ng device sa likod ng Face ID o Touch ID, kaya mabubuksan ang statement ng susunod na buwan nang hindi na nagta-type ulit. Kung tinanggihan ang password

  • Suriin ang malalaking titik. Case-sensitive ang mga password ng PDF. Maraming bangko ang gumagamit ng pangalan mo sa malalaking titik.
  • Suriin ang format ng petsa. Karaniwan ang DDMMYYYY, DDMMYY at DDMM, at hindi sila magkapalit.
  • Suriin ang email. Karaniwang sinasabi ng mga bangko at card issuer ang format sa email na kasama ng statement.
  • Tingnan kung may typo o autofill na espasyo. I-type ang password nang mano-mano sa halip na i-paste.

Dapat ba talagang tanggalin?

Mabubuksan ng sinumang makakakuha ng file ang PDF na naka-unlock. Kung iniimbak mo ito sa shared na iCloud folder o ipinapasa, isipin kung sino ang maaaring makaabot dito. Para sa mas malalim na talakayan, basahin ang ligtas bang tanggalin ang password ng PDF.

Mga tanong

Puwede ba akong magtanggal ng password ng PDF sa iPhone nang hindi alam ito?

Hindi. Ang bawat lehitimong paraan, kasama ang mga app ng Apple at UnKey, ay nangangailangan muna ng tamang password para mabuksan ang file. Kung nakalimutan mo ito, kunin sa nagpadala o i-download ulit ang dokumento.

May libreng paraan ba na hindi kailangang mag-install ng kahit ano?

Mayroon. Subukan ang Lock setting ng Preview o ang paraan gamit ang Print screen, na nagse-save ng bagong kopyang walang password. Tiyaking normal na bumubukas ang bagong kopya bago burahin ang orihinal.

Ina-upload ba ng UnKey ang PDF ko?

Hindi. Ina-unlock ng UnKey ang file sa iPhone mo at walang ina-upload.

Papalitan ba ng naka-unlock na kopya ang orihinal ko?

Hindi, maliban kung pipiliin mong i-overwrite ito. Mas ligtas na i-save ang kopya sa bagong pangalan, suriin ito, saka magpasya kung itatago ang orihinal.
