Buksan ang PDF na May Password mula sa WhatsApp o Gmail sa iPhone

Na-update noong Oktubre 2026

I-tap ang PDF para i-preview at ilagay ang password, o gamitin ang Share button para i-save ito sa Files o ipadala sa app tulad ng UnKey.

Para magbukas ng PDF na may password sa iPhone, i-tap ang attachment at ilagay ang password kapag hiningi. Kung hindi humihingi ang viewer sa loob ng app, o gusto mong itabi ang file, gamitin ang Share button para i-save ito sa Files o buksan sa ibang app. Kailangan pa rin ng tamang password sa lahat ng ruta sa ibaba.

Mula sa Apple Mail

  1. Buksan ang email at i-tap ang PDF attachment para i-preview. Ilagay ang password kung hiningi.
  2. Para itabi ito, pindutin nang matagal ang attachment at piliin ang Save to Files. Para buksan sa ibang app, piliin ang Share, saka piliin ang app (Apple: Download email attachments in Mail on iPhone).

Tip: sa Mail, puwede mong i-filter ang isang mailbox para ipakita lang ang mga mensaheng may attachment, na nakakatulong kapag naghahanap ka ng lumang statement.

Mula sa Gmail

  1. Buksan ang mensahe at i-tap ang attachment para buksan ito (Gmail Help: Open & download attachments on iPhone).
  2. Kung hindi maipakita ng viewer ng Gmail dahil sa password, gamitin ang share o "open in" na opsyon para ipasa ang file sa iOS. Mula sa iOS Share sheet, puwede mong piliin ang Save to Files o app tulad ng Preview o UnKey.
  3. Nag-aalok din ang Gmail ng Save to Drive, na nag-a-upload ng file sa Google Drive mo. Maginhawa ito, pero inilalagay nito ang file sa cloud.

Nagbabago paminsan-minsan ang mga pangalan ng button sa Gmail. Kung hindi mo makita, hanapin ang Share icon (parisukat na may arrow) o ang three-dot menu.

Mula sa WhatsApp

  1. I-tap ang dokumento sa chat. Nagpapakita ang WhatsApp ng preview, at para sa protektadong PDF, maaaring wala itong maipakitang kapaki-pakinabang o humingi ng password.
  2. I-tap ang Share button sa preview at piliin ang Save to Files, o pumili ng app mula sa Share sheet.
  3. Buksan ito mula sa Files at ilagay ang password.

Kung natanggap mo ang PDF mula sa ibang tao, hingin ang password sa hiwalay na mensahe o tawag, hindi sa parehong chat ng file.

Pagbubukas ng na-save na file

  • Files: i-tap ang PDF at ilagay ang password kapag hiningi.
  • Preview (iOS 26 pataas): hanapin ang file sa Browse o Recents at i-tap ito (Apple: Open and view PDFs in Preview on iPhone).
  • UnKey: piliin ang UnKey mula sa Share sheet sa Mail, Gmail, WhatsApp o Files. Ilagay ang password at puwede mong tingnan ang PDF o mag-save ng naka-unlock na kopya. Gumagana ito offline, kaya hindi ina-upload ang file. Puwede mong i-save ang password para ang mga susunod na statement sa parehong format ay mabuksan gamit ang Face ID.

Kung sinabing mali ang password

  • I-type ito nang mano-mano. Minsan nagkakaroon ng espasyo sa dulo ang mga na-paste na password.
  • Suriin ang malalaking titik. Case-sensitive ang mga password.
  • Suriin ang format ng petsa: DDMMYYYY, DDMMYY o DDMM.
  • Basahin ang orihinal na email o SMS mula sa nag-isyu, na karaniwang nagpapaliwanag ng format.
  • Kung na-forward sa WhatsApp ang file, maaaring hawak ng nagpadala ang password, o maaaring nag-forward siya ng naka-unlock nang kopya na ngayon ay sira na. Hilingin sa kanyang ipadala ulit.

Kung hindi talaga mabuksan ang PDF

Maaaring magmukhang problema sa password ang download na hindi natapos. Burahin ang kopya, i-download ulit sa magandang koneksyon, at subukan muli. Kung nagko-compress ng file ang app ng nagpadala, hilingin sa kanyang ipadala ito bilang document sa halip na bilang media.

Mga tanong

Bakit blangkong pahina ang ipinapakita ng WhatsApp para sa PDF ko?

Maaaring hindi kayang hawakan ng preview ng WhatsApp ang mga PDF na may password. I-save ang file sa Files o buksan sa ibang app mula sa Share sheet, saka doon ilagay ang password.

Mabubuksan ko ba ang protektadong PDF mula sa Gmail nang hindi dina-download?

Maaaring hindi mabuksan ng viewer ng Gmail ang mga file na may password. Ang pag-save ng file sa Files, o pagbubukas nito sa app sa pamamagitan ng Share, ang maaasahang ruta.

Ligtas bang magbukas ng statement PDF sa UnKey?

Gumagana ang UnKey offline sa iPhone mo at hindi nag-a-upload ng mga file. Mga PDF lang na nalagyan mo ng password ang binubuksan nito.
