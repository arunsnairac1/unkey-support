Paano Magtanggal ng Password sa PDF sa Mac (2026)

Na-update noong Oktubre 2026

Buksan ang PDF sa Preview gamit ang password nito, piliin ang File > Export, tiyaking walang open password na nakatakda, at mag-save ng bagong kopya.

Sa Mac, puwede mong tanggalin nang libre ang password ng PDF gamit ang Preview, ang app na kasama ng macOS. Buksan ang PDF, ilagay ang password, saka piliin ang File > Export at mag-save ng bagong kopyang walang open password. Kailangan mong alam ang password. Hindi bubuksan ng Preview ang file kung wala ito.

Paraan 1: Preview, File > Export

  1. I-double-click ang PDF para buksan sa Preview at ilagay ang password.
  2. Piliin ang File > Export at bigyan ng bagong pangalan ang kopya, tulad ng "Statement-Oct-unlocked".
  3. I-click ang Permissions at tiyaking hindi napili ang Require Password To Open Document. Sa mga mas lumang bersyon ng macOS, may Encrypt checkbox sa halip sa Export window. Iwanang walang tsek.
  4. I-click ang Save.
  5. Isara ang bagong file at buksan ulit. Dapat itong bumukas nang hindi humihingi ng password.

Inilalarawan ng kasalukuyang gabay ng Apple ang Export window, ang Permissions button at ang opsyong Require Password To Open Document (Apple: Password-protect a PDF in Preview on Mac). Direktang sinabi sa bersyon ng parehong pahina para sa macOS Big Sur ng Apple: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide).

Kung may owner (permissions) password din ang PDF at alam mo ito, hinahayaan ka ng File > Edit Permissions na baguhin ang opening password at kung aling feature ang nangangailangan ng password.

Paraan 2: Print > Save as PDF

Anumang Mac app na kayang mag-print ay puwedeng gumawa ng bagong PDF (Apple: Save a document as a PDF on Mac):

  1. Buksan ang PDF gamit ang password nito.
  2. Piliin ang File > Print.
  3. I-click ang PDF pop-up menu at piliin ang Save as PDF.
  4. Huwag i-click ang Security Options, dahil doon ka maglalagay ulit ng password.

Ang na-print na kopya ay maaaring mawalan ng mga link, form field o bookmark. Kung humaharang sa pag-print ang dokumento, maaaring naka-grey ang paraang ito.

Paraan 4: Command line (para sa mga teknikal na user)

Magagawa ito ng libre at open-source na tool na qpdf sa Terminal: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. Inilalarawan ng dokumentasyon nito ang --decrypt bilang paggawa ng "an output file with no encryption even if the input file is encrypted" (qpdf documentation). Ikaw mismo ang mag-i-install nito, halimbawa gamit ang Homebrew. Ang pag-type ng password sa command line ay maaaring maiwan sa shell history mo.

Kung humihingi pa rin ng password

  • Baka ang orihinal ang nabuksan mo sa halip na ang kopya. Tingnan ang pangalan ng file.
  • I-export ulit at tiyaking naka-off ang Require Password To Open Document sa Permissions.
  • Subukan na lang ang Print > Save as PDF.
  • Kung tinatanggihan ng Preview ang password, suriin ang malalaking titik at ang format ng petsa, at basahin ang email na kasama ng dokumento.

Bago burahin ang orihinal

Mabubuksan ng sinumang may hawak ng file ang naka-unlock na PDF. Kasama dito ang mga iCloud Drive folder na ibinabahagi sa pamilya at sinumang manghiram ng Mac mo. Itago ang mga naka-unlock na statement sa pribadong lugar. Tingnan ang ligtas bang tanggalin ang password ng PDF para sa iba pang detalye.

Mga tanong

Libre ba talaga ang Preview?

Oo. Kasama ang Preview sa bawat Mac at kaya nitong mag-export ng PDF na walang open password kapag nailagay mo na ang password.

Matatanggal ba ng Preview ang password na hindi ko alam?

Hindi. Humihingi ng password ang Preview bago buksan ang file, at walang lehitimong paraan para lampasan iyon.

Paano mag-unlock ng maraming PDF nang sabay sa Mac?

Isang file lang kada pagkakataon ang kaya ng Preview. Kaya ng UnKey Pro na mag-batch unlock ng ilang PDF na iisa ang password, at puwedeng mag-script ng qpdf ang mga teknikal na user. Tingnan ang gabay namin sa pag-unlock ng maraming PDF nang sabay.

Bakit naka-grey ang Print > Save as PDF?

Maaaring may permissions password ang PDF na humaharang sa pag-print. Kung alam mo ang owner password, ilagay ito sa File > Edit Permissions. Kung hindi, gamitin ang Export na paraan.
