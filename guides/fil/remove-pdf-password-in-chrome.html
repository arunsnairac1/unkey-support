Paano Magtanggal ng Password sa PDF sa Chrome (2026)

Na-update noong Oktubre 2026

Buksan ang PDF sa Chrome gamit ang password nito, pindutin ang Ctrl+P o Cmd+P, itakda ang destination sa Save as PDF, at mag-save ng bagong kopyang walang password.

Kaya ng Google Chrome na mag-save ng kopya ng PDF na may password na wala na nito, nang libre, sa Windows, Mac at Linux. Buksan ang PDF sa Chrome, i-type ang password, pindutin ang Ctrl + P (Cmd + P sa Mac), itakda ang destination sa Save as PDF, at i-save. Kailangan mong alam na ang password. Hindi mabubuksan ng Chrome ang file kung wala ito.

Hakbang-hakbang (computer)

  1. I-drag ang PDF sa isang Chrome window, o i-right-click ang file at piliin ang Open with > Google Chrome.
  2. Hihingi ng password ang Chrome. I-type ito at pindutin ang Enter.
  3. Pindutin ang Ctrl + P sa Windows o Linux, o Cmd + P sa Mac. Puwede ring gamitin ang menu: File > Print.
  4. Sa print window, itakda ang Destination sa Save as PDF.
  5. I-click ang Save. Bigyan ng malinaw na pangalan ang bagong file, tulad ng Statement-Sep-2026-unlocked.pdf.
  6. Isara ito at buksan ulit ang bagong file. Dapat agad itong bumukas, walang hinihinging password.

Inilalarawan ng help page ng Google ang mga keyboard shortcut, ang pagpili ng destination sa print window, at ang opsyong Save as PDF (Google: Print from Chrome).

Sa Android phone

May parehong opsyon ang Chrome sa Android. Ito ang mga hakbang ng Google: i-tap ang More > Share, i-tap ang Print, saka i-tap ang Save as PDF at piliin kung saan ise-save ang file (Google: Print from Chrome on Android). Depende sa bersyon ng Chrome kung bubuksan nito ang PDF na nasa phone mo. Kung hindi, tingnan ang gabay namin sa pagbubukas ng PDF na may password sa Android.

Ano ang mawawala sa paraang ito

Gumagawa ng bagong PDF ang pag-save sa print window mula sa nasa screen. Ayos ito para sa pagbabasa, pag-aarchive o pag-upload ng statement. Pero suriin ang kopya bago burahin ang orihinal:

  • Maaaring hindi na gumana ang mga link at bookmark.
  • Maaaring maging patag ang mga form field, kaya hindi ka na makakapag-type sa mga ito.
  • Hindi nadadala ang digital signature. Kung kailangan ng portal ang pirmadong orihinal, i-upload ang orihinal.
  • Sumusunod sa print settings ang laki ng pahina. Sa ilalim ng More settings, tiyaking hindi lumiit o na-crop ang mga pahina dahil sa paper size at scale.

Kung hindi gumana ang Save as PDF

  • Naka-block ang pag-print. May mga PDF na may permissions password na pumipigil sa pag-print. Hiwalay ang permissions password sa open password. Tingnan ang paliwanag sa mga restriction ng pag-print at pagkopya ng PDF.
  • Tinatanggihan ng Chrome ang password. Suriin ang malalaking titik, ang format ng petsa at ang detalyeng nasa talaan ng bangko mo. Tingnan ang bakit hindi gumagana ang password ng PDF.
  • Nabuksan ang file sa ibang app. May mga computer na bumubukas ng PDF sa ibang reader bilang default. I-drag na lang ang file sa isang Chrome tab.

Iba pang paraan para tanggalin ang password

Ganoon din ang paraan ng Microsoft Edge sa Windows (tingnan ang pagtanggal ng password ng PDF sa Windows). Sa Mac, kayang mag-export ng Preview ng kopyang walang password (gabay para sa Mac). Sa iPhone, iPad at Mac, nagse-save ang UnKey ng naka-unlock na kopya offline at pinapanatili ang teksto, link at pahina, dahil inaalis nito ang encryption sa halip na i-print ulit ang file. Tulad ng Chrome, gumagana lang ito sa password na alam mo na.

Mga tanong

Ina-upload ba ng Chrome ang PDF ko kapag ginawa ito?

Hindi. Nangyayari sa browser sa computer mo ang pagbubukas ng PDF mula sa computer at pag-save nito gamit ang Save as PDF. Gamitin lang ang hiwalay na destinasyong “Save to Google Drive” kung gusto mo ng kopya sa Drive.

Matatanggal ba ng Chrome ang password na hindi ko alam?

Hindi. Humihingi ng password ang Chrome bago magpakita ng anuman. Kung nawala mo ito, tingnan ang gagawin kapag nakalimutan ang password ng PDF.

Bakit iba ang na-save na kopya sa orihinal?

Ipini-print ng Save as PDF ang mga pahina sa bagong file, kaya maaaring hindi manatili ang mga link, form field at lagda. Karaniwang pareho ang itsura ng teksto at layout.

Pinapayagan ba ito?

Para sa sarili mong dokumento, tulad ng bank statement mo, oo. Huwag tanggalin ang proteksyon ng mga file na wala kang karapatang buksan nang malaya.
