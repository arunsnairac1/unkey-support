Isang PDF lang kada pagkakataon ang kaya ng Preview; para mag-unlock ng maraming statement na iisa ang password, gumamit ng batch tool tulad ng UnKey Pro o qpdf script.

Kung marami kang statement, halimbawa labindalawang buwan mula sa iisang bangko, na pare-pareho ang password, hindi mo na kailangang isa-isahin ang pag-unlock. Isang file lang kada pagkakataon ang kaya ng mga built-in na tool tulad ng Preview. Kaya silang gawin nang sabay ng batch tool tulad ng UnKey Pro, o ng maikling qpdf script sa Mac. Kailangan mo pa ring alam ang password.

Bakit nakakatulong ang batch unlocking

Karamihan ng nag-isyu ay pinoprotektahan ang bawat statement gamit ang parehong format ng password na batay sa detalye mo. Kaya ang password para sa October ay karaniwang nakakabukas din sa January hanggang September. Doon nakakatipid ng oras ang batch tool, karaniwan tuwing panahon ng buwis, sa loan application, o kapag ibinibigay mo ang isang taon ng statement sa accountant.

Libreng opsyon: Preview sa Mac, isa-isa

Kayang magbukas ng ilang PDF nang sabay ang Preview, pero trabaho kada file ang pagtanggal ng password. Sa bawat PDF, ilalagay mo ang password, pipiliin ang File > Export, titiyaking naka-off ang Require Password To Open Document sa ilalim ng Permissions, at magse-save (Apple: Password-protect a PDF in Preview). Ayos na ito para sa tatlo o apat na file. Para sa tatlumpu, nakakapagod na at madaling malaktawan ang isa.

Sa iPhone at iPad, isa-isa rin ang mga libreng paraan (Lock setting ng Preview, o ang Print-to-PDF na paraan).

  4. Nagse-save ang UnKey ng naka-unlock na kopya ng bawat file. Suriin ang resulta, at i-unlock nang hiwalay ang anumang file na iba ang password.

Nangyayari ang lahat sa device mo, at walang ina-upload.

Libreng opsyon para sa mga teknikal na user: qpdf

Ang qpdf ay libre at open-source na command-line tool. Gamit ang --password at --decrypt, gumagawa ito ng hindi naka-encrypt na kopya ng file (qpdf documentation). Sa Terminal, ganito ang itsura ng loop sa isang folder:

for f in *.pdf; do qpdf --decrypt --password="$PDFPASS" "$f" "unlocked-$f"; done

I-set muna ang PDFPASS, mas mabuti kung hindi maiiwan sa shell history mo. Ang mga file na iba ang password ay magkakaroon ng error at hindi tahimik na lalaktawan. Ikaw mismo ang mag-i-install ng qpdf, halimbawa gamit ang Homebrew.

Kapag hindi iisa ang password ng mga file

  • Magkakaibang account: madalas magkaiba ang format ng savings account at credit card mula sa iisang bangko. Ihiwalay sila sa magkakahiwalay na folder.
  • Nagbago ang format: minsan binabago ng nag-isyu ang format. Ang mga lumang statement ay maaaring mangailangan ng dating format.
  • Joint o business account: maaaring batay ang password sa detalye ng pangunahing may-ari o ng kumpanya.

Pagkatapos mag-unlock ng batch

  • Buksan ang dalawa o tatlo sa mga kopya para suriin bago burahin ang anumang orihinal.
  • Gumamit ng malilinaw na pangalan, halimbawa "2026-04-statement-unlocked.pdf".
  • Panatilihing pribado ang folder ng mga naka-unlock. Detalyadong larawan ng pananalapi mo ang isang taon ng statement.
  • Kung ipapadala sa accountant, pag-isipang ipadala ang mga protektadong orihinal at ibahagi nang hiwalay ang password.
