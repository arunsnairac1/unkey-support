Paano Magtanggal ng Password sa PDF sa Windows (2026)

Na-update noong Oktubre 2026

Buksan ang PDF sa Microsoft Edge o Chrome gamit ang password nito, pindutin ang Ctrl+P, piliin ang Save as PDF (o Microsoft Print to PDF) at mag-save ng bagong kopya; kayang direktang magtanggal ng security ang bayad na Acrobat.

Sa Windows 10 at 11, puwede mong tanggalin nang libre ang password ng PDF gamit ang browser na nasa iyo na. Buksan ang PDF sa Microsoft Edge o Google Chrome, i-type ang password, pindutin ang Ctrl + P, piliin ang Save as PDF (o Microsoft Print to PDF) bilang printer, at i-save. Mabubuksan nang walang password ang bagong file. Kailangan mo munang alam ang password.

Paraan 1: Microsoft Edge (built in)

  1. I-right-click ang PDF sa File Explorer at piliin ang Open with > Microsoft Edge.
  2. I-type ang password kapag hiningi ng Edge.
  3. Pindutin ang Ctrl + P, o buksan ang More menu (ang tatlong tuldok) at piliin ang Print.
  4. Sa ilalim ng Printer, piliin ang Save as PDF o Microsoft Print to PDF.
  5. I-click ang Save (o Print), pumili ng folder at bigyan ng bagong pangalan ang kopya.
  6. Buksan ang bagong file para tiyaking hindi na ito humihingi ng password.

Ipinapakita ng gabay ng Microsoft para sa built-in PDF reader nito ang ruta sa Edge: hanapin ang Print sa ilalim ng More menu, piliin ang mga opsyon, saka mag-print (Microsoft: View, print, and edit PDFs in a PDF reader). Ang Microsoft Print to PDF ay printer na kasama ng Windows. Kung wala ito sa listahan, sabi ng Microsoft ay maibabalik ito sa Windows Optional Features (Microsoft: KB5058499 known issue).

Paraan 2: Google Chrome

Kung Chrome ang gamit mo, halos pareho ang mga hakbang: buksan ang PDF sa Chrome, ilagay ang password, pindutin ang Ctrl + P, itakda ang Destination sa Save as PDF, at i-click ang Save (Google: Print from Chrome). Mas detalyado sa gabay namin para sa Chrome.

Paraan 3: Adobe Acrobat Pro o Standard (bayad)

Ang bayad na Acrobat ay nag-aalis mismo ng encryption sa halip na i-print ulit ang file, kaya nananatiling buo ang mga link at form field. Dalawang ruta ang dokumentado ng Adobe (Adobe: Remove passwords from PDFs):

  • Protect tools: buksan ang PDF, pumunta sa Protect tools at piliin ang Remove Security. Kung open password lang ang file, kumpirmahin gamit ang OK. Kung may permissions password din ito, hihingin muna ng Acrobat ang password na iyon.
  • Security settings: buksan ang security properties ng dokumento, pumunta sa Security tab, piliin ang Change Settings, alisin ang mga password option at i-save.

Nagbabago ang lugar ng mga menu ng Adobe sa pagitan ng mga bersyon, kaya kung hindi mo makita ang eksaktong pangalang ito, hanapin ang “Remove Security” sa tool search ng Acrobat. Kayang magbukas ng protektadong PDF ng libreng Acrobat Reader pero hindi ito ang tool para magtanggal ng security. Gamitin ang Paraan 1 o 2.

Paraan 4: qpdf (para sa mga teknikal na user)

Tumatakbo sa Windows ang libre at open-source na qpdf. Ang qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf ay gumagawa ng kopyang walang encryption (qpdf documentation). Maaaring ma-save ang password sa command history mo, kaya burahin ito pagkatapos kung shared na PC.

Mga dapat suriin

  • Naka-grey ang Print? Maaaring may permissions password ang PDF na humaharang sa pag-print. Tingnan ang mga restriction sa pag-print at pagkopya.
  • Tinanggihan ang password? Suriin ang Caps Lock, ang format ng petsa at ang detalyeng hawak ng bangko mo. Tingnan ang bakit hindi gumagana ang password ng PDF.
  • Shared o office na PC? Mabubuksan ng sinumang makakakita ang naka-unlock na kopya. I-save ito sa pribadong folder at burahin sa Downloads.

Mga tanong

Kailangan ko bang mag-install ng anuman sa Windows?

Hindi. Kasama ng Windows 10 at 11 ang Microsoft Edge at ang Microsoft Print to PDF na printer.

Mas gagana ba ang mga online na site na “unlock PDF”?

Pareho ang trabaho nila pero ina-upload nila ang dokumento mo sa server ng iba. Para sa mga bank statement at papeles sa buwis, mas ligtas ang mga offline na paraan dito.

May makakatanggal ba nito ng password na nakalimutan ko?

Wala. Kailangan ng Edge, Chrome, Acrobat at qpdf ang tamang password. Tingnan ang email na kasama ng PDF para sa format.

Bakit hindi na gumagana ang mga link sa kopya?

Binubuo ulit ng pag-print sa PDF ang mga pahina, na maaaring mag-alis ng link at form field. Pinapanatili ang mga ito ng Remove Security ng Acrobat o ng qpdf.
