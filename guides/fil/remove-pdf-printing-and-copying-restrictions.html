Paliwanag sa Restriction ng Pag-print at Pagkopya ng PDF

Na-update noong Oktubre 2026

Pinipigilan ng open password ang sinuman na magbasa ng PDF; ang owner (permissions) password ay naghihigpit lang sa mga aksyon tulad ng pag-print, pagkopya at pag-edit.

Maaaring may dalawang magkaibang password ang mga PDF. Kailangan ang open password (tinatawag ding user password) para makita ang file. Ang owner password (tinatawag ding permissions password) ay hinahayaan kang magbukas ng file pero naghihigpit sa mga bagay tulad ng pag-print, pagkopya ng teksto o pag-edit. Para maalis nang maayos ang mga restriction, kailangan mo ang owner password.

Ganito rin ang paghahati ayon sa Adobe. Kailangan ang Document Open password para mabuksan ang PDF, at ang permissions password ay naghihigpit sa mga feature tulad ng pag-print, pag-edit at pagkopya (Adobe: Password security overview). May mahalagang detalye ang dokumentasyon ng qpdf: "apply security restrictions to files opened with the user password" at "allow security restrictions to be changed or overridden when files are opened with the owner password" ang mga reader (qpdf). Ibig sabihin, ipinapatupad ng mga reader ang mga restriction sa file na binuksan gamit ang user password, at hinahayaang baguhin o i-override ang mga ito kapag owner password ang ginamit.

Paano ipinapatupad ang mga restriction

Nakadepende ang mga restriction sa pagpapasya ng PDF reader na igalang ang mga ito. Sinasabi ng Adobe na ipinapatupad ito ng sarili nitong mga produkto, pero kung hindi sinusuportahan ng mga third-party na produkto ang mga setting na ito, maaaring malusutan ng mga tatanggap ang ilan o lahat ng restriction (Adobe). Kaya magalang na "pakiusap huwag" ang permissions password, hindi kandado. Hindi ito dahilan para balewalain ang kagustuhan ng may-akda. Kung may naghigpit ng pagkopya, karaniwang may dahilan, tulad ng copyright o kontrata.

Pagbabago ng mga restriction kung hawak mo ang owner password

Sa Mac (Preview): buksan ang PDF, piliin ang File > Edit Permissions, at ilagay ang owner password. Pagkatapos, piliin ang mga aksyong gusto mong payagan nang walang password at i-click ang Apply (Apple: Password-protect a PDF in Preview on Mac). Lumalabas din ang parehong Permissions panel sa ilalim ng File > Export kung gusto mo ng bagong kopya.

Sa Adobe Acrobat: ang tagubilin ng Adobe sa pagtanggal ng permissions password ay ipinapa-type ito sa Enter Password box (Adobe: How to remove a PDF password).

Sa command line: ang qpdf na may --password=OWNERPASSWORD --decrypt ay gumagawa ng kopyang walang encryption. Ayon sa dokumentasyon nito, hindi sinadya ang opsyong ito para lusutan ang mga restriction na inilalagay ng mga producer sa mga file (qpdf).

Sarili mong dokumento na may parehong password

Karaniwang open password lang ang ginagamit ng mga bank statement. Kapag nabuksan mo na ito, karaniwang malaya ka nang mag-print at kumopya. Kung ikaw mismo ang gumawa ng PDF sa Preview o Acrobat at naglagay ng parehong password, gamitin ang owner password para baguhin ang permissions o para mag-export ng kopyang walang restriction.

Para tanggalin ang open password sa sarili mong mga file, tulad ng buwanang statement, puwede mong gamitin ang Preview sa Mac o ang UnKey sa iPhone, iPad o Mac. Gumagana ang UnKey offline at sa mga password lang na alam mo na.

Kapag wala sa iyo ang owner password

  • Hilingin sa may-akda o nagpadala ang kopyang walang restriction, o ang pahintulot na mag-print o kumopya.
  • Para sa form na kailangan mong punan, tingnan kung pinapayagan na ang pagpuno. Maraming restricted na PDF ang pumapayag pa rin sa pagpuno ng form.
  • Para sa dokumentong pantrabaho o legal, ipagpalagay na sinadya ang restriction.

Mga tanong

Ano ang owner password ng PDF?

Password ito na kumokontrol sa mga permission tulad ng pag-print, pagkopya at pag-edit. Mabubuksan ang file nang wala ito, pero naka-block ang mga restricted na aksyon sa mga reader na gumagalang sa mga setting.

Bakit nabubuksan ko ang PDF pero hindi ko ma-print?

May owner (permissions) password ang file na hindi pumapayag sa pag-print. Ilagay ang owner password sa Preview sa ilalim ng File > Edit Permissions, o hingin sa nagpadala ang kopyang walang restriction.

May restriction ba sa pag-print ang mga bank statement?

Karaniwang wala. Open password lang ang karaniwang gamit nila, kaya kapag bukas na ang file ay puwede mo na itong i-print.

Legal ba ang pagtanggal ng restriction sa pagkopya ng PDF?

Ayos ang pagbabago ng permissions sa sarili mong file gamit ang sarili mong owner password. Ang paglusot sa restriction ng dokumento ng iba ay maaaring lumabag sa copyright o sa mga tuntunin ng kontrata, kaya magtanong sa may-ari.
