I-compress ang Scanned PDF para sa Limit ng Upload

Na-update noong Oktubre 2026

Malaki ang scanned PDF dahil litrato ang bawat pahina; paliitin ito gamit ang Reduce File Size ng Preview sa Mac o ang export options ng Preview sa iPhone, mag-scan ng mas kaunti at mas simpleng pahina, at alisin ang password bago mag-upload.

Madalas may limit ang mga portal ng visa, passport, exam at loan na ilang daang kilobyte o ilang megabyte lang kada file. Lumalampas dito ang mga scanned PDF dahil naka-save bilang litrato ang bawat pahina. Ang pinakamabilis na solusyon: i-save muli ang PDF na may image compression (libre ito sa Preview sa Mac o iPhone), i-scan lang ang mga pahinang kailangan, at alisin muna ang password, dahil maraming portal ang hindi nakakabasa ng protektadong file.

Bago mag-compress

  • Tingnan ang eksaktong limit at format sa pahina ng portal: ang pinakamalaking size, kung bawat file ba ito o kabuuan, at kung PDF o JPEG ang hinihingi. Magkakaiba ang patakaran ng bawat portal at nagbabago ito, kaya sundin kung ano ang nakasulat sa upload page.
  • Alisin ang password. Hindi mabubuksan ng portal ang protektadong PDF para suriin ito. Tingnan ang iPhone, Mac, Windows o Android.
  • Itabi ang orihinal. Bumababa ang kalidad ng larawan kapag nag-compress. Magtabi ng kopyang buo ang kalidad kung sakaling tanggihan ng portal ang malabong scan.

Sa Mac: Preview

  1. Buksan ang PDF sa Preview at piliin ang File > Export.
  2. Sa menu ng Quartz Filter, piliin ang Reduce File Size.
  3. Pangalanan ito ng bago at i-click ang Save.

Ayon sa Apple, ang na-compress na PDF ay “maaaring mas mababa ang kalidad kaysa sa orihinal.” Nag-aalok din ang parehong Export window ng Optimize images for screen at Save images as JPEG (Apple: Reduce the size of a PDF in Preview on Mac). Maaaring maging mahirap basahin ang mga scan na puro teksto kapag ginamit ang Reduce File Size, kaya buksan ang resulta at mag-zoom in bago mag-upload.

Sa iPhone o iPad: Preview (iOS 26 pataas)

  1. Buksan ang PDF sa Preview app.
  2. I-tap ang menu sa tabi ng pangalan ng file, saka i-tap ang Export.
  3. Piliin ang PDF, saka i-on ang Optimize Images for Screen at Save Images as JPEG.
  4. I-tap ang confirm button, pumili ng lokasyon, palitan ang pangalan at i-tap ang Save.

Sabi ng Apple, ang Optimize Images for Screen ay “gumagawa ng mas maliit na file” (Apple: Export or compress PDFs in Preview on iPhone). Kung JPEG ang gusto ng portal, puwede ring mag-export sa JPEG sa parehong screen, may slider para sa size.

Mag-scan nang mas maliit mula sa simula

  • Mga hinihinging pahina lang. Burahin ang sobrang pahina bago mag-upload. Kaya ng Preview sa iPhone na magbura at mag-ayos ng pagkakasunod ng mga pahina (Apple).
  • Gamitin ang document scanner, hindi ang camera. Kino-crop at pinapatag ng Notes, Files at Preview ang pahina (Apple: How to scan documents on iPhone). Mas maliit ang na-crop na scan kaysa sa litrato ng buong mesa.
  • Greyscale o itim-at-puti para sa mga dokumentong puro teksto, kung pinapayagan ng portal. Hinahayaan ka ng scanner ng Preview na ayusin ang kulay ng bawat scan (Apple). Panatilihin ang kulay para sa mga litrato at sa anumang may selyo o stamp na kailangang makita ng opisyal.
  • Isang dokumento kada file. Kung may hiwa-hiwalay na slot ang portal, huwag pagsamahin ang lahat sa iisang napakalaking PDF.

Mga karaniwang problema

  • Malaki pa rin: mag-export ulit na naka-on ang dalawang option, o mag-scan ulit sa greyscale.
  • Malabo ang teksto: sobra ang compression. Bumalik sa orihinal at isang option lang ang gamitin.
  • Sabi ng portal na “corrupt” o “encrypted” ang file: malamang may password o restriction pa rin ito. Alisin ang password at subukan ulit.
  • Lumaki ang file: maliit na talaga ang mga PDF na halos totoong teksto. Maaari pa itong lumaki kapag in-save ulit. I-upload ang orihinal.

Mga tanong

Mawawalan ba ng linaw ang mga dokumento ko kapag nag-compress?

Puwede, kapag sobra. Laging buksan ang na-compress na kopya, mag-zoom in sa maliliit na letra, at itabi ang orihinal.

Bakit 8 MB ang 2-pahinang scan?

Mataas na resolution na litrato ang bawat scanned na pahina. Maliit ang mga text PDF mula sa bangko dahil teksto ang laman nila, hindi larawan.

Tumatanggap ba ang mga portal ng PDF na may password?

Marami ang hindi nakakabasa nito. Alisin ang password bago mag-upload maliban kung iba ang sabi ng portal.

Ligtas ba ang mga online compressor para sa passport at statement?

Ina-upload nila ang file mo sa isang server. Para sa mga dokumentong pang-ID at pampinansyal, mas ligtas na mag-compress sa sarili mong device.
