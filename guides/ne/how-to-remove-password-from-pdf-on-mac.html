Mac मा PDF को पासवर्ड कसरी हटाउने (2026)

अक्टोबर २०२६ मा अपडेट गरिएको

यो भाषामा पढ्नुहोस्: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

Preview मा पासवर्डले PDF खोल्नुहोस्, File > Export छान्नुहोस्, खोल्ने पासवर्ड सेट नगरिएको निश्चित गर्नुहोस्, र नयाँ प्रति सेभ गर्नुहोस्।

Mac मा macOS सँगै आउने Preview एपबाट तपाईं निःशुल्क PDF को पासवर्ड हटाउन सक्नुहुन्छ। PDF खोल्नुहोस्, पासवर्ड हाल्नुहोस्, अनि File > Export छानेर खोल्ने पासवर्ड नभएको नयाँ प्रति सेभ गर्नुहोस्। तपाईंलाई पासवर्ड थाहा हुनुपर्छ। त्यसविना Preview ले फाइल खोल्दैन।

तरिका 1: Preview, File > Export

  1. PDF मा डबल-क्लिक गरेर Preview मा खोल्नुहोस् र पासवर्ड हाल्नुहोस्।
  2. File > Export छान्नुहोस् र प्रतिलाई “Statement-Oct-unlocked” जस्तो नयाँ नाम दिनुहोस्।
  3. Permissions मा क्लिक गरी Require Password To Open Document नछानिएको निश्चित गर्नुहोस्। पुराना macOS संस्करणमा Export विन्डोमा यसको सट्टा Encrypt चेकबक्स हुन्छ। त्यसलाई टिक नगर्नुहोस्।
  4. Save मा क्लिक गर्नुहोस्।
  5. नयाँ फाइल बन्द गरेर फेरि खोल्नुहोस्। यसले पासवर्ड नसोधी खुल्नुपर्छ।

Apple को हालको गाइडले Export विन्डो, Permissions बटन र Require Password To Open Document विकल्पको वर्णन गर्छ (Apple: Password-protect a PDF in Preview on Mac)। उही पेजको Apple को macOS Big Sur संस्करणमा यसो भनिएको थियो: “To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option” अर्थात् तपाईंले इन्क्रिप्ट गरेको PDF को पासवर्ड हटाउन, PDF खोलेर फेरि एक्सपोर्ट गर्नुहोस् र यसपटक इन्क्रिप्सन विकल्प अफ गर्नुहोस् (Apple, macOS Big Sur guide)।

PDF मा मालिकको (अनुमति) पासवर्ड पनि छ र तपाईंलाई थाहा छ भने File > Edit Permissions बाट खोल्ने पासवर्ड र कुन सुविधालाई पासवर्ड चाहिन्छ भन्ने बदल्न सकिन्छ।

तरिका 2: Print > Save as PDF

प्रिन्ट गर्न सक्ने Mac को जुनसुकै एपले नयाँ PDF बनाउन सक्छ (Apple: Save a document as a PDF on Mac):

  1. PDF लाई यसको पासवर्डले खोल्नुहोस्।
  2. File > Print छान्नुहोस्।
  3. PDF पप-अप मेनुमा क्लिक गरी Save as PDF छान्नुहोस्।
  4. Security Options मा क्लिक नगर्नुहोस्, किनकि पासवर्ड फेरि थप्ने ठाउँ त्यही हो।

प्रिन्ट गरिएको प्रतिमा लिंक, फारमका फिल्ड वा बुकमार्क हराउन सक्छन्। कागजातले प्रिन्ट रोकेको छ भने यो तरिका ग्रे हुन सक्छ।

तरिका 3: Mac को लागि UnKey

UnKey Mac मा पनि निःशुल्क छ। UnKey Pro, एकपटकको खरिद, ले iPhone, iPad र Mac मा ब्याच अनलक र अन्य Pro टुल थप्छ। PDF लाई विन्डोमा तान्नुहोस्, पासवर्ड हाल्नुहोस्, र यसले अनलक गरिएको प्रति सेभ गर्छ। UnKey Pro ले एकैपटक धेरै फाइल ब्याचमा अनलक पनि गर्न सक्छ, जुन एउटै पासवर्ड भएका वर्षभरिका मासिक स्टेटमेन्टका लागि उपयोगी हुन्छ। UnKey अफलाइन चल्छ, केही अपलोड गर्दैन, र तपाईंलाई पहिल्यै थाहा भएको पासवर्ड मात्र हटाउँछ।

तरिका 4: कमान्ड लाइन (प्राविधिक प्रयोगकर्ताका लागि)

निःशुल्क, ओपन-सोर्स टुल qpdf ले Terminal मा यो गर्न सक्छ: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf। यसको डकुमेन्टेसनले --decrypt लाई इनपुट फाइल इन्क्रिप्ट गरिएको भए पनि इन्क्रिप्सनविनाको आउटपुट फाइल बनाउने भनी वर्णन गर्छ (“an output file with no encryption even if the input file is encrypted”) (qpdf documentation)। यो तपाईं आफैंले इन्स्टल गर्नुपर्छ, जस्तै Homebrew बाट। कमान्ड लाइनमा पासवर्ड टाइप गर्दा त्यो तपाईंको shell history मा रहन सक्छ।

अझै पासवर्ड सोध्छ भने

  • तपाईंले प्रतिको सट्टा मूल फाइल खोल्नुभएको हुन सक्छ। फाइलको नाम जाँच्नुहोस्।
  • फेरि एक्सपोर्ट गर्नुहोस् र Permissions मा Require Password To Open Document अफ छ कि जाँच्नुहोस्।
  • यसको सट्टा Print > Save as PDF प्रयास गर्नुहोस्।
  • Preview ले पासवर्ड अस्वीकार गर्छ भने ठूला अक्षर र मिति ढाँचा जाँच्नुहोस्, र कागजातसँग आएको इमेल पढ्नुहोस्।

मूल फाइल मेट्नुअघि

अनलक गरिएको PDF फाइल हुने जो कोहीले खोल्न सक्छ। यसमा परिवारसँग साझा गरिएका iCloud Drive फोल्डर र तपाईंको Mac मागेर चलाउने कोही पनि पर्छन्। अनलक गरिएका स्टेटमेन्ट निजी ठाउँमा राख्नुहोस्। थप जान्न PDF पासवर्ड हटाउनु सुरक्षित छ कि भन्ने हेर्नुहोस्।

प्रश्नहरू

Preview साँच्चै निःशुल्क हो?

हो। Preview हरेक Mac सँग आउँछ र पासवर्ड हालेपछि खोल्ने पासवर्डविना PDF एक्सपोर्ट गर्न सक्छ।

मलाई थाहा नभएको पासवर्ड Preview ले हटाउन सक्छ?

सक्दैन। Preview ले फाइल खोल्नुअघि पासवर्ड सोध्छ, र त्यसलाई छल्ने कुनै वैध तरिका छैन।

Mac मा एकैपटक धेरै PDF कसरी अनलक गर्ने?

Preview ले एकपटकमा एउटा फाइल मात्र सम्हाल्छ। UnKey Pro ले एउटै पासवर्ड भएका धेरै PDF ब्याचमा अनलक गर्न सक्छ, र प्राविधिक प्रयोगकर्ताले qpdf को स्क्रिप्ट बनाउन सक्छन्। हाम्रो एकैपटक धेरै PDF अनलक गर्ने गाइड हेर्नुहोस्।

Print > Save as PDF किन ग्रे छ?

PDF मा प्रिन्ट रोक्ने अनुमति पासवर्ड हुन सक्छ। मालिकको पासवर्ड थाहा छ भने File > Edit Permissions मा हाल्नुहोस्। अन्यथा Export तरिका प्रयोग गर्नुहोस्।

ढाँचा परिवर्तन हुन सक्छ। पासवर्ड काम नगरे कागजातसँग आएको इमेल हेर्नुहोस् वा जारीकर्तालाई सम्पर्क गर्नुहोस्। यहाँ उल्लेख गरिएका कुनै पनि बैंक, रोजगारदाता वा निकायसँग UnKey को सम्बन्ध छैन।

अङ्ग्रेजीबाट अनुवाद गरिएको। केही फरक भए अङ्ग्रेजी पृष्ठ नै आधार हुनेछ।

एकपटक अनलक गर्नुहोस्।

तपाईंले पहिल्यै खोल्न सक्ने PDF बाट UnKey ले पासवर्ड हटाउँछ, iPhone, iPad र Mac मा। अफलाइन चल्छ, केही पनि अपलोड हुँदैन। पासवर्ड एकपटक सेभ गर्नुहोस्, अर्को महिनाको स्टेटमेन्ट Face ID ले खोल्छ।
