Windows मा PDF को पासवर्ड कसरी हटाउने (2026)

अक्टोबर २०२६ मा अपडेट गरिएको

यो भाषामा पढ्नुहोस्: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · नेपाली · Português · සිංහල · தமிழ் · తెలుగు

Microsoft Edge वा Chrome मा पासवर्डले PDF खोल्नुहोस्, Ctrl+P थिच्नुहोस्, Save as PDF (वा Microsoft Print to PDF) छानी नयाँ प्रति सेभ गर्नुहोस्; सशुल्क Acrobat ले सुरक्षा सीधै हटाउन सक्छ।

Windows 10 र 11 मा तपाईंसँग भएको ब्राउजरबाट नै निःशुल्क PDF को पासवर्ड हटाउन सकिन्छ। PDF लाई Microsoft Edge वा Google Chrome मा खोल्नुहोस्, पासवर्ड टाइप गर्नुहोस्, Ctrl + P थिच्नुहोस्, प्रिन्टरमा Save as PDF (वा Microsoft Print to PDF) छान्नुहोस्, र सेभ गर्नुहोस्। नयाँ फाइल पासवर्डविना खुल्छ। तपाईंलाई पहिले पासवर्ड थाहा हुनुपर्छ।

तरिका 1: Microsoft Edge (बिल्ट-इन)

  1. File Explorer मा PDF मा राइट-क्लिक गरी Open with > Microsoft Edge छान्नुहोस्।
  2. Edge ले सोध्दा पासवर्ड टाइप गर्नुहोस्।
  3. Ctrl + P थिच्नुहोस्, वा More मेनु (तीन थोप्ला) खोलेर Print छान्नुहोस्।
  4. Printer मुनि Save as PDF वा Microsoft Print to PDF छान्नुहोस्।
  5. Save (वा Print) मा क्लिक गर्नुहोस्, फोल्डर छान्नुहोस् र प्रतिलाई नयाँ नाम दिनुहोस्।
  6. नयाँ फाइल खोलेर अब पासवर्ड नसोधेको जाँच गर्नुहोस्।

Microsoft को बिल्ट-इन PDF रिडरको गाइडले Edge को बाटो देखाउँछ: More मेनुमा Print खोज्नुहोस्, विकल्प छान्नुहोस्, अनि प्रिन्ट गर्नुहोस् (Microsoft: View, print, and edit PDFs in a PDF reader)। Microsoft Print to PDF Windows सँग आउने प्रिन्टर हो। सूचीमा छैन भने Microsoft का अनुसार Windows Optional Features मा गई फेरि अन गर्न सकिन्छ (Microsoft: KB5058499 known issue)।

तरिका 2: Google Chrome

Chrome प्रयोग गर्नुहुन्छ भने चरण लगभग उस्तै हुन्: Chrome मा PDF खोल्नुहोस्, पासवर्ड हाल्नुहोस्, Ctrl + P थिच्नुहोस्, Destination लाई Save as PDF राख्नुहोस्, र Save मा क्लिक गर्नुहोस् (Google: Print from Chrome)। थप विवरण हाम्रो Chrome गाइड मा छ।

तरिका 3: Adobe Acrobat Pro वा Standard (सशुल्क)

सशुल्क Acrobat ले फाइल फेरि प्रिन्ट गर्ने सट्टा इन्क्रिप्सन नै हटाउँछ, त्यसैले लिंक र फारम फिल्ड जस्ताका तस्तै रहन्छन्। Adobe ले दुई बाटो बताएको छ (Adobe: Remove passwords from PDFs):

  • Protect टुल: PDF खोल्नुहोस्, Protect टुलमा गएर Remove Security छान्नुहोस्। फाइलमा खोल्ने पासवर्ड मात्र छ भने OK ले पुष्टि गर्नुहोस्। अनुमति पासवर्ड पनि छ भने Acrobat ले पहिले त्यो पासवर्ड सोध्छ।
  • Security सेटिङ: कागजातको security properties खोल्नुहोस्, Security ट्याबमा गएर Change Settings छान्नुहोस्, पासवर्ड विकल्प खाली गर्नुहोस् र सेभ गर्नुहोस्।

Adobe का मेनु संस्करणअनुसार सर्छन्, त्यसैले यी ठ्याक्कै नाम देखिएनन् भने Acrobat को टुल खोजमा “Remove Security” खोज्नुहोस्। निःशुल्क Acrobat Reader ले सुरक्षित PDF खोल्न सक्छ तर सुरक्षा हटाउने टुल होइन। तरिका 1 वा 2 प्रयोग गर्नुहोस्।

तरिका 4: qpdf (प्राविधिक प्रयोगकर्ता)

निःशुल्क, ओपन-सोर्स qpdf टुल Windows मा चल्छ। qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf ले इन्क्रिप्सनविनाको प्रति लेख्छ (qpdf documentation)। पासवर्ड तपाईंको कमान्ड इतिहासमा सेभ हुन सक्छ, त्यसैले साझा PC मा पछि त्यो खाली गर्नुहोस्।

जाँच्नुपर्ने कुरा

  • Print ग्रे छ? PDF मा प्रिन्ट रोक्ने अनुमति पासवर्ड हुन सक्छ। प्रिन्टिङ र कपी प्रतिबन्ध हेर्नुहोस्।
  • पासवर्ड अस्वीकार भयो? Caps Lock, मिति ढाँचा र बैंकसँग भएका विवरण जाँच्नुहोस्। PDF पासवर्ड किन काम गरिरहेको छैन हेर्नुहोस्।
  • साझा वा कार्यालयको PC? अनलक गरिएको प्रति भेट्ने जो कोहीले खोल्न सक्छ। निजी फोल्डरमा सेभ गर्नुहोस् र Downloads बाट मेट्नुहोस्।

तपाईंसँग iPhone, iPad वा Mac पनि छ भने, UnKey ले ती उपकरणमा अफलाइन पासवर्ड हटाउँछ र अर्को महिनाको स्टेटमेन्टका लागि पासवर्ड सेभ गर्न सक्छ। Windows का लागि UnKey एप छैन।

प्रश्नहरू

Windows मा केही इन्स्टल गर्नुपर्छ?

पर्दैन। Microsoft Edge र Microsoft Print to PDF प्रिन्टर Windows 10 र 11 सँगै आउँछन्।

अनलाइन &ldquo;unlock PDF&rdquo; साइटले राम्रो काम गर्छन्?

तिनले उही काम गर्छन् तर तपाईंको कागजात अर्कैको सर्भरमा अपलोड गर्छन्। बैंक स्टेटमेन्ट र कर कागजातका लागि यहाँका अफलाइन तरिका बढी सुरक्षित छन्।

यीमध्ये कुनैले बिर्सिएको पासवर्ड हटाउन सक्छ?

सक्दैन। Edge, Chrome, Acrobat र qpdf सबैलाई सही पासवर्ड चाहिन्छ। ढाँचाका लागि PDF सँगै आएको इमेल हेर्नुहोस्।

प्रतिमा लिंक किन काम गर्न छोड्छन्?

PDF मा प्रिन्ट गर्दा पेजहरू फेरि बन्छन्, जसले लिंक र फारम फिल्ड गुमाउन सक्छ। Acrobat को Remove Security वा qpdf ले तिनलाई जोगाउँछन्।
