How to Remove a Password from a PDF on Mac (2026)

Updated October 2026

Read in: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Bahasa Melayu · नेपाली · Português · සිංහල · தமிழ் · తెలుగు · اردو

Open the PDF in Preview with its password, choose File > Export, make sure no open password is set, and save a new copy.

On a Mac you can remove a PDF password for free with Preview, the app that comes with macOS. Open the PDF, enter the password, then choose File > Export and save a new copy that has no open password. You need to know the password. Preview won't open the file without it.

Method 1: Preview, File > Export

  1. Double-click the PDF to open it in Preview and enter the password.
  2. Choose File > Export and give the copy a new name, such as "Statement-Oct-unlocked".
  3. Click Permissions and make sure Require Password To Open Document is not selected. On older macOS versions, the Export window has an Encrypt checkbox instead. Leave it unticked.
  4. Click Save.
  5. Close the new file and open it again. It should open without asking for a password.

Apple's current guide describes the Export window, the Permissions button and the Require Password To Open Document option (Apple: Password-protect a PDF in Preview on Mac). Apple's macOS Big Sur version of the same page put it directly: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, macOS Big Sur guide).

If the PDF also has an owner (permissions) password and you know it, File > Edit Permissions lets you change the opening password and which features need a password.

Method 2: Print > Save as PDF

Any Mac app that can print can make a fresh PDF (Apple: Save a document as a PDF on Mac):

  1. Open the PDF with its password.
  2. Choose File > Print.
  3. Click the PDF pop-up menu and choose Save as PDF.
  4. Don't click Security Options, because that's where you'd add a password back.

The printed copy can lose links, form fields or bookmarks. If the document blocks printing, this method may be greyed out.

Method 4: Command line (for technical users)

The free, open-source tool qpdf can do it in Terminal: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. Its documentation describes --decrypt as creating "an output file with no encryption even if the input file is encrypted" (qpdf documentation). You install it yourself, for example with Homebrew. Typing a password on the command line can leave it in your shell history.

If it still asks for a password

  • You may have opened the original instead of the copy. Check the file name.
  • Re-export and check that Require Password To Open Document is turned off in Permissions.
  • Try Print > Save as PDF instead.
  • If Preview rejects the password, check capital letters and the date format, and read the email the document came with.

Before you delete the original

An unlocked PDF opens for anyone who has the file. That includes iCloud Drive folders shared with family and anyone who borrows your Mac. Keep unlocked statements somewhere private. See is it safe to remove a PDF password for more.

Questions

Is Preview really free?

Yes. Preview comes with every Mac and can export a PDF without an open password once you've entered the password.

Can Preview remove a password I don't know?

No. Preview asks for the password before it opens the file, and there's no legitimate way around that.

How do I unlock many PDFs at once on a Mac?

Preview handles one file at a time. UnKey Pro can batch-unlock several PDFs that share a password, and technical users can script qpdf. See our guide to unlocking many PDFs at once.

Why is Print > Save as PDF greyed out?

The PDF may have a permissions password that blocks printing. If you know the owner password, enter it under File > Edit Permissions. Otherwise, use the Export method.
