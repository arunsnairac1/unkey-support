Cara Membuka PDF Berpassword di Android (2026)

Buka PDF di aplikasi pembaca PDF seperti Google Drive, Files by Google, atau Adobe Acrobat Reader dan masukkan password; untuk menyimpan salinan tanpa password, cetak ke Save as PDF.

Untuk membuka PDF berpassword di ponsel Android, buka di aplikasi pembaca PDF seperti Google Drive, Files by Google, atau Adobe Acrobat Reader, lalu ketik password saat diminta. Untuk menyimpan salinan yang terbuka tanpa password, pakai opsi Print (Cetak) di aplikasi dan pilih Save as PDF sebagai printer.

Membuka PDF

  1. Simpan file ke ponsel dulu. Di Gmail, ketuk ikon unduh pada lampiran. Di WhatsApp, buka dokumennya sekali agar terunduh.
  2. Buka di aplikasi pembaca PDF. Ketuk file di Download, atau pakai Open with (Buka dengan) dan pilih aplikasi yang Anda percaya. Google Drive, Files by Google, dan Adobe Acrobat Reader semuanya bisa membuka PDF terproteksi setelah Anda mengetik password.
  3. Ketik password. Perhatikan keyboard. Keyboard Android sering membuat huruf pertama menjadi kapital atau menambah spasi setelah saran kata. Matikan saran untuk kolom ini, atau ketik pelan-pelan dan periksa tiap karakter.

Kalau aplikasi menampilkan halaman kosong atau pesan galat alih-alih kotak password, coba pembaca lain. Beberapa layar pratinjau, seperti yang ada di dalam aplikasi obrolan atau email, tidak bisa menangani PDF terenkripsi.

Menyimpan salinan tanpa password

Android punya printer bawaan Save as PDF. Bantuan Chrome dari Google menjelaskannya: di layar cetak, ketuk daftar printer di bagian atas, pilih Save as PDF, lalu pilih tempat menyimpan file (Google: Print from Chrome on Android). Printer yang sama muncul di aplikasi lain yang bisa mencetak:

  1. Buka PDF dan masukkan password.
  2. Buka menu aplikasi (biasanya tiga titik, atau Share) dan ketuk Print.
  3. Di bagian atas layar cetak, pilih Save as PDF.
  4. Ketuk tombol PDF, pilih folder, lalu simpan dengan nama baru.
  5. Buka salinan baru untuk memastikan tidak meminta password.

Menu berbeda di tiap aplikasi dan merek ponsel, jadi opsi Print mungkin ada di bawah Share, More, atau ⋮. Kalau Print tidak ada atau berwarna abu-abu, PDF mungkin punya password izin yang memblokir pencetakan (lihat pembatasan pencetakan dan penyalinan).

Tips Google Drive

  • Mengunggah file asli yang terproteksi ke Drive lebih aman daripada mengunggah salinan tanpa password. Siapa pun yang berbagi folder dengan Anda bisa membuka salinan tanpa password.
  • Di komputer, unduh file dari Drive dan buka di Chrome untuk menghapus password. Lihat cara menghapus password PDF di Chrome.

Jika password tidak berfungsi

Password rekening koran bank dan kartu disusun dari data Anda dengan pola tertentu, dan email yang menyertai rekening koran biasanya menjelaskannya. Periksa huruf kapital, format tanggal, dan nomor ponsel mana yang dimiliki bank. Panduan kami membahas SBI, HDFC Bank, ICICI Bank, e-Aadhaar, dan banyak lagi, serta alasan password ditolak.

Pertanyaan

Aplikasi apa yang harus saya pakai untuk membuka PDF terproteksi di Android?

Pembaca PDF tepercaya mana pun yang meminta password, seperti Google Drive, Files by Google, atau Adobe Acrobat Reader. Kalau satu aplikasi menampilkan galat, coba yang lain.

Bagaimana agar tidak mengetik password setiap kali?

Simpan salinan tanpa password dengan mencetak ke Save as PDF, dan simpan salinan itu di folder pribadi.

Bisakah Android membuka PDF jika saya lupa password?

Tidak. Anda memerlukan passwordnya. Email atau SMS yang menyertai rekening koran bank biasanya menjelaskan cara menyusunnya.
