Cara Menghapus Password dari PDF di Mac (2026)

Diperbarui Oktober 2026

Baca dalam: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · Português · தமிழ் · తెలుగు

Buka PDF di Preview dengan passwordnya, pilih File > Export, pastikan tidak ada password buka yang diatur, lalu simpan salinan baru.

Di Mac, Anda bisa menghapus password PDF secara gratis dengan Preview, aplikasi bawaan macOS. Buka PDF, masukkan password, lalu pilih File > Export dan simpan salinan baru tanpa password buka. Anda perlu tahu passwordnya. Preview tidak akan membuka file tanpa password itu.

Metode 1: Preview, File > Export

  1. Klik dua kali PDF untuk membukanya di Preview dan masukkan password.
  2. Pilih File > Export dan beri salinan nama baru, misalnya "Statement-Oct-unlocked".
  3. Klik Permissions dan pastikan Require Password To Open Document tidak dipilih. Pada macOS versi lama, jendela Export memiliki kotak centang Encrypt. Biarkan tidak dicentang.
  4. Klik Save.
  5. Tutup file baru dan buka lagi. File seharusnya terbuka tanpa meminta password.

Panduan Apple saat ini menjelaskan jendela Export, tombol Permissions, dan opsi Require Password To Open Document (Apple: Password-protect a PDF in Preview on Mac). Versi macOS Big Sur dari halaman yang sama menyatakannya langsung: "To remove a password from a PDF that you encrypted, open the PDF and export it again, this time turning off the encryption option" (Apple, panduan macOS Big Sur).

Kalau PDF juga memiliki password pemilik (izin) dan Anda mengetahuinya, File > Edit Permissions memungkinkan Anda mengubah password buka dan fitur mana yang memerlukan password.

Metode 2: Print > Save as PDF

Aplikasi Mac mana pun yang bisa mencetak dapat membuat PDF baru (Apple: Save a document as a PDF on Mac):

  1. Buka PDF dengan passwordnya.
  2. Pilih File > Print.
  3. Klik menu pop-up PDF dan pilih Save as PDF.
  4. Jangan klik Security Options, karena di sanalah password akan ditambahkan kembali.

Salinan hasil cetak bisa kehilangan tautan, kolom formulir, atau bookmark. Jika dokumen memblokir pencetakan, metode ini mungkin berwarna abu-abu.

Metode 4: Baris perintah (untuk pengguna teknis)

Alat sumber terbuka gratis qpdf bisa melakukannya di Terminal: qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf. Dokumentasinya menjelaskan --decrypt sebagai pembuat "an output file with no encryption even if the input file is encrypted" (dokumentasi qpdf). Anda memasangnya sendiri, misalnya dengan Homebrew. Mengetik password di baris perintah bisa meninggalkannya di riwayat shell.

Jika masih meminta password

  • Mungkin Anda membuka file asli, bukan salinannya. Periksa nama file.
  • Ekspor ulang dan pastikan Require Password To Open Document dimatikan di Permissions.
  • Coba Print > Save as PDF sebagai gantinya.
  • Jika Preview menolak password, periksa huruf kapital dan format tanggal, lalu baca email yang menyertai dokumen.

Sebelum menghapus file asli

PDF tanpa password terbuka untuk siapa saja yang memegang filenya. Itu termasuk folder iCloud Drive yang dibagikan dengan keluarga dan siapa pun yang meminjam Mac Anda. Simpan rekening koran tanpa password di tempat pribadi. Lihat apakah aman menghapus password PDF untuk selengkapnya.

Pertanyaan

Apakah Preview benar-benar gratis?

Ya. Preview sudah ada di setiap Mac dan dapat mengekspor PDF tanpa password buka setelah Anda memasukkan passwordnya.

Bisakah Preview menghapus password yang tidak saya ketahui?

Tidak. Preview meminta password sebelum membuka file, dan tidak ada cara sah untuk menyiasatinya.

Bagaimana cara membuka banyak PDF sekaligus di Mac?

Preview menangani satu file dalam satu waktu. UnKey Pro dapat membuka kunci beberapa PDF yang memakai password sama sekaligus, dan pengguna teknis dapat membuat skrip qpdf. Lihat panduan kami tentang membuka banyak PDF sekaligus.

Mengapa Print > Save as PDF berwarna abu-abu?

PDF mungkin memiliki password izin yang memblokir pencetakan. Jika Anda tahu password pemiliknya, masukkan di File > Edit Permissions. Jika tidak, gunakan metode Export.
