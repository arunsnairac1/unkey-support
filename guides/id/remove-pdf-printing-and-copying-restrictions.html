Penjelasan Pembatasan Cetak dan Salin pada PDF

Diperbarui Oktober 2026

Password buka mencegah siapa pun membaca PDF; password pemilik (izin) hanya membatasi tindakan seperti mencetak, menyalin, dan mengedit.

PDF bisa memiliki dua password yang berbeda. Password buka (disebut juga password pengguna) diperlukan untuk melihat file sama sekali. Password pemilik (disebut juga password izin) membiarkan Anda membuka file tetapi membatasi hal-hal seperti mencetak, menyalin teks, atau mengedit. Untuk mencabut pembatasan dengan benar, Anda memerlukan password pemilik.

Dua password dengan bahasa sederhana

Password buka (pengguna)Password pemilik (izin)
Yang Anda lihatPermintaan password sebelum apa pun tampilFile terbuka, tetapi Print atau Copy berwarna abu-abu
Yang dilindungiSeluruh isi, yang dienkripsiTindakan seperti mencetak, menyalin, mengedit, dan memberi komentar
Pemakaian umumRekening koran, dokumen pajakLaporan terbitan, formulir, kontrak

Adobe menjelaskan pembagian ini dengan cara yang sama. Password Document Open diperlukan untuk membuka PDF, dan password izin membatasi fitur seperti mencetak, mengedit, dan menyalin (Adobe: Password security overview). Dokumentasi qpdf menambahkan detail penting: pembaca "apply security restrictions to files opened with the user password" dan "allow security restrictions to be changed or overridden when files are opened with the owner password" (qpdf).

Bagaimana pembatasan diberlakukan

Pembatasan bergantung pada pembaca PDF yang memilih untuk menghormatinya. Adobe mencatat bahwa produknya sendiri memberlakukannya, tetapi jika produk pihak ketiga tidak mendukung pengaturan ini, penerima mungkin bisa menyiasati sebagian atau seluruh pembatasan (Adobe). Jadi password izin lebih berupa imbauan sopan "mohon jangan" daripada gembok. Namun itu bukan alasan untuk mengabaikan keinginan penulisnya. Jika seseorang membatasi penyalinan, biasanya ada alasannya, seperti hak cipta atau kontrak.

Mengubah pembatasan jika Anda punya password pemilik

Di Mac (Preview): buka PDF, pilih File > Edit Permissions, dan masukkan password pemilik. Lalu Anda bisa memilih tindakan yang ingin diizinkan tanpa password dan klik Apply (Apple: Password-protect a PDF in Preview on Mac). Panel Permissions yang sama muncul di File > Export jika Anda ingin salinan baru.

Di Adobe Acrobat: petunjuk Adobe untuk menghapus password izin meminta Anda mengetikkannya di kotak Enter Password (Adobe: How to remove a PDF password).

Di baris perintah: qpdf dengan --password=OWNERPASSWORD --decrypt menulis salinan tanpa enkripsi. Dokumentasinya mencatat bahwa opsi ini tidak dimaksudkan untuk menyiasati pembatasan yang dipasang produsen pada file (qpdf).

Dokumen Anda sendiri dengan kedua password

Rekening koran biasanya hanya memakai password buka. Setelah membukanya, Anda biasanya bebas mencetak dan menyalin. Jika Anda membuat PDF sendiri di Preview atau Acrobat dan mengatur kedua password, gunakan password pemilik untuk mengubah izin atau mengekspor salinan tanpa batasan.

Untuk menghapus password buka dari file Anda sendiri, seperti rekening koran bulanan, Anda bisa memakai Preview di Mac atau UnKey di iPhone, iPad, atau Mac. UnKey bekerja offline dan hanya bekerja dengan password yang sudah Anda ketahui.

Jika Anda tidak punya password pemilik

  • Minta salinan tanpa batasan kepada penulis atau pengirim, atau izin untuk mencetak atau menyalin.
  • Untuk formulir yang perlu Anda isi, periksa apakah pengisian sudah diizinkan. Banyak PDF yang dibatasi tetap mengizinkan pengisian formulir.
  • Untuk dokumen kerja atau hukum, anggap pembatasan itu disengaja.

Pertanyaan

Apa itu password pemilik PDF?

Password yang mengatur izin seperti mencetak, menyalin, dan mengedit. File bisa dibuka tanpanya, tetapi tindakan terbatas diblokir di pembaca yang menghormati pengaturannya.

Mengapa saya bisa membuka PDF tetapi tidak bisa mencetaknya?

File memiliki password pemilik (izin) yang melarang pencetakan. Masukkan password pemilik di Preview lewat File > Edit Permissions, atau minta salinan tanpa batasan kepada pengirim.

Apakah rekening koran bank memiliki pembatasan cetak?

Biasanya tidak. Umumnya hanya memakai password buka, jadi setelah file terbuka Anda bisa mencetaknya.

Apakah legal menghapus pembatasan salin PDF?

Mengubah izin pada file milik sendiri, dengan password pemilik Anda sendiri, tidak masalah. Menyiasati pembatasan pada dokumen orang lain bisa melanggar hak cipta atau ketentuan kontrak, jadi tanyakan kepada pemiliknya.
