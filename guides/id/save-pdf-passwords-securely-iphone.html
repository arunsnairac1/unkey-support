Cara Menyimpan Password PDF dengan Aman di iPhone

Diperbarui Oktober 2026

Simpan password PDF di aplikasi Passwords Apple, catatan terkunci, atau aplikasi yang menyimpannya di Keychain dengan Face ID, jangan pernah di catatan biasa.

Tempat paling aman untuk password PDF di iPhone adalah aplikasi Passwords Apple, catatan terkunci, atau aplikasi yang menyimpannya di Keychain iPhone dengan pengamanan Face ID atau Touch ID. Catatan biasa atau "pesan ke diri sendiri" di WhatsApp bukan tempat yang baik, karena siapa pun yang memegang ponsel Anda yang terbuka bisa membacanya.

Mengapa bukan catatan atau obrolan biasa?

  • Tanpa kunci tambahan. Catatan biasa terbuka begitu ponsel dibuka kuncinya.
  • Muncul di pencarian. Mengetik "password" di pencarian iPhone bisa memunculkannya.
  • Menyebar. Catatan di Gmail atau akun tersinkron lainnya, cadangan obrolan, dan tangkapan layar berakhir di lebih banyak tempat daripada yang Anda kira.
  • Password berdampingan dengan filenya. Jika rekening koran dan passwordnya sama-sama ada di satu obrolan, password PDF tidak melindungi apa pun.

Opsi 1: Aplikasi Passwords Apple

Aplikasi Passwords menyimpan entri dalam bentuk terenkripsi, dan iCloud Keychain menjaganya tetap terbarui di perangkat Anda yang disetujui (Apple: View your passwords). Aplikasi ini dibuat untuk login situs web, tetapi Anda bisa menambahkan entri untuk dokumen:

  1. Buka Passwords, ketuk All, lalu ketuk tombol tambah (Apple: Create a password).
  2. Isi kolom situs web atau aplikasi dengan sesuatu seperti "Bank statement PDF", tambahkan label sebagai nama pengguna, dan ketik password PDF.
  3. Simpan. Nanti, ketuk Edit > Notes untuk menambahkan keterangan seperti "format: 4 huruf pertama nama + DDMM". Apple menyebut Anda dapat menyimpan catatan seperti nomor PIN dan pertanyaan keamanan di sini dengan aman.

Menyimpan format-nya, bukan passwordnya sendiri, adalah trik yang rapi untuk rekening koran yang memakai data Anda. Rekening koran tahun depan akan memakai aturan yang sama.

Opsi 2: Catatan terkunci

Di Notes Anda bisa mengunci catatan dengan kode sandi perangkat atau password terpisah dan membukanya dengan Face ID atau Touch ID (Apple: Lock your notes on iPhone). Hal yang perlu diketahui:

  • Anda hanya bisa mengunci catatan yang tersimpan di perangkat atau di iCloud, bukan catatan yang tersinkron dengan Gmail atau akun lain.
  • Anda tidak bisa mengunci catatan yang berisi lampiran PDF, jadi pisahkan catatan password dari filenya.
  • Judul catatan tetap terlihat di daftar, jadi beri judul yang polos.
  • Jika Anda memakai password Notes khusus lalu lupa, Apple menyatakan tidak dapat membantu Anda masuk kembali ke catatan itu.

Opsi 3: Simpan di aplikasi yang membuka PDF

UnKey dapat menyimpan password saat Anda membuka kunci rekening koran, sehingga PDF bulan depan dengan format yang sama terbuka dengan Face ID atau Touch ID. Password tersimpan tetap berada di Keychain iPhone pada perangkat itu. Password tidak diunggah ke mana pun. Karena hanya ada di perangkat, password tidak ikut ke ponsel baru, jadi simpan cadangan untuk yang penting di aplikasi Passwords.

Praktik yang baik

  • Gunakan kode sandi perangkat yang kuat. Face ID hanya seaman kode sandi di baliknya.
  • Jangan tangkap layar password. Tangkapan layar tersinkron ke Photos dan mudah terbagikan tanpa sengaja.
  • Saat membagikan PDF terproteksi, kirim passwordnya lewat cara lain, misalnya telepon.
  • Hapus entri yang tidak lagi diperlukan. Di Passwords, buka entri, ketuk Edit, lalu Delete.

Pertanyaan

Bisakah saya menyimpan password PDF di aplikasi Passwords iPhone?

Bisa. Tambahkan entri baru dengan label deskriptif dan passwordnya, lalu gunakan kolom Notes untuk formatnya. Apple mengenkripsi entri ini dan menyinkronkannya dengan iCloud Keychain jika Anda mengaktifkannya.

Apakah catatan terkunci aman untuk password PDF?

Ya, selama catatan tersimpan di iCloud atau di perangkat dan terkunci. Anda tidak bisa mengunci catatan yang berisi lampiran PDF, jadi pisahkan keduanya.

Apakah UnKey mengunggah password tersimpan saya?

Tidak. UnKey menyimpan password di Keychain perangkat dengan pengamanan Face ID atau Touch ID, dan password tetap berada di perangkat itu.

Apa yang terjadi pada password tersimpan UnKey jika saya ganti ponsel?

Password disimpan di perangkat, jadi rencanakan untuk memasukkannya lagi di ponsel baru. Menyimpan salinan password penting di aplikasi Passwords akan membantu.
