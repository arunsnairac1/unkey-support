Cara Menghapus Password PDF di Windows (2026)

Diperbarui Oktober 2026

Buka PDF di Microsoft Edge atau Chrome dengan passwordnya, tekan Ctrl+P, pilih Save as PDF (atau Microsoft Print to PDF) dan simpan salinan baru; Acrobat berbayar bisa menghapus keamanan secara langsung.

Di Windows 10 dan 11 Anda bisa menghapus password PDF secara gratis dengan browser yang sudah ada. Buka PDF di Microsoft Edge atau Google Chrome, ketik password, tekan Ctrl + P, pilih Save as PDF (atau Microsoft Print to PDF) sebagai printer, lalu simpan. File baru terbuka tanpa password. Anda harus tahu passwordnya lebih dulu.

Metode 1: Microsoft Edge (bawaan)

  1. Klik kanan PDF di File Explorer dan pilih Open with > Microsoft Edge.
  2. Ketik password saat Edge memintanya.
  3. Tekan Ctrl + P, atau buka menu More (tiga titik) dan pilih Print.
  4. Di bawah Printer, pilih Save as PDF atau Microsoft Print to PDF.
  5. Klik Save (atau Print), pilih folder, dan beri salinan nama baru.
  6. Buka file baru untuk memastikan tidak lagi meminta password.

Panduan Microsoft untuk pembaca PDF bawaannya menunjukkan jalur Edge: temukan Print di menu More, pilih opsi, lalu cetak (Microsoft: View, print, and edit PDFs in a PDF reader). Microsoft Print to PDF adalah printer bawaan Windows. Jika tidak ada di daftar, Microsoft menyebut printer itu bisa diaktifkan kembali lewat Windows Optional Features (Microsoft: KB5058499 known issue).

Metode 2: Google Chrome

Jika Anda memakai Chrome, langkahnya hampir sama: buka PDF di Chrome, masukkan password, tekan Ctrl + P, atur Destination ke Save as PDF, lalu klik Save (Google: Print from Chrome). Detail lebih lengkap ada di panduan Chrome kami.

Metode 3: Adobe Acrobat Pro atau Standard (berbayar)

Acrobat berbayar menghapus enkripsinya sendiri, bukan mencetak ulang file, sehingga tautan dan kolom formulir tetap utuh. Adobe mendokumentasikan dua jalur (Adobe: Remove passwords from PDFs):

  • Alat Protect: buka PDF, masuk ke alat Protect dan pilih Remove Security. Jika file hanya punya password buka, konfirmasi dengan OK. Jika juga punya password izin, Acrobat meminta password itu lebih dulu.
  • Pengaturan keamanan: buka properti keamanan dokumen, masuk ke tab Security, pilih Change Settings, hapus opsi password, lalu simpan.

Menu Adobe berpindah antar versi, jadi jika Anda tidak melihat nama persis ini, cari “Remove Security” di pencarian alat Acrobat. Acrobat Reader gratis bisa membuka PDF terproteksi tetapi bukan alat untuk menghapus keamanan. Gunakan Metode 1 atau 2.

Metode 4: qpdf (pengguna teknis)

Alat sumber terbuka gratis qpdf berjalan di Windows. qpdf --decrypt --password=YOURPASSWORD in.pdf out.pdf menulis salinan tanpa enkripsi (dokumentasi qpdf). Password mungkin tersimpan di riwayat perintah, jadi hapus sesudahnya di PC bersama.

Hal yang perlu diperiksa

  • Print berwarna abu-abu? PDF mungkin punya password izin yang memblokir pencetakan. Lihat pembatasan pencetakan dan penyalinan.
  • Password ditolak? Periksa Caps Lock, format tanggal, dan data yang dimiliki bank Anda. Lihat mengapa password PDF tidak berfungsi.
  • PC bersama atau kantor? Salinan tanpa password terbuka untuk siapa saja yang menemukannya. Simpan di folder pribadi dan hapus dari Downloads.

Pertanyaan

Apakah saya perlu memasang sesuatu di Windows?

Tidak. Microsoft Edge dan printer Microsoft Print to PDF sudah ada di Windows 10 dan 11.

Apakah situs “unlock PDF” online bekerja lebih baik?

Mereka melakukan pekerjaan yang sama tetapi mengunggah dokumen Anda ke server orang lain. Untuk rekening koran dan dokumen pajak, metode offline di sini lebih aman.

Bisakah salah satunya menghapus password yang sudah saya lupakan?

Tidak. Edge, Chrome, Acrobat, dan qpdf semuanya memerlukan password yang benar. Cek email tempat PDF itu datang untuk mengetahui formatnya.

Mengapa tautan tidak berfungsi di salinan?

Mencetak ke PDF membangun ulang halaman, yang dapat menghilangkan tautan dan kolom formulir. Remove Security di Acrobat atau qpdf mempertahankannya.
