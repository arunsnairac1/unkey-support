Cara Menghapus Password PDF di Chrome (2026)

Diperbarui Oktober 2026

Baca dalam: English · العربية · বাংলা · Deutsch · Español · Français · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · Português · தமிழ் · తెలుగు

Buka PDF di Chrome dengan passwordnya, tekan Ctrl+P atau Cmd+P, atur tujuan ke Save as PDF, dan simpan salinan baru tanpa password.

Google Chrome bisa menyimpan salinan PDF berpassword tanpa passwordnya, gratis, di Windows, Mac, dan Linux. Buka PDF di Chrome, ketik password, tekan Ctrl + P (Cmd + P di Mac), atur tujuan ke Save as PDF, lalu simpan. Anda harus sudah tahu passwordnya. Chrome tidak bisa membuka file tanpa itu.

Langkah demi langkah (komputer)

  1. Seret PDF ke jendela Chrome, atau klik kanan file dan pilih Open with > Google Chrome.
  2. Chrome meminta password. Ketik lalu tekan Enter.
  3. Tekan Ctrl + P di Windows atau Linux, atau Cmd + P di Mac. Anda juga bisa lewat menu: File > Print.
  4. Di jendela cetak, atur Destination ke Save as PDF.
  5. Klik Save. Beri file baru nama yang jelas, seperti Statement-Sep-2026-unlocked.pdf.
  6. Tutup lalu buka lagi file baru. File seharusnya langsung terbuka, tanpa permintaan password.

Halaman bantuan Google menjelaskan pintasan keyboard, memilih tujuan di jendela cetak, dan opsi Save as PDF (Google: Print from Chrome).

Di ponsel Android

Chrome di Android punya opsi yang sama. Langkah dari Google: ketuk More > Share, ketuk Print, lalu ketuk Save as PDF dan pilih tempat menyimpan file (Google: Print from Chrome on Android). Apakah Chrome membuka PDF yang tersimpan di ponsel tergantung versi Chrome. Kalau tidak, lihat panduan kami tentang membuka PDF berpassword di Android.

Yang hilang dengan metode ini

Menyimpan lewat jendela cetak membuat PDF yang benar-benar baru dari apa yang tampil di layar. Itu cukup untuk membaca, mengarsipkan, atau mengunggah rekening koran. Tetapi periksa salinannya sebelum menghapus file asli:

  • Tautan dan bookmark mungkin berhenti berfungsi.
  • Kolom formulir mungkin diratakan, sehingga tidak bisa diisi lagi.
  • Tanda tangan digital tidak ikut terbawa. Jika portal memerlukan file asli bertanda tangan, unggah file aslinya.
  • Ukuran halaman mengikuti pengaturan cetak. Di More settings, pastikan ukuran kertas dan skala tidak mengecilkan atau memotong halaman.

Jika Save as PDF tidak berfungsi

  • Pencetakan diblokir. Sebagian PDF punya password izin yang menghentikan pencetakan. Password izin terpisah dari password buka. Lihat penjelasan pembatasan pencetakan dan penyalinan PDF.
  • Chrome menolak password. Periksa huruf kapital, format tanggal, dan data yang tercatat di bank Anda. Lihat mengapa password PDF tidak berfungsi.
  • File terbuka di aplikasi lain. Sebagian komputer membuka PDF di pembaca lain secara bawaan. Seret file ke tab Chrome sebagai gantinya.

Cara lain menghapus password

Microsoft Edge bekerja dengan cara yang sama di Windows (lihat menghapus password PDF di Windows). Di Mac, Preview dapat mengekspor salinan tanpa password (panduan Mac). Seperti Chrome, UnKey hanya bekerja dengan password yang sudah Anda ketahui.

Pertanyaan

Apakah Chrome mengunggah PDF saya saat saya melakukan ini?

Tidak. Membuka file PDF dari komputer dan menyimpannya dengan Save as PDF terjadi di browser pada komputer Anda. Gunakan tujuan “Save to Google Drive” yang terpisah hanya jika Anda ingin salinan di Drive.

Bisakah Chrome menghapus password yang tidak saya ketahui?

Tidak. Chrome meminta password sebelum menampilkan apa pun. Kalau Anda kehilangannya, lihat apa yang harus dilakukan jika lupa password PDF.

Mengapa salinan yang disimpan berbeda dari aslinya?

Save as PDF mencetak halaman ke file baru, jadi tautan, kolom formulir, dan tanda tangan mungkin tidak ikut. Teks dan tata letak biasanya terlihat sama.

Apakah ini diperbolehkan?

Untuk dokumen milik sendiri, seperti rekening koran Anda, ya. Jangan menghapus proteksi dari file yang tidak berhak Anda buka dengan bebas.
