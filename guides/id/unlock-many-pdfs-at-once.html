Cara Membuka Banyak PDF Sekaligus (Rekening Koran Bulanan)

Diperbarui Oktober 2026

Baca dalam: English · العربية · Español · हिन्दी · Bahasa Indonesia · Português · தமிழ்

Preview menangani satu PDF dalam satu waktu; untuk membuka banyak rekening koran dengan password sama, pakai alat massal seperti UnKey Pro atau skrip qpdf.

Kalau Anda punya setumpuk rekening koran, misalnya dua belas bulan dari bank yang sama, yang semuanya memakai password sama, Anda tidak perlu membukanya satu per satu. Alat bawaan seperti Preview bekerja satu file dalam satu waktu. Alat massal seperti UnKey Pro, atau skrip qpdf singkat di Mac, bisa mengerjakan semuanya sekaligus. Anda tetap harus tahu passwordnya.

Mengapa buka kunci massal membantu

Kebanyakan penerbit melindungi setiap rekening koran dengan format password yang sama berdasarkan data Anda. Jadi password bulan Oktober biasanya juga membuka Januari sampai September. Di situlah alat massal menghemat waktu, biasanya saat musim pajak, untuk pengajuan pinjaman, atau saat menyerahkan rekening koran setahun kepada akuntan.

Opsi gratis: Preview di Mac, satu per satu

Preview bisa membuka beberapa PDF sekaligus, tetapi menghapus password adalah pekerjaan per file. Untuk setiap PDF, masukkan password, pilih File > Export, pastikan Require Password To Open Document mati di bawah Permissions, lalu simpan (Apple: Password-protect a PDF in Preview). Untuk tiga atau empat file itu tidak masalah. Untuk tiga puluh file jadi melelahkan, dan mudah ada yang terlewat.

Di iPhone dan iPad, metode gratis (pengaturan Lock di Preview, atau trik Print-ke-PDF) juga satu file dalam satu waktu.

UnKey Pro: buka kunci massal di iPhone, iPad, dan Mac

  1. Taruh rekening koran di satu folder di Files atau Finder.
  2. Di UnKey, gunakan buka kunci massal dan pilih filenya. Di Mac Anda bisa menyeretnya ke jendela.
  3. Masukkan password, atau biarkan UnKey memakai password yang Anda simpan sebelumnya dengan Face ID atau Touch ID.
  4. UnKey menyimpan salinan tanpa password untuk setiap file. Periksa hasilnya, dan buka kunci file yang memakai password berbeda secara terpisah.

Buka kunci massal adalah bagian dari UnKey Pro, pembelian sekali bayar (₹249 di India, $5.99 di AS). Pro juga menambahkan pemindaian, tanda tangan dan pengisian formulir, penguncian, kompresi, dan redaksi, dan satu pembelian mencakup iPhone, iPad, dan Mac. Membuka kunci satu file gratis. Semuanya terjadi di perangkat Anda, dan tidak ada yang diunggah.

Opsi gratis untuk pengguna teknis: qpdf

qpdf adalah alat baris perintah sumber terbuka yang gratis. Dengan --password dan --decrypt, qpdf menulis salinan file tanpa enkripsi (dokumentasi qpdf). Di Terminal, perulangan pada satu folder terlihat seperti ini:

for f in *.pdf; do qpdf --decrypt --password="$PDFPASS" "$f" "unlocked-$f"; done

Atur PDFPASS terlebih dahulu, sebaiknya tanpa meninggalkannya di riwayat shell. File yang memakai password berbeda akan gagal dengan pesan galat dan tidak dilewati diam-diam. Anda memasang qpdf sendiri, misalnya dengan Homebrew.

Jika file tidak memakai satu password yang sama

  • Rekening berbeda: rekening tabungan dan kartu kredit dari bank yang sama sering memakai format berbeda. Pisahkan ke folder terpisah.
  • Perubahan format: penerbit kadang mengubah formatnya. Rekening koran lama mungkin memerlukan format lama.
  • Rekening bersama atau bisnis: password mungkin didasarkan pada data pemegang rekening utama atau perusahaan.

Setelah membuka kunci satu kelompok file

  • Buka dua atau tiga salinan untuk memeriksanya sebelum menghapus file asli.
  • Gunakan nama yang jelas, misalnya "2026-04-statement-unlocked.pdf".
  • Jaga folder tanpa password tetap pribadi. Rekening koran setahun adalah gambaran rinci keuangan Anda.
  • Jika mengirimnya ke akuntan, pertimbangkan mengirim file asli yang terproteksi dan membagikan passwordnya secara terpisah.

Pertanyaan

Bisakah Preview di Mac membuka beberapa PDF sekaligus?

Tidak. Anda bisa membuka banyak PDF di Preview, tetapi masing-masing harus diekspor terpisah untuk menghapus passwordnya.

Apakah buka kunci massal berfungsi jika tiap rekening koran memiliki password berbeda?

Satu kelompok bekerja dengan satu password dalam satu waktu. Kelompokkan file berdasarkan password, dan buka kunci yang berbeda secara terpisah.

Apakah buka kunci massal UnKey gratis?

Buka kunci massal adalah bagian dari UnKey Pro, pembelian sekali bayar. Membuka kunci satu file gratis.

Apakah buka kunci massal dilakukan secara online?

Dengan UnKey atau qpdf, tidak. Keduanya bekerja di perangkat Anda sendiri, dan file tidak diunggah.
