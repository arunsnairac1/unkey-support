PDF Printing and Copying Restrictions Explained

Updated October 2026

Read in: English · العربية · বাংলা · Deutsch · Español · Français · ગુજરાતી · हिन्दी · Bahasa Indonesia · ಕನ್ನಡ · മലയാളം · मराठी · Português · தமிழ் · తెలుగు

An open password stops anyone reading the PDF; an owner (permissions) password only restricts actions like printing, copying and editing.

PDFs can have two different passwords. An open password (also called a user password) is needed to view the file at all. An owner password (also called a permissions password) lets you open the file but restricts things like printing, copying text or editing. To lift the restrictions properly, you need the owner password.

The two passwords in plain terms

Open (user) passwordOwner (permissions) password
What you seeA password prompt before anything showsThe file opens, but Print or Copy is greyed out
What it protectsThe whole contents, which are encryptedActions such as printing, copying, editing and commenting
Typical useBank statements, tax documentsPublished reports, forms, contracts

Adobe describes the split the same way. A Document Open password is needed to open the PDF, and a permissions password restricts features such as printing, editing and copying (Adobe: Password security overview). qpdf's documentation adds an important detail: readers "apply security restrictions to files opened with the user password" and "allow security restrictions to be changed or overridden when files are opened with the owner password" (qpdf).

How restrictions are enforced

Restrictions depend on the PDF reader choosing to honour them. Adobe notes that its own products enforce them, but if third-party products don't support these settings, recipients may be able to bypass some or all of the restrictions (Adobe). So a permissions password is a polite "please don't" rather than a lock. It isn't a reason to ignore the author's wishes, though. If someone restricted copying, there's usually a reason, such as copyright or a contract.

Changing restrictions when you have the owner password

On Mac (Preview): open the PDF, choose File > Edit Permissions, and enter the owner password. You can then select the actions you want to allow without a password and click Apply (Apple: Password-protect a PDF in Preview on Mac). The same Permissions panel appears under File > Export if you want a fresh copy.

In Adobe Acrobat: Adobe's instructions for removing a permissions password ask you to type it into the Enter Password box (Adobe: How to remove a PDF password).

On the command line: qpdf with --password=OWNERPASSWORD --decrypt writes a copy with no encryption. Its documentation notes this option isn't meant for getting around restrictions that producers place on files (qpdf).

Your own documents with both passwords

Bank statements normally use only an open password. Once you've opened one, you can usually print and copy freely. If you created a PDF yourself in Preview or Acrobat and set both passwords, use the owner password to change permissions or to export an unrestricted copy.

To remove an open password from your own files, such as monthly statements, you can use Preview on a Mac or UnKey on iPhone, iPad or Mac. UnKey works offline and only works with passwords you already know.

When you don't have the owner password

  • Ask the author or sender for an unrestricted copy, or for permission to print or copy.
  • For a form you need to fill in, check whether filling is already allowed. Many restricted PDFs still permit form filling.
  • For a work or legal document, assume the restriction is intentional.

Questions

What is a PDF owner password?

It's a password that controls permissions such as printing, copying and editing. The file can be opened without it, but restricted actions are blocked in readers that respect the settings.

Why can I open a PDF but not print it?

The file has an owner (permissions) password that disallows printing. Enter the owner password in Preview under File > Edit Permissions, or ask the sender for an unrestricted copy.

Do bank statements have printing restrictions?

Usually not. They typically use only an open password, so once the file is open you can print it.

Is it legal to remove PDF copy restrictions?

Changing permissions on your own file, with your own owner password, is fine. Bypassing restrictions on someone else's document may break copyright or contract terms, so ask the owner.
